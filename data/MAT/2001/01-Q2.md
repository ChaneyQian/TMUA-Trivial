## 题目
**(a)**

Factorize the expression $x^{2} + 3x - 10$.

**(b)**

If $x^{3} + ax^{2} + bx + c = (x - \alpha)(x - \beta)(x - \gamma)$ for all values of $x$, find $a$, $b$, $c$ in terms of $\alpha$, $\beta$, $\gamma$.

**(c)**

Find a value of $b$ for which $x^{3} + bx + 2 = 0$ has exactly two distinct solutions.

## 解析
**(a)** Two numbers with product $-10$ and sum $3$ are $5$ and $-2$, so

$$x^2 + 3x - 10 = (x+5)(x-2).$$

**(b)** Expanding the product,

$$(x-\alpha)(x-\beta)(x-\gamma) = x^3 - (\alpha+\beta+\gamma)x^2 + (\alpha\beta + \beta\gamma + \gamma\alpha)x - \alpha\beta\gamma.$$

Comparing coefficients,

$$a = -(\alpha+\beta+\gamma), \qquad b = \alpha\beta+\beta\gamma+\gamma\alpha, \qquad c = -\alpha\beta\gamma.$$

**(c)** For $x^3 + bx + 2$ the coefficient of $x^2$ is $0$ and the constant term is $2$, so by (b) the roots satisfy

$$\alpha + \beta + \gamma = 0, \qquad \alpha\beta\gamma = -2.$$

A cubic has exactly two distinct solutions precisely when one root is repeated, so take the roots to be $\alpha, \alpha, \beta$. Then $2\alpha + \beta = 0$, so $\beta = -2\alpha$, and

$$\alpha \cdot \alpha \cdot (-2\alpha) = -2 \implies \alpha^3 = 1 \implies \alpha = 1,$$

the only real cube root of $1$. Hence the roots are $1, 1, -2$, and

$$b = \alpha\beta+\beta\gamma+\gamma\alpha = (1)(1) + (1)(-2) + (-2)(1) = -3.$$

Checking, $x^3 - 3x + 2 = (x-1)^2(x+2)$, which indeed has exactly the two distinct solutions $x=1$ and $x=-2$. So

$$b = -3.$$
