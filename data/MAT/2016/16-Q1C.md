## 题目
The origin lies inside the circle with equation

$$
x^{2} + a x + y^{2} + b y = c
$$

precisely when

(a) $c > 0 ,$
(b) $a^{2} + b^{2} > c ,$
(c) $a^{2} + b^{2} < c ,$
(d) $a^{2} + b^{2} > 4 c ,$
(e) $a^{2} + b^{2} < 4 c .$

## 备注

### 我的备注

### AI备注

## 答案
A

## 解析
We can rewrite the given equation as $\begin{array} { r } { ( x + \frac { a } { 2 } ) ^{2} + ( y + \frac { b } { 2 } ) ^{2} = c + \frac { a^{2} } { 4 } + \frac { b^{2} } { 4 } } \end{array}$ . For the circle to contain the origin, the distance from the centre to the origin must be less than the radius, so $\begin{array} { r } { \frac { a^{2} } { 4 } + \frac { b^{2} } { 4 } < c + \frac { a^{2} } { 4 } + \frac { b^{2} } { 4 } } \end{array}$ The answer is (a).
