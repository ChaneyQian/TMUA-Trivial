## 题目
How many solutions does $\cos^{n} ( x ) + \cos^{2n} ( x ) = 0$ have in the range $0 \leqslant x \leqslant 2 \pi$ for an integer $n \geqslant 1$?

(a) $1$ for all $n ,$
(b) $2$ for all $n ,$
(c) $3$ for all $n ,$
(d) $2$ for even $n$ and $3$ for odd $n ,$
(e) $3$ for even $n$ and $2$ for odd $n .$

## 解析
$\cos^{n} ( x ) + \cos^{2n} ( x ) = \cos^{n} ( x ) ( 1 + \cos^{n} ( x ) ) = 0$ . For this to be true, if n is even, $\cos ( x ) = 0$ has two roots, but when n is odd either $\cos ( x ) = 0 \ \mathrm { o r \ c o s } ( x ) = - 1$ , which is three roots. Hence the answer is (d).
