## 解析
4. (i) [3 marks] Let $d_{1}$ be the distance from $( 0 , 0 )$ to the point where $C_{1}$ touches the x-axis. Note that the x-axis is tangent to $C_{1}$ and hence perpendicular to the radius at this point. So $C_{1}$ has centre $( d_{1} , 1 )$ . We have a right-angled triangle, with $\begin{array} { r } { \frac { 1 } { d_{1} } = \tan ( \alpha ) } \end{array}$ , so $\begin{array} { r } { d_{1} = \frac { 1 } { \tan ( \alpha ) } } \end{array}$ So the centre of $C_{1}$ is $\textstyle { \big ( } { \frac { 1 } { \tan ( \alpha ) } } , 1 { \big ) }$ .

(ii) [1 mark] $C_{1}$ has centre $\textstyle { \left( { \frac { 1 } { \tan ( \alpha ) } } , 1 \right) }$ and radius 1, so has equation

$$
(x - \frac {1}{\tan (\alpha)}) ^{2} + (y - 1) ^{2} = 1.
$$

(iii) [3 marks] Let $d_{2}$ be the distance between the points where $C_{1}$ and $C_{2}$ touch the x-axis. Then Pythagoras on the right-angled triangle gives $( 1 + 3 ) ^{2} = 2 ^{2} + d_{2} ^{2}$ so $d_{2} ^{2} = 12$ Also we have similar triangles (both have a right angle and share angle $\alpha$) so

$$
\frac {3}{1} = \frac {d_{2} + d_{1}}{d_{1}}
$$

so $d_{2} = 2 d_{1}$

So $12 d_{2} ^{2} = ( 2 d_{1} ) ^{2} = 4 d_{1} ^{2}$ , so $d_{1} = { \sqrt { 3 } }$ (must have $d_{1} > 0 )$ . So tan $\begin{array} { r } { ( \alpha ) = \frac { 1 } { d_{1} } = \frac { 1 } { \sqrt { 3 } } } \end{array}$ so $\alpha = 30 ^{\circ} ~ ( \mathrm { o r } ~ \frac { \pi } { 6 } )$

(iv) [3 marks] Take $\alpha = 30 ^{\circ}$ . Let $C_{3}$ have radius r. Let $d_{3}$ be the distance between the points where $C_{2}$ and $C_{3}$ touch the x-axis. Then by similar triangles we have

$$
{\frac {r}{d_{1} + d_{2} + d_{3}}} = {\frac {1}{d_{1}}} = {\frac {1}{\sqrt {3}}}.
$$

So $\begin{array} { r } { r = \frac { d_{1} + d_{2} + d_{3} } { \sqrt { 3 } } = 3 + \frac { d_{3} } { \sqrt { 3 } } } \end{array}$ . So $d_{3} = \sqrt { 3 } ( r - 3 )$

Also since $\breve { C } _{2}$ and $C_{3}$ touch Pythagoras gives

$$
(r + 3) ^{2} = (r - 3) ^{2} + d_{3} ^{2} = (r - 3) ^{2} + 3 (r - 3) ^{2} = 4 (r - 3) ^{2},
$$

so $r^{2} + 6 r + 9 = 4 r^{2} - 24 r + 36$ , which factorises to $( r - 1 ) ( r - 9 ) = 0$

We're looking for $C_{3}$ larger than $C_{2}$ so $r = 9$

(v) [5 marks] Centres of triangle $C_{1}$ and $C_{2}$ are $\textstyle { \bigl ( } { \frac { 1 } { \tan ( \alpha ) } } , 1 { \bigr ) }$ and $\left( { \frac { 3 } { \tan ( \alpha ) } } , 3 \right)$ respectively. Area of trapezium is half (bottom plus top) times height, so:

$$
\frac {3 + 1}{2} \frac {2}{\tan (\alpha)} = \frac {4}{\tan (\alpha)}.
$$

Or break down as rectangle $\begin{array} { r } { ( \mathrm { a r e a } = \frac { 2 } { \tan ( \alpha ) } ) } \end{array}$ plus triangle $\begin{array} { r } { ( \mathrm { a r e a } = \frac { 2 } { \tan ( \alpha ) } ) } \end{array}$

Now deduct $C_{1}$ sector and $C_{2}$ sector from trapezium area. Area of $C_{1}$ sector is $\begin{array} { r } { \frac { 1 } { 2 } 1 ^{2} ( \frac { \pi } { 2 } + \alpha ) = \frac { \pi } { 4 } + \frac { \alpha } { 2 } } \end{array}$ Area of $C_{2}$ sector is $\begin{array} { r } { \frac { 1 } { 2 } 3 ^{2} ( \frac { \pi } { 2 } - \alpha ) = \frac { 9 \pi } { 4 } - \frac { 9 \alpha } { 2 } } \end{array}$

So interstitial area is:

$$
{\frac {4}{\tan (\alpha)}} - \left({\frac {\pi}{4}} + {\frac {\alpha}{2}}\right) - \left({\frac {9 \pi}{4}} - {\frac {9 \alpha}{2}}\right) = {\frac {4}{\tan (\alpha)}} - {\frac {5 \pi}{2}} + 4 \alpha = 4 \sqrt {3} - {\frac {11 \pi}{6}}
$$
