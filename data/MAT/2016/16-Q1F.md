## 题目
Let $n$ be a positive integer. Then $x^{2} + 1$ is a factor of

$$
(3 + x^{4}) ^{n} - (x^{2} + 3) ^{n} (x^{2} - 1) ^{n}
$$

for

(a) all $n ,$
(b) even $n ,$
(c) odd $n ,$
(d) $n \geqslant 3 ,$
(e) no values of $n$.

## 答案
B

## 解析
Using the factor theorem, for $( x^{2} + 1 )$ to be a factor, $( x^{2} + 1 ) = 0 , { \mathrm { s o ~ } } x^{2} = - 1$ . Then the equation given becomes $( 4 ) ^{n} - ( 2 ) ^{n} ( - 2 ) ^{n} = 0$ . This only holds when $(-2)^{n}$ is positive, so the answer is (b).
