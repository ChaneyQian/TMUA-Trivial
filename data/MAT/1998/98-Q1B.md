## 题目
The polynomial $(x^2 - 1)(x^2 + 1)$ is divisible by (that is, has as a factor)

(i) $(x+1)^2$,
(ii) $x^3 - x^2 + x - 1$,
(iii) $x^3 + x^2 - x + 1$,
(iv) $x^3 - 1$,
(v) none of these.

## 备注

### 我的备注

### AI备注


## 答案
(ii)

## 解析
We can factorise the given polynomial as $(x^2 - 1)(x^2 + 1) = (x - 1)(x + 1)(x^2 + 1)$. We can also factorise option (ii) by grouping:

$$x^3 - x^2 + x - 1 = x^2(x - 1) + 1(x - 1) = (x - 1)(x^2 + 1)$$

Since $(x - 1)(x^2 + 1)$ is clearly a factor of $(x - 1)(x + 1)(x^2 + 1)$, the polynomial in option (ii) is a factor. The answer is (ii).
