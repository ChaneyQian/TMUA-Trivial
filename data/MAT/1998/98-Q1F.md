## 题目
The function $y = x^2 e^{5x}$ satisfies the equation

(i) $\ln y = 5x \ln(x^2)$,
(ii) $\frac{dy}{dx} - 5y = e^{5x}$,
(iii) $y^2 = x^4 e^{10x^2}$,
(iv) $\ln\!\left(\frac{dy}{dx}\right) = 5x + \ln x + \ln(5x + 2)$,
(v) none of these.

## 备注

### 我的备注

### AI备注


## 答案
(iv)

## 解析
We differentiate the given function using the product rule:

$$\frac{\mathrm{d}y}{\mathrm{d}x} = 2x \mathrm{e}^{5x} + 5x^2 \mathrm{e}^{5x} = x \mathrm{e}^{5x} (2 + 5x)$$

Taking the natural logarithm of both sides gives

$$\ln\left(\frac{\mathrm{d}y}{\mathrm{d}x}\right) = \ln(x) + \ln(\mathrm{e}^{5x}) + \ln(5x + 2) = \ln x + 5x + \ln(5x + 2)$$

This matches option (iv). The answer is (iv).
