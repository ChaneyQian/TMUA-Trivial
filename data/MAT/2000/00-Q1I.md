## 题目
A grid of size $3\,\mathrm{cm} \times 5\,\mathrm{cm}$ is drawn, ruled at $1\,\mathrm{cm}$ intervals. The number of squares that can be drawn using the grid lines is
(a) $15$
(b) $18$
(c) $26$
(d) $37$.

### AI备注


## 答案
C

## 解析
We count the number of squares of each possible size $k \times k$ in the $3 \times 5$ grid.
For $1 \times 1$ squares, there are $3 \times 5 = 15$ squares.
For $2 \times 2$ squares, there are $(3 - 1) \times (5 - 1) = 2 \times 4 = 8$ squares.
For $3 \times 3$ squares, there are $(3 - 2) \times (5 - 2) = 1 \times 3 = 3$ squares.
The total number of squares is $15 + 8 + 3 = 26$. The answer is (c).
