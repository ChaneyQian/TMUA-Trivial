## 题目
Let $p$ and $q$ be real numbers. Show that the graph
$$
y = x^3 + px + q
$$
has turning points if and only if $p$ is negative.

Assume now that $p$ is negative. Find the values of $y$ at the turning points and hence show that the equation
$$
x^3 + px + q = 0
$$
has three (distinct) real roots if and only if $27q^2 < -4p^3$.

[You may find it helpful to sketch the graph, clearly indicating the turning points.]

## 解析
Differentiating,

$$\frac{\mathrm{d}y}{\mathrm{d}x} = 3x^2 + p.$$

Turning points occur where $3x^2 + p = 0$, i.e. $x^2 = -p/3$. If $p > 0$ there is no real solution; if $p = 0$ the only solution is the repeated root $x = 0$, where $\mathrm{d}y/\mathrm{d}x = 3x^2 \geqslant 0$ does not change sign, so this is a point of inflexion and not a turning point. If $p < 0$ there are two distinct roots

$$x = \pm t, \qquad t = \sqrt{-\frac{p}{3}} > 0,$$

and $\mathrm{d}y/\mathrm{d}x$ changes sign at each. So the graph has turning points **if and only if** $p$ is negative.

Assume now $p<0$, so $p = -3t^2$. The values of $y$ at the turning points are

$$y(\pm t) = \pm t^3 + p(\pm t) + q = \pm t^3 \mp 3t^3 + q = q \mp 2t^3 .$$

So the maximum value (at $x=-t$) is $q + 2t^3$ and the minimum value (at $x = t$) is $q - 2t^3$.

The graph is a cubic with positive leading coefficient: it increases from $-\infty$ to the local maximum at $x=-t$, decreases to the local minimum at $x=t$, then increases to $+\infty$. A horizontal line $y=0$ therefore cuts it in three distinct points exactly when the local maximum is strictly positive and the local minimum strictly negative — if either turning value is zero a root is repeated, and if they have the same sign there is only one crossing. So there are three distinct real roots if and only if

$$\left(q + 2t^3\right)\left(q - 2t^3\right) < 0 \iff q^2 < 4t^6.$$

Finally $t^6 = \left(t^2\right)^3 = \left(-\dfrac{p}{3}\right)^3 = -\dfrac{p^3}{27}$, so the condition becomes

$$q^2 < -\frac{4p^3}{27}, \qquad \text{that is} \qquad 27q^2 < -4p^3.$$
