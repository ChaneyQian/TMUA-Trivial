## 题目
What is the value of $\int_{0} ^{1} \left( e^{x} - x \right) ( e^{x} + x ) \ \mathrm { d } x ?$

(a) $\dfrac { 3 e^{2} - 2 } { 6 } ,$
(b) $\dfrac { 3 e^{2} + 2 } { 6 } ,$
(c) $\dfrac { 2 e^{2} - 3 } { 6 } ,$
(d) $\dfrac { 3 e^{2} - 5 } { 6 } ,$
(e) $\dfrac { e^{2} + 3 } { 6 } .$

## 备注

### 我的备注

### AI备注

## 答案
D

## 解析
Using the difference of two squares, this is $\int_{0} ^{1} e^{2x} - x^{2}$ dx. Notice that, since the derivative of $e^{2x}$ is $2 e^{2x}$ , this integral is

$$
\left[ \frac {1}{2} e^{2x} - \frac {x^{3}}{3} \right] _{0} ^{1} = \frac {e^{2}}{2} - \frac {1}{3} - \frac {1}{2} = \frac {3 e^{2} - 5}{6}
$$

The answer is (d)
