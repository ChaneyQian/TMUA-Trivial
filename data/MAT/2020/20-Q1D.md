## 题目
The largest value achieved by $3 \cos^{2} x + 2 \sin x + 1$ equals

(a) $\dfrac { 11 } { 5 } ,$
(b) $\dfrac { 13 } { 3 } ,$
(c) $\dfrac { 12 } { 5 } ,$
(d) $\dfrac { 14 } { 9 } ,$
(e) $\dfrac { 12 } { 7 } .$

## 备注

### 我的备注

### AI备注

## 答案
B

## 解析
$3 \cos^{2} x + 2 \sin x + 1 = 3 ( 1 - \sin^{2} x ) + 2 \sin x + 1 = - 3 ( \sin x - 1 / 3 ) ^{2} + 1 / 3 + 4$ . This takes its maximum value when sin $x = 1 / 3$ , and that value is $4 + 1 / 3 = 13 / 3$ The answer is (b)
