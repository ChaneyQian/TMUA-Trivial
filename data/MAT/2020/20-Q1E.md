## 题目
A line is tangent to the parabola $y = x^{2}$ at the point $( a , a^{2} )$ where $a > 0$ . The area of the region bounded by the parabola, the tangent line, and the x-axis equals

(a) $\dfrac { a^{2} } { 3 } ,$
(b) $\dfrac { 2 a^{2} } { 3 } ,$
(c) $\dfrac { a^{3} } { 12 } ,$
(d) $\dfrac { 5 a^{3} } { 6 } ,$
(e) $\dfrac { a^{4} } { 10 } .$

## 备注

### AI备注

## 答案
C

## 解析
The tangent is $y = 2 a x - a^{2}$ , which crosses the x-axis at $( a / 2 , 0 )$

![[Image/20-Q1E-sol1.jpg]]

The area is $\int_{0} ^{a} x^{2} \mathrm { d } x - ( \mathrm { a r e a ~ o f ~ A P Q } )$ where A is $( a , a^{2} )$ , P is (a, 0) and Q is $( a / 2 , 0 )$ . This is $\frac { a^{3} } { 3 } - \frac { a^{3} } { 4 } = \frac { \dot { a } ^{3} } { 12 }$

The answer is (c)
