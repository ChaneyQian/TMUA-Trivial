## 题目
In the range $- 90 ^{\circ} < x < 90 ^{\circ}$ , how many values of x are there for which the sum to infinity

$$
{\frac {1}{\tan x}} + {\frac {1}{\tan^{2} x}} + {\frac {1}{\tan^{3} x}} + \ldots
$$

equals tan x?

(a) $0$
(b) $1$
(c) $2$
(d) $3$
(e) $4.$

### 我的备注

### AI备注

## 答案
B

## 解析
The geometric sum converges if $\dot { \mathrm { : } } \ \frac { 1 } { \left| \tan x \right| } < 1$ , and converges to

$$
{\frac {1}{\tan x}} + {\frac {1}{\tan^{2} x}} + {\frac {1}{\tan^{3} x}} + \dots = {\frac {{\frac {1}{\tan x}}}{{1 - {\frac {1}{\tan x}}}}} = {\frac {1}{\tan x - 1}}.
$$

Let $u \ : = \ : \tan \ x x .$ , then this sum is equal to tan x if and only if $u^{2} - u = 1$ , so if and only if $u = { \textstyle { \frac { 1 } { 2 } } } ( 1 \pm { \sqrt { 5 } } )$ . But the condition | tan x| > 1 means that we must take $\textstyle u = { \frac { 1 } { 2 } } ( 1 + { \sqrt { 5 } } )$ . There is one value of x in the range $- 90 ^{\circ} < x < 90 ^{\circ}$ with this value of tan x. The answer is (b)
