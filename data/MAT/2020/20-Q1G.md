## 题目
A cubic has equation $y = x^{3} + a x^{2} + b x + c$ and has turning points at (1, 2) and (3, d) for some d. What is the value of d?

(a) $-4,$
(b) $-2,$
(c) $0,$
(d) $2,$
(e) $4.$

## 答案
B

## 解析
The turning points have $\begin{array} { r } { { \frac { \mathrm { d } y } { \mathrm { d } x } } = 0 } \end{array}$ at $x = 1$ and at $x = 3 .$ , so $3 + 2 a + b = 0$ and $27 + 6 a + b = 0 .$ Solve these for $a = - 6 , b = 9$ . Now $y = 2$ at x = 1 so $c = - 2 .$ Then $y = - 2$ at $x = 3$ gives $d = - 2$

The answer is (b)
