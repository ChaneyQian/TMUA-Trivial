## 题目
How many values of $x$ satisfy the equation
$$
\sin 2x + \sin^{2} x = 1
$$
in the range $0 \leqslant x < 2\pi$?
(a) $2$
(b) $4$
(c) $6$
(d) $8$

## 备注

### 我的备注

### AI备注


## 答案
B

## 解析
We can rewrite the equation $\sin 2x + \sin^{2} x = 1$ using the identity $1 - \sin^{2} x = \cos^{2} x$:

$$\sin 2x = \cos^{2} x$$

Using the double angle identity $\sin 2x = 2\sin x \cos x$, we get:

$$2\sin x \cos x = \cos^{2} x \implies \cos x(2\sin x - \cos x) = 0$$

This gives two cases:
1. $\cos x = 0$: In the range $0 \leqslant x < 2\pi$, this gives two solutions: $x = \frac{\pi}{2}$ and $x = \frac{3\pi}{2}$.
2. $2\sin x - \cos x = 0 \implies \tan x = \frac{1}{2}$: In the range $0 \leqslant x < 2\pi$, the tangent function completes two full periods and takes the positive value $\frac{1}{2}$ exactly twice (once in the first quadrant and once in the third quadrant). This gives two more solutions.

Thus, there are $2 + 2 = 4$ solutions in total. The answer is (b).
