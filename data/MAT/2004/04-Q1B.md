## 题目
The smallest value of the function
$$
f(x) = 2x^{3} - 9x^{2} + 12x + 3
$$
in the range $0 \leqslant x \leqslant 2$ is
(a) $1$
(b) $3$
(c) $5$
(d) $7$

### 我的备注

### AI备注


## 答案
B

## 解析
To find the smallest value of $f(x) = 2x^{3} - 9x^{2} + 12x + 3$ on the interval $[0, 2]$, we first find its critical points by taking the derivative:

$$f'(x) = 6x^{2} - 18x + 12 = 6(x^{2} - 3x + 2) = 6(x - 1)(x - 2)$$

Setting $f'(x) = 0$, we find the critical points in the interval are $x = 1$ and $x = 2$. We evaluate $f(x)$ at the critical points and the endpoints:
- $f(0) = 3$
- $f(1) = 2(1) - 9(1) + 12(1) + 3 = 8$
- $f(2) = 2(8) - 9(4) + 12(2) + 3 = 16 - 36 + 24 + 3 = 7$

Comparing these values, the smallest value is $3$. The answer is (b).
