## 解析
Throughout, note that only the *parity* of the number of times each line is flipped matters, since flipping the same row or column twice restores it. So a whole sequence of moves is described by saying, for each row $i$ and each column $j$, whether it has been flipped an odd number of times; and the counter in position $(i,j)$ ends up changed exactly when row $i$ and column $j$ have been flipped an odd number of times *in total*.

**(a)** The starting pattern is

$$\begin{array}{cc} B & W \\ W & B \end{array}$$

There are $2 \times 2 = 4$ lines, each either flipped or not, giving $2^4 = 16$ combinations; but flipping *every* row and *every* column changes each counter twice and so has no effect, and this pairs the $16$ combinations off into $8$ pairs with identical results. The eight obtainable patterns are

$$\begin{array}{cc} B & W \\ W & B \end{array} \quad \begin{array}{cc} W & W \\ B & B \end{array} \quad \begin{array}{cc} B & B \\ W & W \end{array} \quad \begin{array}{cc} W & B \\ B & W \end{array} \quad \begin{array}{cc} W & B \\ W & B \end{array} \quad \begin{array}{cc} B & W \\ B & W \end{array} \quad \begin{array}{cc} B & B \\ B & B \end{array} \quad \begin{array}{cc} W & W \\ W & W \end{array}$$

(the last two come from flipping the first row together with the first column, and the first row together with the second column). Counting whites, the possible numbers of white counters are

$$0, \qquad 2 \qquad \text{and} \qquad 4.$$

**(b)** Each move flips a whole line of $4$ counters. If that line contains $w$ whites beforehand, it contains $4-w$ afterwards, so the total number of whites changes by $4 - 2w$, which is **even**. Hence the parity of the number of white counters on the board never changes.

The four-by-four starting pattern is a chequerboard, with $8$ whites — an even number. A pattern with only one white counter has an odd number of whites, so it can never be reached.

**(c)** On the five-by-five board each move flips a line of $5$ counters. If that line contains $w$ whites beforehand, the number of whites changes by $5-2w$, which is **odd**. So every move changes the parity of the number of white counters.

The given starting pattern is the chequerboard with black in the corners, so it has $13$ blacks and $12$ whites — an even number of whites. The all-white pattern has $25$ whites, an odd number. The parity must therefore be changed an odd number of times, so any such sequence of moves consists of an odd number of moves.

For the least number, suppose row $i$ is flipped $R_i$ times and column $j$ is flipped $C_j$ times. The counter at $(i,j)$ starts black exactly when $i+j$ is even, and it must finish white, so we need

$$R_i + C_j \text{ odd} \iff i+j \text{ even}.$$

Taking $i=j=1$ and then varying $j$ shows that the parities of $C_1, C_2, \ldots, C_5$ alternate, and likewise for the $R_i$; so there are just two possibilities:

* $R_1, R_3, R_5$ odd and $C_2, C_4$ odd (all others even), or
* $R_2, R_4$ odd and $C_1, C_3, C_5$ odd (all others even).

Either way exactly five of the ten counts are odd, hence at least $1$ each, so

$$\text{total number of moves} = \sum_i R_i + \sum_j C_j \geqslant 5.$$

And $5$ is achieved: flip rows $1$, $3$, $5$ and columns $2$, $4$, one flip each. Then a counter at $(i,j)$ is flipped once if $i$ is odd and $j$ is odd, or if $i$ is even and $j$ is even — that is, exactly when $i+j$ is even, which is exactly where the black counters are. Every counter ends up white.

So the least number of moves is $5$, which is odd, as it must be.
