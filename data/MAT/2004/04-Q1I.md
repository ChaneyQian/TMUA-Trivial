## 题目
Given numbers $a$, $b$, $c$, which of the following statements about the simultaneous equations
$$
\begin{aligned}
2x + y &= 5, \\
ax + by &= c,
\end{aligned}
$$
is true?
(a) There are no solutions when $a = 2b$ and $c = 5b$;
(b) There is a unique solution when $a \neq 2b$ and $c = 5b$;
(c) There are an infinite number of solutions when $a = 2$, $b = 1$, and $c = 0$;
(d) There are no solutions when $a \neq 2b$ and $c = 5b$.

## 答案
B

## 解析
We write the simultaneous equations in matrix form:

$$
\begin{pmatrix} 2 & 1 \\ a & b \end{pmatrix} \begin{pmatrix} x \\ y \end{pmatrix} = \begin{pmatrix} 5 \\ c \end{pmatrix}
$$

The determinant of the coefficient matrix is $2b - a$.
Let's check the options:
(a) If $a = 2b$ and $c = 5b$, the second equation becomes $2bx + by = 5b$, which simplifies to $2x + y = 5$ (assuming $b \neq 0$). This is identical to the first equation, so there are infinitely many solutions, not "no solutions".
(b) If $a \neq 2b$, the determinant $2b - a \neq 0$. Thus, the matrix is invertible, and there is a unique solution for any value of $c$, including $c = 5b$.
(c) If $a = 2, b = 1, c = 0$, the equations are $2x + y = 5$ and $2x + y = 0$, which are parallel lines and have no solutions (not infinite).
(d) If $a \neq 2b$, there is a unique solution, not "no solutions".

Thus, only statement (b) is true. The answer is (b).
