## 题目
You are given two whole numbers $p$ and $q$, and told that three of the following statements concerning $p$ and $q$ are true and that the other statement is false. Which is the false statement?
(a) $pq$ is even;
(b) $p + q$ is even;
(c) $2p + q^{2}$ is odd;
(d) $p^{2} + 2q$ is odd.

## 答案
A

## 解析
Let's evaluate the truth conditions for statements (c) and (d) first:
- $2p + q^{2}$ is odd: Since $2p$ is always even, this expression is odd if and only if $q^{2}$ is odd, which happens if and only if $q$ is odd.
- $p^{2} + 2q$ is odd: Since $2q$ is always even, this expression is odd if and only if $p^{2}$ is odd, which happens if and only if $p$ is odd.

If we assume both $p$ and $q$ are odd, let's see which statements hold:
(a) $pq$ is odd $\times$ odd = odd (False)
(b) $p + q$ is odd $+$ odd = even (True)
(c) $2p + q^{2}$ is even $+$ odd = odd (True)
(d) $p^{2} + 2q$ is odd $+$ even = odd (True)

Under the assumption that $p$ and $q$ are both odd, exactly three statements are true ((b), (c), (d)) and exactly one is false ((a)). 
If we check other parities (both even, or one odd and one even), we do not get exactly three true statements. Thus, the unique false statement is (a). The answer is (a).
