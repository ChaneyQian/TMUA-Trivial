## 题目
What is the reflection of the point $(3, 4)$ in the line $3x + 4y = 50$?
(a) $(9, 12)$
(b) $(6, 8)$
(c) $(12, 16)$
(d) $(16, 12)$

### AI备注


## 答案
A

## 解析
Let the given point be $P(3, 4)$ and the line be $L: 3x + 4y = 50$. The normal vector to $L$ is $\mathbf{n} = (3, 4)$. 
We want to find the reflection $P'$ such that the midpoint of $PP'$ lies on $L$ and the segment $PP'$ is perpendicular to $L$. 
First, we find the value of $3x + 4y$ at point $P$:
$3(3) + 4(4) = 9 + 16 = 25$.
Since we need to reach $50$ on the line, we are "missing" $25$. The distance vector from $P$ to the line is in the direction of the normal. We move by some multiple $t$ of the normal:
$3(3 + 3t) + 4(4 + 4t) = 50 \implies 25 + 25t = 50 \implies t = 1$.
So the closest point on the line is $(3 + 3(1), 4 + 4(1)) = (6, 8)$.
To find the reflection, we continue the same distance past the line, which means $t = 2$.
The reflection point is $P' = (3 + 3(2), 4 + 4(2)) = (9, 12)$. The answer is (a).
