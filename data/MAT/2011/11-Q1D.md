## 题目
The fraction of the interval $0 \leqslant x \leqslant 2 \pi$ , for which one (or both) of the inequalities

$$
\sin x \geqslant \frac {1}{2},\quad \sin 2x \geqslant \frac {1}{2}
$$

is true, equals

(a) $\dfrac { 1 } { 3 } ,$
(b) $\dfrac { 13 } { 24 } ,$
(c) $\dfrac { 7 } { 12 } ,$
(d) $\dfrac { 5 } { 8 } .$

## 备注

### 我的备注

### AI备注

## 答案
B

## 解析
In the range $0 \leqslant x \leqslant 2\pi$ we have

$\sin x \geqslant \frac 12$ when ${ \frac { \pi } { 6 } } \leqslant x \leqslant { \frac { 5 \pi } { 6 } } ;$ $\sin 2x \geqslant \frac 12$ when ${ \frac { \pi } { 12 } } \leqslant x \leqslant { \frac { 5 \pi } { 12 } }$ and when ${ \frac { 13 \pi } { 12 } } \leqslant x \leqslant { \frac { 17 \pi } { 12 } } .$

One or both of these inequalities hold for $x$ in the ranges

$$
\frac {\pi}{12} \leqslant x \leqslant \frac {5 \pi}{6} \text {and} \frac {13 \pi}{12} \leqslant x \leqslant \frac {17 \pi}{12}
$$

which are intervals of total length $13\pi/12$. The relevant fraction is $( 13 \pi / 12 ) / ( 2 \pi ) = 13 / 24$ . The answer is (b).
