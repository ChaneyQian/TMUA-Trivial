## 题目
Given $\theta$ in the range $0 \leqslant \theta < \pi$ , the equation

$$
x^{2} + y^{2} + 4 x \cos \theta + 8 y \sin \theta + 10 = 0
$$

represents a circle for

(a) $0 < \theta < \dfrac { \pi } { 3 } ,$
(b) $\dfrac { \pi } { 4 } < \theta < \dfrac { 3 \pi } { 4 } ,$
(c) $0 < \theta < \dfrac { \pi } { 2 } ,$
(d) all values of $\theta$.

## 备注

### 我的备注

### AI备注

## 答案
B

## 解析
Note that

$$
x^{2} + y^{2} + 4 x \cos \theta + 8 y \sin \theta + 10 = 0
$$

rearranges to

$$
(x + 2 \cos \theta) ^{2} + (y + 4 \sin \theta) ^{2} = 4 \cos^{2} \theta + 16 \sin^{2} \theta - 10 = 12 \sin^{2} \theta - 6
$$

and so the equation defines a circle of radius $\sqrt { 12 \sin^{2} \theta - 6 }$ provided $\sin^{2} \theta > \frac { 1 } { 2 }$ . In the given range, $0 \leqslant \theta < \pi$ , we have $\sin \theta \geqslant 0$ and so we need $\scriptstyle { \frac { 1 } { \sqrt { 2 } } } < \sin \theta$. The answer is (b).
