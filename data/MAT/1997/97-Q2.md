## 题目
**(a)**

Show that $x^2 + 4x + 4 \geq 0$ for all values of $x$.

**(b)**

For which values of the constant $a$ is there at least one solution, $x$, of the inequality
$$
ax^2 + 4x + 3 \leq x^2 - 1?
$$

**(c)**

Suppose that $1 < a \leq 2$. Find all values of $x$ for which the inequality in (b) holds.

## 解析
**(a)** Completing the square,

$$x^2 + 4x + 4 = (x+2)^2,$$

and a square of a real number is never negative, so $x^2+4x+4 \geqslant 0$ for all $x$.

**(b)** Rearranging the inequality,

$$ax^2 + 4x + 3 \leqslant x^2 - 1 \iff (a-1)x^2 + 4x + 4 \leqslant 0.$$

Write $g(x) = (a-1)x^2 + 4x + 4$ and consider the sign of the leading coefficient.

* If $a < 1$ then $g$ is a downward parabola, so $g(x) \to -\infty$ as $x \to \infty$ and solutions certainly exist.
* If $a = 1$ then $g(x) = 4x+4 \leqslant 0$ for all $x \leqslant -1$, so solutions exist.
* If $a > 1$ then $g$ is an upward parabola, so it takes a value $\leqslant 0$ exactly when it has real roots, i.e. when

$$16 - 16(a-1) \geqslant 0 \iff a \leqslant 2.$$

Combining the three cases, there is at least one solution precisely when

$$a \leqslant 2.$$

Note the borderline case $a = 2$ is part (a): there $g(x) = x^2+4x+4 = (x+2)^2 \geqslant 0$, with equality only at the single point $x = -2$.

**(c)** For $1 < a \leqslant 2$ the coefficient $a - 1$ is positive, so $g$ is an upward parabola and $g(x) \leqslant 0$ exactly on the closed interval between its roots. Solving $(a-1)x^2+4x+4 = 0$,

$$x = \frac{-4 \pm \sqrt{16 - 16(a-1)}}{2(a-1)} = \frac{-2 \pm 2\sqrt{2-a}}{a-1}.$$

Since $a - 1 = 1 - (2-a) = \left(1-\sqrt{2-a}\right)\left(1+\sqrt{2-a}\right)$, these roots simplify to

$$\frac{-2}{1+\sqrt{2-a}} \qquad \text{and} \qquad \frac{-2}{1-\sqrt{2-a}}.$$

The second is the smaller (its denominator is the smaller positive number), so the inequality holds exactly for

$$\frac{-2}{1-\sqrt{2-a}} \leqslant x \leqslant \frac{-2}{1+\sqrt{2-a}}.$$

When $a = 2$ both ends equal $-2$ and the only solution is $x = -2$, agreeing with (a).
