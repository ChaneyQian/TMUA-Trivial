## 题目
There is a solution to the equation $x^3 + x^2 + 3 = 0$ between
(i) $-2$ and $-1$,
(ii) $-1$ and $0$,
(iii) $0$ and $1$,
(iv) $1$ and $2$.

## 备注

### 我的备注

### AI备注


## 答案
(i)

## 解析
Let $f(x) = x^3 + x^2 + 3$. We can test the function values at the endpoints of the given intervals:

$$f(-2) = (-2)^3 + (-2)^2 + 3 = -8 + 4 + 3 = -1$$
$$f(-1) = (-1)^3 + (-1)^2 + 3 = -1 + 1 + 3 = 3$$

Since $f(-2) < 0$ and $f(-1) > 0$, the continuous function $f(x)$ must cross the $x$-axis between $-2$ and $-1$ by the Intermediate Value Theorem. Therefore, there is a root in this interval. The answer is (i).
