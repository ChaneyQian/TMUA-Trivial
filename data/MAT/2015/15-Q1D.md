## 题目
Let

$$
f (x) = \int_{0} ^{1} (x t) ^{2} \mathrm{d} t, \quad \text { and } \quad g (x) = \int_{0} ^{x} t^{2} \mathrm{d} t.
$$

Let $A > 0$ . Which of the following statements is true?

(a) $g ( f ( A ) )$ is always bigger than $f ( g ( A ) )$

(b) $f ( g ( A ) )$ is always bigger than $g ( f ( A ) )$ .

(c) They are always equal.

(d) $f ( g ( A ) )$ is bigger if $A < 1$ , and $g ( f ( A ) )$ is bigger if $A > 1$

(e) $g ( f ( A ) )$ is bigger if $A < 1$ and $f ( g ( A ) )$ is bigger if $A > 1$

## 备注

### 我的备注

### AI备注

## 答案
B

## 解析
Evaluating the integrals $\begin{array} { r } { f ( x ) = \frac { x^{2} } { 3 } } \end{array}$ and $\begin{array} { r } { g ( x ) = \frac { x^{3} } { 3 } } \end{array}$ . Hence $\begin{array} { r } { g ( f ( A ) ) = \frac { A^{6} } { 3 ^{4} } } \end{array}$ and $\begin{array} { r } { f ( g ( A ) ) = \frac { A^{6} } { 3 ^{3} } } \end{array}$ . Hence the answer is (b).
