## 题目
In the interval $0 \leqslant x \leqslant 2 \pi$ , the equation

$$
\sin (2 \cos (2 x) + 2) = 0
$$

has exactly

(a) $2$ solutions,
(b) $3$ solutions,
(c) $4$ solutions,
(d) $6$ solutions,
(e) $8$ solutions.

## 备注

### 我的备注

### AI备注

## 答案
D

## 解析
$\sin ( x ) = 0$ when $x = 0 , \pi$ , or $2\pi$ in the interval $0 \leqslant x \leqslant 2 \pi$ . Hence $2 \cos ( 2 x ) + 2 = 0 , \pi ,$ or $2 \pi$. Rearranging gives $\begin{array} { r } { \cos ( 2 x ) = - 1 , \frac { \pi - 2 } { 2 } } \end{array}$ , or $\pi - 1$. $\cos ( 2 x )$ achieves the first of these values twice for two different values of $x ,$ achieves the second of these values four times, and never achieves the value of $\pi - 1$ and so the answer is (d).
