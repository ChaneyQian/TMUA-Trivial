## 题目
Just one of the following expressions is equal to $\sin 5\alpha$ for all values of $\alpha$. Which one is it?
(a) $5\sin\alpha - 20\sin^{3}\alpha + 16\sin^{5}\alpha$
(b) $5\sin\alpha - 20\sin^{3}\alpha + 14\sin^{5}\alpha$
(c) $5\sin\alpha - 10\sin^{2}\alpha + 10\sin^{3}\alpha - 5\sin^{4}\alpha + \sin^{5}\alpha$
(d) $\sin\alpha - 5\sin^{2}\alpha + 10\sin^{3}\alpha - 10\sin^{4}\alpha + 5\sin^{5}\alpha$.

## 答案
A

## 解析
Using De Moivre's Theorem, $\cos 5\alpha + i\sin 5\alpha = (\cos \alpha + i\sin \alpha)^5$. We expand the right-hand side using the Binomial Theorem and extract the imaginary part to find $\sin 5\alpha$:

$$\sin 5\alpha = \binom{5}{1}\cos^{4}\alpha \sin\alpha - \binom{5}{3}\cos^{2}\alpha \sin^{3}\alpha + \binom{5}{5}\sin^{5}\alpha$$

Substituting $\cos^{2}\alpha = 1 - \sin^{2}\alpha$, we have:

$$= 5(1 - \sin^{2}\alpha)^{2} \sin\alpha - 10(1 - \sin^{2}\alpha) \sin^{3}\alpha + \sin^{5}\alpha$$
$$= 5(1 - 2\sin^{2}\alpha + \sin^{4}\alpha) \sin\alpha - 10(\sin^{3}\alpha - \sin^{5}\alpha) + \sin^{5}\alpha$$
$$= 5\sin\alpha - 10\sin^{3}\alpha + 5\sin^{5}\alpha - 10\sin^{3}\alpha + 10\sin^{5}\alpha + \sin^{5}\alpha$$
$$= 5\sin\alpha - 20\sin^{3}\alpha + 16\sin^{5}\alpha$$

The answer is (a).
