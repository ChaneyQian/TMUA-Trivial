## 题目
Which of the following integrals has the greatest value?

(a) $\displaystyle\int_{0}^{\pi/2}\sin^{2}x\cos x\,\mathrm{d}x$

(b) $\displaystyle\int_{0}^{\pi}\sin^{2}x\cos x\,\mathrm{d}x$

(c) $\displaystyle\int_{0}^{\pi/2}\sin x\cos^{2}x\,\mathrm{d}x$

(d) $\displaystyle\int_{0}^{\pi/2}\sin 2x\cos x\,\mathrm{d}x$.

### AI备注


## 答案
D

## 解析
We evaluate the definite integrals in each option:
(a) $\int_{0}^{\pi/2} \sin^{2}x \cos x \,\mathrm{d}x = \left[ \frac{1}{3}\sin^{3}x \right]_{0}^{\pi/2} = \frac{1}{3}$
(b) $\int_{0}^{\pi} \sin^{2}x \cos x \,\mathrm{d}x = \left[ \frac{1}{3}\sin^{3}x \right]_{0}^{\pi} = 0$
(c) $\int_{0}^{\pi/2} \sin x \cos^{2}x \,\mathrm{d}x = \left[ -\frac{1}{3}\cos^{3}x \right]_{0}^{\pi/2} = \frac{1}{3}$
(d) $\int_{0}^{\pi/2} \sin 2x \cos x \,\mathrm{d}x = \int_{0}^{\pi/2} 2\sin x \cos^{2}x \,\mathrm{d}x = 2 \left( \frac{1}{3} \right) = \frac{2}{3}$

Comparing the values, the integral in (d) has the greatest value of $\frac{2}{3}$. The answer is (d).
