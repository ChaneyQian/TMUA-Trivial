## 题目
The fixed positive integers $a, b, c, d$ are such that exactly two of the following four statements are valid:

(i) $a \leqslant b < c \leqslant d$

(ii) $a + b = c + d$

(iii) $a = c$ and $b = d$

(iv) $ad = bc$.

You are also told that (ii) and (iv) is not the pair of valid statements. Which of the following must be the pair of valid statements?
(a) (i) and (ii)
(b) (i) and (iii)
(c) (i) and (iv)
(d) (iii) and (iv).

## 答案
C

## 解析
If (i) is true, then $a \leqslant b < c \leqslant d$, which strictly implies $a + b < c + d$. Thus, (i) and (ii) cannot be simultaneously valid. 
If (iii) is true, then $a = c$ and $b = d$. This directly implies $a + b = c + d$ (so (ii) is true) and $ad = cb$ (so (iv) is true). That would mean at least three statements are true, violating the condition that exactly two are valid. Thus, (iii) must be false. 
Since (ii) and (iv) is not the pair by the problem description, and any pair involving (iii) or both (i) and (ii) is impossible, the only remaining possible pair of valid statements is (i) and (iv). We can verify this is possible: e.g., $a=1, b=2, c=3, d=6$ satisfies $1 \leqslant 2 < 3 \leqslant 6$ and $1 \times 6 = 2 \times 3$, while violating (ii) and (iii). The answer is (c).
