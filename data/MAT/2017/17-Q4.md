## 题目
For **APPLICANTS IN** $\left\{\begin{array}{l}\textbf{MATHEMATICS} \\ \textbf{MATHEMATICS \& STATISTICS} \\ \textbf{MATHEMATICS \& PHILOSOPHY}\end{array}\right\}$ **ONLY**.

A horse is attached by a rope to the corner of a square field of side length 1.

(i) What length of rope allows the horse to reach precisely half the area of the field?

Another horse is placed in the field, attached to the corner diagonally opposite from the first horse. Each horse has a length of rope such that each can reach half the field.

(ii) Explain why the area that both can reach is the same as the area neither can reach.

![[Image/17-Q4-fig1.jpg]]

(iii) The angle $\alpha$ is marked in the diagram above. Show that $\alpha = \cos^{-1} \left( { \frac { \sqrt { \pi } } { 2 } } \right)$ and hence show that the area neither can reach is $\textstyle { \frac { 4 } { \pi } } \cos^{-1} \left( { \frac { \sqrt { \pi } } { 2 } } \right) - { \sqrt { \frac { 4 - \pi } { \pi } } }$ . Note that $\cos^{-1}$ can also be written as arccos.

A third horse is placed in the field, and the three horses are rearranged. One horse is now attached to the midpoint of the bottom side of the field, and another horse is now attached to the midpoint of the left side of the field. The third horse is attached to the upper right corner.

(iv) Given each horse can access an equal area of the field and that none of the areas overlap, what length of rope must each horse have to minimise the area that no horse can reach?

The horses on the bottom and left midpoints of the field are each replaced by a goat; each goat is attached by a rope of length g to the same midpoint as in part (iii). The remaining horse is attached to the upper right corner with rope length h.

(v) Given that $0 \leqslant h \leqslant 1$ , and that none of the animals' areas can overlap, show that $\begin{array} { r } { \frac { \sqrt { 5 } - 2 } { 2 } \leqslant g \leqslant \frac { 1 } { 2 \sqrt { 2 } } } \end{array}$ holds if the area that the animals can reach is maximised.

## 解析
4.(i) [2 marks] We require that the area of the sector is $\begin{array} { r } { \frac { r^{2} \theta } { 2 } = \frac { 1 } { 2 } . \ \theta = \frac { \pi } { 2 } } \end{array}$ as a quarter circle is formed. Hence the length of rope required is $\textstyle { \sqrt { \frac { 2 } { \pi } } }$

(ii) [2 marks] Both horses can reach half the area of the field, so without overlap these would sum to 1. This is the same area as the total field, hence the overlapping area between the two quarter circles must equal the areas outside the quarter circles.

(iii) [5 marks]

![[Image/17-Q4-sol1.jpg]]

To calculate $\alpha$: Distance from bottom left corner of square to centre is $\textstyle { \frac { \sqrt { 2 } } { 2 } }$ . Hypotenuse (distance from bottom left corner to point where both quarter circles intersect) is the radius calculated in part (i), so ${ \begin{array} { r } { { \sqrt { \frac { 2 } { \pi } } } . \ \operatorname { S o } \cos ( \alpha ) = { \frac { \frac { \sqrt { 2 } } { 2 } } { \sqrt { \frac { 2 } { \pi } } } } = { \frac { \sqrt { \pi } } { 2 } } } \end{array} }$ . Hence $\begin{array} { r } { \alpha = \cos^{-1} \left( \frac { \sqrt { \pi } } { 2 } \right) } \end{array}$

To calculate overlapping area: Length of line from centre of field to intersection of quarter circles $\begin{array} { r } { = \sqrt { \left( { \sqrt { \frac { 2 } { \pi } } } \right) ^{2} - \left( { \frac { \sqrt { 2 } } { 2 } } \right) ^{2} } = { \sqrt { \frac { 4 - \pi } { 2 \pi } } } } \end{array}$

Area of tria ${ \mathrm { n g l e } } = { \textstyle \frac { { \frac { \sqrt { 2 } } { 2 } } { \sqrt { \frac { 4 - \pi } { 2 \pi } } } } { 2 } } = { \sqrt { \frac { 4 - \pi } { 16 \pi } } }$

Area of sector $\begin{array} { r } { = { \frac { { \frac { 2 } { \pi } } \cos^{-1} \left( { \frac { \sqrt { \pi } } { 2 } } \right) } { 2 } } = { \frac { 1 } { \pi } } \cos^{-1} \left( { \frac { \sqrt { \pi } } { 2 } } \right) } \end{array}$

So total area $\begin{array} { r } { = { \frac { 4 } { \pi } } \cos^{-1} \left( { \frac { \sqrt { \pi } } { 2 } } \right) - { \sqrt { \frac { 4 - \pi } { \pi } } } } \end{array}$ as required.

(iv) [4 marks]

![[Image/17-Q4-sol2.jpg]]

We require all the areas to be equal. Two distinct shapes will be formed - two half circles and one quarter circle. Hence we require $\textstyle { \bar { \frac { \pi r^{2} } { 2 } } } = { \frac { \pi s^{2} } { 4 } }$ , where r is the radius of the half circles and s is the radius of the semi-circles. Hence we know the relationship between r and s is $2 r^{2} = s^{2}$

To calculate r note that both half circles can expand to touch on the $y = x$ diagonal. As the horses are attached at the midpoint of the fence, the diagonal distance between midpoints must be $\textstyle { \frac { 1 } { \sqrt { 2 } } }$ Hence $\begin{array} { r } { r = \frac { 1 } { 2 \sqrt { 2 } } } \end{array}$

Using the relationship above we know that $\begin{array} { r } { s = \frac { 1 } { 2 } } \end{array}$

(v) [2 marks] From previous part note that $\begin{array} { r } { 0 \leqslant g \leqslant \frac { 1 } { 2 \sqrt { 2 } } } \end{array}$ . We can relate g to h as $( g + h ) ^{2} = 0 . 5 ^{2} + 1 ^{2}$ by Pythagoras, so $g = { \sqrt { \frac { 5 } { 4 } } } - h$ . As we know the maximum h can be is 1, the actual range for g is $\begin{array} { r } { \frac { \sqrt { 5 } - 2 } { 2 } \leqslant g \leqslant \frac { 1 } { 2 \sqrt { 2 } } } \end{array}$
