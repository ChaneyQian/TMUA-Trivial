## 题目
Let

$$
f (x) = 2 x^{3} - k x^{2} + 2 x - k.
$$

For what values of the real number k does the graph $y = f ( x )$ have two distinct real stationary points?

(a) $- 2 \sqrt { 3 } < k < 2 \sqrt { 3 }$

(b) $k < - 2 \sqrt { 3 } \ \mathrm { o r } \ 2 \sqrt { 3 } < k$

(c) $k < - { \sqrt { 21 } } - 3 { \mathrm { ~ o r ~ } } { \sqrt { 21 } } - 3 < k$

(d) $- { \sqrt { 21 } } - 3 < k < { \sqrt { 21 } } - 3$

(e) all values of k.

## 备注

### 我的备注

### AI备注

## 答案
B

## 解析
In order to have two distinct real stationary points we require $4 k^{2} - 48$ to be positive. Rearranging gives $k > \sqrt { 12 }$ or $k < - { \sqrt { 12 } }$ so the answer is (b).
