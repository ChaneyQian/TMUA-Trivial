## 题目
Which of these integrals has the largest value? You are not expected to calculate the exact value of any of these.

(a) $\int_{0} ^{2} ( x^{2} - 4 ) \sin^{8} ( \pi x ) \mathrm { d } x$
(b) $\int_{0} ^{2\pi} ( 2 + \cos x ) ^{3} \mathrm { d } x$
(c) $\int_{0} ^{\pi} \sin^{100} x \mathrm { d } x$
(d) $\int_{0} ^{\pi} ( 3 - \sin x ) ^{6} \mathrm { { d } } x$
(e) $\int_{0} ^{8\pi} 108 ( \sin^{3} x - 1 ) \mathrm { d } x .$

## 备注

### AI备注

## 答案
D

## 解析
Considering each of the integrals in turn:

(a) note that $( x^{2} - 4 ) \sin^{8} ( \pi x ) \leqslant 0$ when $0 \leqslant x \leqslant 2$ so this integral will evaluate as negative;

(b) $( 2 + \cos x )$ will always evaluate positive as it translates the $y = \cos x $ graph positively along the y-axis, so the integral will be positive and will be less than $54\pi$ for $0 \leqslant x \leqslant 2 \pi ;$

(c) the maximum value of $\sin^{100} ( x )$ is 1, and so the value of the integral for $0 \leqslant x \leqslant \pi$ must be $\leqslant \pi$

(d) for $0 \leqslant x \leqslant \pi$ the smallest $( 3 - \sin x ) ^{6}$ can be is $64\pi$ ;

(e) $( \sin^{3} ( x ) - 1 )$ will always be $\leqslant 0$ , and so this integral will evaluate as negative.

The answer is (d).
