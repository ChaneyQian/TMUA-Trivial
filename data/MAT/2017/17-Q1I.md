## 题目
Let $a , b , c > 0$ and $a \neq 1$ . The equation

$$
\log_{b} \left(\left(b^{x}\right) ^{x}\right) + \log_{a} \left(\frac {c^{x}}{b^{x}}\right) + \log_{a} \left(\frac {1}{b}\right) \log_{a} (c) = 0
$$

has a repeated root when

(a) $b^{2} = 4 a c$
(b) $b = { \dfrac { 1 } { a } }$
(c) $c = { \dfrac { b } { a } }$
(d) $c = \dfrac { 1 } { b }$
(e) $a = b = c .$

## 备注

### 我的备注

### AI备注

## 答案
D

## 解析
By algebraic manipulation we have

$$
\log_{b} \left(\left(b^{x}\right) ^{x}\right) + \log_{a} \left(\frac {c^{x}}{b^{x}}\right) + \log_{a} \left(\frac {1}{b}\right) \log_{a} (c) = 0
$$

$$
\begin{array}{r c l} x^{2} + x (\log_{a} (c) - \log_{a} (b)) - \log_{a} (b) \log_{a} (c) & = & 0 \\ (x + \log_{a} (c)) (x - \log_{a} (b)) & = & 0. \end{array}
$$

The question asks when the equation has a repeated root, which is satisfied when

$$
- \log_{a} (c) = \log_{a} (b)
$$

$$
\log_{a} \left(\frac {1}{c}\right) = \log_{a} (b)
$$

and so the answer is (d).
