## 题目
Let a and b be positive integers such that $a + b = 20$ . What is the maximum value that $a^{2} b$ can take?

(a) $1000$
(b) $1152$
(c) $1176$
(d) $1183$
(e) $1196.$

## 答案
D

## 解析
Rearranging so that $b = 20 - a$ gives $a^{2} ( 20 - a )$ . Differentiating and setting equal to 0 to find the maximum gives $\begin{array} { r } { a = \frac { 40 } { 3 } } \end{array}$ . The closest integer to this is 13 and so $b = 7$ . The answer is (d).
