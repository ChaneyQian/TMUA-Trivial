## 题目
The picture below shows the unit circle, where each point has coordinates (cos x, sin x) for some x. Which of the marked arcs corresponds to

$$
\tan x <   \cos x <   \sin x?
$$

![[Image/17-Q1F-fig1.jpg]]

(a) $A$
(b) $B$
(c) $C$
(d) $D$
(e) $E$.

## 答案
C

## 解析
Rewriting tan $\begin{array} { r } { x = \frac { \sin x } { \cos x } } \end{array}$ gives $\frac { \sin x } { \cos x } < \cos x <$ sin x. In order to satisfy this inequality we know that sin x cannot be negative, since cos x would then also be negative, but tan x would be positive. This rules out (d) and (e). If $0 < \cos x < \sin x$ , then cos x < tan x, so cos x $\leqslant 0$ and the answer is (c).
