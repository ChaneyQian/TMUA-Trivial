## 题目
In this question a and b are real numbers, and a is non-zero.

When the polynomial $x^{2} - 2 a x + a^{4}$ is divided by $x + b$ the remainder is 1.

The polynomial $b x^{2} + x + 1$ has $a x - 1$ as a factor.

It follows that b equals

(a) $1$ only
(b) $0 \ \mathrm { o r \mathrm { ~ - ~ } 2 \mathrm { } }$
(c) $\mathrm { 1 ~ o r ~ 2 }$
(d) $\mathrm { 1 ~ o r ~ 3 }$
(e) $- 1 \mathrm { o r } 2 .$

B

## 解析
By the remainder theorem $f ( - b ) = 1$ , so

$$
b^{2} + 2 a b + a^{4} = 1.
$$

By the factor theorem $f \left( { \frac { 1 } { a } } \right) = 0$ 2

$$
\frac {b}{a^{2}} + \frac {1}{a} + 1 = 0
$$

$$
\begin{array}{r c l} {b + a + a^{2}} & = & 0 \\ {- a - a^{2}} & = & b. \end{array}
$$

Combining these two equations we find that

$$
2 a^{4} - a^{2} = 1
$$

and so $a = - 1 \mathrm { o r } 1$ . Hence $b = - 2 \ \mathrm { o r } \ 0$ , and so the answer is (b).
