## 题目
In this question we shall consider the function $f(x)$ defined by
$$
f(x) = x^{2} - 2px + 3,
$$
where $p$ is a constant.

**(a)**

Show that the function $f(x)$ has one stationary value in the range $0 < x < 1$ if $0 < p < 1$, and no stationary values in that range otherwise.

In the remainder of the question, we shall be interested in the smallest value attained by $f(x)$ in the range $0 \leqslant x \leqslant 1$. Of course, this value, which we shall call $m$, will depend on $p$.

**(b)**

Show that if $p \geqslant 1$ then $m = 4 - 2p$.

**(c)**

What is the value of $m$ if $p \leqslant 0$?

**(d)**

Obtain a formula for $m$ in terms of $p$, valid for $0 < p < 1$.

**(e)**

Using the axes opposite, sketch the graph of $m$ as a function of $p$ in the range $-2 \leqslant p \leqslant 2$.

## 解析
**(a)** Differentiating, $f'(x) = 2x - 2p$, which vanishes exactly at $x = p$. So $f$ has a stationary value in the open range $0 < x < 1$ precisely when $0 < p < 1$, and no stationary value there otherwise.

Note also that $f$ is an upward parabola with vertex at $x=p$, so $f$ is decreasing for $x < p$ and increasing for $x > p$.

**(b)** If $p \geqslant 1$ then the vertex lies at or to the right of $x=1$, so $f$ is decreasing throughout $0 \leqslant x \leqslant 1$ and the smallest value is attained at the right-hand endpoint:

$$m = f(1) = 1 - 2p + 3 = 4 - 2p.$$

**(c)** If $p \leqslant 0$ the vertex lies at or to the left of $x = 0$, so $f$ is increasing throughout $0 \leqslant x \leqslant 1$ and the smallest value is attained at the left-hand endpoint:

$$m = f(0) = 3.$$

**(d)** If $0 < p < 1$ the vertex lies inside the range, so the minimum is the value at the vertex:

$$m = f(p) = p^2 - 2p^2 + 3 = 3 - p^2.$$

**(e)** Collecting the three cases,

$$m = \begin{cases} 3 & \text{for } p \leqslant 0,\\ 3 - p^2 & \text{for } 0 < p < 1,\\ 4-2p & \text{for } p \geqslant 1.\end{cases}$$

On $-2 \leqslant p \leqslant 0$ the graph is the horizontal line $m = 3$. On $0 < p < 1$ it is the arc of the downward parabola $m = 3-p^2$ falling from $3$ to $2$; it leaves the horizontal line smoothly, since $\dfrac{\mathrm{d}m}{\mathrm{d}p} = -2p = 0$ at $p=0$. On $1 \leqslant p \leqslant 2$ it is the straight line $m = 4-2p$, running from $m=2$ at $p=1$ down to $m=0$ at $p=2$; this also joins on smoothly, since both pieces have gradient $-2$ at $p=1$. The graph is thus continuous, equal to $3$ up to $p=0$ and then decreasing steadily to $0$ at $p=2$.
