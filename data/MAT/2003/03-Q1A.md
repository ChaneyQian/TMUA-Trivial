## 题目
Depending on the value of the constant $d$, the equation
$$
d x^{2} - (d - 1)x + d = 0
$$
may have two real solutions, one real solution or no real solutions. For how many values of $d$ does it have just one real solution?
(a) for one value of $d$;
(b) for two values of $d$;
(c) for three values of $d$;
(d) for infinitely many values of $d$.

## 答案
B

## 解析
The equation is $dx^2 - (d-1)x + d = 0$. For it to be a quadratic equation (which is implicitly assumed since it's presented in the form of a quadratic), we must have $d \neq 0$. 
A quadratic equation has exactly one real solution if and only if its discriminant is zero:

$$\Delta = (-(d-1))^2 - 4(d)(d) = (d-1)^2 - 4d^2 = 0$$

This can be factored as a difference of squares:

$$((d-1) - 2d)((d-1) + 2d) = 0 \implies (-d-1)(3d-1) = 0$$

This gives two values for $d$: $d = -1$ and $d = \frac{1}{3}$. Both values satisfy $d \neq 0$, so there are exactly two values of $d$ that yield a single real solution. The answer is (b).

*(Note: If we allow $d=0$, the equation becomes linear $x=0$, which also has one solution, giving three values. However, the official answer is (b), implying the quadratic form requires the leading coefficient to be non-zero.)*
