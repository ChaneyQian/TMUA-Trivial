## 题目
![[Image/03-Q5-fig1.jpg]]

The diagram represents an array of $N$ electric lights arranged in a circle. Initially, each light may be set to be ON or OFF in an arbitrary way. After one second the settings are updated according to the following rule which determine the new state of a bulb in terms of the initial states of that bulb and the one just next to it in the clockwise direction.

if initially bulb $n$ and bulb $n + 1$ are in the same state (i.e. either both OFF or both ON) then after $1$ second bulb $n$ will be OFF;

if initially bulb $n$ and bulb $n + 1$ are in different states (i.e. one OFF the other ON) then after $1$ second bulb $n$ will be ON;

Of course, if $n = N$, we replace $n + 1$ with $1$ in the above.

Subsequently, the settings are updated each second by reapplying the same rule.

**(a)**

Explain why after one second there cannot be exactly one bulb ON.

**(b)**

More generally, explain why after one second there cannot be an odd number of bulbs ON.

**(c)**

Show that the state of bulb $n$ after $2$ seconds is completely determined by the initial states of bulbs $n$ and $n + 2$ (with appropriate modifications when $n = N$ or $n = N - 1$).

**(d)**

The initial states of which bulbs determine the state of bulb $n$ after $4$ seconds?

**(e)**

Show that if $N = 8$ then, irrespective of the initial settings, all bulbs will eventually be OFF. How long will this take?

## 解析
Record the state of bulb $n$ by a number $b_n$, with $b_n = 1$ for ON and $b_n = 0$ for OFF, and read all subscripts around the circle (so bulb $N+1$ means bulb $1$). The updating rule says the new state is $0$ when $b_n$ and $b_{n+1}$ agree and $1$ when they differ, that is

$$b_n' = b_n \oplus b_{n+1},$$

where $\oplus$ denotes addition modulo $2$.

**(a)** Suppose exactly one bulb were ON after one second, say bulb $m$. Then $b_n$ and $b_{n+1}$ agree for every $n \neq m$ and differ for $n = m$. Walking once round the circle from bulb $1$ back to bulb $1$, the state would change exactly once, so bulb $1$ would end up in the opposite state to the one it started in — which is absurd. So this cannot happen.

**(b)** The same idea in general. The number of bulbs ON after one second is the number of $n$ for which $b_n \neq b_{n+1}$, i.e. the number of places where the state changes as one goes once round the circle. Since the walk returns to its starting bulb, the state must change an even number of times. Hence the number of bulbs ON after one second is always even, and in particular never odd.

(Equivalently, modulo $2$ the number ON is $\sum_n \left(b_n \oplus b_{n+1}\right) \equiv \sum_n \left(b_n + b_{n+1}\right) = 2\sum_n b_n \equiv 0$.)

**(c)** Applying the rule twice,

$$b_n'' = b_n' \oplus b_{n+1}' = \left(b_n \oplus b_{n+1}\right) \oplus \left(b_{n+1} \oplus b_{n+2}\right) = b_n \oplus b_{n+2},$$

because $b_{n+1} \oplus b_{n+1} = 0$. So after $2$ seconds bulb $n$ is ON exactly when bulbs $n$ and $n+2$ started in different states, and OFF when they started in the same state — determined entirely by the initial states of bulbs $n$ and $n+2$.

**(d)** Applying the result of (c) twice, with the "two-second rule" playing the role of the one-second rule,

$$b_n^{(4)} = b_n^{(2)} \oplus b_{n+2}^{(2)} = \left(b_n \oplus b_{n+2}\right) \oplus \left(b_{n+2} \oplus b_{n+4}\right) = b_n \oplus b_{n+4}.$$

So after $4$ seconds the state of bulb $n$ is determined by the initial states of bulbs $n$ and $n+4$ alone (again reading subscripts around the circle).

**(e)** Repeating the doubling once more,

$$b_n^{(8)} = b_n^{(4)} \oplus b_{n+4}^{(4)} = \left(b_n \oplus b_{n+4}\right) \oplus \left(b_{n+4} \oplus b_{n+8}\right) = b_n \oplus b_{n+8}.$$

When $N = 8$, bulb $n+8$ *is* bulb $n$, so

$$b_n^{(8)} = b_n \oplus b_n = 0$$

for every $n$: after $8$ seconds all the bulbs are OFF, whatever the initial settings.

It can take the full $8$ seconds. For instance, if initially exactly one bulb is ON, then by (d) the state after $4$ seconds is $b_n \oplus b_{n+4}$, which is ON both for that bulb and for the one diametrically opposite, so the array is not yet all OFF. Tracking that example forward, the numbers of bulbs ON after $1,2,\ldots,8$ seconds are

$$2,\; 2,\; 4,\; 2,\; 4,\; 4,\; 8,\; 0,$$

so it reaches all-OFF only at $8$ seconds (and, as (b) requires, every one of these counts is even). So the process always finishes within $8$ seconds, and in the worst case takes exactly $8$.
