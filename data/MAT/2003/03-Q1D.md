## 题目
What is the value of the definite integral
$$
\int_{1}^{2} \dfrac{\mathrm{d}x}{x + x^{3}}?
$$
(a) $\ln 2 - \pi/6$
(b) $2\ln 2 - \ln 5$
(c) $\dfrac{1}{2}\ln\dfrac{8}{5}$
(d) None of the above.

### 我的备注

### AI备注


## 答案
C

## 解析
We evaluate the integral using partial fractions. We can rewrite the integrand as:

$$\frac{1}{x + x^3} = \frac{1}{x(1 + x^2)} = \frac{1}{x} - \frac{x}{1 + x^2}$$

Now we can integrate term by term:

$$\int_{1}^{2} \left( \frac{1}{x} - \frac{x}{1 + x^2} \right) \mathrm{d}x = \left[ \ln x - \frac{1}{2}\ln(1 + x^2) \right]_{1}^{2}$$

Evaluating at the limits:

$$= \left( \ln 2 - \frac{1}{2}\ln 5 \right) - \left( \ln 1 - \frac{1}{2}\ln 2 \right)$$

Since $\ln 1 = 0$, this simplifies to:

$$= \ln 2 - \frac{1}{2}\ln 5 + \frac{1}{2}\ln 2 = \frac{3}{2}\ln 2 - \frac{1}{2}\ln 5$$

Using logarithm rules, this becomes:

$$= \frac{1}{2}(3\ln 2 - \ln 5) = \frac{1}{2}(\ln 8 - \ln 5) = \frac{1}{2}\ln\frac{8}{5}$$

The answer is (c).
