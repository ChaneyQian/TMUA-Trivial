## 题目
Let $n$ be a positive integer. The coefficient of $x^{3} y^{5}$ in the expansion of

$$
(1 + x y + y^{2}) ^{n}
$$

equals

(a) $n ,$
(b) $2 ^{n} ,$
(c) $\binom { n } { 3 } \binom { n } { 5 } ,$
(d) $4 \binom { n } { 4 } ,$
(e) $\binom { n } { 8 } .$

## 备注

### 我的备注

### AI备注

## 答案
D

## 解析
Recall from the Binomial Theorem for $( a + b ) ^{n}$ that the sum of the exponents of a and b in each term always equals $n ,$ so an expansion of $( x y + y^{2} ) ^{k}$ would lead solely to terms of total exponent 2k (in x and y together). As $x^{3} y^{5}$ has total exponent 8 then we need to focus on the $k = 4$ term. The correct term in the binomial expansion of $( 1 + x y + y^{2} ) ^{n}$ is

$$
\binom {n} {4} (x y + y^{2}) ^{4}.
$$

and as $x^{3} y^{5} = ( x y ) ^{3} y^{2}$ we need to choose 3 xy-terms and 1 $y^{2}$ term, so and there are ${ \binom { 4 } { 1 } } = 4$ ways of doing this. The answer is (d).
