## 题目
For all real numbers $x$, the function $f ( x )$ satisfies

$$
6 + f (x) = 2 f (- x) + 3 x^{2} \left(\int_{-1} ^{1} f (t) \mathrm{d} t\right).
$$

It follows that $\int_{-1} ^{1} f ( x ) \, \mathrm{d} x$ equals

(a) $4,$
(b) $6,$
(c) $11,$
(d) ${ \dfrac { 27 } { 2 } } ,$
(e) $23.$

## 答案
A

## 解析
We are interested in the integral between −1 and 1 of $f ( x )$ . If we integrate the original identity between −1 and 1, we find

$$
12 + \int_{-1} ^{1} f (x) \mathrm{d} u = 2 \int_{-1} ^{1} f (- x) \mathrm{d} u + \left[ x^{3} \right] _{-1} ^{1} \int_{-1} ^{1} f (x) \mathrm{d} u.
$$

Note that $\textstyle \int_{-1} ^{1} f ( - x ) \mathrm { d } u = \int_{-1} ^{1} f ( x ) \mathrm { d } u$ as the graph of $y = f ( - x )$ is just a reflection in the y-axis of the graph of $y = f ( x )$ . Substituting $\textstyle A = \int_{-1} ^{1} f ( x )$ du means we are left with

$$
12 + A = 2 A + 2 A,
$$

so that A = 4 and the answer is (a).
