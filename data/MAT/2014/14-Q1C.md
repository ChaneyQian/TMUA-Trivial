## 题目
The cubic

$$
y = k x^{3} - (k + 1) x^{2} + (2 - k) x - k
$$

has a turning point, that is a minimum, when $x = 1$ precisely for

(a) $k > 0 ,$
(b) $0 < k < 1 ,$
(c) $k > { \dfrac { 1 } { 2 } } ,$
(d) $k < 3 ,$
(e) all values of $k$.

### 我的备注

### AI备注

## 答案
C

## 解析
The first derivative is given by

$$
{\frac {\mathrm{d} y}{\mathrm{d} x}} = 3 k x^{2} - (2 k + 2) x + (2 - k)
$$

which at $x = 1$ takes the value $3 k - 2 k - 2 + 2 - k = 0$ . So the gradient is zero for all values of k. However for this to be a minimum we also need that the second derivative is positive. The second derivative is equal to

$$
\frac {\mathrm{d} ^{2} y}{\mathrm{d} x^{2}} = 6 k x - 2 (k + 1)
$$

which equals $4 k - 2$ when x = 1. This is positive when $k > \frac 12$ and so the answer is (c).
