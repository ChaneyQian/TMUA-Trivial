## 题目
Let $a , b , c$ and d be real numbers. The two curves $y = a x^{2} + c$ and $y = b x^{2} +$ d have exactly two points of intersection precisely when

(a) $\dfrac { a } { b } < 1 ,$
(b) $\dfrac { a } { b } < \dfrac { c } { d } ,$
(c) $a < b ,$
(d) $c < d ,$
(e) $( d - c ) ( a - b ) > 0 .$

## 解析
We have $a x^{2} + c = b x^{2} + d$ if and only if $( a - b ) x^{2} = ( d - c )$ . If $( a - b ) = 0$ then we either have no solutions $( \mathrm { i f } \ c \neq d )$ or infinitely many solutions $( \operatorname { i f } c = d )$ . Otherwise, we can safely divide by $( a - b )$ and get $x^{2} = ( d - c ) / ( a - b )$ . Then there are two roots precisely when $( d - c ) / ( a - b ) > 0$ . Multiplying up by $( a - b ) ^{2}$ , which is positive, our expression becomes $( d - c ) ( a - b ) > 0$ . The answer is (e).
