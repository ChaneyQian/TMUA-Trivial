## 题目
The parabolas with equations $y = x^{2} .$ +c and $y^{2} = x$ touch (that is, meet tangentially) at a single point. It follows that c equals

(a) ${ \dfrac { 1 } { 2 { \sqrt { 3 } } } } ,$
(b) ${ \dfrac { 3 } { 4 { \sqrt [ { 3 } ] { 4 } } } } ,$
(c) ${ \dfrac { - 1 } { 2 } } ,$
(d) ${ \sqrt { 5 } } - { \sqrt { 3 } } ,$
(e) ${ \sqrt { \dfrac { 2 } { 3 } } } .$

## 备注

### 我的备注

### AI备注

## 答案
B

## 解析
The curves meet and have the same gradient, so

$$
\begin{array}{c} {x^{2} + c = x^{1/2}} \\ {2 x = \frac {1}{2 x^{1/2}}} \end{array}
$$

The second equation gives $x = 4 ^{-2/3}$ , and then substituting this into the first equation gives

$$
c = 4 ^{-1/3} - 4 ^{-4/3} = 4 ^{-1/3} \left(1 - \frac {1}{4}\right) = \frac {3}{4 \sqrt [ 3 ]{4}}
$$

The answer is (b).
