## 题目
For precisely which non-zero real values of x is it true that

$$
x^{2} - 3 x + 2 <   \frac {x - 1}{x}?
$$

(a) $x < 1 - { \sqrt { 2 } } { \mathrm { ~ o r ~ } } x > 1 + { \sqrt { 2 } } ,$

(b) $1 - { \sqrt { 2 } } < x < 0 { \mathrm { ~ o r ~ } } 1 < x < 1 + { \sqrt { 2 } } ,$

(c) $1 < x < 1 + { \sqrt { 2 } } ,$

(d) $1 - { \sqrt { 2 } } < x < 1 + { \sqrt { 2 } } ,$

(e) $1 - { \sqrt { 2 } } < x < 0 .$

## 答案
B

## 解析
The left-hand side factorises to give

$$
(x - 1) (x - 2) <   \frac {(x - 1)}{x}
$$

When are the two sides equal? That happens when $x = 1$ or when $x ( x - 2 ) = 1$ , that is when $x = 1 \pm { \sqrt { 2 } }$ . Note that one of these roots is negative and the other is positive.

That helps us to draw a graph (it's perhaps useful to note that the right-hand side is $1 - 1 / x )$

From the graph, we see that the quadratic is below the reciprocal graph for $1 - \sqrt { < } x < 0$ and for $1 < x < 1 + { \sqrt { 2 } }$

The answer is (b)
