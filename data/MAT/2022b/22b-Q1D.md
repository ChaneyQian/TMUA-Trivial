## 题目
Consider the two inequalities

$$
1 \leq x^{2} + y^{2} \leq 4 \quad \text { and } \quad x^{2} \geq 3 y^{2}.
$$

The total area of all regions of the (x, y)-plane where both inequalities hold is

(a) $\pi { \sqrt { 3 } } ,$
(b) $\pi ,$
(c) $2 \pi ,$
(d) $\dfrac { \pi } { 2 } ,$
(e) $\dfrac { \pi^{2} } { 6 } .$

## 备注

### AI备注


## 答案
B

## 解析
The first inequality describes a region between two concentric circles. The second inequality is true if either (case 1) $x \geq 0$ and $- x \leq \sqrt { 3 } y \leq x$ , or (case 2) $x \leq 0$ and $x \leq \sqrt { 3 } y \leq - x$

![[Image/22b-Q1D-sol1.jpg]]

The intersection points between the inner circle and those lines are $( { \sqrt { 3 } } / { 2 } , 1 / 2 )$ and reflections, so the acute angle subtended at the origin by the two lines is $60 ^{\circ}$ . We would therefore like onefourthird of the area between the two circles, which is ${ \scriptstyle { \frac { 1 } { 3 } } } \pi ( 2 ^{2} - 1 ^{2} ) = \pi$ The answer is (b)
