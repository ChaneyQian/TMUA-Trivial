## 题目
Let $d ( n )$ be the number of digits in a positive integer n (with n written in the usual decimal notation). For example $d ( 2 ) = 1 , d ( 103 ) = 3$ , and $d ( 10 ^{6} ) = 7$ Define the sequence $s_{n} = ( 20 ) ^{-d(n)}$ . What is the sum $\sum_{n=1} ^{\infty} s_{n}$ equal to?

(a) $\dfrac { 1 } { 2 }$
(b) $\dfrac { 4 } { 5 }$
(c) $\dfrac { 9 } { 10 }$
(d) $1$
(e) $\dfrac { 9 } { 5 }$

## 答案
C

## 解析
Starting with 1, there are nine one-digit numbers. Then from 11 to 99 there are 90 two-digit numbers, then there are 900 three-digit numbers, and so on. So the required sum is (grouping terms by the number of digits of n) equal to

$$
9 \times 20 ^{-1} + 90 \times 20 ^{-2} + 900 \times 20 ^{-3} + \dots
$$

which is a geometric series with first term $\frac { 9 } { 20 }$ , common ratio $\frac { 1 } { 2 }$ and sum to infinity equal to $\frac { 9 } { 10 }$ . The answer is (c)
