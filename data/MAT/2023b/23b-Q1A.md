## 题目
The function $p ( x ) = x^{3}$ is an example of a polynomial with the property that there is a point on the graph $y = p ( x )$ with zero derivative which is neither a local maximum nor a local minimum. Which one of the following polynomials has the same property?

(a) $y = x^{3} - 3 x^{2} + x$

(b) $y = x^{3} - 3 x^{2} + 2 x$

(c) $y = x^{3} - 3 x^{2} + 3 x$

(d) $y = x^{3} - 3 x^{2} + 4 x$

(e) $y = x^{3} - 3 x^{2} + 5 x$

## 备注

### 我的备注

### AI备注


## 答案
C

## 解析
Each of the given polynomials is of the form $y = x^{3} - 3 x^{2} + k x$ . The first derivative is $3 x^{2} - 6 x + k$ and the second derivative is 6x − 6. So if there is a point with zero derivative, then it will either be a local maximum or a local minimum, unless $x = 1$ . At $x = 1$ the first derivative is $k - 3$ , which is only zero if $k = 3$

The answer is (c)
