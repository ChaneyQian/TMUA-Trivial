## 题目
Which of the following numbers is the smallest?

(a) $\log_{10} { \left( \sqrt [ 10 ] { 10 ^{11} } \right) }$

(b) $\dfrac { \pi } { 2 }$

(c) $\dfrac { 11 } { 9 }$

(d) $\sqrt { \dfrac { 3 } { 2 } }$

(e) ${ \sqrt { 3 } } \cos ( 44 ^{\circ} )$

## 备注

### 我的备注

### AI备注


## 答案
A

## 解析
Note that $\sqrt [ 10 ] { 10 ^{11} }$ is $10 ^{11/10}$ , so $\textstyle \log_{10} { \left( \sqrt [ 10 ] { 10 ^{11} } \right) } = { \frac { 11 } { 10 } }$ . This is less than $\textstyle { \frac { 11 } { 9 } }$

To compare $\sqrt { \frac { 3 } { 2 } }$ with $\frac { 11 } { 10 }$ , compare their squares; compare $\frac { 3 } { 2 }$ with $\frac { 121 } { 100 }$ . The former is $\frac { 150 } { 100 }$ which is larger than $\frac { 121 } { 100 }$

Now note that ${ \sqrt { 3 } } \cos ( 44 ^{\circ} )$ is slightly larger than ${ \sqrt { 3 } } \cos ( 45 ^{\circ} )$ which is ${ \sqrt { \frac { 3 } { 2 } } } .$

Finally note that $\pi > 3$ so $\textstyle { \frac { \pi } { 2 } } > { \frac { 3 } { 2 } } > { \frac { 11 } { 10 } }$

So the smallest of the numbers is $\frac { 11 } { 10 }$

The answer is (a)
