## 题目
The sum

$$
\sin^{2} (1 ^{\circ}) + \sin^{2} (2 ^{\circ}) + \sin^{2} (3 ^{\circ}) + \dots + \sin^{2} (89 ^{\circ}) + \sin^{2} (90 ^{\circ})
$$

is equal to

(a) $44,$
(b) $44\dfrac{1}{2},$
(c) $45,$
(d) $45\dfrac{1}{2},$
(e) $46.$

## 答案
D

## 解析
We can use the fact that $\sin^{2} ( 90 ^{\circ} - n ) = \cos^{2} ( n )$ for any n, and $\sin^{2} x + \cos^{2} x = 1$ . So we have $\sin^{2} 1 ^{\circ} + \sin^{2} 89 ^{\circ} = 1$ and $\sin^{2} 2 ^{\circ} + \sin^{2} 88 ^{\circ} = 1$ and so on up to $\sin^{2} 44 ^{\circ} + \sin^{2} 46 ^{\circ} = 1$ . We also have $\sin^{2} 45 ^{\circ} = { \frac { 1 } { 2 } }$ and $\sin^{2} 90 ^{\circ} = 1 { }$ for a total of $45 \frac 12$ The answer is (d)
