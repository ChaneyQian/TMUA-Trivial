## 题目
A regular dodecagon is a 12-sided polygon with all sides the same length and all internal angles equal. If I construct a regular dodecagon by connecting 12 equally-spaced points on a circle of radius 1, then the area of this polygon is

(a) $6 + 3\sqrt{3},$
(b) $2\sqrt{2},$
(c) $3\sqrt{2},$
(d) $3\sqrt{3},$
(e) $3.$

## 备注

### AI备注

## 答案
E

## 解析
Connect each point to the centre of the circle to split the shape into 12 isosceles triangles, each with angle $30 ^{\circ}$ at the centre. Then the area of each triangle is ${ \begin{array} { l } { { \frac { 1 } { 2 } } \times 1 \times 1 \times \sin 30 ^{\circ} = { \frac { 1 } { 4 } } } \end{array} }$ , and there are 12 triangles, for a total area of 3.

The answer is (e)
