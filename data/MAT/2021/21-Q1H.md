## 解析
The function inside the brackets is $6 \sin^{2} x - 8 \sin x + 3$ which is a quadratic for sin x. We could therefore consider the quadratic $6 u^{2} - 8 u + 3 ~ \mathrm { f o r } ~ - 1 \le u \le 1$ . Complete the square to write this as $6 \left( u - { \textstyle { \frac { 2 } { 3 } } } \right) ^{2} + { \frac { 1 } { 3 } }$ . This reaches a minimum value when $\begin{array} { r } { u = \frac { 2 } { 3 } } \end{array}$ . For $u = \sin x$ in the range $0 \leq x \leq 360 ^{\circ}$ , this happens for two values of x both in $0 < x < 180 ^{\circ}$ . The value there is $\mathrm { l o g_{2} } \left( \textstyle { \frac { 1 } { 3 } } \right) < 0$ . Only one of the graphs reaches a negative minimum value twice in that range. The answer is (a)
