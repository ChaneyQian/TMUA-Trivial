## 题目
Six vectors $v_{1}$ , $v_{2}$ , $v_{3}$ , $v_{4}$ , $v_{5}$ , $v_{6}$ are each chosen to be either $\begin{pmatrix}1\\1\end{pmatrix}$ or $\begin{pmatrix}3\\2\end{pmatrix}$ with equal probability, with each choice made independently. The probability that the sum $v_{1} + v_{2} + v_{3} + v_{4} + v_{5} + v_{6}$ is equal to the vector $\begin{pmatrix}10\\8\end{pmatrix}$ is

(a) $0,$
(b) $\dfrac{3}{64},$
(c) $\dfrac{15}{64},$
(d) $\dfrac{1}{6},$
(e) $\dfrac{5}{16}.$

## 答案
C

## 解析
In order to make the vector $\binom { 10 } { 8 }$ we would need $a { \binom { 1 } { 1 } } + b { \binom { 3 } { 2 } } = { \binom { 10 } { 8 } }$ where a is the number of times we pick $\binom { 1 } { 1 }$ and b is the number of times we pick $\binom { 3 } { 2 }$

Since we have six vectors, $a + b = 6$ . Solving the simultaneous equations $a + 3 b = 10$ and $a + 2 b = 8$ , we get $a = 4$ and $b = 2$ , and we can check that $a + b = 6$ for this solution! So we want exactly two of the six vectors to be $\binom { 3 } { 2 }$ . There are $^ 6 C_{2} = 15$ ways that this could happen, each with probability $\frac { 1 } { 64 }$ , so the answer is $\frac { 15 } { 64 }$ The answer is (c)
