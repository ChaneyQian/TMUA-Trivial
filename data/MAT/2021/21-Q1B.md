## 题目
The positive number $a$ satisfies

$$
\int_{0} ^{a} \left(\sqrt {x} + x^{2}\right) \mathrm{d} x = 5
$$

if

(a) $a = \left( \sqrt{21} - 1 \right)^{1/3},$
(b) $a = \sqrt{3},$
(c) $a = 3^{2/3},$
(d) $a = (\sqrt{6} - 1)^{2/3},$
(e) $a = 5^{2/3}.$

## 备注

### 我的备注

### AI备注

## 答案
C

## 解析
The integral is

$$
\int_{0} ^{a} \sqrt {x} + x^{2} \mathrm{d} x = \int_{0} ^{a} x^{1/2} + x^{2} \mathrm{d} x = \left[ \frac {2}{3} x^{3/2} + \frac {1}{3} x^{3} \right] _{0} ^{a} = \frac {2}{3} a^{3/2} + \frac {1}{3} a^{3}.
$$

So we have $2 a^{3/2} + a^{3} = 15$ . This factorises as $( a^{3/2} - 3 ) ( a^{3/2} + 5 ) = 0$ . Since $a > 0$ we want $a^{3/2} > 0$ , so it's 3, so $a = 3 ^{2/3}$

The answer is (c)
