## 题目
Let $n \geqslant 2$ be an integer and $p_{n} ( x )$ be the polynomial

$$
p_{n} (x) = (x - 1) + (x - 2) + \dots + (x - n).
$$

What is the remainder when $p_{n} ( x )$ is divided by $p_{n-1} ( x )$?

(a) $\dfrac { n } { 2 } ;$
(b) ${ \dfrac { n + 1 } { 2 } } ;$
(c) ${ \dfrac { n^{2} + n } { 2 } } ;$
(d) ${ \dfrac { - n } { 2 } } .$

## 备注

### 我的备注

### AI备注

## 答案
D

## 解析
By summing the defining arithmetic progression we see

$$
p_{n} (x) = n x - \frac {n (n + 1)}{2}, \qquad p_{n-1} (x) = (n - 1) x - \frac {n (n - 1)}{2}.
$$

One can then either do the long division, noting $p_{n-1}(x)$ divides $\frac{n}{n-1}$ times into $p_{n}(x)$ leaving remainder

$$
\begin{array}{r c l} p_{n} (x) - \frac {n}{n - 1} p_{n-1} (x) & = & \left(n x - \frac {n (n + 1)}{2}\right) - \frac {n}{n - 1} \left((n - 1) x - \frac {n (n - 1)}{2}\right) \\ & = & - \frac {n (n + 1)}{2} + \frac {n}{n - 1} \frac {n (n - 1)}{2} \\ & = & \frac {- n^{2} - n + n^{2}}{2} = \frac {- n}{2}, \end{array}
$$

or one could apply the Remainder Theorem and evaluate $p_{n}(n/2)$ to find the same result. The answer is (d).
