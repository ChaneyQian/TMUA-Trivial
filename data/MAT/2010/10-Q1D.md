## 解析
The function $y = \sin^{2} { \sqrt { x } }$ only takes non-negative values which discounts (a). The function has a local maximum with value 1 whenever $x = \left( n + { \textstyle { \frac { 1 } { 2 } } } \right) ^{2} \pi^{2}$ for any integer n, which discounts (c). Further the zeros of y are at $x = n^{2} \pi^{2}$ , for any integer n, which do not occur at regular intervals, and this discounts (d). The answer is (b).
