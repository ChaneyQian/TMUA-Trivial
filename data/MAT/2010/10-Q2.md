## 题目
For **ALL APPLICANTS**.

Suppose that $a , b , c$ are integers such that

$$
a \sqrt {2} + b = c \sqrt {3}.
$$

(i) By squaring both sides of the equation, show that $a = b = c = 0$

[You may assume that ${ \sqrt { 2 } } , { \sqrt { 3 } }$ and $\sqrt { 2 / 3 }$ are all irrational numbers. An irrational number is one which cannot be written in the form $p / q$ where $p$ and $q$ are integers.]

(ii) Suppose now that $m , n , M , N$ are integers such that the distance from the point $( m , n )$ to $( { \sqrt { 2 } } , { \sqrt { 3 } } )$ equals the distance from $( M , N )$ to $( { \sqrt { 2 } } , { \sqrt { 3 } } )$

Show that $m = M$ and $n = N$

Given real numbers $a , b$ and a positive number $r ,$ let $N \left( a , b , r \right)$ be the number of integer pairs $x , y$ such that the distance between the points $( x , y )$ and $( a , b )$ is less than or equal to r. For example, we see that $N \left( 1 . 2 , 0 , 1 . 5 \right) = 7$ in the diagram below.

![[Image/10-Q2-fig1.jpg]]

(iii) Explain why N (0.5, 0.5, r) is a multiple of 4 for any value of $r .$ .

(iv) Let k be any positive integer. Explain why there is a positive number r such that

$$
N \left(\sqrt {2}, \sqrt {3}, r\right) = k.
$$

## 解析
2. (i) [4 marks] If $a { \sqrt { 2 } } + b = c { \sqrt { 3 } }$ then squaring both sides of the equation gives

$$
2 a^{2} + b^{2} + 2 a b \sqrt {2} = 3 c^{2}.
$$

If ab $\neq 0$ then

$$
\sqrt {2} = \frac {3 c^{2} - 2 a^{2} - b^{2}}{2 a b}
$$

is rational  -  a contradiction and so $a = 0$ or $b = 0$ . If $a = 0$ then we have ${ \sqrt { 3 } } = b / c$ unless $b = c = 0 $ if $b = 0$ then we have ${ \sqrt { 2 / 3 } } = c / a$ unless $c = a = 0$

(ii) [4 marks] We have that the square of the distance from $( m , n )$ to $( { \sqrt { 2 } } , { \sqrt { 3 } } )$ equals the square of the distance from $( M , N )$ to $( { \sqrt { 2 } } , { \sqrt { 3 } } )$ , or put algebraically

$$
\left(m - \sqrt {2}\right) ^{2} + \left(n - \sqrt {3}\right) ^{2} = \left(M - \sqrt {2}\right) ^{2} + \left(N - \sqrt {3}\right) ^{2}.\tag{1}
$$

Rearranging this gives

$$
2 (M - m) \sqrt {2} + (m^{2} + n^{2} - M^{2} - N^{2}) = 2 (n - N) \sqrt {3}.
$$

By part (i) we have that $2 \left( M - m \right) = 0 = 2 \left( n - N \right)$ and hence $M = m$ and $N = n$

(iii) [4 marks] If a particular point $( x , y )$ is within distance r of $\left( { \frac { 1 } { 2 } } , { \frac { 1 } { 2 } } \right)$ then so will its reflection in the $\begin{array} { r } { x = \frac { 1 } { 2 } } \end{array}$ line, the $\begin{array} { r } { y = \frac { 1 } { 2 } } \end{array}$ line and in both lines as these are diameters of the circle. The coordinates of the three points are integers also. Precisely these are the points

$$
(1 - x, y), \qquad (x, 1 - y), \qquad (1 - x, 1 - y).
$$

As the lattice points within the circle can be divided into sets of four like above then $N \left( { \frac { 1 } { 2 } } , { \frac { 1 } { 2 } } , r \right)$ is a multiple of 4.

(iv) [3 marks] As r increases then the circle (and its boundary) consumes lattice points. But because no two lattice points are equidistant from $( { \sqrt { 2 } } , { \sqrt { 3 } } ) - \mathrm { a s }$ shown in part (ii)  -  then the lattice points are consumed one at a time and all positive integers are achieved by $N \left( { \sqrt { 2 } } , { \sqrt { 3 } } , r \right)$
