## 题目
For a positive number a, let

$$
I (a) = \int_{0} ^{a} \left(4 - 2 ^{x^{2}}\right) \mathrm{d} x.
$$

Then $\mathrm { d } I / \mathrm { d } a = 0$ when a equals

(a) $\dfrac { 1 + { \sqrt { 5 } } } { 2 } ,$
(b) $\sqrt { 2 } ,$
(c) $\dfrac { { \sqrt { 5 } } - 1 } { 2 } ,$
(d) $1.$

## 备注

### 我的备注

### AI备注

## 答案
B

## 解析
We have

$$
I (a) = \int_{0} ^{a} \left(4 - 2 ^{x^{2}}\right) \mathrm{d} x
$$

where $a \geqslant 0$ . If one considers the graph $y = 4 - 2 ^{x^{2} }$ then we see that $y > 0$ for $0 < x < { \sqrt { 2 } }$ and that $y < 0$ for ${ \sqrt { 2 } } < x$ . We see that $I \left( a \right)$ is increasing for $0 < a < { \sqrt { 2 } }$ with $I \left( a \right)$ recording ever larger amounts of the area below the graph $y = 4 - 2 ^{x^{2} }$ and which is above the x-axis. $I \left( a \right)$ reaches a maximum at $I \left( a \right)$ and is decreasing after that as negative contributions are recorded from the (signed) area where the graph $y = 4 - 2 ^{x^{2} }$ has moved under the x-axis. So the answer is (b).
