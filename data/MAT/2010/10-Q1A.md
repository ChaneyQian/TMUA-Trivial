## 题目
The values of $k$ for which the line $y = kx$ intersects the parabola $y = ( x - 1 ) ^{2}$ are precisely

(a) $k \leqslant 0 ,$
(b) $k \geqslant - 4 ,$
(c) $k \geqslant 0 \mathrm { ~or~ } k \leqslant - 4 ,$
(d) $- 4 \leqslant k \leqslant 0 .$

## 备注

### 我的备注

### AI备注

## 答案
C

## 解析
The line y = kx intersects the parabola $y = \left( x - 1 \right) ^{2}$ when the equation

$$
(x - 1) ^{2} = k x \iff x^{2} - (k + 2) x + 1 = 0
$$

has real solutions. This quadratic equation has discriminant $\left( k + 2 \right) ^{2} - 4$ which is non-negative when

$$
k + 2 \geqslant 2, \quad \text { i.e. } k \geqslant 0 \quad \text { or } \quad k + 2 \leqslant - 2, \quad \text { i.e. } k \leqslant - 4.
$$

The answer is (c).
