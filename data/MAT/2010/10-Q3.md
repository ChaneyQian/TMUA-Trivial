## 解析
3.(i) [4 marks] Let $x$ denote the angle substended by the two sides of length 1. The area of the smaller triangle is $\frac { 1 } { 2 }$ sin x, of the sector is ${ \frac { 1 } { 2 } } x$ and of the larger triangle is $\frac { 1 } { 2 }$ tan x. So sin $x < x <$ tan x. Multiplying the second inequality by cos $x > 0$ (for $\begin{array} { r } { 0 < x < \frac { \pi } { 2 } ) } \end{array}$ we have $x \cos x < \sin x < x$

(ii) [4 marks]

![[Image/10-Q3-sol1.jpg]]

We have cos x $< \frac { \sin x } { x } < 1$ for small values of x. As cos $x \approx 1$ for small values of x then sin $x / x \approx 1$ for small values of 1.

(iii) [2 marks] The line should be drawn so that it passes through the origin and is tangential to the second hump above the y-axis and likewise tangential in the third quadrant.

![[Image/10-Q3-sol2.jpg]]  
(iv) [2 marks] The line $y = c$ should be tangential with the second positive hump of the $y = \sin x / x$ graph.

(v) [3 marks] As X is a solution of sin $x \ = \ c x$ then we have sin $X \ = \ c X$ . But $y \ = \ c x$ is also tangential to $y = \sin x$ when $x = X$ and so the gradients also agree, i.e. cos $X = c$ . Eliminating c and rearranging we get tan $X = X$ . Others may know the quotient rule and show

$$
\frac {\mathrm{d}}{\mathrm{d} x} \left(\frac {\sin x}{x}\right) = \frac {x \cos x - \sin x}{x^{2}} \implies \text { at } X \text { we   have } X \cos X = \sin X \implies \tan X = X.
$$
