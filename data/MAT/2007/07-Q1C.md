## 题目
The number of solutions $x$ to the equation
$$
7 \sin x + 2 \cos^{2} x = 5,
$$
in the range $0 \leqslant x < 2\pi$, is

(a) $1,$
(b) $2,$
(c) $3,$
(d) $4.$

### AI备注

## 答案
B

## 解析
Using the identity si $\begin{array} { r } { { \mathrm {  ~ n } } ^{2} x + \cos^{2} x = 1 } \end{array}$ we see

$$
\begin{array}{c} 7 \sin x + 2 \cos^{2} x = 5 \\ \iff 2 \sin^{2} x - 7 \sin x + 3 = 0 \\ \iff (2 \sin x - 1) (\sin x - 3) = 0 \end{array}
$$

Now sin $x = 3$ has no solutions, and in the range $0 \leqslant x < 2 \pi$ we note sin x takes the value $1 / 2$ twice $( \mathrm { a t } ~ \pi / 6$ and at $5 \pi / 6 )$ . The answer is (b).
