## 题目
For **APPLICANTS IN** $\left\{\begin{array}{l}\textbf{MATHEMATICS} \\ \textbf{MATHEMATICS \& STATISTICS} \\ \textbf{MATHEMATICS \& PHILOSOPHY} \\ \textbf{MATHEMATICS \& COMPUTER SCIENCE}\end{array}\right\}$ **ONLY**.

Let
$$
I(c) = \int_{0}^{1} \left( (x - c)^{2} + c^{2} \right) \mathrm{d}x
$$
where $c$ is a real number.

**(i)** Sketch $y = (x - 1)^{2} + 1$ for the values $-1 \leqslant x \leqslant 3$ on the axes below and show on your graph the area represented by the integral $I(1)$.

**(ii)** Without explicitly calculating $I(c)$, explain why $I(c) \geqslant 0$ for any value of $c$.

**(iii)** Calculate $I(c)$.

**(iv)** What is the minimum value of $I(c)$ (as $c$ varies)?

**(v)** What is the maximum value of $I(\sin \theta)$ as $\theta$ varies?

QUESTION 3: (i) [3 marks]

(ii) [2 marks] As $\left( x - c \right) ^{2} + c^{2} \geqslant 0$ for all x then $I \left( c \right) \geqslant 0$

(iii) [4 marks]

$$
I (c) = \int_{0} ^{1} ((x - c) ^{2} + c^{2}) \mathrm{d} x = \left[ \frac {(x - c) ^{3}}{3} \right] _{0} ^{1} + c^{2} = \frac {(1 - c) ^{3}}{3} + \frac {c^{3}}{3} + c^{2} = 2 c^{2} - c + \frac {1}{3}.
$$

(iv) [3 marks] Completing the square

$$
I (c) = 2 \left(c^{2} - \frac {c}{2} + \frac {1}{6}\right) = 2 \left(\left(c - \frac {1}{4}\right) ^{2} + \frac {5}{48}\right) = 2 \left(c - \frac {1}{4}\right) ^{2} + \frac {5}{24}.
$$

So the minimum is $5 / 24$

(v) [3 marks] If c can only vary between 1 then the maximum is at $I \left( - 1 \right) { \mathrm { a s ~ } } - 1$ is furthest from $1 / 4 .$ . In this case

$$
I (- 1) = 2 \left(\frac {5}{4}\right) ^{2} + \frac {5}{24} = \frac {50}{16} + \frac {5}{24} = \frac {150 + 10}{48} = \frac {160}{48} = \frac {10}{3}.
$$
