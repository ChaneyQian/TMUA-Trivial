## 题目
The greatest value which the function
$$
f(x) = \left(3 \sin^{2} (10x + 11) - 7\right)^{2}
$$
takes, as $x$ varies over all real values, equals

(a) $9,$
(b) $16,$
(c) $49,$
(d) $100.$

## 备注

### 我的备注

### AI备注

## 答案
C

## 解析
sin (10x + 11) takes values between 1 and 1 as x varies;

$\sin^{2} \left( 10 x + 11 \right)$ takes values between 0 and 1 as x varies;

$3 \sin^{2} \left( 10 x + 11 \right)$ takes values between 0 and 3 as x varies;

$3 \sin^{2} \left( 10 x + 11 \right) - 7$ takes values between 7 and 4 as x varies;

$\left( 3 \sin^{2} \left( 10 x + 11 \right) - 7 \right) ^{2}$ takes values between 16 and 49 as x varies.

The answer is (c).
