## 题目
For **ALL APPLICANTS**.

Let $f(n)$ be a function defined, for any integer $n \geqslant 0$, as follows:
$$
f(n) = \begin{cases}
1 & \text{if } n = 0, \\
\left(f(n/2)\right)^{2} & \text{if } n > 0 \text{ and } n \text{ is even}, \\
2 f(n - 1) & \text{if } n > 0 \text{ and } n \text{ is odd}.
\end{cases}
$$

**(i)** What is the value of $f(5)$?

The recursion depth of $f(n)$ is defined to be the number of other integers $m$ such that the value of $f(m)$ is calculated whilst computing the value of $f(n)$. For example, the recursion depth of $f(4)$ is $3$, because the values of $f(2)$, $f(1)$, and $f(0)$ need to be calculated on the way to computing the value of $f(4)$.

**(ii)** What is the recursion depth of $f(5)$?

Now let $g(n)$ be a function, defined for all integers $n \geqslant 0$, as follows:
$$
g(n) = \begin{cases}
0 & \text{if } n = 0, \\
1 + g(n/2) & \text{if } n > 0 \text{ and } n \text{ is even}, \\
1 + g(n - 1) & \text{if } n > 0 \text{ and } n \text{ is odd}.
\end{cases}
$$

**(iii)** What is $g(5)$?

**(iv)** What is $g(2^k)$, where $k \geqslant 0$ is an integer? Briefly explain your answer.

**(v)** What is $g(2^l + 2^k)$ where $l > k \geqslant 0$ are integers? Briefly explain your answer.

**(vi)** Explain briefly why the value of $g(n)$ is equal to the recursion depth of $f(n)$.

## 解析
QUESTION 5: (i) [2 marks]

$$
f (5) = 2 f (4) = 2 (f (2)) ^{2} = 2 \left(\left(f (1) ^{2}\right)\right) ^{2} = 2 \left(\left(2 ^{2}\right) ^{2}\right) = 32.
$$

(ii) [2 marks] As we had to calculate $f \left( 4 \right) , f \left( 2 \right) , f \left( 1 \right) , f \left( 0 \right)$ on the way then f (5) has recursion depth 4.

(iii) [2 marks]

$$
g (5) = 1 + g (4) = 1 + 1 + g (2) = 1 + 1 + 1 + g (1) = 1 + 1 + 1 + 1 + g (0) = 4.
$$

(iv) [3 marks] For any natural number k

$$
g \left(2 ^{k}\right) = 1 + g \left(2 ^{k-1}\right) = \dots = k + g \left(2 ^{0}\right) = k + g (1) = k + 1.
$$

(v) [4 marks] For natural numbers $l > k \geqslant 0$

$$
g \left(2 ^{l} + 2 ^{k}\right) = k + g \left(2 ^{l-k} + 1\right) = k + 1 + g \left(2 ^{l-k}\right) = k + 1 + l - k + 1 = l + 2.
$$

(vi) [2 marks] In the definition of $g \left( n \right)$ a further 1 is added to previously calculated values at each stage whether n is even or odd; as $g \left( 0 \right) = 0$ then $g \left( n \right)$ is a measure of the number of previously calculated values, i.e. $g \left( n \right)$ equals the recursion depth.
