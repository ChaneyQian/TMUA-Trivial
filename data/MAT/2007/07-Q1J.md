## 题目
The inequality
$$
(n + 1) + (n^{4} + 2) + (n^{9} + 3) + (n^{16} + 4) + \dots + (n^{10000} + 100) > k
$$
is true for all $n \geqslant 1$. It follows that

(a) $k < 1300$.
(b) $k^{2} < 101$
(c) $k \geqslant 101^{10000}$
(d) $k < 5150$

## 答案
D

## 解析
Note that

$$
(n + 1) + (n^{4} + 2) + (n^{9} + 3) + (n^{16} + 4) + \dots + (n^{10000} + 100)
$$

increases as n increases. So the inequality will hold for all n $\geqslant 1$ if it holds for $n = 1$ . So we need

$$
\begin{array}{r l} (1 + 1) + (1 + 2) + (1 + 3) + (1 + 4) + \dots + (1 + 100) & > k \\ \iff 2 + 3 + 4 + \dots + 101 > k \\ \iff \frac {100}{2} (2 + 101) > k \\ \iff 5150 > k. \end{array}
$$

The answer is (d).
