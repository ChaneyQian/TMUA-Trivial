## 题目
For **APPLICANTS IN COMPUTER SCIENCE ONLY**.

Suppose we have a collection of tiles, each containing two strings of letters, one above the other. A **match** is a list of tiles from the given collection (tiles may be used repeatedly) such that the string of letters along the top is the same as the string of letters along the bottom. For example, given the collection
$$
\left\{\left[ \frac{AA}{A} \right], \left[ \frac{B}{ABA} \right], \left[ \frac{CCA}{CA} \right] \right\},
$$
the list
$$
\left[ \frac{AA}{A} \right] \left[ \frac{B}{ABA} \right] \left[ \frac{AA}{A} \right]
$$
is a match since the string AABAA occurs both on the top and bottom.

Consider the following set of tiles:
$$
\left\{\left[ \frac{X}{U} \right], \left[ \frac{UU}{U} \right], \left[ \frac{Z}{X} \right], \left[ \frac{E}{ZE} \right], \left[ \frac{Y}{U} \right], \left[ \frac{Z}{Y} \right] \right\}.
$$

**(a)** What tile must a match begin with?

**(b)** Write down all the matches which use four tiles (counting any repetitions).

**(c)** Suppose we replace the tile $\left[ \dfrac{E}{ZE} \right]$ with $\left[ \dfrac{E}{ZZZE} \right]$.

What is the least number of tiles that can be used in a match?

How many different matches are there using this smallest numbers of tiles?

[Hint: you may find it easiest to construct your matches backwards from right to left.]

Consider a new set of tiles $\left\{ \left[ \dfrac{\text{XXXXXXX}}{\text{X}} \right], \left[ \dfrac{\text{X}}{\text{XXXXXXXXXX}} \right] \right\}$. (The first tile has seven Xs on top, and the second tile has ten Xs on the bottom.)

**(d)** For which numbers $n$ do there exist matches using $n$ tiles? Briefly justify your answer.

## 解析
QUESTION 7:

(a) [2 marks] A match must begin with $\left[ \frac { \mathsf { U U } } { \mathsf { U } } \right]$

(b) [4 marks] There are two matches including four tiles.

$$
\left[ \begin{array}{c} U U \\ \hline U \end{array} \right] \left[ \begin{array}{c} X \\ \hline U \end{array} \right] \left[ \begin{array}{c} Z \\ \hline X \end{array} \right] \left[ \begin{array}{c} E \\ \hline Z E \end{array} \right]
$$

$$
\left[ \frac {U U}{U} \right] \left[ \frac {Y}{U} \right] \left[ \frac {Z}{Y} \right] \left[ \frac {E}{Z E} \right].
$$

(c) [6 marks] With the new tile, the shortest match consists of three copies of $\left[ \frac { \mathsf { U U } } { \mathsf { U } } \right]$ , followed by a free choice of three tiles from $\left\{ \left[ { \frac { \mathsf { X } } { \mathsf { U } } } \right] , \left[ { \frac { \mathsf { Y } } { \mathsf { U } } } \right] \right\}$ , then three tiles from $\left\{ \left[ { \frac { Z } { X } } \right] , \left[ { \frac { Z } { Y } } \right] \right\}$ (the selection of which is determined by the previous choice), and finally the new tile $\left[ \frac { \mathsf { E } } { { \mathsf { Z Z Z E } } } \right]$

Thus the shortest match involves 10 tiles.

There are $2 ^{3} = 8$ matches of of this length.

(d) [3 marks] A list of x tiles of the first type and y tiles of the second type is a match if $7 x + y = x + 10 y$ , i.e., $2 x = 3 y$

This implies that $y = 2 k$ for some $k > 0$ and $x = 3 k ,$ ., giving $x + y = 5 k$ . So the number of tiles used has to be a multiple of 5.
