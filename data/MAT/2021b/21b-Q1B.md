## 题目
In the expansion of $( x^{2} + x y + y^{2} ) ^{n}$ , where n is a positive whole number, the coefficient of $x^{3} y^{2n-3}$ is

(a) $\binom { n } { 3 }$

(b) ${ \binom { n } { 3 } } \times { \binom { n } { 2 } }$

(c) ${ \binom { n } { 3 } } + 2 \times { \binom { n } { 2 } }$

(d) $2 \times { \binom { n } { 2 } }$

(e) ${ \binom { n } { 3 } } + { \binom { n } { 2 } }$

## 备注

### 我的备注

### AI备注


## 答案
C

## 解析
The first few terms of the binomial expansion of $( ( x^{2} + x y ) + y^{2} ) ^{n}$ are

$$
\binom {n} {0} y^{2n} + \binom {n} {1} (x^{2} + x y) y^{2n-2} + \binom {n} {2} (x^{2} + x y) ^{2} y^{2n-4} + \binom {n} {3} (x^{2} + x y) ^{3} y^{2n-6} + \ldots
$$

The first two terms don't contain any $x^{3} y^{2n-3}$ terms, and any terms after these four must have a factor of $x^{4}$ , so they don't contribute either. We need to think about the expansion of $( x^{2} + x y ) ^{2}$ which includes $2 x^{2} x y$ , and the expansion of $( x^{2} + x y ) ^{3}$ which includes $( x y ) ^{3}$ . So the coefficient is $2 \times { \binom { n } { 2 } } + { \binom { n } { 3 } }$

The answer is (c)
