## 题目
Given that there are positive real numbers $a , b , c$ that satisfy

$$
\int_{a} ^{b} \log_{c} \left(\sin^{4} x \tan^{2} x\right) \mathrm{d} x = 1 \quad \mathrm{and} \quad \int_{a} ^{b} \log_{c} \left(\sin^{2} x \cos^{2} x\right) \mathrm{d} x = 3,
$$

it follows that the value of

$$
\int_{a} ^{b} \log_{c} \left(\sin^{4} x \cos^{2} x\right) \mathrm{d} x
$$

must be equal to

(a) $4,$

(b) $5,$

(c) $6,$

(d) $7,$

(e) $8.$

[Note that $\sin^{4} x$ means $( \sin x ) ^{4} .$ ]

## 答案
A

## 解析
Write

$$
A = \int_{a} ^{b} \log_{c} \sin^{2} x \mathrm{d} x, \quad B = \int_{a} ^{b} \log_{c} \cos^{2} x \mathrm{d} x
$$

The given equations are $3 A - B = 1$ and $A + B = 3$ with solution A = 1, B = 2. The integral we're asked for is $2 A + B$ which is 4.

The answer is (a)
