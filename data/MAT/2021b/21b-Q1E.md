## 题目
The polynomial equation $x^{4} - ( 2 k + 1 ) x^{2} + 2 x + k^{2} - 1 = 0$ has exactly four real solutions x if and only if

(a) $k > 1$

(b) $k > - \dfrac { 5 } { 4 } ,$

(c) $k > { \dfrac { 3 } { 4 } } ,$

(d) $k < - \dfrac { 5 } { 4 } \ \mathrm { o r } \ k > \dfrac { 3 } { 4 } .$

(e) ${ \dfrac { 3 } { 4 } } < k < 1 { \mathrm { ~ o r ~ } } k > 1$

## 答案
E

## 解析
The given polynomial is $( x^{2} - k ) ^{2} - ( x - 1 ) ^{2}$ which can be factorised as

$$
(x^{2} - k - x + 1) (x^{2} - k + x - 1).
$$

The first quadratic has two real roots if and only if $k > 3 / 4$ . The second quadratic has two real roots if and only if $k > - 5 / 4$ . So for four real roots we would need $k > 3 / 4$ . But we need those four roots to be distinct, so we need to check that none of the roots of the first quadratic are also roots of the second quadratic. Equating the quadratics, this happens only if $x = 1$ which is a root if and only if $k = 1$ . So we have exactly four real roots if $3 / 4 < k < 1$ or $k > 1$ but for no other values of k.

The answer is (e)
