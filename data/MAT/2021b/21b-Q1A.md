## 题目
Which of the following expressions has the largest value? Note that all angles are given in degrees.

(a) $\cos(10^{\circ}),$
(b) $\sin(115^{\circ}),$
(c) $\cos(375^{\circ}),$
(d) $\sin(85^{\circ}),$
(e) $\cos(-20^{\circ}).$

## 备注

### 我的备注

### AI备注


## 答案
D

## 解析
We can rewrite each of these to be $\cos ( x )$ for some angle x with $0 < x < 180 ^{\circ}$ . Option (a) is $\cos ( 10 ^{\circ} )$ . Option (b) is $\cos ( 25 ^{\circ} )$ . Option (c) is $\cos ( 15 ^{\circ} )$ . Option (d) is $\cos ( 5 ^{\circ} )$ . Option (e) is $\cos ( 20 ^{\circ} )$ . Now cos(x) is a decreasing function of x between 0 and $180 ^{\circ}$ , so the largest value is $\cos(5^{\circ})$

The answer is (d)
