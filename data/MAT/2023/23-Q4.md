## 题目
For **Oxford applicants** in Mathematics / Mathematics & Statistics / Mathematics & Philosophy, OR those not applying to Oxford, ONLY.

Point A is on the parabola $y = { \textstyle \frac { 1 } { 2 } } x^{2}$ at $( a , { \textstyle \frac { 1 } { 2 } } a^{2} )$ with $a > 0$ . The line L is normal to the parabola at A, and point B lies on L such that the distance $| A B |$ is a fixed positive number $d ,$ with B above and to the left of A.

(i) [6 marks] Find the coordinates of B in terms of a and $d .$

(ii) [4 marks] Show that in order for B to lie on the parabola, we must have

$$
a^{2} d = 2 (1 + a^{2}) ^{3/2}. \qquad (*)
$$

(iii) [2 marks] Let $t = a^{2}$ and express the equality (∗) in the form $d^{2/3} = f ( t )$ for some function $f$ which you should determine explicitly.

(iv) [3 marks] Find the minimum value of $f ( t )$ . Hence show that the equality (∗) holds for some real value of a if and only if d is greater than or equal to some value, which you should identify.

## 解析
(i) The normal at $x = a$ is

$$
y = - \frac {1}{a} (x - a) + \frac {a^{2}}{2}.
$$

Let B have coordinates $( x_{b} , y_{b} )$ . Then the distance from A is d so

$$
(x_{b} - a) ^{2} + \left(y_{b} - \frac {a^{2}}{2}\right) ^{2} = d^{2}
$$

Substitute in the equation of the line and simplify for $\begin{array} { r } { ( x_{b} - a ) ^{2} ( 1 + \frac { 1 } { a^{2} } ) = d^{2} } \end{array}$

B is above and to the left of A and $a > 0$ so $x_{b} < a$

The coordinates of B are therefore

$$
x_{b} = a - \frac {d}{\sqrt {1 + 1 / a^{2}}} = a - \frac {a d}{\sqrt {1 + a^{2}}} \quad \text {and} \quad y_{b} = \frac {a^{2}}{2} + \frac {d}{\sqrt {1 + a^{2}}}
$$

6 marks

(ii) We would need $y_{b} = { \textstyle \frac { 1 } { 2 } } x_{b} ^{2}$ so

$$
\frac {a^{2}}{2} + \frac {L}{\sqrt {1 + a^{2}}} = \frac {1}{2} \left(a - \frac {a d}{\sqrt {1 + a^{2}}}\right) ^{2}
$$

Expand and simplify this to get

$$
\frac {d}{\sqrt {1 + a^{2}}} + \frac {a^{2} d}{\sqrt {1 + a^{2}}} = \frac {a^{2} d^{2}}{2 (1 + a^{2})}
$$

Divide by d and multiply by $2 { \sqrt { 1 + a^{2} } }$

$$
2 (1 + a^{2}) ^{3/2} = a^{2} d.
$$

4 marks

(iii) Divide by $a^{2}$ and raise both sides to the power of $2 / 3$ .

$d^{2/3} = 2^{2/3}(1 + a^{2})/a^{4/3} = f (a^{2})$ where $f (t) = 2^{2/3}(1 + t)/t^{2/3} = 2^{2/3}(t^{-2/3} + t^{1/3})$. 2 marks

(iv) $t^{-2/3} + t^{1/3}$ is minimised where $- { \textstyle \frac { 2 } { 3 } } t^{-5/3} + { \textstyle \frac { 1 } { 3 } } t^{-2/3} = 0 \ { \mathrm { i . e . } } \ t = 2$ . The value of $f ( t )$ there is 3. So if $d < 3 { \sqrt { 3 } }$ then d is lower than the minimum and there's no such value of a. 3 marks
