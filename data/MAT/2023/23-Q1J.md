## 题目
[4 marks] Let ⌊x⌋ denote the largest whole number that is less than or equal to x. For example, $\lfloor - \pi \rfloor = - 4$ . A function $f ( x )$ is defined as follows; if $0 < x < 2$ then

$$
f (x) = \left(\frac {3}{4}\right) ^{\lfloor\log_{2} (x) \rfloor}
$$

and $f ( x ) = 0$ otherwise. Note that, for example, $f \left( { \frac { 1 } { 2 } } \right) = { \frac { 4 } { 3 } } .$ . The value of $\int_{0} ^{2} f ( x ) \mathrm { d } x$ is

(a) $1,$
(b) $2,$
(c) $3,$
(d) $4,$
(e) $5.$

## 备注

### 我的备注

### AI备注

## 答案
C

## 解析
The area under the graph is made up of infinitely many rectangles, each half the width and $4 / 3$ the height of the previous, reading from right-to-left.

![[Image/23-Q1J-sol1.jpg]]

The areas of the rectangles form a geometric progression, so the total area is a geometric series with first term 1 and common ratio $2 / 3$

The answer is (c).
