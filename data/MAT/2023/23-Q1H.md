## 题目
[4 marks] Which of these triangles has the largest area?

(a) an isosceles triangle with side lengths $10$, $10$, $1$;

(b) an isosceles triangle with side lengths $10$, $10$, $5$;

(c) an isosceles triangle with side lengths $10$, $10$, $10$;

(d) an isosceles triangle with side lengths $10$, $10$, $15$;

(e) an isosceles triangle with side lengths $10$, $10$, $19$.

## 备注

### 我的备注

### AI备注

## 答案
D

## 解析
Consider the area formula ${ \scriptstyle { \frac { 1 } { 2 } } } a b \sin\gamma$ with $a = b = 10$ fixed. We would maximise this by making $\sin\gamma$ large, which occurs when $\gamma$ is close to $90^{\circ}$, which is when the opposite side is close to $\sqrt { 2 }$ times the length of the short sides. Note that ${ \sqrt { 2 } } \approx 3 / 2$ because $2 \approx 9 / 4$ , so the triangle with the largest area is the (10, 10, 15) triangle. The answer is (d).
