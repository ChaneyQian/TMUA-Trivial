## 题目
[4 marks] The polynomial $p ( x )$ has degree 3 and has $p ( 0 ) = 0 , p ( 1 ) = 1 , p ( 2 ) = 2$ The polynomial has a repeated root at $x = M$ with $M > 0$ . The value of M is

(a) $\dfrac { 7 } { 6 } ,$
(b) $\dfrac { 6 } { 5 } ,$
(c) $\dfrac { 5 } { 4 } ,$
(d) $\dfrac { 4 } { 3 } ,$
(e) $\dfrac { 3 } { 2 } .$

## 备注

### 我的备注

### AI备注

## 答案
E

## 解析
$p ( x ) = A x ( x - M ) ^{2}$ because 0 is a root and M is a repeated root. Now set $p ( 1 ) = 1$ and $p ( 2 ) = 2$ for

$$
1 = A (1 - M) ^{2} \quad \text { and } \quad 2 = 2 A (2 - M) ^{2}
$$

Eliminate A for the quadratic $( 2 - M ) ^{2} = ( 1 - M ) ^{2}$ . Solve; either $2 - M = 1 - M$ which is nonsense, or $2 - M = M - 1$ , which gives solution $M = 3 / 2$ The answer is (e).
