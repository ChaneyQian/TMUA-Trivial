## 题目
[4 marks] Two circles are inside a square ABCD of side-length 1. One of the circles is tangent to sides AB and to BC. The other circle is tangent to sides CD and DA. The circles are tangent to each other. The area of the larger circle is 10 times the area of the smaller circle. The diagram is not to scale.

![[Image/23-Q1C-fig1.jpg]]

The sum of the radii of the circles is

(a) $\dfrac { 1 + { \sqrt { 10 } } } { 8 } ,$
(b) $2 - { \sqrt { 2 } } ,$
(c) $\dfrac { \sqrt { 2 } } { 2 } ,$
(d) $\sqrt { \dfrac { 2 } { 5 } } ,$
(e) ${ \sqrt { 10 } } - 1 .$

## 备注

### 我的备注

### AI备注

## 答案
B

## 解析
Call the radii $r_{1}$ and $r_{2}$ . Then drawing lines from the centres to the points of tangency and doing some trigonometry reveals that $r_{1} + ( r_{1} + r_{2} ) / \sqrt { 2 } + r_{2} = 1$

![[Image/23-Q1C-sol1.jpg]]

So we can deduce the value of $\begin{array} { r } { r_{1} + r_{2} = \frac { 1 } { 1 + 1 / \sqrt { 2 } } = \frac { \sqrt { 2 } } { \sqrt { 2 } + 1 } = 2 - \sqrt { 2 } } \end{array}$ without actually solving for $r_{1}$ and $r_{2}$ separately. The answer is (b).
