## 题目
[4 marks] The real numbers a, b, and c are non-zero. Each of the following quadratic equations has a repeated real root (not necessarily the same value).

$$
a x^{2} + b x + c = 0, \qquad b x^{2} + c x + a = 0.
$$

How many distinct real roots does the equation $c x^{2} + a x + b = 0$ have?

(a) $0,$
(b) $1,$
(c) $2,$
(d) $3,$
(e) It depends on a.

## 答案
A

## 解析
Given $b^{2} \ = \ 4 a c$ and $c^{2} = 4 a b$ we can multiply for $b^{2} c^{2} = 16 a^{2} b c$ . Since bc $\neq 0$ we have $\textstyle a^{2} = { \frac { 1 } { 16 } } b c .$ . The discriminant of the third quadratic is $a^{2} - 4 b c = - 63 a^{2} < 0$ . So this has no real roots.

Alternatively, solve $b^{2} = 4 a c$ and $c^{2} = 4 a b$ in terms of a (multiply the first by b and the second by c to see that $b^{3} = c^{3} )$ for $b = 4 a$ and $c = 4 a$ . Then $a^{2} - 4 b c = - 63 a^{2}$ is negative. The answer is (a).
