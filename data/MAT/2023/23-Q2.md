## 题目
For **ALL APPLICANTS**.

For n a positive whole number, and for $x \neq 0$ , let $p_{n} ( x ) = x^{n} + x^{-n}$

(i) [3 marks] Sketch the graph of $y = p_{1} ( x )$ . Label any turning points on your sketch.

(ii) [1 mark] Show that $p_{2} ( x ) = p_{1} ( x ) ^{2} - 2$

(iii) [1 mark] Find an expression for $p_{3} ( x )$ in terms of $p_{1} ( x )$

(iv) [5 marks] Find all real solutions x to the equation

$$
x^{4} + x^{3} - 10 x^{2} + x + 1 = 0.
$$

(v) [5 marks] Find all real solutions x to the equation

$$
x^{7} + 2 x^{6} - 5 x^{5} - 7 x^{4} + 7 x^{3} + 5 x^{2} - 2 x - 1 = 0.
$$

## 解析
(i) Sketch $p_{1} ( x ) = x + 1 / x$

![[Image/23-Q2-sol1.jpg]]

Turning points are at $1 - x^{-2} = 0 \mathrm { \ s o \ } x = \pm 1$ . Corresponding values of $y$ are $\pm 2$ respectively.

3 marks

(ii) We have $p_{1} ( x ) ^{2} - 2 = ( x + x^{-1} ) ^{2} - 2 = x^{2} + 2 + x^{-2} - 2 = p_{2} ( x )$

1 mark

(iii) We have $p_{1} ( x ) ^{3} = x^{3} + 3 x + 3 x^{-1} + x^{-3} = p_{3} ( x ) + 3 p_{1} ( x ) \mathrm { ~ s o ~ } p_{3} ( x ) = p_{1} ( x ) ^{3} - 3 p_{1} ( x ) .$

1 mark

(iv) x isn't zero, so divide by $x^{2}$ . Then the left-hand side becomes $p_{2} ( x ) + p_{1} ( x ) - 10$ which is $p_{1} ( x ) ^{2} + p_{1} ( x ) - 12$ . That's a quadratic for $p_{1} ( x )$ which factorises as $( p_{1} ( x ) - 3 ) ( p_{1} ( x ) + 4 ) = 0$ so $p_{1} ( x ) = 3 ~ \mathrm { o r } ~ p_{1} ( x ) = - 4$ . Each of those is a quadratic for $x ;$ we have

$$
x^{2} - 3 x + 1 = 0 \qquad \mathrm{or} \qquad x^{2} + 4 x + 1 = 0
$$

The solutions are $\textstyle x = { \frac { 3 \pm { \sqrt { 5 } } } { 2 } } { \mathrm { ~ o r ~ } } x = - 2 \pm { \sqrt { 3 } } .$

5 marks

(v) First note that $x = 1$ is a solution, and divide by $( x - 1 )$

Now adapt the work in the previous part; divide by $x^{3}$ to get $p_{3} ( x ) + 3 p_{2} ( x ) - 2 p_{1} ( x ) - 9 = 0 \quad$ Now write this in terms of $p_{1} ( x )$ using part (ii) and factorise;

$$
\begin{array}{r l} & p_{3} (x) + 3 p_{2} (x) - 2 p_{1} (x) - 9 = p_{1} (x) ^{3} - 3 p_{1} (x) + 3 p_{1} (x) ^{2} - 6 - 2 p_{1} (x) - 9 \\ & \qquad = p_{1} (x) ^{3} + 3 p_{1} (x) ^{2} - 5 p_{1} (x) - 15 \\ & \qquad = (p_{1} (x) + 3) (p_{1} (x) ^{2} - 5) \\ & \qquad = (p_{1} (x) + 3) (p_{1} (x) - \sqrt {5}) (p_{1} (x) + \sqrt {5}) \end{array}
$$

Solve $p_{1} ( x ) = - 3$ for $\textstyle x = { \frac { - 3 \pm { \sqrt { 5 } } } { 2 } }$ , solve $p_{1} ( x ) = \sqrt { 5 }$ for $\textstyle { \frac { { \sqrt { 5 } } \pm 1 } { 2 } }$ , and solve $\begin{array} { r } { p_{1} ( x ) = - \sqrt { 5 } \mathrm { ~ f o r ~ } \frac { - \sqrt { 5 } \pm 1 } { 2 } } \end{array}$ 5 marks
