## 题目
[4 marks] How many distinct real solutions x are there to the equation $\left( \left( \left( x^{2} - 1 \right) ^{2} - 2 \right) ^{2} - 3 \right) ^{2} = 4$ ?

(a) $5,$
(b) $6,$
(c) $7,$
(d) $8,$
(e) $9.$

## 答案
C

## 解析
Work from the outside inwards

$$
\begin{array}{r l} ((x^{2} - 1) ^{2} - 2) ^{2} - 3 = & 2 \quad \mathrm{or} \quad - 2 \\ ((x^{2} - 1) ^{2} - 2) ^{2} = & 5 \quad \mathrm{or} \quad 1 \\ (x^{2} - 1) ^{2} - 2 = & \sqrt {5} \quad \mathrm{or} \quad - \sqrt {5} \quad \mathrm{or} \quad - 1 \quad \mathrm{or} \quad 1 \\ (x^{2} - 1) ^{2} = & 2 + \sqrt {5} \quad \mathrm{or} \quad 2 - \sqrt {5} \quad \mathrm{or} \quad 1 \quad \mathrm{or} \quad 3 \\ x^{2} - 1 = & \sqrt {2 + \sqrt {5}} \quad \mathrm{or} \quad - \sqrt {2 + \sqrt {5}} \quad \mathrm{or} \quad 1 \quad \mathrm{or} \quad - 1 \quad \mathrm{or} \quad \sqrt {3} \quad \mathrm{or} \quad - \sqrt {3} \\ x^{2} = & 1 + \sqrt {2 + \sqrt {5}} \quad \mathrm{or} \quad 1 - \sqrt {2 + \sqrt {5}} \quad \mathrm{or} \quad 2 \quad \mathrm{or} \quad 0 \quad \mathrm{or} \quad 1 + \sqrt {3} \quad \mathrm{or} \quad 1 - \sqrt {3} \end{array}
$$

Where we have used the fact that $2 - { \sqrt { 5 } } < 0$ . Now note that ${ \sqrt { 2 + { \sqrt { 5 } } } } > { \sqrt { 2 } } > 1$ so $1 - { \sqrt { 2 + { \sqrt { 5 } } } }$ is (very) negative. Also, $1 - { \sqrt { 3 } }$ is negative. The number of real solutions is therefore seven; two from each positive value of $x^{2}$ and one from the zero solution. The answer is (c).
