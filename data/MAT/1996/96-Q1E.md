## 题目
If $|x - 3| < 1$ and $|x - 1| > 2$, then:

(i) $-1 < x < 4$; (ii) $3 < x < 4$; (iii) $2 < x < 3$; (iv) $2 < x < 4$.

## 备注

### 我的备注

### AI备注


## 答案
(ii)

## 解析
The first inequality $|x - 3| < 1$ is equivalent to

$$2 < x < 4$$

The second inequality $|x - 1| > 2$ is equivalent to $x - 1 > 2$ or $x - 1 < -2$, which gives

$$x > 3 \quad \text{or} \quad x < -1$$

The values of $x$ satisfying both inequalities must lie in the intersection of these two sets, which is $3 < x < 4$. The answer is (ii).
