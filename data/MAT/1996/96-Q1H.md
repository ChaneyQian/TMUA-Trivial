## 题目
The derivative of the function $y = (\mathrm{e}^{\cos (5x)})^2$ is:

(i) $-5\sin (5x)(\mathrm{e}^{\cos (5x)})^2$;
(ii) $-20\sin (5x)\cos (5x)(\mathrm{e}^{\cos (5x)})^2$;
(iii) $-10\sin (5x)(\mathrm{e}^{\cos (5x)})^2$;
(iv) $-10\sin (5x)\cos (5x)(\mathrm{e}^{\cos (5x)})^2$.

## 备注

### 我的备注

### AI备注


## 答案
(iii)

## 解析
We can simplify the function using exponent rules to

$$y = \mathrm{e}^{2\cos (5x)}$$

Using the chain rule, the derivative is

$$\frac{\mathrm{d}y}{\mathrm{d}x} = \mathrm{e}^{2\cos (5x)} \cdot \frac{\mathrm{d}}{\mathrm{d}x}(2\cos (5x))$$

This evaluates to $-10\sin(5x)\mathrm{e}^{2\cos (5x)}$, which is equivalent to $-10\sin(5x)(\mathrm{e}^{\cos (5x)})^2$. The answer is (iii).
