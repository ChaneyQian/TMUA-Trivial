## 题目
The complete set of solutions of the equation $\sin 2x = \cos x$ in the range $0 \leq x \leq 2\pi$ is:

(i) $\{\pi/2, 3\pi/2\}$; (ii) $\{\pi/6, 5\pi/6\}$; (iii) $\{\pi/6, \pi/2\}$; (iv) $\{\pi/6, \pi/2, 5\pi/6, 3\pi/2\}$.

## 备注

### 我的备注

### AI备注


## 答案
(iv)

## 解析
Using the double angle formula $\sin 2x = 2\sin x \cos x$, the equation becomes

$$2\sin x \cos x - \cos x = 0$$

Factoring out $\cos x$ gives

$$\cos x(2\sin x - 1) = 0$$

This yields $\cos x = 0$ or $\sin x = \frac{1}{2}$. In the range $0 \leq x \leq 2\pi$, $\cos x = 0$ gives $x = \frac{\pi}{2}, \frac{3\pi}{2}$, while $\sin x = \frac{1}{2}$ gives $x = \frac{\pi}{6}, \frac{5\pi}{6}$. The set of all solutions is therefore $\{\frac{\pi}{6}, \frac{\pi}{2}, \frac{5\pi}{6}, \frac{3\pi}{2}\}$. The answer is (iv).
