## 题目
**(a)**

Factorise the expression $x^2 + x - 6$.

**(b)**

For which values of the real constant $a$ does the equation

$$
x^2 + x - a = 0
$$

have at least one real solution? Write down these solutions in terms of $a$.

**(c)**

Show that, for any value of the real constant $b$, the equation

$$
x^3 - (b + 1)x + b = 0
$$

has $x = 1$ as a solution. Find all values of $b$ for which this equation has exactly two distinct solutions.

## 解析
**(a)** Two numbers with product $-6$ and sum $1$ are $3$ and $-2$, so

$$x^2 + x - 6 = (x+3)(x-2).$$

**(b)** The equation $x^2 + x - a = 0$ has discriminant

$$\Delta = 1^2 - 4(1)(-a) = 1 + 4a,$$

and there is at least one real solution exactly when $\Delta \geqslant 0$, that is when

$$a \geqslant -\frac{1}{4}.$$

For such $a$ the solutions are

$$x = \frac{-1 \pm \sqrt{1+4a}}{2}.$$

(When $a = -\frac14$ these coincide at $x = -\frac12$.)

**(c)** Substituting $x = 1$ into the cubic gives

$$1 - (b+1) + b = 1 - b - 1 + b = 0,$$

so $x = 1$ is a solution whatever the value of $b$. Hence $x - 1$ is a factor, and dividing out,

$$x^3 - (b+1)x + b = (x-1)\left(x^2 + x - b\right).$$

(Expanding the right-hand side confirms this.) The remaining solutions are the roots of $x^2 + x - b = 0$, whose discriminant is $1 + 4b$. The cubic has **exactly two distinct real solutions** in precisely two situations.

* The quadratic has a repeated root, distinct from $1$. This needs $1 + 4b = 0$, so $b = -\frac{1}{4}$; the repeated root is $x = -\frac12 \neq 1$, and the solution set is $\{1, -\frac12\}$.
* The quadratic has two distinct roots, one of which is $1$. Putting $x=1$ into $x^2 + x - b$ gives $2 - b = 0$, so $b = 2$; then $x^2 + x - 2 = (x-1)(x+2)$ and the solution set is $\{1, -2\}$.

(If $1 + 4b < 0$ the quadratic has no real roots and $x=1$ is the only solution, so that case is excluded.) Therefore

$$b = -\frac{1}{4} \qquad \text{or} \qquad b = 2.$$
