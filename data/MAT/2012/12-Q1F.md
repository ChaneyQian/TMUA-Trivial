## 题目
Let

$$
T = \left(\int_{-\pi/2} ^{\pi/2} \cos x \mathrm{d} x\right) \times \left(\int_{\pi} ^{2\pi} \sin x \mathrm{d} x\right) \times \left(\int_{0} ^{\pi/8} \frac {\mathrm{d} x}{\cos 3 x}\right).
$$

Which of the following is true?

(a) $T = 0 ;$
(b) $T < 0 ;$
(c) $T > 0 ;$
(d) $T$ is not defined.

## 备注

### 我的备注

### AI备注

## 答案
B

## 解析
None of the integrals needs to be calculated. We need only note

$$
\begin{array}{r l} \int_{-\pi/2} ^{\pi/2} \cos x \mathrm{d} x & > 0 \quad \text {as} \cos x > 0 \text {for} - \frac {\pi}{2} <   x <   \frac {\pi}{2}; \\ \int_{\pi} ^{2\pi} \sin x \mathrm{d} x & <   0 \quad \text {as} \sin x <   0 \text {for} \pi <   x <   2 \pi ; \end{array}
$$

and

$\int_{0} ^{\pi/8} { \frac { \mathrm { d } x } { \cos 3 x } }$ is defined and positive as cos $3 x > \cos { \frac { 3 \pi } { 8 } } > 0 { \mathrm { ~ f o r ~ } } 0 < 3 x < { \frac { 3 \pi } { 8 } } ;$

The product of two positive numbers and a negative one is negative. The answer is (b).
