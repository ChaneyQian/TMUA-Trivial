## 题目
Which is the smallest of the following numbers?

(a) $\left( { \sqrt { 3 } } \right) ^{3} ,$
(b) $\log_{3} \left( 9 ^{2} \right) ,$
(c) $\left( 3 \sin { \dfrac { \pi } { 3 } } \right) ^{2} ,$
(d) $\log_{2} { \left( \log_{2} { \left( 8 ^{5} \right) } \right) } .$

## 备注

### 我的备注

### AI备注

## 答案
D

## 解析
Note that $\log_{3} { ( 9 ^{2} ) } = 2 \log_{3} { 9 } = 4$ . By comparison with this number

$$
\left(\sqrt {3}\right) ^{3} = 3 \sqrt {3} > 4 \quad \text {   as   on   squaring   } 27 > 16;
$$

$$
\left(3 \sin {\frac {\pi}{3}}\right) ^{2} = \left(\frac {3 \sqrt {3}}{2}\right) ^{2} = \frac {27}{4} > 4;
$$

$$
\log_{2} \left(\log_{2} \left(8 ^{5}\right)\right) = \log_{2} (5 \log_{2} 8) = \log_{2} 15 <   \log_{2} 16 = 4.
$$

The answer is (d).
