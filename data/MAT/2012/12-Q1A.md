## 题目
Which of the following lines is a tangent to the circle with equation

$$
x^{2} + y^{2} = 4?
$$

(a) $x + y = 2 ;$
(b) $y = x - 2 { \sqrt { 2 } } ;$
(c) $x = { \sqrt { 2 } } ;$
(d) $y = { \sqrt { 2 } } - x .$

## 备注

### 我的备注

### AI备注

## 答案
B

## 解析
One can proceed by elimination. Point (1, 1) lies on line (a) and is clearly inside the given circle. $( \sqrt { 2 } , 0 )$ lies on both lines (c) and (d) which is again inside the given circle. The answer is (b).
