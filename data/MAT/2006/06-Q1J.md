## 题目
**For ALL APPLICANTS.**

The two circles with equations
$$
x^{2} + y^{2} = 1, \qquad (x - a)^{2} + (y - b)^{2} = r^{2}
$$
(where $r > 0$) do **not** intersect if
(a) $\sqrt{a^{2} + b^{2}} + r < 1$, (and only this part),
(b) $\sqrt{a^{2} + b^{2}} + 1 < r$, (and only this part),
(c) $\sqrt{a^{2} + b^{2}} - r > 1$, (and only this part),
(d) all of the above.
