## 题目
**For ALL APPLICANTS.**

The cubic
$$
x^{3} + ax + b
$$
has both $(x - 1)$ and $(x - 2)$ as factors. Then
(a) $a = -7$ and $b = 6$,
(b) $a = -3$ and $b = 2$,
(c) $a = 0$ and $b = -2$,
(d) $a = 5$ and $b = 4$.

## 备注

### 我的备注

### AI备注


## 答案
A

## 解析
Let $P(x) = x^{3} + ax + b$. By the Factor Theorem, if $(x - 1)$ and $(x - 2)$ are factors of $P(x)$, then $P(1) = 0$ and $P(2) = 0$.
Substituting $x = 1$:
$$1^{3} + a(1) + b = 0 \implies a + b = -1$$
Substituting $x = 2$:
$$2^{3} + a(2) + b = 0 \implies 2a + b = -8$$
We have a system of two linear equations:
1. $a + b = -1$
2. $2a + b = -8$

Subtracting the first equation from the second gives:
$a = -7$
Substituting $a = -7$ into the first equation:
$-7 + b = -1 \implies b = 6$
The answer is (a).
