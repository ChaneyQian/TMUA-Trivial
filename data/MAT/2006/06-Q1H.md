## 题目
**For ALL APPLICANTS.**

How many solutions does the equation
$$
2 = \sin x + \sin^{2} x + \sin^{3} x + \sin^{4} x + \dots
$$
have in the range $0 \leqslant x < 2\pi$?
(a) $0$
(b) $1$
(c) $2$
(d) $3$

### 我的备注

### AI备注


## 答案
C

## 解析
The right-hand side is an infinite geometric series with first term $a = \sin x$ and common ratio $r = \sin x$. The sum of this infinite series converges if and only if $|r| = |\sin x| < 1$. Under this condition, the sum is given by $\frac{a}{1 - r}$, so the equation becomes:
$$2 = \frac{\sin x}{1 - \sin x}$$

Solving for $\sin x$:
$$2(1 - \sin x) = \sin x \implies 2 - 2\sin x = \sin x \implies 3\sin x = 2 \implies \sin x = \frac{2}{3}$$

We verify that $|\frac{2}{3}| < 1$, so the series converges. In the range $0 \leqslant x < 2\pi$, the sine function takes the positive value $\frac{2}{3}$ exactly twice (once in the first quadrant and once in the second quadrant). Thus, there are $2$ solutions. The answer is (c).
