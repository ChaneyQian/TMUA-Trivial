## 题目
**For ALL APPLICANTS.**

The inequality
$$
\frac{x^{2} + 1}{x^{2} - 1} < 1
$$
is true:
(a) for no values of $x$,
(b) whenever $-1 < x < 1$,
(c) whenever $x > 1$,
(d) for all values of $x$.

## 备注

### 我的备注

### AI备注


## 答案
B

## 解析
We subtract $1$ from both sides to analyze the inequality:
$$\frac{x^{2} + 1}{x^{2} - 1} - 1 < 0$$
Finding a common denominator:
$$\frac{x^{2} + 1 - (x^{2} - 1)}{x^{2} - 1} < 0 \implies \frac{2}{x^{2} - 1} < 0$$

Since the numerator $2$ is strictly positive, the fraction is negative if and only if the denominator is strictly negative:
$$x^{2} - 1 < 0 \implies x^{2} < 1 \implies -1 < x < 1$$
The inequality holds whenever $-1 < x < 1$. The answer is (b).
