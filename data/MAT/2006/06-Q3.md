Let
$$
f(x) = x^{3} - 3x^{2} + 2x.
$$

**(a)**

On the axes below, sketch the curve $y = f(x)$ for the range $-1 < x < 3$, carefully labelling any turning points.

![[Image/06-Q3-fig1.jpg]]

**(b)**

The equation $f(x) = k$ has exactly one positive solution and exactly one negative solution. Find $k$.

**(c)**

For $x$ in the range $0 \leqslant x \leqslant 2$ the functions $g(x)$ and $h(x)$ are defined by
$$
\begin{aligned}
g(x) &= \int_{0}^{x} f(t)\,\mathrm{d}t \\
h(x) &= \int_{0}^{x} |f(t)|\,\mathrm{d}t.
\end{aligned}
$$
Find the value $X_{1}$ of $x$ in the range $0 \leqslant x \leqslant 2$ for which $g(x)$ is greatest.

Calculate $g(X_{1})$.

**(d)**

Find the value $X_{2}$ of $x$ in the range $0 \leqslant x \leqslant 2$ for which $h(x)$ is greatest. [You are not asked to calculate $h(X_{2})$.]

## 解析
**(a)** Factorising, $f(x) = x(x-1)(x-2)$, so the curve crosses the $x$-axis at $x=0,1,2$. Differentiating,

$$f'(x) = 3x^2-6x+2 = 0 \implies x = 1 \pm \frac{1}{\sqrt3}.$$

Writing $t = \dfrac{1}{\sqrt3}$ and using the factorised form,

$$f(1-t) = (1-t)(-t)(-1-t) = t\left(1-t^2\right) = t - t^3, \qquad f(1+t) = (1+t)(t)(t-1) = t^3-t,$$

so with $t^3 = \dfrac{1}{3\sqrt3}$ the turning points are

$$\left(1-\frac{1}{\sqrt3},\; \frac{2\sqrt3}{9}\right) \approx (0.42,\, 0.38) \quad\text{(maximum)}, \qquad \left(1+\frac{1}{\sqrt3},\; -\frac{2\sqrt3}{9}\right) \approx (1.58,\, -0.38) \quad\text{(minimum)}.$$

On $-1 < x < 3$ the curve rises from below, peaks at the first turning point, dips to the second, and then climbs steeply.

**(b)** For $x < 0$ all three factors $x$, $x-1$, $x-2$ are negative, so $f(x) < 0$; and $f$ is increasing on $(-\infty, 1-t)$, so it takes each negative value exactly once for $x<0$. Hence there is exactly one negative solution precisely when $k < 0$, and no negative solution when $k \geqslant 0$.

Now count the positive solutions when $k<0$. On $(0, 1-t)$ the values of $f$ are positive, so there are none there. On $\left[1-t, 1+t\right]$, $f$ decreases from $\tfrac{2\sqrt3}{9}$ to $-\tfrac{2\sqrt3}{9}$, and on $\left[1+t,\infty\right)$ it increases from $-\tfrac{2\sqrt3}{9}$ to $\infty$. So for $-\tfrac{2\sqrt3}{9} < k < 0$ there are **two** positive solutions, one on each of these stretches; for $k < -\tfrac{2\sqrt3}{9}$ there are **none**, as $k$ is below the minimum value; and for

$$k = -\frac{2\sqrt3}{9}$$

the two merge into the single solution $x = 1 + \tfrac{1}{\sqrt3}$. This is therefore the only value of $k$ giving exactly one positive and exactly one negative solution:

$$k = -\frac{2\sqrt3}{9} = -\frac{2}{3\sqrt3}.$$

**(c)** Integrating,

$$g(x) = \int_0^x \left(t^3-3t^2+2t\right)\mathrm{d}t = \frac{x^4}{4} - x^3 + x^2 .$$

Since $g'(x) = f(x) = x(x-1)(x-2)$, on $0 \leqslant x \leqslant 2$ we have $g' \geqslant 0$ for $0 \leqslant x \leqslant 1$ and $g' \leqslant 0$ for $1 \leqslant x \leqslant 2$. So $g$ increases then decreases, and is greatest at

$$X_1 = 1, \qquad g(X_1) = \frac14 - 1 + 1 = \frac14.$$

**(d)** Here $h'(x) = |f(x)| \geqslant 0$ for all $x$, so $h$ is non-decreasing on $0 \leqslant x \leqslant 2$ (and strictly increasing except at the isolated points $x=0,1,2$). Its greatest value on the range is therefore attained at the right-hand end:

$$X_2 = 2.$$
