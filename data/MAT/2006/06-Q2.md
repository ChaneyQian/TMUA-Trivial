## 题目
**For ALL APPLICANTS.**

The real numbers $x$ and $y$ satisfy the equation
$$
x^{2} + xy + y^{2} = 1. \tag{1}
$$

**(a)**

If $y = 1$ then find the possible values of $x$.

**(b)**

For what values of $y$ are there two possible (real) values of $x$?

**(c)**

Find the largest possible value of $y$ which satisfies (1) and the corresponding value of $x$.

**(d)**

Show that, for all values of $\theta$, the numbers
$$
\begin{aligned}
x &= \frac{1}{\sqrt{3}}\cos\theta + \sin\theta, \\
y &= \frac{1}{\sqrt{3}}\cos\theta - \sin\theta,
\end{aligned}
$$
satisfy the equation (1).

## 解析
**(a)** Putting $y = 1$ into (1),

$$x^2 + x + 1 = 1 \implies x^2 + x = 0 \implies x(x+1) = 0,$$

so $x = 0$ or $x = -1$.

**(b)** Regard (1) as a quadratic in $x$ with $y$ as a parameter:

$$x^2 + yx + \left(y^2-1\right) = 0.$$

Its discriminant is

$$y^2 - 4\left(y^2-1\right) = 4 - 3y^2,$$

and there are two distinct real values of $x$ exactly when this is strictly positive, i.e. when

$$y^2 < \frac43, \qquad \text{that is} \qquad -\frac{2}{\sqrt3} < y < \frac{2}{\sqrt3}.$$

**(c)** A real $x$ exists exactly when $4 - 3y^2 \geqslant 0$, i.e. $|y| \leqslant \dfrac{2}{\sqrt3}$. So the largest possible value is

$$y = \frac{2}{\sqrt3} = \frac{2\sqrt3}{3}.$$

At that value the discriminant is zero, so there is a single (repeated) root

$$x = -\frac{y}{2} = -\frac{1}{\sqrt3} = -\frac{\sqrt3}{3}.$$

(Check: $\tfrac13 - \tfrac23 + \tfrac43 = 1$.)

**(d)** Note the identity

$$x^2 + xy + y^2 = \frac34 (x+y)^2 + \frac14 (x-y)^2,$$

which is checked by expanding: the $x^2$ and $y^2$ terms give $\tfrac34+\tfrac14 = 1$ each, and the $xy$ terms give $\tfrac32 - \tfrac12 = 1$.

For the given $x$ and $y$,

$$x + y = \frac{2}{\sqrt3}\cos\theta, \qquad x - y = 2\sin\theta,$$

so

$$x^2+xy+y^2 = \frac34 \cdot \frac43\cos^2\theta + \frac14 \cdot 4\sin^2\theta = \cos^2\theta + \sin^2\theta = 1.$$

Hence (1) is satisfied for every value of $\theta$.
