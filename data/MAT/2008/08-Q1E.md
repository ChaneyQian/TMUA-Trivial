## 题目
The highest power of $x$ in

$$
\left. \right.\left\{\left[ (2 x^{6} + 7) ^{3} + (3 x^{8} - 12) ^{4} \right] ^{5} + \left[ (3 x^{5} - 12 x^{2}) ^{5} + (x^{7} + 6) ^{4} \right] ^{6} \right\} ^{3}
$$

is

(a) $x^{424} ,$
(b) $x^{450} .$
(c) $x^{500} { \mathrm { . } }$
(d) $x^{504} .$

## 答案
D

## 解析
The highest power of x in $\left( 2 x^{6} + 7 \right) ^{3}$ is $x^{18}$ and in $\left( 3 x^{8} - 12 \right) ^{4}$ is $x^{32}$ so the highest power in $[ \cdot \cdot \cdot ] ^{5} { \mathrm { ~ i s ~ } } ( x^{32} ) ^{5} = x^{160}$ . The highest power of x in $( 3 x^{5} - 12 x^{2} ) ^{5} { \mathrm { ~ i s ~ } } x^{25}$ and in $\bar { ( x^{7} + 6 ) ^{4} }$ is $x^{28}$ so that the highest power of x in $[ \ldots ] ^{6}$ is $\left( x^{28} \right) ^{6} = \dot { x } ^{168}$ . Thus the highest power of x in $\left\{ \ldots \right\} ^{3}$ is $\left( x^{168} \right) ^{3} = x^{504}$ . The answer is (d).
