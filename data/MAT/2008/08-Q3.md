## 解析
3. (i) [3 marks] (A) is -f (x) ; (B) is f (-x) ; (C) is $f \left( x - 1 \right)$

(ii) [9 marks] As $2 ^{2x-x^{2} } = 2 \times 2 ^{-\left(x-1\right)^{2} }$ then the graph of $y = 2 ^{2x-x^{2} }$ is the graph of $y = 2 ^{-x^{2} }$ translated to the right by 1 and stretched parallel to the y-axis by a factor of 2.

![[Image/08-Q3-sol1.jpg]]

(iii) [3 marks] $\begin{array} { r } { c = \frac { 1 } { 2 } } \end{array}$ . The graph of $2 ^{-(x-c)^{2} }$ is the graph of $2 ^{-x^{2} }$ translated c to the right. The integral I (c) represents the area under the graph between $0 \leqslant x \leqslant 1$ . As the graph is symmetric/even and decreasing away from 0 then this area is maximised by having the apex half way along the interval $0 \leqslant x \leqslant 1$ , i.e. at $x = 1 / 2$ which occurs when $\begin{array} { r } { c = \frac { 1 } { 2 } } \end{array}$
