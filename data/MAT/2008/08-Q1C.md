## 题目
The simultaneous equations in $x , y ,$

$$
(\cos \theta) x - (\sin \theta) y = 2
$$

$$
(\sin \theta) x + (\cos \theta) y = 1
$$

are solvable

(a) for all values of $\theta$ in the range $0 \leqslant \theta < 2 \pi$ ;
(b) except for one value of $\theta$ in the range $0 \leqslant \theta < 2 \pi ;$
(c) except for two values of $\theta$ in the range $0 \leqslant \theta < 2 \pi$ ;
(d) except for three values of $\theta$ in the range $0 \leqslant \theta < 2 \pi$ .

## 备注

### 我的备注

### AI备注

## 答案
A

## 解析
We will write $c = \cos \theta$ and $s = \sin { \theta }$ for ease of notation. Eliminating y from the simultaneous equations

$$
c x - s y = 2, \qquad s x + c y = 1;
$$

we get

$$
2 c + s = c (c x - s y) + s (s x + c y) = \left(c^{2} + s^{2}\right) x = x
$$

and similarly eliminating x we find

$$
c - 2 s = (- s) (c x - s y) + c (s x + c y) = \left(s^{2} + c^{2}\right) y = y.
$$

Hence the equations care solvable for any value of $\theta$. The answer is (a).
