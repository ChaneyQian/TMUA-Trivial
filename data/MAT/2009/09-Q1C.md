## 题目
Given a real constant c, the equation

$$
x^{4} = (x - c) ^{2}
$$

has four real solutions (including possible repeated roots) for

(a) $c \leqslant \dfrac { 1 } { 4 } ,$
(b) $- \dfrac { 1 } { 4 } \leqslant c \leqslant \dfrac { 1 } { 4 } ,$
(c) $c \leqslant - \dfrac { 1 } { 4 } ,$
(d) all values of $c.$

## 备注

### 我的备注

### AI备注

## 答案
B

## 解析
Taking square roots of both sides of $x^{4} = \left( x - c \right) ^{2}$ , we see

$$
x^{2} = x - c, \qquad \mathrm{or} \qquad x^{2} = c - x.
$$

The first quadratic has discriminant 1 − 4c and the second quadratic has discriminant $1 + 4 c .$ In order that the original equation has four real solutions both of these quadratic must have two real solutions and so nonnegative discriminants. Hence $c \leqslant 1 / 4$ and $c \geqslant - 1 / 4$ . The answer is (b).
