## 题目
When the trapezium rule is used to estimate the integral

$$
\int_{0} ^{1} 2 ^{x} \mathrm{d} x
$$

by dividing the interval $0 \leqslant x \leqslant 1$ into N subintervals the answer achieved is

(a) $\dfrac { 1 } { 2 N } \left\{ 1 + \dfrac { 1 } { 2 ^{1/N} + 1 } \right\},$
(b) $\dfrac {1}{2 N} \left\{1 + \dfrac {2}{2 ^{1/N} - 1} \right\},$
(c) $\dfrac { 1 } { N } \left\{ 1 - \dfrac { 1 } { ( 2 ^{1/N} - 1 ) } \right\},$
(d) $\dfrac { 1 } { 2 N } \left\{ \dfrac { 5 } { 2 ^{1/N} + 1 } - 1 \right\}.$

### 我的备注

### AI备注

## 答案
B

## 解析
Using the trapezium rule with N subintervals to calculate $\textstyle \int_{0} ^{1} 2 ^{x}$ dx we get

$$
\begin{array}{r l} & {\frac {h}{2} \left[ y_{0} + 2 y_{1} + \dots + 2 y_{N-1} + y_{N} \right]} \\ {=} & {\frac {1}{2 N} \left[ 1 + 2 \times 2 ^{1/N} + \dots + 2 ^{(N-1)/N} + 2 \right]} \\ {=} & {\frac {1}{2 N} \left[ 2 \left(1 + 2 ^{1/N} + \dots + 2 ^{(N-1)/N}\right) + 1 \right]} \\ {=} & {\frac {1}{2 N} \left[ \frac {2 \left(\left(2 ^{1/N}\right) ^{N} - 1\right)}{2 ^{1/N} - 1} + 1 \right]} \\ {=} & {\frac {1}{2 N} \left\{1 + \frac {2}{2 ^{1/N} - 1} \right\}.} \end{array}
$$

The answer is (b).
