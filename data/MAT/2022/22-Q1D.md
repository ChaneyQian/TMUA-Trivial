## 题目
A sequence has $a_{0}=3$ , and then for $n\geqslant1$ the sequence satisfies $a_{n}=8(a_{n-1})^{4}$ . The value of $a_{10}$ is

(a) $\dfrac{2^{(2^{20})}}{3},$
(b) $\dfrac{6^{(2^{20})}}{3},$
(c) $\dfrac{3^{(2^{20})}}{2},$
(d) $\dfrac{18^{(2^{20})}}{2},$
(e) $\dfrac{6^{(2^{20})}}{2}.$

## 备注

### 我的备注

### AI备注

## 答案
E

## 解析
$a_{1} = 8 \times ( 3 ) ^{4}$ and $a_{2} = 8 ( 8 \times 3 ^{4} ) ^{4} = 8 \times 8 ^{4} \times ( 3 ^{4} ) ^{4}$ and $a_{3} = 8 \times { ( 8 \times 8 ^{4} \times ( 3 ^{4} ) ^{4} ) } ^{4}$ . In a similar way,

$$
a_{n} = 8 \times 8 ^{4} \times 8 ^{16} \times \dots \times 8 ^{4^{n-1}} \times 3 ^{(4^{n})}
$$

The exponent on the 8s is $1 + 4 + 16 + \cdot \cdot \cdot + 4 ^{n-1} = { \textstyle { \frac { 1 } { 3 } } } \left( 4 ^{n} - 1 \right)$ . Then $8 ^{1/3} = 2$ . Also use $4 ^{n} = 2 ^{2n}$

$$
a_{n} = 2 ^{2^{2n} - 1} 3 ^{(2^{2n})} = \frac {6 ^{2^{2n}}}{2}
$$

So for $n = 10$ we get $\scriptstyle { \frac { 1 } { 2 } } 6 ^{(2^{20} ) }$

The answer is (e).
