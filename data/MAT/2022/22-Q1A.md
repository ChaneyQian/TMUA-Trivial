## 题目
How many real solutions $x$ are there to the equation $x|x| + 1 = 3|x|$?

(a) $0,$
(b) $1,$
(c) $2,$
(d) $3,$
(e) $4.$

[Note that $|x|$ is equal to $x$ if $x \geqslant 0$ , and equal to $-x$ otherwise.]

## 答案
D

## 解析
Either $x \geq 0$ and $x^{2} + 1 = 3 x$ or $x < 0$ and $- x^{2} + 1 = - 3 x$ . The first equation has solutions ${ \begin{array} { l } { { \frac { 1 } { 2 } } } \end{array} } ( 3 \pm { \sqrt { 5 } } )$ which are both positive. The second equation has solutions ${ \bar { \frac { 1 } { 2 } } } ( 3 \pm { \sqrt { 13 } } )$ and only one of these is actually negative. So there are three solutions in total.

The answer is (d).
