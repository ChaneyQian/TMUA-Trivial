## 题目
The four digit number $2652$ is such that any two consecutive digits from it make a multiple of $13$. Another number $N$ has this same property, is $100$ digits long, and begins in a $9$. What is the last digit of $N$?
(a) $2$
(b) $3$
(c) $6$
(d) $9$

## 答案
D

## 解析
We are looking for pairs of digits that form two-digit multiples of $13$. The two-digit multiples of $13$ are:
$13, 26, 39, 52, 65, 78, 91$
We are building a sequence of digits where each overlapping pair must be in this list. The number $N$ begins with the digit $9$.
- If the current digit is $9$, the next digit must be $1$ (to form $91$).
- If the current digit is $1$, the next digit must be $3$ (to form $13$).
- If the current digit is $3$, the next digit must be $9$ (to form $39$).
From here, the pattern loops back to $9$. Thus, the sequence of digits is strictly periodic:
$9, 1, 3, 9, 1, 3, 9, 1, 3, \dots$
The pattern "9, 1, 3" has a length of $3$. We want to find the $100^{\text{th}}$ digit. We divide $100$ by $3$ to find the remainder:
$100 = 33 \times 3 + 1$
Since the remainder is $1$, the $100^{\text{th}}$ digit is the $1^{\text{st}}$ digit of the repeating block, which is $9$. The answer is (d).
