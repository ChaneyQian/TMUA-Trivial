## 题目
Given that
$$
\log_{10} 2 = 0.3010 \text{ to 4 d.p. and that } 10^{0.2} < 2
$$
it is possible to deduce that
(a) $2^{100}$ begins in a $1$ and is $30$ digits long;
(b) $2^{100}$ begins in a $2$ and is $30$ digits long;
(c) $2^{100}$ begins in a $1$ and is $31$ digits long;
(d) $2^{100}$ begins in a $2$ and is $31$ digits long.

## 解析
We want to find the first digit and the number of digits of $2^{100}$. We can rewrite $2^{100}$ in base $10$:

$$2^{100} = 10^{100 \log_{10} 2}$$

Using the given approximation $\log_{10} 2 \approx 0.3010$, we have:

$$2^{100} \approx 10^{100(0.3010)} = 10^{30.10} = 10^{30} \times 10^{0.10}$$

Since $0 < 0.10 < 0.2$, it follows that $10^{0} < 10^{0.10} < 10^{0.2}$. We are given that $10^{0.2} < 2$, which means:

$$1 < 10^{0.10} < 2$$

Therefore, $2^{100}$ is equal to a number strictly between $1$ and $2$ multiplied by $10^{30}$. This implies its leading digit must be $1$. The number of digits of an integer written in scientific notation as $a \times 10^{n}$ (where $1 \leqslant a < 10$) is $n + 1$. Here, the number of digits is $30 + 1 = 31$. The answer is (c).
