## 题目
[4 marks] How many solutions does

$$-\frac{3}{8} = \cos x + \cos^3 x + \cos^5 x + \cdots$$

have for $x \in [0, 2\pi]$?

(a) $0$
(b) $1$
(c) $2$
(d) $3$
(e) $4$

## 答案
C

## 解析
The right-hand side is geometric with first term $\cos x$ and ratio $\cos^{2} x$, converging exactly
when $\cos^{2} x < 1$, to $\dfrac{\cos x}{1 - \cos^{2} x}$. Writing $c = \cos x$,

$$\frac{c}{1-c^{2}} = -\frac{3}{8} \;\Longrightarrow\; 3c^{2} - 8c - 3 = 0 \;\Longrightarrow\; c = 3 \ \text{ or } \ c = -\frac{1}{3}.$$

Only $c = -\dfrac{1}{3}$ is attainable, and $\cos x = -\dfrac{1}{3}$ has two solutions in $[0, 2\pi]$, one in
$\left(\dfrac{\pi}{2}, \pi\right)$ and one in $\left(\pi, \dfrac{3\pi}{2}\right)$.

The answer is (c).
