## 题目
[4 marks] The inequality

$$(a + b + c + d)^2 \le C \cdot (a^2 + b^2 + c^2 + d^2)$$

holds for **all** real $a, b, c, d$. Find the **minimum** value of $C$ for which this is always true.

(a) $1$
(b) $2$
(c) $3$
(d) $4$
(e) $8$

## 答案
D

## 解析
By Cauchy--Schwarz against $(1,1,1,1)$,

$$(a+b+c+d)^{2} \le (1^{2}+1^{2}+1^{2}+1^{2})(a^{2}+b^{2}+c^{2}+d^{2}) = 4(a^{2}+b^{2}+c^{2}+d^{2}),$$

so $C = 4$ works. Nothing smaller does: $a = b = c = d = 1$ forces $16 \le 4C$.

The answer is (d).
