## 题目
The area between the parabolas with equations $y = x^{2} + 2ax + a$ and $y = a - x^{2}$ equals 9. The possible values of $a$ are

(a) $a = 1,$
(b) $a = -3$ or $a = 3,$
(c) $a = -3,$
(d) $a = -1$ or $a = 1,$
(e) $a = 1$ or $a = 3.$

## 备注

### 我的备注

### AI备注

## 答案
B

## 解析
$$
\left| \int_{-a} ^{0} \left| (x^{2} + 2 a x + a) - (a - x^{2}) \right| \mathrm{d} x \right| = \left| \left[ \left| \frac {2 x^{3}}{3} + a x^{2} \right| \right] _{-a} ^{0} \right| = \left| \frac {a^{3}}{3} \right|
$$

so the integral is 9 for $a = 3 { \mathrm { ~ o r ~ } } a = - 3$ The answer is (b)
