## 题目
Which of the following is true about $f(x) = a - (bx + c)^{2}$?

$$\mathbf{A} \quad \text{It has a minimum at } x = \frac{c}{b}$$

$$\mathbf{B} \quad \text{It has a minimum at } x = -\frac{c}{b}$$

$$\mathbf{C} \quad \text{It has a minimum value of } a - c^{2}$$

$$\mathbf{D} \quad \text{It has a maximum at } x = -\frac{b}{c}$$

$$\mathbf{E} \quad \text{It has a maximum at } x = \frac{c}{b}$$

$$\mathbf{F} \quad \text{It has a maximum at } x = -\frac{c}{b}$$

$$\mathbf{G} \quad \text{The graph of } y = f(x) \text{ is symmetric about the } y \text{-axis}$$

$$\mathbf{H} \quad y = f(x) \text{ meets the } x \text{-axis at two distinct points whatever the values of } a, b \text{ and } c$$

  各干扰项针对的错误：
  - A: 针对「极值类型与解方程符号双错」——既把开口方向看反，又把 $bx+c=0$ 解成 $x=\frac{c}{b}$。
  - B: 针对「外面的负号看漏」——把 $a-(bx+c)^2$ 当成开口向上，位置对但判成最小值。
  - C: 针对「把 $f(0)$ 当极值」——代 $x=0$ 得 $a-c^2$ 就当成极值，且极值类型也判反。
  - D: 针对「$b$、$c$ 位置互换」——把 $bx+c=0$ 的解写成 $-\frac{b}{c}$。
  - E: 针对「移项符号错」——由 $bx=-c$ 时丢掉负号。
  - G: 针对「以为完全平方式一定关于 $y$ 轴对称」——忽略 $c\neq 0$ 会把对称轴平移。
  - H: 针对「忘了判别式条件」——$a-(bx+c)^2=0$ 有两个相异实根需 $a>0$ 且 $b\neq 0$。

## 答案
F

## 解析
**回忆答案:** Has maximum at $x = -\dfrac{c}{b}$
