## 题目
$$f(x) = x^{3} - 3\sqrt{2}x^{2} + 6x - 2\sqrt{2}$$

$$g(x) = x^{2} - 2\sqrt{2}x + 2$$

For what range of $x$, does $f(x) \geq g(x)$?

$$\mathbf{A} \quad x \geq \sqrt{2} + 1$$

$$\mathbf{B} \quad x = \sqrt{2} \ \text{ or } \ x \geq \sqrt{2} + 1$$

$$\mathbf{C} \quad x = \sqrt{2} \ \text{ or } \ x > \sqrt{2} + 1$$

$$\mathbf{D} \quad x \leq \sqrt{2} + 1$$

$$\mathbf{E} \quad x \geq \sqrt{2}$$

$$\mathbf{F} \quad x = \sqrt{2} \ \text{ or } \ x \geq \sqrt{2} - 1$$

## 答案
B

## 解析
**回忆答案:** $x = \sqrt{2}$ or $x \geq \sqrt{2} + 1$

原稿注：观察可得 $f(x) = (x - \sqrt{2})^{3}$，$g(x) = (x - \sqrt{2})^{2}$。

![[Image/25-Q33-sol1.png]]
The surds are a disguise. Expanding the binomials,

$$(x - \sqrt{2})^{3} = x^{3} - 3\sqrt{2}x^{2} + 3 \cdot 2 \cdot x - 2\sqrt{2} = f(x), \qquad (x - \sqrt{2})^{2} = x^{2} - 2\sqrt{2}x + 2 = g(x).$$

So with the substitution $t = x - \sqrt{2}$ the inequality $f(x) \geq g(x)$ becomes

$$t^{3} \geq t^{2}, \qquad \text{i.e.} \qquad t^{2}(t - 1) \geq 0.$$

Do **not** divide by $t^{2}$: that would discard the case $t = 0$. Instead read off the sign. Since $t^{2} \geq 0$ always, the product is non-negative exactly when $t^{2} = 0$ or $t - 1 \geq 0$:

$$t = 0 \quad \text{or} \quad t \geq 1.$$

Translating back with $x = t + \sqrt{2}$,

$$x = \sqrt{2} \quad \text{or} \quad x \geq \sqrt{2} + 1.$$

Both pieces are needed. At $x = \sqrt{2}$ we get $f = g = 0$, so the weak inequality holds there, which is why the isolated point cannot be dropped; and at $x = \sqrt{2} + 1$ we get $f = g = 1$, so that endpoint is included too. In between, say at $x = \sqrt{2} + \tfrac12$, we have $f - g = \tfrac18 - \tfrac14 < 0$, and for $x < \sqrt{2}$, say $x = \sqrt{2} - \tfrac12$, we have $f - g = -\tfrac18 - \tfrac14 < 0$, so nothing else can be added.

The answer is B.
