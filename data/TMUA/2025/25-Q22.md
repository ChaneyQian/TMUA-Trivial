## 题目
$f(x) > 0$ when $2 \leq x \leq 3$, otherwise $f(x) < 0$.

$g(x) < 0$ when $2.5 \leq x \leq 4$, otherwise $g(x) > 0$.

$h(x) = f(x) \cdot g(x)$.

What is the area enclosed by $h(x)$ and the $x$-axis between $1 \leq x \leq 5$?

$$\mathbf{A} \quad \int_{1}^{2} h(x)\,dx + \int_{2}^{2.5} h(x)\,dx + \int_{2.5}^{3} h(x)\,dx + \int_{3}^{4} h(x)\,dx + \int_{4}^{5} h(x)\,dx$$

$$\mathbf{B} \quad -\int_{1}^{2} h(x)\,dx + \int_{2}^{2.5} h(x)\,dx + \int_{2.5}^{3} h(x)\,dx - \int_{3}^{4} h(x)\,dx - \int_{4}^{5} h(x)\,dx$$

$$\mathbf{C} \quad \int_{1}^{2} h(x)\,dx + \int_{2}^{2.5} h(x)\,dx - \int_{2.5}^{3} h(x)\,dx - \int_{3}^{4} h(x)\,dx + \int_{4}^{5} h(x)\,dx$$

$$\mathbf{D} \quad -\int_{1}^{2} h(x)\,dx + \int_{2}^{2.5} h(x)\,dx - \int_{2.5}^{3} h(x)\,dx - \int_{3}^{4} h(x)\,dx - \int_{4}^{5} h(x)\,dx$$

$$\mathbf{E} \quad \int_{1}^{2} h(x)\,dx - \int_{2}^{2.5} h(x)\,dx + \int_{2.5}^{3} h(x)\,dx - \int_{3}^{4} h(x)\,dx + \int_{4}^{5} h(x)\,dx$$

$$\mathbf{F} \quad -\int_{1}^{2} h(x)\,dx + \int_{2}^{2.5} h(x)\,dx - \int_{2.5}^{3} h(x)\,dx + \int_{3}^{4} h(x)\,dx - \int_{4}^{5} h(x)\,dx$$

## 解析
**回忆答案:**

$$-\int_{1}^{2} h(x)\,dx + \int_{2}^{2.5} h(x)\,dx - \int_{2.5}^{3} h(x)\,dx + \int_{3}^{4} h(x)\,dx - \int_{4}^{5} h(x)\,dx$$

原稿符号表：

| 区间 | $f(x)$ | $g(x)$ | $h(x)$ |
|---|---|---|---|
| $1 \leq x < 2$ | $<0$ | $>0$ | $<0$ |
| $2 \leq x < 2.5$ | $>0$ | $>0$ | $>0$ |
| $2.5 \leq x < 3$ | $>0$ | $<0$ | $<0$ |
| $3 \leq x < 4$ | $<0$ | $<0$ | $>0$ |
| $4 \leq x < 5$ | $<0$ | $>0$ | $<0$ |

原稿注：具体数字记不得了，考场上选的是最后一个选项，反正考察积分的几何意义。

Area is $\int |h|$, so on every subinterval where $h$ is positive we take $+\int h$ and on every subinterval where $h$ is negative we take $-\int h$. The only work is to get the sign of $h = fg$ right on each piece.

The two sign changes of $f$ are at $x = 2$ and $x = 3$; those of $g$ are at $x = 2.5$ and $x = 4$. These four points cut $1 \leq x \leq 5$ into the five intervals listed in the options, and on each one the sign of $h$ is the product of the signs of $f$ and $g$:

$$\begin{aligned}
1 <  x <  2 &: \ f <  0, \ g > 0 \ \Rightarrow\ h <  0 \\
2 <  x <  2.5 &: \ f > 0, \ g > 0 \ \Rightarrow\ h > 0 \\
2.5 <  x <  3 &: \ f > 0, \ g <  0 \ \Rightarrow\ h <  0 \\
3 <  x <  4 &: \ f <  0, \ g <  0 \ \Rightarrow\ h > 0 \\
4 <  x <  5 &: \ f <  0, \ g > 0 \ \Rightarrow\ h <  0
\end{aligned}$$

So the signs attached to the five integrals must be $-, +, -, +, -$, giving

$$-\int_{1}^{2} h\,dx + \int_{2}^{2.5} h\,dx - \int_{2.5}^{3} h\,dx + \int_{3}^{4} h\,dx - \int_{4}^{5} h\,dx .$$

(The key step is the fourth interval, where $f$ and $g$ are both negative and so $h$ is *positive*; the option that puts a minus sign there is the one designed to catch that slip. Taking all five signs positive just computes $\int_{1}^{5} h\,dx$, the signed area.)

The answer is F.
