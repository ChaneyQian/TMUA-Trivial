## 题目
Let $a, b, c$ be real numbers such that $0 < a < b < c$. The functions $p, q, r$ are defined for all real $x$ as:
$$p(x) = |x - a|(x - b)(x - c)$$
$$q(x) = (x - a)|x - b|(x - c)$$
$$r(x) = (x - a)(x - b)|x - c|$$

These functions have minimum values $P$, $Q$ and $R$, respectively.

Which one of the following is impossible to be the greatest among these values?

$$\mathbf{A} \quad P$$

$$\mathbf{B} \quad Q$$

$$\mathbf{C} \quad R$$

$$\mathbf{D} \quad P \text{ or } R$$

$$\mathbf{E} \quad P \text{ and } Q$$

$$\mathbf{F} \quad \text{Neither of them}$$

- 边界说明：当 $b - a = c - b$ 时三次函数关于拐点中心对称，$P = Q = R$ 三者相等，此时谈不上「谁最大」。题目问的是「不可能成为最大者」，按严格最大理解答案 B 不受影响。

## 答案
B

## 解析
Let $g(x) = (x - a)(x - b)(x - c)$. Each of $p, q, r$ tends to $+\infty$ as $x \to \pm\infty$, so each minimum is attained where the function is negative.

For $p$: when $x < a$ or $a < x < b$ we have $p(x) \geqslant 0$, and when $b < x < c$ we have $p(x) = g(x) < 0$. So $P$ is the local minimum value of $g$ on $(b, c)$.

For $r$: $r(x) < 0$ only when $a < x < b$, where $r(x) = -g(x)$. So $R = -M$, where $M$ is the local maximum value of $g$ on $(a, b)$.

For $q$: $q(x) < 0$ exactly when $a < x < c$ with $x \neq b$. On $(a, b)$ we have $q(x) = -g(x)$, whose minimum is $-M = R$; on $(b, c)$ we have $q(x) = g(x)$, whose minimum is $P$. Hence
$$Q = \min(P, R).$$

So $Q$ can never exceed both $P$ and $R$. On the other hand, $P$ and $R$ can each be the greatest: moving $b$ closer to $a$ makes the positive hump of $g$ on $(a, b)$ small, so $R$ is close to $0$ and is the greatest, while moving $b$ closer to $c$ does the same for $P$.

The answer is B.
