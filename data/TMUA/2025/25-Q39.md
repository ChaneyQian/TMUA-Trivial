What is $p - 3q$?

（`TAGS: 待补答案`：题干中 $x_1+x_2$ 与 $x_1-x_2$ 的两个数值缺失，无法得出具体答数；以下给出一般方法。）

Take the quadratic to be monic, $f(x) = x^{2} + px + q$, with roots $x_1$ and $x_2$ (the leading coefficient is not recorded either; if it were some $k \neq 1$, every formula below would carry an extra factor, with $x_1 + x_2 = -p/k$ and $x_1x_2 = q/k$). Write $S$ for the given value of the sum $x_1 + x_2$ and $D$ for the given value of the difference $x_1 - x_2$; the recalled stem has lost both numbers, so the work can only be carried out symbolically.

By Vieta's formulas,

$$x_1 + x_2 = -p, \qquad x_1 x_2 = q.$$

The sum gives $p$ immediately:

$$p = -S.$$

For $q$, use the identity that connects the difference of the roots to the discriminant:

$$(x_1 - x_2)^{2} = (x_1 + x_2)^{2} - 4x_1 x_2 = p^{2} - 4q,$$

so $D^{2} = S^{2} - 4q$ and hence

$$q = \frac{S^{2} - D^{2}}{4}.$$

(Equivalently, solve $x_1 + x_2 = S$, $x_1 - x_2 = D$ to get $x_1 = \tfrac{S+D}{2}$, $x_2 = \tfrac{S-D}{2}$, and multiply.) Note that "it has two roots" means $D \neq 0$ and, for real roots, $D^{2} = p^2 - 4q > 0$.

Combining the two results,

$$p - 3q = -S - \frac{3\left(S^{2} - D^{2}\right)}{4} = \frac{3\left(D^{2} - S^{2}\right)}{4} - S.$$

So the answer is $p - 3q = \dfrac{3\left(D^{2} - S^{2}\right)}{4} - S$, where $S$ and $D$ are the two numerical values given in the original paper; those numbers were not recorded, so no single value can be stated here. (For example, had the paper given $S = 2$ and $D = 4$, the value would be $p = -2$, $q = -3$ and $p - 3q = 7$.)
