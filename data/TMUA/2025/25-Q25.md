## 题目
A student wants to prove $V$ lies on $XZ$. Which of the following is necessary and sufficient?

![[Image/25-Q25-fig1.png]]
	I. $a + d = b + c$
	II. $a + c = b + d$
	III. $a + b = c + d$

$$\mathbf{A} \quad \text{none of them}$$

$$\mathbf{B} \quad \text{I only}$$

$$\mathbf{C} \quad \text{II only}$$

$$\mathbf{D} \quad \text{III only}$$

$$\mathbf{E} \quad \text{I and II only}$$

$$\mathbf{F} \quad \text{I and III only}$$

$$\mathbf{G} \quad \text{II and III only}$$

$$\mathbf{H} \quad \text{I, II and III}$$

## 答案
D

## 解析
**回忆答案:** III

Four rays $VX$, $VY$, $VZ$, $VW$ leave $V$ in that cyclic order, and the four marked angles are $a = \angle XVY$, $b = \angle YVZ$, $c = \angle ZVW$, $d = \angle WVX$. Angles at a point give the one relation available:

$$a + b + c + d = 360^\circ .$$

"$V$ lies on $XZ$" means that $XVZ$ is a straight line, i.e. that the two rays $VX$ and $VZ$ are opposite, i.e.

$$\angle XVZ = a + b = 180^\circ .$$

**III is necessary and sufficient.** Using the $360^\circ$ relation, $c + d = 360^\circ - (a+b)$, so

$$a + b = c + d \iff a + b = 360^\circ - (a+b) \iff a + b = 180^\circ ,$$

which is exactly the condition for $X$, $V$, $Z$ to be collinear. Both directions hold.

**I is neither.** By the same manipulation, $a + d = b + c \iff a + d = 180^\circ$, and $a + d = \angle XVY + \angle WVX = \angle YVW$ measured through $VX$; so I is the condition for $Y$, $V$, $W$ to be collinear — a statement about the *other* line. It is not necessary: $a = b = 90^\circ$, $c = 110^\circ$, $d = 70^\circ$ puts $V$ on $XZ$ but has $a + d = 160^\circ \neq 200^\circ = b + c$. It is not sufficient: $a = 110^\circ$, $b = 100^\circ$, $c = 80^\circ$, $d = 70^\circ$ gives $a + d = 180^\circ = b + c$, yet $a + b = 210^\circ \neq 180^\circ$.

**II is neither.** Likewise $a + c = b + d \iff a + c = 180^\circ$, which pairs up *opposite* angles and corresponds to no collinearity at all. Not necessary: the first example above has $a + c = 200^\circ \neq 160^\circ = b + d$ although $V$ lies on $XZ$. Not sufficient: $a = 100^\circ$, $b = 90^\circ$, $c = 80^\circ$, $d = 90^\circ$ gives $a + c = 180^\circ = b + d$, but $a + b = 190^\circ$, so $V$ does not lie on $XZ$.

The answer is D.
