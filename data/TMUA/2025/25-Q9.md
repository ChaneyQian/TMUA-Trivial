## 题目
What is the graph in the $x, y$ plane that satisfies $\sqrt{4^{x^{2}} 4^{y^{2}}} = 2^{x} \cdot 2^{y}$?

$$\mathbf{A} \quad \text{every point in the } x, y \text{ plane}$$

$$\mathbf{B} \quad \text{the single point } \left(\frac{1}{2}, \frac{1}{2}\right)$$

$$\mathbf{C} \quad \text{the pair of straight lines } x + y = 0 \text{ and } x + y = 1$$

$$\mathbf{D} \quad \text{a circle with centre } (0, 0) \text{ and radius } \frac{\sqrt{2}}{2}$$

$$\mathbf{E} \quad \text{a circle with centre } \left(\frac{1}{2}, \frac{1}{2}\right) \text{ and radius } \frac{1}{2}$$

$$\mathbf{F} \quad \text{a circle with centre } \left(\frac{1}{2}, \frac{1}{2}\right) \text{ and radius } \frac{\sqrt{2}}{2}$$

$$\mathbf{G} \quad \text{a circle with centre } (1, 1) \text{ and radius } \sqrt{2}$$

  - B: 针对「配方后右端算成 0」——把 $\frac{1}{4}+\frac{1}{4}$ 忘了加回右边，半径变成 $0$。
  - C: 针对「把 $x^2+y^2$ 当成 $(x+y)^2$」——得 $(x+y)^2=x+y$，解出两条平行直线。
  - D: 针对「忘了配方带来的圆心平移」——只看 $x^2+y^2=\cdots$ 就断定圆心在原点。
  - E: 针对「忘了开平方」——把 $r^2=\frac{1}{2}$ 直接当成 $r=\frac{1}{2}$。
