## 题目
$$|1 - x| = 3x - 4 \quad (*)$$

	I. $|1 - x| = 1 - x$ or $-(1 - x)$
	II. $1 - x = 3x - 4 \implies x = \dfrac{5}{4}$
	III. $x - 1 = 3x - 4 \implies x = \dfrac{3}{2}$
	IV. Hence, $x = \dfrac{5}{4}, \dfrac{3}{2}$ are solutions to $(*)$.

Which step does the first error occur in?

## 解析
**回忆答案:** Step IV

分支 $x \le 1$：$1 - x = 3x - 4$ 给 $x = \dfrac54$，但 $\dfrac54 > 1$，违反分支条件，是**增根**；分支 $x > 1$：$x - 1 = 3x - 4$ 给 $x = \dfrac32$，代回 $|1 - 1.5| = 0.5 = 3(1.5) - 4$ 成立，是**真解**。I、II、III 每一步作为「若…则…」都成立；IV 第一次把未经回代检验的 $\dfrac54$ 当成解，**首错在 IV**。增根不是来自平方（本题从未平方），而是分支条件没有回代。

First solve $(*)$ properly. The right-hand side must be non-negative, so $3x - 4 \geq 0$, i.e. $x \geq \tfrac{4}{3} > 1$; hence $|1-x| = x - 1$ and

$$x - 1 = 3x - 4 \implies 2x = 3 \implies x = \tfrac{3}{2},$$

which satisfies $x \geq \tfrac43$. Checking, $\left|1 - \tfrac32\right| = \tfrac12$ and $3\left(\tfrac32\right) - 4 = \tfrac12$. So $(*)$ has the single solution $x = \tfrac{3}{2}$, and $x = \tfrac54$ is not a solution: $\left|1 - \tfrac54\right| = \tfrac14$ but $3\left(\tfrac54\right) - 4 = -\tfrac14$.

Now examine each step as a stated implication.

- **I** is true: $|1-x|$ is equal to $1-x$ or to $-(1-x)$, since that is what the modulus means. The step does not claim to know which case holds, so nothing is wrong yet.
- **II** is true as an implication: *if* $1 - x = 3x - 4$ *then* $4x = 5$, so $x = \tfrac54$. Solving a linear equation correctly is not an error; the step never asserts that $\tfrac54$ solves $(*)$.
- **III** is true in the same way: $x - 1 = 3x - 4$ does give $x = \tfrac32$.
- **IV** is false. It converts the two candidates into solutions of $(*)$, but the case analysis in I only gives implications in one direction: a solution of $(*)$ must satisfy one of the two linear equations, not conversely. Each candidate still has to be tested against the case that produced it (or substituted back). Here $x = \tfrac54$ came from the branch $1 - x \geq 0$, i.e. $x \leq 1$, which $\tfrac54$ violates, so it is an extraneous root; only $x = \tfrac32$ survives.

So the first step containing an error is IV. Note that the extraneous root does not come from squaring — nothing was squared here — but from failing to check the sign condition of the branch.

The answer is IV.
