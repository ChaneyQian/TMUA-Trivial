## 题目
Polynomial $p(x)$ has 2 distinct real roots.

	I. $x \cdot p(x)$ has 3 distinct real roots.
	II. $x \cdot p(x)$ and $x^{2} \cdot p(x)$ have same number of distinct real roots.
	III. $\dfrac{1}{x^{2} + 2} p(x)$ and $p(x)$ have same number of distinct real roots.

Which of the following is/are correct?

$$\mathbf{A} \quad \text{none of them}$$

$$\mathbf{B} \quad \text{I only}$$

$$\mathbf{C} \quad \text{II only}$$

$$\mathbf{D} \quad \text{III only}$$

$$\mathbf{E} \quad \text{I and II only}$$

$$\mathbf{F} \quad \text{I and III only}$$

$$\mathbf{G} \quad \text{II and III only}$$

$$\mathbf{H} \quad \text{I, II and III}$$

## 答案

## 解析
**回忆答案:** II and III only

Throughout, what is being counted is *distinct* real roots, so what matters is the zero **set**, not multiplicities. Note that nothing says $p(0) \neq 0$ — that is the whole point of the question.

**I is false.** Multiplying by $x$ adds $0$ to the zero set, but only if $0$ was not there already. Take $p(x) = x(x-1)$, which has exactly the two distinct real roots $0$ and $1$. Then $x \cdot p(x) = x^{2}(x-1)$ still has zero set $\{0, 1\}$, so only $2$ distinct real roots, not $3$.

**II is true.** For any $p$,

$$\{x : x\,p(x) = 0\} = \{0\} \cup \{x : p(x) = 0\} = \{x : x^{2} p(x) = 0\} ,$$

since $x = 0$ and $x^{2} = 0$ have the same solution set. Raising the power only changes the multiplicity of the root $0$, never the number of distinct roots, so the two polynomials always have the same count (namely $2$ or $3$, according as $p(0) = 0$ or not).

**III is true.** The denominator satisfies $x^{2} + 2 \geq 2 > 0$ for every real $x$, so it never vanishes and never makes the expression undefined. Hence

$$\frac{p(x)}{x^{2}+2} = 0 \iff p(x) = 0 ,$$

and the two have identical zero sets, so the same number ($2$) of distinct real roots.

The answer is G.
