## 题目
Statement $(*)$: If $p$ is prime, $q$ is an integer, then $q^{p-1}$ must be one more than a multiple of $p$. Find a counterexample.

$$\mathbf{A} \quad \text{there is no counterexample; } (*) \text{ is true for every prime } p \text{ and every integer } q$$

$$\mathbf{B} \quad \text{any } p \text{ and } q \text{ with } p = 2 \text{ and } q \text{ odd}$$

$$\mathbf{C} \quad \text{any } p \text{ and } q \text{ for which } q \text{ is a multiple of } p$$

$$\mathbf{D} \quad \text{any } p \text{ and } q \text{ with } q = p + 1$$

$$\mathbf{E} \quad p = 9 \text{ and } q = 2$$

$$\mathbf{F} \quad \text{any } p \text{ and } q \text{ with } q = -1 \text{ and } p \text{ an odd prime}$$

$$\mathbf{G} \quad \text{any } p \text{ and } q \text{ with } q \text{ prime and } q \neq p$$

Statement $(*)$ is Fermat's little theorem with one hypothesis quietly removed. The theorem says that if $p$ is prime and $p \nmid q$, then $q^{p-1} \equiv 1 \pmod p$. A counterexample must therefore come from the one case the theorem does not cover, namely $p \mid q$.

If $q$ is a multiple of $p$, then $q \equiv 0 \pmod p$, and since $p - 1 \geq 1$,

$$q^{p-1} \equiv 0 \pmod p.$$

So $q^{p-1}$ is a multiple of $p$, and it could only also be one more than a multiple of $p$ if $p \mid 1$, which is impossible for $p \geq 2$. The smallest instance is $p = 2$, $q = 2$: here $q^{p-1} = 2$, and $2 - 1 = 1$ is not a multiple of $2$. So this is a genuine counterexample.

The other options all satisfy $p \nmid q$ (or fail the hypotheses), so none of them can break the statement:

- $p = 2$ with $q$ odd gives $q^{p-1} = q$, which is odd, i.e. one more than a multiple of $2$.
- $q = p + 1 \equiv 1 \pmod p$ gives $q^{p-1} \equiv 1$.
- $q = -1$ with $p$ an odd prime gives $(-1)^{p-1} = 1$ since $p - 1$ is even.
- $q$ prime with $q \neq p$ gives $p \nmid q$, which is exactly when the theorem applies.
- $p = 9$, $q = 2$ gives $2^{8} = 256$ and $255$ is not a multiple of $9$, but $9$ is not prime, so the hypothesis of $(*)$ is not met and this is not a counterexample to $(*)$ at all. This is the trap option: a counterexample has to satisfy the premises and contradict the conclusion.

The answer is C.
