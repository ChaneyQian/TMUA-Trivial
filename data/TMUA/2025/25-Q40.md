## 题目
A function $f(x)$ is defined as *wobbly* if there exists a real $x$ such that
$$f'(x) = 0,$$
where $f'(x)$ denotes the derivative of $f(x)$.

Among the following functions, the one that is **not wobbly** is:

I. $y = x + 2$

II. $y = 2^{x}$

III. $y = x^{2} + 3x - 2$

$$\mathbf{A} \quad \text{none}$$

$$\mathbf{B} \quad \text{I only}$$

$$\mathbf{C} \quad \text{II}$$

$$\mathbf{D} \quad \text{III}$$

$$\mathbf{E} \quad \text{I, II}$$

$$\mathbf{F} \quad \text{I, III}$$

$$\mathbf{G} \quad \text{II, III}$$

$$\mathbf{H} \quad \text{I, II, III}$$

## 答案
E

## 解析
A function is not wobbly exactly when its derivative is never zero.

For I, $f'(x) = 1$, which is never zero, so I is not wobbly.

For II, $f'(x) = 2^{x}\ln 2$, and $2^{x} > 0$ for all real $x$, so this is never zero either; II is not wobbly.

For III, $f'(x) = 2x + 3$, which is zero at $x = -\tfrac{3}{2}$, so III is wobbly.

The functions that are not wobbly are I and II. The answer is E.
