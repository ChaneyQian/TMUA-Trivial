## 题目
A geometric sequence has common ratio of $q^{2} - 4q + 2$. The sequence is convergent. What is the range of $q$?

$$\mathbf{A} \quad 2 - \sqrt{3} < q < 2 + \sqrt{3}$$

$$\mathbf{B} \quad q < 1 \ \text{ or } \ q > 3$$

$$\mathbf{C} \quad 1 < q < 3$$

$$\mathbf{D} \quad 2 - \sqrt{3} < q < 1 \ \text{ or } \ 3 < q < 2 + \sqrt{3}$$

$$\mathbf{E} \quad 2 - \sqrt{3} \leq q \leq 1 \ \text{ or } \ 3 \leq q \leq 2 + \sqrt{3}$$

$$\mathbf{F} \quad 2 - \sqrt{2} < q < 2 + \sqrt{2}$$
