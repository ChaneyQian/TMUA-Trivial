## 题目
The radius of the circle $2 x ^ { 2 } + 2 y ^ { 2 } - 8 x + 1 2 y + 1 5 = 0$ is

$$
\mathbf {A} \quad \sqrt { \frac { 5 } { 2}}
$$

$$
\mathbf {B} \quad \sqrt { \frac { 1 1 } { 2}}
$$

$$
\mathbf {C} \quad \sqrt { \frac { 4 1 } { 2}}
$$

$$
\mathbf {D} \quad \sqrt { 3 7}
$$

$$
\mathbf {E} \quad \sqrt { 6 7}
$$
## 备注

### 我的备注

### AI备注


## 答案
B

## 解析
We first divide by 2 to get $x ^ { 2 } + y ^ { 2 } + \ldots$ , then complete the square for x and $y \colon$

$$
\begin{array}{r l r} & & 2 x ^ {2} + 2 y ^ {2} - 8 x + 1 2 y + 1 5 = 0 \\ & \Longleftrightarrow & x ^ {2} + y ^ {2} - 4 x + 6 y + \frac {1 5}{2} = 0 \\ & \Longleftrightarrow & (x - 2) ^ {2} - 2 ^ {2} + (y + 3) ^ {2} - 3 ^ {2} + \frac {1 5}{2} = 0 \\ & \Longleftrightarrow & (x - 2) ^ {2} + (y + 3) ^ {2} = \frac {1 1}{2} \end{array}
$$

so the radius is $\scriptstyle { \sqrt { \frac { 1 1 } { 2 } } }$ , which is option B.
