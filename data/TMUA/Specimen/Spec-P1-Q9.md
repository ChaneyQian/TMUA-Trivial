## 题目
The roots of the equation $2x^{2} - 11x + c = 0$ differ by 2. The value of $c$ is

$$
\mathbf {A} \quad \frac{105}{8}
$$

$$
\mathbf {B} \quad \frac{113}{8}
$$

$$
\mathbf {C} \quad \frac{117}{8}
$$

$$
\mathbf {D} \quad \frac{119}{8}
$$
## 备注

### 我的备注

### AI备注


## 答案
A

## 解析
The roots of the equation, using the quadratic formula, are

$$
x = \frac {1 1 \pm \sqrt {1 1 ^ {2} - 8 c}}{4}
$$

and these difer by

$$
x = \frac {2 \sqrt {1 1 ^ {2} - 8 c}}{4} = 2
$$

so we require $\sqrt { 1 1 ^ { 2 } - 8 c } = 4$ , or $1 2 1 - 8 c = 1 6$ . Thus $8 c = 1 0 5$ , so $\begin{array} { r } { c = \frac { 1 0 5 } { 8 } } \end{array}$ and the answer is A.
