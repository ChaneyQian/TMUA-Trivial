## 题目
The curve $y = \cos x$ is reflected in the line $y = 1$ and the resulting curve is then translated by $\frac{\pi}{4}$ units in the positive $x$-direction. The equation of this new curve is

$$
\mathbf{A} \quad y = 2 + \cos\left(x + \frac{\pi}{4}\right)
$$

$$
\mathbf{B} \quad y = 2 + \cos\left(x - \frac{\pi}{4}\right)
$$

$$
\mathbf{C} \quad y = 2 - \cos\left(x + \frac{\pi}{4}\right)
$$

$$
\mathbf{D} \quad y = 2 - \cos\left(x - \frac{\pi}{4}\right)
$$

## 答案
D

## 解析
When the graph is reflected in the line $y = 1$ , we obtain the following:

![[Image/Spec-P1-Q10-sol1.jpg]]

We can find the equation of the reflected curve in a variety of ways. One is to observe that the reflection is centred about $y = 2$ , as the values go from $y = 1$ to $y = 3$ . The cosine curve is ‘upside-down’, so the equation must be $y = - ( \cos x ) + 2 = 2 - \cos x$

Another way to see this is as follows. The refletion of $y = \operatorname { f } ( x )$ in the x-axis $( y = 0 )$ is $y = - \mathrm { f } ( x )$ When the line of reflection is translated, the whole reflection is translated. Since $y = 0$ is transformed to $y = 2$ , the reflection of the function must be translated to give $y = 2 - \operatorname { f } ( x )$

The result is then translated by $\frac { \pi } { 4 }$ in the positive x-direction, so that x is replaced by $\textstyle x - { \frac { \pi } { 4 } }$ (We can see this because the new $\textstyle x = { \frac { \pi } { 4 } }$ corresponds to the old $x = 0 . )$

Therefore, the equation of the resulting graph is

$$
y = 2 - \cos \left(x - \frac {\pi}{4}\right).
$$

Thus the correct answer is option D.
