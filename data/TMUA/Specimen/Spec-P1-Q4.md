## 题目
The complete set of values of $x$ for which $(x^2 - 1)(x - 2) > 0$ is

$$
\mathbf {A} \quad x < -1, 1 < x < 2
$$

$$
\mathbf {B} \quad x < -1, x > 2
$$

$$
\mathbf {C} \quad -1 < x < 2
$$

$$
\mathbf {D} \quad x < 1, x > 2
$$

$$
\mathbf {E} \quad -1 < x < 1, x > 2
$$

## 解析
We can factorise the given inequality to give $( x + 1 ) ( x - 1 ) ( x - 2 ) > 0$ . The function $\operatorname { f } ( x ) =$ $( x + 1 ) ( x - 1 ) ( x - 2 )$ is zero when $x = - 1$ $x = 1$ and $x = 2$.

We can now make a table showing the signs of the three factors for different values of $x$. (This is a useful technique in general.)

<table><tr><td></td><td> $x < -1$ </td><td> $x = -1$ </td><td> $-1 < x < 1$ </td><td> $x = 1$ </td><td> $1 < x < 2$ </td><td> $x = 2$ </td><td> $x > 2$ </td></tr><tr><td> $x + 1$ </td><td>-</td><td>0</td><td>+</td><td>+</td><td>+</td><td>+</td><td>+</td></tr><tr><td> $x - 1$ </td><td>-</td><td>-</td><td>-</td><td>0</td><td>+</td><td>+</td><td>+</td></tr><tr><td> $x - 2$ </td><td>-</td><td>-</td><td>-</td><td>-</td><td>-</td><td>0</td><td>+</td></tr><tr><td> $f(x)$ </td><td>-</td><td>0</td><td>+</td><td>0</td><td>-</td><td>0</td><td>+</td></tr></table>

Therefore f(x) is positive when $- 1 < x < 1$ and when $x > 2$. , so the answer is E.
