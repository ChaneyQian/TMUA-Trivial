## 题目
The perpendicular bisector of the line segment joining the points $(2, -6)$ and $(5, 4)$ cuts the $x$-axis at the point with $x$-coordinate

$$
\mathbf {A} \quad \frac{1}{20}
$$

$$
\mathbf {B} \quad \frac{1}{6}
$$

$$
\mathbf {C} \quad \frac{1}{3}
$$

$$
\mathbf {D} \quad \frac{19}{5}
$$

$$
\mathbf {E} \quad \frac{41}{6}
$$

## 答案
B

## 解析
We find the equation of the perpendicular bisector first, and then find the x-coordinate of this line when $y = 0$

The midpoint of the line segment joining $( 2 , - 6 )$ and (5, 4) is $( { \textstyle { \frac { 7 } { 2 } } } , - 1 )$ , and the gradient of this line segment is $\textstyle { \frac { 4 - ( - 6 ) } { 5 - 2 } } = { \frac { 1 0 } { 3 } }$

Therefore the perpendicular bisector passes through $( { \textstyle { \frac { 7 } { 2 } } } , - 1 )$ and has gradient $- \frac { 3 } { 1 0 }$ . Its equation is therefore

$$
y - (- 1) = - \frac {3}{1 0} \left(x - \frac {7}{2}\right).
$$

We could expand and simplify this equation, but that is not necessary for our purposes. Instead, we substitute $y = 0$ to obtain

$$
1 = - \frac {3}{1 0} \left(x - \frac {7}{2}\right)
$$

giving

$$
x - \frac {7}{2} = - \frac {1 0}{3}
$$

so $\begin{array} { r } { x = \frac { 7 } { 2 } - \frac { 1 0 } { 3 } = \frac { 2 1 } { 6 } - \frac { 2 0 } { 6 } = \frac { 1 } { 6 } } \end{array}$ showing that the correct answer is option B.
