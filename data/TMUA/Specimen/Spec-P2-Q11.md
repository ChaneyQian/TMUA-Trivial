## 题目
Which one of the following numbers is largest in value?
(All angles are given in radians.)

$$
\mathbf{A} \quad \tan\left(\dfrac{3\pi}{4}\right)
$$

$$
\mathbf{B} \quad \log_{10}100
$$

$$
\mathbf{C} \quad \sin^{10}\left(\dfrac{\pi}{2}\right)
$$

$$
\mathbf{D} \quad \log_2 10
$$

$$
\mathbf{E} \quad (\sqrt{2}-1)^{10}
$$

## 备注

### 我的备注

### AI备注


## 答案
D

## 解析
We work out or approximate all five numbers.

A $\begin{array} { r } { \tan \left( \frac { 3 \pi } { 4 } \right) = - 1 } \end{array}$

B $\log _ { 1 0 } 1 0 0 = 2$

C $\begin{array} { r } { \sin ^ { 1 0 } \bigl ( \frac { \pi } { 2 } \bigr ) = 1 ^ { 1 0 } = 1 } \end{array}$

D $\log _ { 2 } 1 0 = 3 . \cdot .$ , or more formally, $3 < \log _ { 2 } 1 0 < 4$ , as $2 ^ { 3 } = 8$ and $2 ^ { 4 } = 1 6$

E $0 < \sqrt { 2 } - 1 < 1$ , so $0 < ( \sqrt { 2 } - 1 ) ^ { 1 0 } < 1$

Only one of these numbers is greater than 3, so the answer is D.
