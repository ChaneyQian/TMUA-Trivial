## 题目
For what values of the non-zero real number $a$ does the quadratic equation $ax^2 + (a - 2)x = 2$ have real distinct roots?

$$
\mathbf {A} \quad \text{All values of } a
$$

$$
\mathbf {B} \quad a = -2
$$

$$
\mathbf {C} \quad a > -2
$$

$$
\mathbf {D} \quad a \neq -2
$$

$$
\mathbf {E} \quad \text{No values of } a
$$
## 备注

### 我的备注

### AI备注


## 答案
D

## 解析
The quadratic equation can be written as $a x ^ { 2 } + ( a - 2 ) x - 2 = 0$ , which has discriminant

$$
(a - 2) ^ {2} - 4 a (- 2) = a ^ {2} - 4 a + 4 + 8 a = a ^ {2} + 4 a + 4 = (a + 2) ^ {2}.
$$

The quadratic has real distinct roots when the disciminant is positive, so when $( a + 2 ) ^ { 2 } > 0$ Now $( a + 2 ) ^ { 2 } = 0$ when $a = - 2$ , and $( a + 2 ) ^ { 2 } \geqslant 0$ for all values of $a$, so $( a + 2 ) ^ { 2 } > 0$ when a $\neq - 2$ which is option D.
