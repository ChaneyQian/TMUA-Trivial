## 题目
The equation $x ^ { 4 } + b x ^ { 2 } + c = 0$ has four distinct real roots if and only if which of the following conditions is satisfied?

$$
\mathbf {A} \quad b ^ { 2 } > 4 c
$$

$$
\mathbf {B} \quad b ^ { 2 } < 4 c
$$

$$
\mathbf {C} \quad c > 0 \quad \text{and} \quad b > 2 \sqrt { c }
$$

$$
\mathbf {D} \quad c > 0 \quad \text{and} \quad b < - 2 \sqrt { c }
$$

$$
\mathbf {E} \quad c < 0 \quad \text{and} \quad b < 0
$$

$$
\mathbf {F} \quad c < 0 \quad \text{and} \quad b > 0
$$

## 答案
D

## 解析
Writing $u = x ^ { 2 }$ , the equation becomes $u ^ { 2 } + b u + c = 0$ . This has two distinct real roots $u _ { 1 }$ and $u _ { 2 }$ if and only if $b ^ { 2 } - 4 c > 0$ , or $b ^ { 2 } > 4 c .$ , so this is a necessary condition.

The roots of the original equation are then given by $x = \pm { \sqrt { u _ { 1 } } }$ and $x = \pm \sqrt { u _ { 2 } }$ . So for the original equation to have four distinct real roots, we require $u _ { 1 }$ and $u _ { 2 }$ to be distinct positive real numbers. We have

$$
u _ {1}, u _ {2} = \frac {- b \pm \sqrt {b ^ {2} - 4 c}}{2}
$$

so the smaller of the two is $\frac { 1 } { 2 } \left( - b - \sqrt { b ^ { 2 } - 4 c } \right)$ . If $b > 0$ , then this will be negative, so we require $b < 0 .$ . Supposing $b < 0 .$ , we also require $- b > { \sqrt { b ^ { 2 } - 4 c } } .$ , which becomes on squaring (as both sides are positive) $ b ^ { 2 } > b ^ { 2 } - 4 c ,$ so $c > 0$

Putting these all together, the original equation will have four distinct real roots if and only if all of the following hold:

$$
\bullet \quad b ^ {2} > 4 c
$$

$$
\bullet \qquad b <   0
$$

$$
\bullet \qquad c > 0
$$

As $c > 0$ , we can deduce that $b ^ { 2 } > 4 c$ if and only if $b > 2 { \sqrt { c } }$ or $b < - 2 { \sqrt { c } } .$ . Since we require $b < 0 ,$ , the first is not possible, so the pair of conditions $b < 0$ and $b ^ { 2 } > 4 c$ is equivalent to the single condition $b < - 2 { \sqrt { c } }$

Therefore a necessary and sufficient condition for the original equation to have four distinct real roots is $c > 0$ and $b < - 2 { \sqrt { c } } .$ , which is option D.
