## 题目
The difference between the maximum and minimum values of the function $f ( x ) = a ^ { \cos x }$ where $a > 0$ and $x$ is real, is $3$. Find the sum of the possible values of $a$.

$$
\mathbf {A} \quad 0
$$

$$
\mathbf {B} \quad 3 2
$$

$$
\mathbf {C} \quad 2
$$

$$
\mathbf {D} \quad 3
$$

$$
\mathbf {E} \quad 10
$$

$$
\mathbf {F} \quad \sqrt { 1 3 }
$$

### AI备注


## 答案
F

## 解析
The minimum and maximum values occur when cos $x = \pm 1$ (though which corresponds to the maximum and which to the minimum depends on whether $a < 1 \mathrm { o r } a > 1 \big )$ . Therefore the minimum and maximum values are a and $1 / a$ in some order.

Assuming $a > 1$ , so that $a > 1 / a$ , we require $\textstyle a - { \frac { 1 } { a } } = 3$ . Multiplying by a and rearranging gives $a ^ { 2 } - 3 a - 1 = 0$ , which has roots $\textstyle a = { \frac { 3 \pm { \sqrt { 1 3 } } } { 2 } }$ . The minus sign would give $a < 0$ , so the root we want is $\textstyle a = { \frac { 3 + { \sqrt { 1 3 } } } { 2 } }$ , and this clearly satisfies $a > 1$

Now assuming $a < 1$ , so that $1 / a > a$, , we require $\textstyle { \frac { 1 } { a } } - a = 3$ . Multiplying by a and rearranging gives $a ^ { 2 } + 3 a - 1 = 0$ , which has roots $a = { \frac { - 3 \pm { \sqrt { 1 3 } } } { 2 } }$ . The minus sign would give $a < 0$ , so the root we want is $\textstyle a = { \frac { - 3 + { \sqrt { 1 3 } } } { 2 } }$ (and as $3 < \sqrt { 1 3 } < 4$ , this lies between 0 and ${ \frac { 1 } { 2 } }$. , hence $a < 1 )$ .

The sum of these two values is $\textstyle { \frac { 3 + { \sqrt { 1 3 } } } { 2 } } + { \frac { - 3 + { \sqrt { 1 3 } } } { 2 } } = { \sqrt { 1 3 } }$ , which is option F.
