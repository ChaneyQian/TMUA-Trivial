## 题目

f (x) = \frac {2}{3} x ^ {3} + 2 m x ^ {2} + n, \quad m > 0
$$

has three distinct real roots.

\mathbf {A} \quad - \frac { 8 } { 3 } m ^ { 3 } < n < 0

## 解析
The function will have three distinct real roots if and only if the graph $y \ = \ f ( x )$ has two stationary points, one above the x-axis and one below. We first find the stationary points. We have

$$
f ^ {\prime} (x) = 2 x ^ {2} + 4 m x = 2 x (x + 2 m)
$$

so $f ^ { \prime } ( x ) = 0$ when $x = 0 \ { \mathrm{or} } \ x = - 2 m$

When $x = 0 , f ( x ) = n$ , and when $x = - 2 m$ 2

$$
f (x) = \frac {2}{3} (- 8 m ^ {3}) + 2 m (4 m ^ {2}) + n = n + \frac {8}{3} m ^ {3}.
$$

Since one of the stationary points has $f ( x ) = n$ , we cannot have $n = 0$

Since $m > 0$ , it follows that if $n > 0$ , then $f ( - 2 m ) > 0$ and both turning points would be above the $x { \mathrm { - a x i s } }$ . We must therefore have $n < 0$ and $n + \textstyle { \frac { 8 } { 3 } } m ^ { 3 } > 0$ . The second inequality rearranges to $- \textstyle { \frac { 8 } { 3 } } m ^ { 3 } < n$ , so we require $- \frac { 8 } { 3 } m ^ { 3 } < n < 0$ , which is option A.
