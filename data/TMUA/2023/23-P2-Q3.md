## 题目
For all positive real numbers $x$ and $y$,

$$
\sqrt {x ^ {y}} = x ^ {\sqrt {y}}
$$

Which of the following is/are a counterexample to the claim?

$$
x = 1, y = 1 6
$$

$$
x = 2, y = 8
$$

$$
\mathbf {A} \quad \text{none of them}
$$

$$
\mathbf {B} \quad \text{I only}
$$

$$
\mathbf {C} \quad \text{II only}
$$

$$
\mathbf {D} \quad \text{III only}
$$

$$
\mathbf {E} \quad \text{I and II only}
$$

$$
\mathbf {F} \quad \text{I and III only}
$$

$$
\mathbf {G} \quad \text{II and III only}
$$

$$
\mathbf {H} \quad \text{I, II and III}
$$
## 备注

### AI备注


## 答案
C

## 解析
We substitute the values into the two sides of the equation:

I ${ \sqrt { 1 ^ { 1 6 } } } = { \sqrt { 1 } } = 1$ and $1 ^ { \sqrt { 1 6 } } = 1 ^ { 4 } = 1$ , so this is not a counterexample.

II ${ \sqrt { 2 ^ { 8 } } } = 2 ^ { 4 } = 1 6$ and $2 ^ { \sqrt { 8 } } \neq 1 6$ , so this is a counterexample.

III ${ \sqrt { 3 ^ { 4 } } } = 3 ^ { 2 } = 9$ and $3 ^ { \sqrt { 4 } } = 3 ^ { 2 } = 9$ , so this is not a counterexample.

Therefore the answer is option C, II only.
