## 解析
Let us first consider the function $y = g ( x )$ , where $g ( x ) = x ^ { 2 } - x $ ; we will then substitute $f ( x )$ into this expression once we understand the behaviour of $y = g ( x )$

$g ( x )$ is a quadratic and we can complete the square: $\begin{array} { r } { g ( x ) = ( x - \frac { 1 } { 2 } ) ^ { 2 } - \frac { 1 } { 4 } } \end{array}$ . So $y = g ( x )$ has a minimum value of $\textstyle y = - { \frac { 1 } { 4 } } { \mathrm { ~ a t ~ } } x = { \frac { 1 } { 2 } }$

When we now substitute the values of $f ( x )$ into this completed-square form for $g ( x )$ , obtaining $\left( f ( x ) \right) ^ { 2 } - f ( x )$ . We can see from the graph that there is some value of $x$ with $\begin{array} { r } { f ( x ) = \frac { 1 } { 2 } } \end{array}$ , so this expression has minimum value of $- { \frac { 1 } { 4 } }$

For the maximum value, we see that the value of $g ( x )$ increases symmetrically either side of $\begin{array} { r } { x = { \frac { 1 } { 2 } } } \end{array}$ . So the maximum value of $\left( f ( x ) \right) ^ { 2 } - f ( x )$ will either occur when $f ( x ) = 2$ or when $f ( x ) \stackrel { = } { = } - 2$ . Since $- 2$ is further from $\begin{array} { l } { { \frac { 1 } { 2 } } } \end{array}$ than 2 is, $f ( x ) = - 2$ will give the maximum value, which is $( - 2 ) ^ { 2 } - ( - 2 ) = 6$ . (And if we hadn’t made that observation, we could have calculated $2 ^ { 2 } - 2 = 2$ and seen that it is smaller than 6.)

Therefore the difference between the maximum and minimum values is $\textstyle { 6 - \left( - { \frac { 1 } { 4 } } \right) = { \frac { 2 5 } { 4 } } }$ , which is option F.
