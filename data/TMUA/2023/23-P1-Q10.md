## 题目
The trapezium rule with 4 strips is used to estimate the integral:

$$
\int_ {- 2} ^ {2} \sqrt {4 - x ^ {2}} \mathrm{d} x
$$

What is the positive difference between the estimate and the exact value of the integral?

$$
\mathbf {A} \quad 2 { \big ( } \pi - 2 - 2 { \sqrt { 3 } } { \big ) }
$$

$$
\mathbf {B} \quad 2 { \big ( } \pi - 1 - { \sqrt { 3 } } { \big ) }
$$

$$
\mathbf {C} \quad 2 \left( 2 \pi - 1 - { \sqrt { 3 } } \right)
$$

$$
\mathbf {D} \quad 4 \left( \pi - 1 - { \sqrt { 3 } } \right)
$$

$$
\mathbf {E} \quad 2 \pi - 3 \sqrt { 3 }
$$

$$
\mathbf {F} \quad 4 \pi - 6 \sqrt { 3 }
$$

## 答案
B

## 解析
Though integrating functions like this is not on the syllabus, the question assumes that we can calculate the value of this integral. There is also a hint from the options offered that it may have something to do with circles, as they all involve $\pi$.

Let us therefore consider the graph $y = { \sqrt { 4 - x ^ { 2 } } }$ . Squaring this gives $y ^ { 2 } = 4 - x ^ { 2 } \ { \mathrm { o r } } \ x ^ { 2 } + y ^ { 2 } = 4$ This is the equation of a circle with centre at the origin and radius 2. However, as the graph involves taking the square root of this, the resulting graph is just the upper semicircle (on and above the x-axis).

![[Image/23-P1-Q10-sol1.jpg]]

The integral is from $x = - 2$ to $x = 2 .$ , which is the whole diameter, so the integral is the area of the semicircle, that is, ${ \begin{array} { l } { { \frac { 1 } { 2 } } \times \pi \times 2 ^ { 2 } = 2 \pi } \end{array} }$

We now need to calculate the area as determined by the trapezium rule with 4 strips. We can draw a table of values:

<table><tr><td>x</td><td>-2</td><td>-1</td><td>0</td><td>1</td><td>2</td></tr><tr><td> $\sqrt{4 - x^2}$ </td><td>0</td><td> $\sqrt{3}$ </td><td>2</td><td> $\sqrt{3}$ </td><td>0</td></tr></table>

The trapezium rule then approximates the area as

$$
\frac {1}{2} \times 1 \times (0 + 2 \times \sqrt {3} + 2 \times 2 + 2 \times \sqrt {3} + 0) = \frac {1}{2} \times (4 + 4 \sqrt {3}) = 2 + 2 \sqrt {3}.
$$

The positive difference (as the trapezium rule underestimates the area) is therefore

$$
2 \pi - (2 + 2 \sqrt {3}) = 2 (\pi - 1 - \sqrt {3})
$$

which is option B.
