## 题目
A triangle $ABC$ is to be drawn with $AB = 10\text{cm}$, $BC = 7\text{cm}$ and the angle at $A$ equal to $\theta$, where $\theta$ is a certain specified angle.

Of the two possible triangles that could be drawn, the larger triangle has three times the area of the smaller one.

What is the value of $\cos\theta$?

$$
\mathbf{A} \quad \frac{5}{7}
$$

$$
\mathbf{B} \quad \frac{151}{200}
$$

$$
\mathbf{C} \quad \frac{2\sqrt{2}}{5}
$$

$$
\mathbf{D} \quad \frac{\sqrt{17}}{5}
$$

$$
\mathbf{E} \quad \frac{\sqrt{51}}{8}
$$

$$
\mathbf{F} \quad \frac{\sqrt{34}}{8}
$$

## 解析
This questions calls for a sketch. We draw $A B = 1 0$ , a line from A at an angle $\theta$ to $A B$ (though we do not know what $\theta$ is), and a circular arc centred on B with radius 7.

![[Image/18-P1-Q19-sol1.jpg]]

The sketch shows the two triangles which could be formed subject to these conditions, with the third vertex being at $C _ { 1 }$ or $C _ { 2 }$

One approach, hinted at by the instruction to find cos $\theta ,$ is to use the cosine rule.

In the triangle $A B C _ { 1 }$ , we have

$$
7 ^ {2} = (A C _ {1}) ^ {2} + 1 0 ^ {2} - 2 (A C _ {1}) 1 0 \cos \theta\tag{1}
$$

while in the triangle $A B C _ { 2 }$ , we have

$$
7 ^ {2} = (A C _ {2}) ^ {2} + 1 0 ^ {2} - 2 (A C _ {2}) 1 0 \cos \theta\tag{2}
$$

Unfortunately, we do not know either $A C _ { 1 }$ or $A C _ { 2 }$ . We do, however, know that the larger triangle has three times the area of the smaller one. Taking $A C _ { 1 }$ or $A C _ { 2 }$ as the base of the triangle, the perpendicular height is from B to the line $A C _ { 2 }$ , and is the same for both triangles. So $A C _ { 2 } = 3 ( A C _ { 1 } )$ 1

We can now substitute this into equation (2) to get

$$
7 ^ {2} = 9 (A C _ {1}) ^ {2} + 1 0 ^ {2} - 6 (A C _ {1}) 1 0 \cos \theta
$$

Subtracting equation (1) then $\mathrm { g i }$ ves

$$
0 = 8 (A C _ {1}) ^ {2} - 4 0 (A C _ {1}) \cos \theta
$$

so dividing by $8 A C _ { 1 }$ , we have $A C _ { 1 } = 5\cos\theta$.

We can now substitute this back into equation (1) to get

$$
7 ^ {2} = (5 \cos \theta) ^ {2} + 1 0 ^ {2} - 2 0 (5 \cos \theta) \cos \theta
$$

so

$$
4 9 = 2 5 \cos^ {2} \theta + 1 0 0 - 1 0 0 \cos^ {2} \theta
$$

which simplifies to

$$
7 5 \cos^ {2} \theta = 5 1
$$

so $\cos ^ { 2 } \theta = { \frac { 5 1 } { 7 5 } } = { \frac { 1 7 } { 2 5 } }$ giving cos $\theta = { \frac { \sqrt { 1 7 } } { 5 } } \ ( \mathrm { a s \ c o s \ } \theta > 0 )$

If we drop a perpendicular from B to the line $A C _ { 2 }$ , and let $x = A C _ { 1 }$ , our diagram becomes:

Now D is midway between $C _ { 1 }$ and $C _ { 2 }$ by symmetry (or by using the $\mathrm { \Delta ^ { 6 6 } R H S ^ { 9 } }$ congruency rule on the triangles $B D C _ { 1 }$ and $B D C _ { 2 } )$ , so $C _ { 1 } D = D C _ { 2 }$
