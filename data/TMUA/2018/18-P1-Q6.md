## 题目
Find the number of solutions of the equation

$x\sin 2x = \cos 2x$

with $0 \leq x \leq 2\pi$ .

\mathbf {A} \quad 0

## 解析
This equation has trigonometric functions and an x on its own. Our best bet is to first rearrange it to bring all of the trigonometric functions together. We have a sin 2x on one side and a cos 2x on the other, which suggests that we should divide by cos 2x to obtain tan 2x. This gives

$$
x \tan 2 x = 1
$$

We should check, though, that we cannot have cos $2 x = 0 ,$ , so that we are allowed to divide by it. If cos $2 x = 0 .$ , this would require x sin $2 x = 0$ , so either sin $2 x = 0 .$ , which is impossible if cos $2 x = 0$ , or $x = 0$ . But ${ \mathrm{if~} } x = 0$ , then cos $2 x = 1$ , so this is also impossible. So we cannot have cos $2 x = 0$

Returning to x tan $2 x = 1$ , we can divide by x to get

$$
\tan 2 x = \frac {1}{x}
$$

This equation is not possible to solve exactly. But the question (thankfully) only asks us how many solutions there are in the range $0 \leqslant x \leqslant 2\pi$

So we can sketch the graphs of $y = \tan 2 x$ and $\textstyle y = { \frac { 1 } { x } }$ and see how many times they intersect.

![[Image/18-P1-Q6-sol1.jpg]]

We see that the graph of $\textstyle y = { \frac { 1 } { x } }$ intersects every positive branch of $y = \tan 2 x$ once. Since there are four branches of $y = \tan 2 x$ in the range $0 \leqslant x \leqslant 2 \pi$ , there are four solutions, so the correct answer is E.
