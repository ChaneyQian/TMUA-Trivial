## 题目
Which one of the following functions provides a counterexample to the statement:

if $f'(x) > 0$ for all real $x$, then $f(x) > 0$ for all real $x$.

$$
\mathbf{A} \quad f(x) = x^2 + 1
$$

$$
\mathbf{B} \quad f(x) = x^2 - 1
$$

$$
\mathbf{C} \quad f(x) = x^3 + x + 1
$$

$$
\mathbf{D} \quad f(x) = 1 - x
$$

$$
\mathbf{E} \quad f(x) = 2^x
$$

## 答案
C

## 解析
A counterexample to an $\bf \cdot i f$ P then $Q '$ statement is an example where the statement is false, that is where $P$ (the antecedent) is true but $Q$ (the consequent) is false.

We can now look through the given functions to see which of them satisfies these requirements. We give our results as a table and make comments on the working below.

<table><tr><td></td><td>f(x)</td><td>f&#x27;(x)</td><td>f&#x27;(x) &gt; 0 for all x</td><td>f(x) &gt; 0 for all x</td></tr><tr><td>A</td><td> $x^{2} + 1$ </td><td>2x</td><td>false</td><td></td></tr><tr><td>B</td><td> $x^{2} - 1$ </td><td>2x</td><td>false</td><td></td></tr><tr><td>C</td><td> $x^{3} + x + 1$ </td><td> $3x^{2} + 1$ </td><td>true</td><td>false</td></tr><tr><td>D</td><td>1 - x</td><td>-1</td><td>false</td><td></td></tr><tr><td>E</td><td> $2^{x}$ </td><td>?</td><td>true</td><td>true</td></tr></table>

Once we know that $\mathrm { f } ^ { \prime } ( x ) > 0$ for all x is false, there is no need to $_ \mathrm{go}$ any further, so for A, B and D, we stop at this point.

For $\mathrm { C } , 3 x ^ { 2 } \geqslant 0$ for all $x ,$ so $3 x ^ { 2 } + 1 \geqslant 1 > 0$ for all $x ,$ and we know that cubics $( x ^ { 3 } + x + 1$ in this case) always take both positive and negative values, so $\operatorname { f } ( x ) > 0$ for all x is false.

For E, we don’t know what the derivative of $2 ^ { x }$ is (or at least, knowledge of it is not required for this test), but we do know that $2 ^ { x }$ is increasing for all $x ,$ so the derivative is positive for all x.

Finally, only C has the antecedent true and the consequent false, so $\mathrm { C }$ provides a counterexample.
