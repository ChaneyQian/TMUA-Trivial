## 题目
What is the smallest positive value of $a$ for which the line $x = a$ is a line of symmetry of the graph of $y = \sin\left(2x - \frac{4\pi}{3}\right)$?

$$
\mathbf{A} \quad \frac{\pi}{12}
$$

$$
\mathbf{B} \quad \frac{5\pi}{12}
$$

$$
\mathbf{C} \quad \frac{7\pi}{12}
$$

$$
\mathbf{D} \quad \frac{11\pi}{12}
$$

$$
\mathbf{E} \quad \frac{19\pi}{12}
$$

### AI备注


## 答案
B

## 解析
The lines of symmetry of a sine or cosine graph (that is, something of the form sin $( k x + \theta ) + c$ or cos $( k x + \theta ) + c )$ are at the x-values where the sine or cosine equals $\pm 1$ . So in this case, if we solve sin $\begin{array} { r } { ( 2 x - \frac { 4 \pi } { 3 } ) = \pm 1 } \end{array}$ we will find the lines of symmetry.

We solve each of them separately.

We have sin $\theta = 1$ when $\textstyle { \theta = { \frac { \pi } { 2 } } + 2 n \pi }$ (for any integer n), so in this case, this gives

$$
\begin{array}{r l r} & & 2 x - \frac {4 \pi}{3} = \frac {\pi}{2} + 2 n \pi \\ & \Longleftrightarrow & 2 x = \frac {1 1 \pi}{6} + 2 n \pi \\ & \Longleftrightarrow & x = \frac {1 1 \pi}{1 2} + n \pi \end{array}
$$

So the smallest positive value of $x$ with sin $\begin{array} { r } { ( 2 x - \frac { 4 \pi } { 3 } ) = 1 } \end{array}$ is $\begin{array} { r } { x = \frac { 1 1 \pi } { 1 2 } } \end{array}$

In the second case, we have sin $\theta = - 1$ when $\theta = - \textstyle { \frac { \pi } { 2 } } + 2 n \pi$ (for any integer n), so in this case, this gives

$$
\begin{array}{r l r} & & 2 x - \frac {4 \pi}{3} = - \frac {\pi}{2} + 2 n \pi \\ & \Longleftrightarrow & 2 x = \frac {5 \pi}{6} + 2 n \pi \\ & \Longleftrightarrow & x = \frac {5 \pi}{1 2} + n \pi \end{array}
$$

So the smallest positive value of $x$ with sin $\begin{array} { r } { ( 2 x - \frac { 4 \pi } { 3 } ) = - 1 } \end{array}$ is $\begin{array} { r } { x = \frac { 5 \pi } { 1 2 } } \end{array}$

This is smaller than $\frac { 1 1 \pi } { 1 2 }$ so the answer is $\frac { 5 \pi } { 1 2 }$ , which is option B.
