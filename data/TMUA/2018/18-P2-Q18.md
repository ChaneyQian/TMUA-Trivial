## 题目
$f(x)$ is a polynomial function defined for all real $x$.

Which of the following is a **necessary** condition for the inequality

$$
\frac{\mathrm{f}(a) + \mathrm{f}(b)}{2} \geq \mathrm{f}\left(\frac{a+b}{2}\right)
$$

to be true for all real numbers $a$ and $b$ with $a < b$?

$$
\mathbf{A} \quad f(x) \geq 0 \text{ for all real } x
$$

$$
\mathbf{B} \quad f'(x) \geq 0 \text{ for all real } x
$$

$$
\mathbf{C} \quad f''(x) \geq 0 \text{ for all real } x
$$

$$
\mathbf{D} \quad f(x) \leq 0 \text{ for all real } x
$$

$$
\mathbf{E} \quad f'(x) \leq 0 \text{ for all real } x
$$

$$
\mathbf{F} \quad f''(x) \leq 0 \text{ for all real } x
$$

## 答案
C

## 解析
It is helpful to draw a sketch of $y = \operatorname { f } ( x )$ to understand what is going on here.

Note first that $\frac { \operatorname { f } ( a ) + \operatorname { f } ( b ) } { 2 }$ is the mean of the $\operatorname { f } ( a )$ and $\operatorname { f } ( b )$ , so if we draw a line segment from $( a , \mathrm { f } ( a ) )$ to (b, f(b)) on the graph of $y = \operatorname { f } ( x )$ , then the point $\left( { \frac { a + b } { 2 } } , { \frac { \operatorname { f } ( a ) + \operatorname { f } ( b ) } { 2 } } \right)$ is the midpoint of this line segment. Likewise, $\left( { \frac { a + b } { 2 } } , \operatorname { f } \left( { \frac { a + b } { 2 } } \right) \right)$ is the point on the graph with this x-coordinate.

The inequality states that the line segment lies above the graph at this point, so the graph could look something like this:

![[Image/18-P2-Q18-sol1.jpg]]

We see the for the inequality to be true in this case, the curve needs to “bend $\mathrm{up} ^ { \mathrm { , } }$ , so that it is below the chord connecting $( a , \mathrm { f } ( a ) )$ ) with $( b , \mathrm { f } ( b ) )$ ). This means that the second derivative, $\mathrm { f ^ { \prime \prime } } ( x )$ must be positive. So it would seem likely that the answer is C.

Without too much dificulty we can see that the other options don’t work, just by looking at the above sketch. This shows that none of D, E or F is necessary (for the curve could bend back upwards for more negative values of $x$, as in a quadratic). If we translate the graph downwards, then it will still have this property, but A is no longer the case, so A is not necessary. And if we continue this graph to more negative values of $x$, it will have $\mathrm { f } ^ { \prime } ( x ) < 0 \ \mathrm{if}$ we $_ \mathrm{go}$ far enough, so B is not necessary either.

Therefore by elimination, C must be necessary.

We can also prove directly that C is necessary. To do so, we will prove the contrapositive: if $\mathrm { f } ^ { \prime \prime } ( x ) < 0$ for some real $x _ { i }$ , then there are real numbers $a$ and $b$ with $a < b$ for which

$$
\frac {\mathrm{f} (a) + \mathrm{f} (b)}{2} <   \mathrm{f} \left(\frac {a + b}{2}\right)\tag{(*)}
$$

Now, $\mathrm { f } ^ { \prime \prime } ( x ) < 0$ means that the curve is “bending downwards” at this point, which means that a sketch of the graph will look like a reflection of the above sketch in a horizontal line (at least near the point where $\mathrm { f ^ { \prime \prime } } ( x ) < 0 )$ . And then the curve will lie above the chord, so (∗) is true. Hence C is necessary.

Commentary: An interesting question to wonder about is whether there are any examples of such polynomial functions. Clearly, constant polynomials $\left( \operatorname { f } ( x ) \ : = \ : c \right)$ satisfy the condition, as do linear polynomials $( \operatorname { f } ( x ) = a x + b )$ and quadratics with a positive coefficient of $x ^ { 2 } \ ( \mathrm { f } ( x ) = a x ^ { 2 } + b x + c$ with $a > 0 )$

For higher degree polynomials, if $\operatorname { f } ( x ) = a x ^ { n } + \cdots$ , then $\mathrm { f } ^ { \prime \prime } ( x ) = a n ( n - 1 ) x ^ { n - 2 } + \cdot \cdot \cdot$ . If n is odd, then this polynomial takes all real values, including negative ones, so this cannot satisfy the condition. If n is even, then it might be the case that $\mathrm { f } ^ { \prime \prime } ( x ) \geqslant 0$ for all x, which will be the case if $f ^ { \prime \prime } ( x ) \geqslant 0$ at all of its stationary points.

For example, if we take $\mathrm { f } ^ { \prime \prime } ( x ) \ = \ 3 x ^ { 1 } + 1$ , then the corresponding f(x) will have this condition.

A function satisfying this condition is called a convex function.
