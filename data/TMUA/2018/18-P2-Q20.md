## 题目
It is given that the equation $\sqrt{x+p}+\sqrt{x}=p$ has at least one real solution for $x$, where $p$ is a real constant.

What is the complete set of possible values for $p$?

$$
\mathbf{A} \quad p = 0 \text{ or } p = 1
$$

$$
\mathbf{B} \quad p = 0 \text{ or } p \geq 1
$$

$$
\mathbf{C} \quad p \geq -x
$$

$$
\mathbf{D} \quad p \geq \sqrt{x}
$$

$$
\mathbf{E} \quad p \geq 0
$$

$$
\mathbf{F} \quad p \geq 1
$$

## 答案
B

## 解析
## An algebraic approach

We can manipulate the equation algebraically. We could square it immediately, but it is probably simpler to first move one of the square roots to the other side so that there is only one square root on each side, that is ${ \sqrt { x + p } } = p - { \sqrt { x } }$

We can now square this to obtain

$$
x + p = p ^ {2} - 2 p \sqrt {x} + x
$$

so $2 p { \sqrt { x } } = p ^ { 2 } - p$

If $p \neq 0$ , we can divide by p to obtain $2 { \sqrt { x } } = p - 1$ . Since the left side of this must be positive, there will be a solution as long as $p \geqslant 1$

We also need to check that when $p \geqslant 1$ , the solution obtained does satisfy the original equation. We have ${ \sqrt { x } } = { \textstyle { \frac { 1 } { 2 } } } ( p - 1 )$ so $\begin{array} { r } { x = \frac { 1 } { 4 } ( p - 1 ) ^ { 2 } } \end{array}$ . Then the left side of the original equation becomes

$$
\sqrt {\frac {1}{4} (p - 1) ^ {2} + p} + \sqrt {\frac {1}{4} (p - 1) ^ {2}} = \sqrt {\frac {1}{4} (p + 1) ^ {2}} + \sqrt {\frac {1}{4} (p - 1) ^ {2}} = \frac {1}{2} (p + 1) + \frac {1}{2} (p - 1) = p
$$

and so this is a real solution.

Finally, when $p = 0$ (which we excluded earlier), the equation becomes ${ \sqrt { x } } + { \sqrt { x } } = 0$ , which has the solution $x = 0$

Thus the correct option is B.

## A graphical approach

We can sketch the graph $y = { \sqrt { x + p } } + { \sqrt { x } }$ . We know that $\sqrt { x }$ is an increasing function, defined for $x \geqslant 0$ , taking only non-negative values. It follows that $y = { \sqrt { x + p } }$ is also an increasing function, defined for x $\geqslant - p .$ , being a translation of $y = { \sqrt { x } }$ by p in the negative x-direction.

Here is a sketch of the two graphs for some $p > 0 :$

Clearly, there cannot be a solution for $p < 0$ , as the left hand side is never negative. For $p \geqslant 0$ the function on the left hand side is defined for all $x \geqslant 0$ , and is increasing towards infinity. So the smallest value the function takes is when $x = 0$ , which is ${ \sqrt { p } } ,$ and it takes on every value larger than this. So there will be a solution to the original equation whenever ${ \sqrt { p } } \leqslant p { \mathrm { : } }$ , which is whenever $p \leqslant p ^ { 2 }$ , that is $p ^ { 2 } - p \geqslant 0 \mathrm{~or~} p ( p - 1 ) \geqslant 0$ . This holds for $p \leqslant 0$ and $p \geqslant 1$ . Since we also require $p \geqslant 0$ , there is a solution for $p = 0$ and for all $p \geqslant 1$

Hence the correct option is B.
