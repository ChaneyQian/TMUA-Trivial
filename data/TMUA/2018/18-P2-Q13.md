## 题目
The following is an attempted proof of the conjecture:

$$
\textbf{if } \tan\theta > 0 \textbf{, then } \sin\theta + \cos\theta > 1.
$$

Suppose $\tan\theta > 0$, so in particular $\cos\theta \neq 0$.

$$
\text{Since } \tan\theta = \frac{\sin\theta}{\cos\theta} \text{, then } \sin\theta\cos\theta = \tan\theta\cos^2\theta > 0. \qquad \text{(I)}
$$

$$
\text{It follows that } 1 + 2\sin\theta\cos\theta > 1. \qquad \text{(II)}
$$

$$
\text{Therefore } \sin^2\theta + 2\sin\theta\cos\theta + \cos^2\theta > 1, \qquad \text{(III)}
$$

$$
\text{which factorises to give } (\sin\theta + \cos\theta)^2 > 1. \qquad \text{(IV)}
$$

$$
\text{Therefore } \sin\theta + \cos\theta > 1. \qquad \text{(V)}
$$

Which one of the following is the case?

$$
\mathbf{A} \quad \text{The proof is correct.}
$$

$$
\mathbf{B} \quad \text{The proof is incorrect, and the first error occurs in line (I).}
$$

$$
\mathbf{C} \quad \text{The proof is incorrect, and the first error occurs in line (II).}
$$

$$
\mathbf{D} \quad \text{The proof is incorrect, and the first error occurs in line (III).}
$$

$$
\mathbf{E} \quad \text{The proof is incorrect, and the first error occurs in line (IV).}
$$

$$
\mathbf{F} \quad \text{The proof is incorrect, and the first error occurs in line (V).}
$$

## 解析
Commentary: One thing we can do when faced with a question like this it to first try different values of $\theta$ to see whether the conjecture appears to be true or false. If it is false, as shown by some counterexample, then substituting this value of $\theta$ into every line might indicate where the error arises. If, on the other hand, we cannot find a counterexample, then the conjecture and argument may well be true.

In this case, given that we are dealing with trigonometric functions, we would do well to think about their graphs and try values of $\theta$ in different quadrants.

If we sketch (or think about) the graphs of sin, cos and tan, we have the following:

![[Image/18-P2-Q13-sol1.jpg]]

If the conjecture is false, we need a value of $\theta$ where tan $\theta > 0$ but sin $\theta + \cos \theta < 1$

We see that tan $\theta > 0$ for $\begin{array} { r } { 0 < \theta < \frac { \pi } { 2 } } \end{array}$ but there sin $\theta +$ cos $\theta > 1$ looks like it might be true. We also have tan $\theta > 0$ when $\textstyle \pi < \theta < { \frac { 3 \pi } { 2 } }$ and there $\sin\theta$ and $\cos\theta$ are both negative, so sin $\theta +$ cos $\theta > 1$ cannot be true. So if we take $\textstyle { \bar { \theta } } = { \frac { 5 \pi } { 4 } }$ we may find the source of the error.

On line (I), we get $\sin\theta \cos\theta = ( - \tfrac { 1 } { \sqrt { 2 } } ) ( - \tfrac { 1 } { \sqrt { 2 } } ) = \tfrac { 1 } { 2 }$ and tan $\begin{array} { r } { \theta \cos ^ { 2 } \theta = 1 \cdot ( - \frac { 1 } { \sqrt { 2 } } ) ^ { 2 } = \frac { 1 } { 2 } } \end{array}$ so this line looks reasonable.

On line (II), we get $1 + 2 \cdot { \frac { 1 } { 2 } } = 1 + 1 > 1$ which is correct.

On line (III), we get $\textstyle { \frac { 1 } { 2 } } + 2 \cdot { \frac { 1 } { 2 } } + { \frac { 1 } { 2 } } = 2 > 1$ so this is correct.

On line (IV), we get $( - { \frac { 1 } { \sqrt { 2 } } } - { \frac { 1 } { \sqrt { 2 } } } ) ^ { 2 } = 2 > 1$ so this line is correct for this value of $\theta$.

On line (V), we have $- { \frac { 1 } { \sqrt { 2 } } } - { \frac { 1 } { \sqrt { 2 } } } = - { \sqrt { 2 } }$ and $- { \sqrt { 2 } } > 1$ is false. So it appears that the first error is likely to occur here: indeed, we have taken the square root of $x ^ { 2 } > 1$ and obtained $x > 1$ • which is not necessarily the case, as we could have $x < - 1$

We should now go back and check that the earlier steps are actually valid, as there could have been an earlier error. But with some thinking, we can see that all of them are correct:

(I) This is obtained by multiplying both sides of tan $\theta > 0$ by $\cos ^ { 2 } \theta > 0$ (and we cannot have cos $\theta = 0 )$ ), and then noting the equality from the definition of $\tan\theta$ given.

(II) This is obtained by doubling the previous inequality and then adding 1.

(III) Here, the identity si $\operatorname { n } ^ { 2 } \theta + \cos ^ { 2 } \theta = 1$ has been used to rewrite the left hand side.

(IV) This factorisation is correct.

(V) As we saw, an error occurs here.

Hence the answer is F.
