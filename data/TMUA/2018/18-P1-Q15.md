## 题目
Find the sum of the real solutions of the equation:

$$
3 ^ {x} - (\sqrt {3}) ^ {x + 4} + 2 0 = 0
$$

$$
\mathbf {A} \quad 1
$$

$$
\mathbf {B} \quad 4
$$

$$
\mathbf {C} \quad 9
$$

$$
\mathbf {D} \quad \log_320
$$

$$
\mathbf {E} \quad 2\log_320
$$

$$
\mathbf {F} \quad 4\log_320
$$

## 答案
E

## 解析
We note that $3 = \left( { \sqrt { 3 } } \right) ^ { 2 }$

So if we write $y = \left( { \sqrt { 3 } } \right) ^ { x }$ , the equation becomes

$$
y ^ {2} - \left(\sqrt {3}\right) ^ {4} y + 2 0 = 0
$$

or

$$
y ^ {2} - 9 y + 2 0 = 0
$$

This factorises to give $( y - 4 ) ( y - 5 ) = 0$ so either $y = 4$ or $y = 5$

We can write $y = \left( 3 ^ { \frac { 1 } { 2 } } \right) ^ { x } = 3 ^ { \frac { 1 } { 2 } x }$ so either $3 ^ { \frac { 1 } { 2 } x } = 4 { \mathrm { ~ o r ~ } } 3 ^ { \frac { 1 } { 2 } x } = 5$

We can now take logs to base 3 to obtain

$$
\frac {1}{2} x = \log_ {3} 4 \quad \mathrm{or} \quad \frac {1}{2} x = \log_ {3} 5
$$

so

$$
x = 2 \log_ {3} 4 \quad \mathrm{or} \quad x = 2 \log_ {3} 5
$$

The question has asked for the sum of the real solutions of the equation. Both of these are real, so we can add them to get $2 \log _ { 3 } 4 + 2 \log _ { 3 } 5 = 2 \log _ { 3 } 2 0$ using the log rule log $a b = \log a + \log b$ Hence the answer is E.
