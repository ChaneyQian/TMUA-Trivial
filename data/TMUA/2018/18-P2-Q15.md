## 题目
It is given that $f(x) = x^{3} + 3qx^{2} + 2$ , where $q$ is a real constant.

The equation $f(x) = 0$ has 3 distinct real roots.

Which of the following statements is/are necessarily true?

I The equation $f(x) + 1 = 0$ has 3 distinct real roots.

II The equation $\mathrm{f}(x + 1) = 0$ has 3 distinct real roots.

III The equation $f(-x) - 1 = 0$ has 3 distinct real roots.

## 解析
This question appears to be related to graph transformations, so we will start with this approach and see where it leads.

The equation $\operatorname { f } ( x ) = 0$ has 3 distinct real roots, so $y = \operatorname { f } ( x )$ intersects the x-axis 3 times.

I The graph of $y = \operatorname { f } ( x ) + 1$ is a translation of $y = \operatorname { f } ( x )$ in the y-direction by 1 unit, which may or may not intersect the x-axis 3 times.

II The graph of $y = \operatorname { f } ( x + 1 )$ is a translation of $y = \operatorname { f } ( x )$ in the negative x-direction by 1 unit, so it will still intersect the x-axis 3 times, and hence $\operatorname { f } ( x + 1 ) = 0$ has 3 distinct roots.

III The graph of $y = \operatorname { f } ( - x )$ is a reflection of $y = \operatorname { f } ( x )$ in the $y \mathrm { - a x i s }$ , which still intersects the x-axis 3 times. Then $y = \operatorname { f } ( - x ) - 1$ is a translation in the negative y-direction by 1 unit, which may or may not intersect the x-axis 3 times.

It is still not clear whether or not I or III are necessarily true. We will have to identify where the turning points of the graph are to determine this.

We have

$$
\mathrm{f} (x) = x ^ {3} + 3 q x ^ {2} + 2
$$

so

$$
\mathrm{f} ^ {\prime} (x) = 3 x ^ {2} + 6 q x
$$

so $\mathrm { f } ^ { \prime } ( x ) = 0$ when $x = 0 { \mathrm{~or~} } x = = - 2 q$ , so the stationary points are at (0, 2) and $( - 2 q , 2 + 4 q ^ { 3 } )$ As the graph crosses the x-axis 3 times, the stationary points must lie either side of the x-axis, so $2 + 4 q ^ { 3 } < 0$

Therefore when the graph is translated up by 1 unit, we may have the new stationary point at $( - 2 q , 2 + 4 q ^ { 3 } + 1 )$ with $2 + 4 q ^ { 3 } + 1 > 0$ , but when it is translated down by 1 unit, they will be at (0, 1) and $( - 2 q , 2 + 4 q ^ { 3 } - 1 )$ , and $2 + 4 q ^ { 3 } - 1 < 0$ . So there will still be 3 intersections.

Therefore II and III are necessarily true, and the answer is G.
