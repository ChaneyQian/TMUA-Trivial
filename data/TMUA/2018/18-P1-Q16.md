## 题目
The curve $C$ has equation $y = x^{2} + bx + 2$ , where $b \geq 0$ .

Find the value of $b$ that minimises the distance between the origin and the stationary point of the curve C.

$$
\mathbf {A} \quad b = 0
$$

$$
\mathbf {B} \quad b = 1
$$

$$
\mathbf {C} \quad b = 2
$$

$$
\mathbf {D} \quad b = \frac {\sqrt {6}}{2}
$$

$$
\mathbf {E} \quad b = \sqrt {2}
$$

$$
\mathbf {F} \quad b = \sqrt {6}
$$

### AI备注


## 答案
F

## 解析
We first need to find the stationary point of the curve C. We can do this either by diferentiating or, as the equation is a quadratic, by completing the square.

By diferentiating, we have

$$
{\frac {\mathrm{d} y}{\mathrm{d} x}} = 2 x + b
$$

so ${ \frac { \mathrm { d } y } { \mathrm { d } x } } = 0$ if and only if $x = - { \frac { 1 } { 2 } } b$ , and so

$$
y = (- \frac {1}{2} b) ^ {2} + b (- \frac {1}{2} b) + 2 = 2 - \frac {1}{4} b ^ {2}
$$

Alternatively, we can complete the square to give $\begin{array} { r } { y = ( x + \frac { 1 } { 2 } b ) ^ { 2 } - \frac { 1 } { 4 } b ^ { 2 } + 2 } \end{array}$ , and so the stationary point is at $\begin{array} { r l } {  { \big ( - \frac { 1 } { 2 } b , 2 - \frac { 1 } { 4 } b ^ { 2 } \big ) } \quad } & { { } } \end{array}$

The distance of this point from the origin is then given by

$$
\sqrt {(- \frac {1}{2} b) ^ {2} + (2 - \frac {1}{4} b ^ {2}) ^ {2}} = \sqrt {\frac {1}{4} b ^ {2} + 4 - 4 (\frac {1}{4} b ^ {2}) + \frac {1}{1 6} b ^ {4}} = \sqrt {\frac {1}{1 6} b ^ {4} - \frac {3}{4} b ^ {2} + 4}
$$

To minimise this square root, we can minimise the expression inside the square root. This is a function of $B = \boldsymbol { b } ^ { 2 }$ , namely $\textstyle { \frac { 1 } { 1 6 } } B ^ { 2 } - { \frac { 3 } { 4 } } B + 4$ , so we can minimise this.

Commentary: If a quartic is actually a quadratic in the variable squared, it is usually much easier to work with the quadratic than the quartic.

We can minimise this by completing the square or diferentiating, as before. We can start by taking out a factor of $\textstyle { \frac { 1 } { 1 6 } }$ so we are trying to minimise $\textstyle { \frac { 1 } { 1 6 } } ( B ^ { 2 } - 1 2 B ) + 4$ . (There’s no need to think about the 4 at the end: this additional term does not change the value of $b$ or B at which the function is minimised.)

We therefore wish to minimise $B ^ { 2 } - 1 2 B = ( B - 6 ) ^ { 2 } - 3 6$ so $B = 6$ gives the minimum value, so $b ^ { 2 } = 6$ giving $b = { \sqrt { 6 } }$ (as $b \geqslant 0 )$ , hence the answer is F.

Commentary: We could have gone ahead and diferentiated the whole square root expression for distance, if we know the chain rule. But that’s more efort than needed. Similarly, we could have diferentiated the expression as a quartic, but again that is more complex than required. It is almost always worth spending a moment thinking how to make the problem a little easier before diving into algebra and calculations.
