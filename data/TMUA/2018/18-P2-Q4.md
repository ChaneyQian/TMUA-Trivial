## 题目
The non-zero real number $c$ is such that the equation $\cos x = c$ has two solutions for $0 < x < \frac{3}{2}\pi$ .

How many solutions of the equation $\cos^2 2x = c^2$ are there in the range $0 < x < \frac{3}{2}\pi$ ?

$$
\mathbf {A} \quad 2
$$

$$
\mathbf {B} \quad 3
$$

$$
\mathbf {C} \quad 4
$$

$$
\mathbf {D} \quad 6
$$

$$
\mathbf {E} \quad 7
$$

$$
\mathbf {F} \quad 8
$$

D

## 解析
It is worth sketching a graph of $y = \cos x $ to understand the meaning of the stated condition. Two lines have been drawn corresponding to diferent values of $c$.

![[Image/18-P2-Q4-sol1.jpg]]

For there to be two solutions for $\textstyle 0 < x < { \frac { 3 } { 2 } } \pi$ , we see from the sketch that we need $- 1 < c < 0$ We now consider the equation $\cos ^ { 2 } 2 x = c ^ { 2 }$ , so cos $2 x = \pm c$

There are two straightforward approaches. The first is to sketch the graph of $y = \cos 2 x$ and look at $\begin{array} { r } { 0 < x < \frac { 3 } { 2 } \pi ; } \end{array}$ the second is to note that the range can be written as $0 < 2 x < 3 \pi$ , so we could write $u = 2 x$ and look for solutions to cos $u = \pm c$ in the range $0 < u < 3 \pi$ . We will use the first approach here; the second is very similar.

We immediately see that, for $\begin{array} { r } { 0 < x < \frac { 3 } { 2 } \pi } \end{array}$ , there are six solutions to our equation, so the correct answer is D.
