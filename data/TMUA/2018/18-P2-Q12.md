## 题目
Consider the following statement:

For any positive integer $N$ there is a positive integer $K$ such that $N(Km+1)-1$ is not prime for any positive integer $m$.

Which one of the following is the negation of this statement?

$$
\mathbf {A} \quad \text{For any positive integer } N \text{ there is a positive integer } K \text{ such that there is a positive integer } m \text{ for which } N(Km+1)-1 \text{ is prime.}
$$

$$
\mathbf {B} \quad \text{For any positive integer } N \text{ there is a positive integer } K \text{ such that there is a positive integer } m \text{ for which } N(Km+1)-1 \text{ is not prime.}
$$

$$
\mathbf {C} \quad \text{For any positive integer } N \text{ there is a positive integer } K \text{ such that for any positive integer } m, N(Km+1)-1 \text{ is not prime.}
$$

$$
\mathbf {D} \quad \text{For any positive integer } N \text{, any positive integer } K \text{ and any positive integer } m, N(Km + 1) - 1 \text{ is not prime.}
$$

$$
\mathbf {E} \quad \text{There is a positive integer } N \text{ such that for any positive integer } K \text{ there is a positive integer } m \text{ for which } N(Km+1)-1 \text{ is not prime.}
$$

$$
\mathbf {F} \quad \text{There is a positive integer } N \text{ such that for any positive integer } K \text{ there is a positive integer } m \text{ for which } N(Km+1)-1 \text{ is prime.}
$$

$$
\mathbf {G} \quad \text{There is a positive integer } N \text{ such that for any positive integer } K \text{ and any positive integer } m, N(Km+1)-1 \text{ is prime.}
$$

$$
\mathbf {H} \quad \text{There is a positive integer } N \text{ and a positive integer } K \text{ for which there is no positive integer } m \text{ for which } N(Km+1)-1 \text{ is prime.}
$$

## 答案
F

## 解析
The negation of ‘for any $N$, $P$’ is ‘there exists $N$ such that not $P$’. So none of options A-D can be a negation of the original statement, but all of E-H still have the potential to be.

In this case, the statement $P$ is ‘there is a postiive integer $K$ such that $N(Km+1)-1$ is not prime for any positive integer $m$’; this is a statement of the form ‘there exists’, and we wish to negate it. The negation of ‘there exists $K$ such that $Q$’ is ‘for all $K$, not $Q$’, so we are looking for a statement which continues with ‘for all positive integers $K$’, and this eliminates option H. (‘For any’ and ‘for all’ are equivalent ways of expressing this.) So we are now looking at options E, F and G.

The statement $Q$ that we wish to negate is ‘$N(Km+1)-1$ is not prime for any positive integer $m$’, which we can rewrite with the quantifier (‘for any’) at the start of the statement to give ‘for any positive integer $m$, $N(Km+1)-1$ is not prime’. And the negation of ‘for all $m$, $R$’ is ‘there exists $m$ such that not $R$’, which in this case is ‘there exists a positive integer $m$ such that it is not the case that $N(Km+1)-1$ is not prime’, so option G is not correct.

Now ‘not not $S$’ is equivalent to $S$, so this becomes ‘there exists a positive integer $m$ such that $N(Km+1)-1$ is prime’. The only option which matches this is option F, and this is therefore the correct answer.
