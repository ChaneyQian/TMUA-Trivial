## 题目
The line $y = mx + 5$ , where $m > 0$, is normal to the curve $y = 10 - x^{2}$ at the point $(p, q)$ .
What is the value of $p$?

$$
\mathbf {A} \quad \frac{\sqrt{2}}{6}
$$

$$
\mathbf {B} \quad -\frac{\sqrt{2}}{6}
$$

$$
\mathbf {C} \quad \frac{3\sqrt{2}}{2}
$$

$$
\mathbf {D} \quad -\frac{3\sqrt{2}}{2}
$$

$$
\mathbf {E} \quad \sqrt{5}
$$

$$
\mathbf {F} \quad -\sqrt{5}
$$

## 答案
C

## 解析
We can find the equation of the normal to the curve $y = 1 0 - x ^ { 2 }$ at the point $( p , q )$ as usual. The derivative is ${ \frac { \mathrm { d } y } { \mathrm { d } x } } = - 2 x$ so at $x = p$ the tangent has gradient $- 2 p$ . Therefore the normal has gradient $\frac { 1 } { 2 p }$ .

The tangent and normal both pass through the point $( p , 1 0 - p ^ { 2 } )$ , which shows that $q = 1 0 - p ^ { 2 }$ The normal thus has equation

$$
y - (1 0 - p ^ {2}) = \frac {1}{2 p} (x - p)
$$

so rearranging into the form $y = m x + c$ gives

$$
y = \frac {1}{2 p} x - \frac {1}{2} + 1 0 - p ^ {2}
$$

We want this to have the form $y = m x + 5$ where $m > 0$ , so we have

$$
- \frac {1}{2} + 1 0 - p ^ {2} = 5.
$$

Rearranging thus gives

$$
p ^ {2} = \frac {9}{2}
$$

and hence $p = \pm { \frac { 3 } { \sqrt { 2 } } } = \pm { \frac { 3 { \sqrt { 2 } } } { 2 } }$

Since $m = \frac { 1 } { 2 p } > 0$ we must have $p > 0$ so $p = { \frac { 3 { \sqrt { 2 } } } { 2 } }$

The correct answer is C.
