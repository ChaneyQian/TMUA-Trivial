## 题目
The function $\mathrm{f}(x)$ is defined for all real numbers.

Consider the following three conditions, where $a$ is a real constant:

I $f(a - x) = f(a + x)$ for all real x.

II $f(2a - x) = f(x)$ for all real $x$ .

III $f(a - x) = f(x)$ for all real x.

Which of these conditions is/are necessary and sufficient for the graph of $y = \mathrm{f}(x)$ to have reflection symmetry in the line x = a?

$$
\mathbf {A} \quad \text{I: yes, II: yes, III: yes}
$$

$$
\mathbf {B} \quad \text{I: yes, II: yes, III: no}
$$

$$
\mathbf {C} \quad \text{I: yes, II: no, III: yes}
$$

$$
\mathbf {D} \quad \text{I: yes, II: no, III: no}
$$

$$
\mathbf {E} \quad \text{I: no, II: yes, III: yes}
$$

$$
\mathbf {F} \quad \text{I: no, II: yes, III: no}
$$

$$
\mathbf {G} \quad \text{I: no, II: no, III: yes}
$$

$$
\mathbf {H} \quad \text{I: no, II: no, III: no}
$$

## 解析
It would help to sketch a graph which has reflection symmetry in $x = a$ . We should pick a value of $a$ which is not zero. Let us pick a positive value of $a$. We can draw a quadratic with vertex at $x = a$, , for example.

![[Image/18-P2-Q10-sol1.jpg]]

We now consider the three conditions and see which are certainly not necessary for the reflection symmetry by looking at this example. We mark on x, a ± x and $2 a - x$ for a value of $x$ which is not equal to $^ { a , }$ where we have chosen $x \approx 1 . 5 a \cdot$

![[Image/18-P2-Q10-sol2.jpg]]

It seems from this sketch that $\operatorname { f } ( x )$ and $\operatorname { f } ( 2 a - x )$ are likely to be equal, as are $\operatorname { f } ( a + x )$ and $\operatorname { f } ( a - x )$ . So we reject condition III, leaving us with conditions I and II to consider.

For a graph $y = \operatorname { f } ( x )$ to be symmetrical about $x = a$, , we need the value of the function to be equal whenever we go the same distance to the right or left of $x = a$ . Looking at this sketch, let’s take the distance to be x. Then we need $\operatorname { f } ( a + x ) = \operatorname { f } ( a - x )$ for every choice of x if the graph is symmetrical about $x = a$ , so condition I is necessary. But it is also sufficient, for how could a graph not be symmetrical? Only if for some $x$, the function values are diferent at $a + x$ and $a - x$

For condition II, we can do the same. This time, the values we want to consider are $2 a - x$ and x. Now $2 a - x$ is $x - a$ to the left of a (assuming that $x > a )$ and x is $x - a$ to the right of a, so these are the same distance from a, and again this condition is necessary. Since every distance can be written as $x - a$ for some choice of x, the condition is also sufficient.

So both conditions I and II are necessary and sufficient, and the correct option is B.
