## 题目
Find the complete set of values of $x$, with $0 \leq x \leq \pi$, for which

$$
(1 - 2\sin x)\cos x \geq 0
$$

$$
\mathbf{A} \quad 0 \leq x \leq \frac{\pi}{6}, \quad \frac{\pi}{2} \leq x \leq \frac{5\pi}{6}
$$

$$
\mathbf{B} \quad 0 \leq x \leq \frac{\pi}{6}, \quad \frac{5\pi}{6} \leq x \leq \pi
$$

$$
\mathbf{C} \quad \frac{\pi}{6} \leq x \leq \frac{\pi}{2}, \quad \frac{5\pi}{6} \leq x \leq \pi
$$

$$
\mathbf{D} \quad \frac{\pi}{6} \leq x \leq \frac{5\pi}{6}
$$

## 解析
Multiplying out the brackets does not look like a particularly useful approach (what would we do with the terms cos x and sin x cos x in the same inequality?), so we will leave the expression in its factored form.

If we temporarily write $a = 1 - 2$ sin x and $b = \cos x$ we will be able to see the structure of the problem a little more clearly. We want $a b \geqslant 0$ , and this will happen when either $a \geqslant 0$ and $b \geqslant 0 .$ , or when $a \leqslant 0$ and $b \leqslant 0$ . So we need to solve each of these simpler inequalities.

We have $1 - 2 \sin x = 0$ when sin $\begin{array} { r } { x = { \frac { 1 } { 2 } } } \end{array}$ , so when $\begin{array} { r } { x = { \frac { \pi } { 6 } } \ \mathrm{or} \ x = { \frac { 5 \pi } { 6 } } } \end{array}$ . We can either sketch the graph of $y = 1 - 2\sin x$ or try values to determine whether $1 - 2\sin x$ is positive or negative in each range. Sketching the graph seems possibly hard, as there are multiple transformations, and it would be easy to make a mistake. So on this occasion, we’ll plug in values: $x = 0$ and $x = \pi$ both give $1 - 2\sin x = 1$; while $\begin{array} { r } { x = \frac { \pi } { 2 } } \end{array}$ gives $1 - 2 \sin x = - 1$ . Therefore

$1 - 2\sin x > 0$ when $\begin{array} { r } { 0 \leqslant x \leqslant \frac { \pi } { 6 } } \end{array}$ and when $\begin{array} { r } { \frac { 5 \pi } { 6 } \leqslant x \leqslant \pi } \end{array}$

$1 - 2\sin x \leqslant 0$ when $\begin{array} { r } { \frac { \pi } { 6 } \leqslant x \leqslant \frac { 5 \pi } { 6 } } \end{array}$

We can do similarly for cos x; this time we can think about the graph in our head, and we have

$$
\cos x \geqslant 0 \text {   when   } 0 \leqslant x \leqslant \frac {\pi}{2}
$$

$$
\cos x \leqslant 0 \text {when} \frac {\pi}{2} \leqslant x \leqslant \pi
$$

We can now put everything together. Both expressions are greater than or equal to 0 when $\begin{array} { r } { 0 \leqslant x \leqslant \frac { \pi } { 6 } } \end{array}$ , and they are both less than or equal to 0 when $\begin{array} { r } { \frac { \pi } { 2 } \leqslant x \leqslant \frac { 5 \pi } { 6 } } \end{array}$
