## 题目
The following question appeared in an examination:

		Given that $\tan x = \sqrt{3}$, find the possible values of $\sin 2x$.

A student gave the following answer:

		$\tan x = \sqrt{3} \text{ so } x = 60^\circ \text{ and } 2x = 120^\circ,$
		therefore $\sin 2x = \frac{\sqrt{3}}{2}.$

Which one of the following statements is correct?

$$
\mathbf{A} \quad \frac{\sqrt{3}}{2} \text{ is the only possible value, and this is fully supported by the reasoning given in the student's answer.}
$$

$$
\mathbf{B} \quad \frac{\sqrt{3}}{2} \text{ is the only possible value, but the reasoning given should consider other possible values of } x \text{ for which } \tan x = \sqrt{3}.
$$

$$
\mathbf{C} \quad \frac{\sqrt{3}}{2} \text{ is the only possible value, but the reasoning given should consider other possible values of } x \text{ for which } \sin 2x = \frac{\sqrt{3}}{2}.
$$

$$
\mathbf{D} \quad \frac{\sqrt{3}}{2} \text{ is \textbf{not} the only possible value because the reasoning given should have considered other possible values of } x \text{ for which } \tan x = \sqrt{3}.
$$

$$
\mathbf{E} \quad \frac{\sqrt{3}}{2} \text{ is \textbf{not} the only possible value because the reasoning given should have considered other possible values of } x \text{ for which } \sin 2x = \frac{\sqrt{3}}{2}.
$$

B

## 解析
Let’s run through every step of the argument with care.

The first step is ‘$\tan x = \sqrt{3}$ so $x = 60^{\circ}$’. We should first check that $x = 60^{\circ}$ is a solution: using our knowledge of trigonometry and special angles, we know that tan $6 0 ^ { \circ } = { \sqrt { 3 } }$, so it is.

But we also know that tan is periodic with period $1 8 0 ^ { \circ }$ : there are multiple values of $x$ which have tan $x = { \sqrt { 3 } }$ , and all solutions to tan $x = { \sqrt { 3 } }$ are therefore of the form $x = 6 0 ^ { \circ } + 1 8 0 n ^ { \circ }$ for $n \in \mathbb { Z }$

So there is unquestionably an error in the student’s answer, but we do not yet know whether there is more than one possible value of sin 2x.

It follows from $x = 6 0 ^ { \circ } + 1 8 0 n ^ { \circ }$ that $2 x = 1 2 0 ^ { \circ } + 3 6 0 n ^ { \circ }$

It is certainly the case that sin $\textstyle 1 2 0 ^ { \circ } = { \frac { \sqrt { 3 } } { 2 } }$ . But since sin is periodic with period $3 6 0 ^ { \circ }$ , we see that sin $( 1 2 0 ^ { \circ } + 3 6 0 n ^ { \circ } ) = { \frac { \sqrt { 3 } } { 2 } }$ for every $n \in \mathbb { Z }$

So there is only one possible value of sin 2x, but the student should have considered other possible values of $x$ for which tan $x = { \sqrt { 3 } }$; this is option B.
