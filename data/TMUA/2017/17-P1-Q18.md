## 题目
The graph of $y = \log_{10} x$ is translated in the positive $y$-direction by 2 units.

This translation is equivalent to a stretch of factor $k$ parallel to the $x$-axis.

What is the value of $k$?

$$
\mathbf{A} \quad 0.01
$$

$$
\mathbf{B} \quad \log_{10} 2
$$

$$
\mathbf{C} \quad 0.5
$$

$$
\mathbf{D} \quad 2
$$

$$
\mathbf{E} \quad \log_2 10
$$

$$
\mathbf{F} \quad 100
$$

## 答案
A

## 解析
We can do this algebraically.

A translation of the graph of $y = \operatorname { f } ( x )$ by 2 units in the positive y-direction gives the graph of $y = \operatorname { f } ( x ) + 2$

A stretch of factor k parallel to the x-axis gives the graph of $\begin{array} { r } { y = \operatorname { f } \left( { \frac { 1 } { k } } x \right) = \operatorname { f } \left( { \frac { x } { k } } \right) } \end{array}$

For these to be the same, we need $\operatorname { f } ( x ) + 2 = \operatorname { f } ( { \textstyle { \frac { 1 } { k } } } x )$ for all (positive) x.

In our case, $\operatorname { f } ( x ) = \log _ { 1 0 } x$. , so we require

$$
\log_ {1 0} x + 2 = \log_ {1 0} (\frac {x}{k})
$$

But $\begin{array} { r } { \log _ { 1 0 } ( \frac { x } { k } ) = \log _ { 1 0 } x - \log _ { 1 0 } k } \end{array}$ , so we require $\log _ { 1 0 } k = - 2$ , giving $k = 1 0 ^ { - 2 } = 0 . 0 1$ . Hence the answer is A.

We have done more than required to answer this question: we have actually shown that these transformations are equivalent. An alternative approach is to assume that the question is correct and that these transformations are equivalent, and to use a single point to find the value of $k$.

We could see which point ends up on the x-axis after the translation: it was at (a, −2), so it must have been at (0.01, −2). Therefore the translated graph crosses the x-axis at 0.01, while the original graph crossed the x-axis at 1. Therefore the stretch needs to be by a factor of 0.01 parallel to the x-axis.

We could have done a similar calculation with any other point.
