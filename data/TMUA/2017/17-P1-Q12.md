## 题目
The polynomial function $f(x)$ is such that $f(x) > 0$ for all values of $x$.

Given $\int_2^4 f(x)\,dx = A$, which one of the following statements **must** be correct?

$$
\mathbf{A} \quad \int_0^2 [f(x+2) + 1]\,dx = A + 1
$$

$$
\mathbf{B} \quad \int_0^2 [f(x+2) + 1]\,dx = A + 2
$$

$$
\mathbf{C} \quad \int_2^4 [f(x+2) + 1]\,dx = A + 1
$$

$$
\mathbf{D} \quad \int_2^4 [f(x+2) + 1]\,dx = A + 2
$$

$$
\mathbf{E} \quad \int_4^6 [f(x+2) + 1]\,dx = A + 1
$$

$$
\mathbf{F} \quad \int_4^6 [f(x+2) + 1]\,dx = A + 2
$$

## 答案
B

## 解析
We have $\textstyle \int _ { 2 } ^ { 4 } \operatorname { f } ( x ) \operatorname { d } x = A$ , and the question asks about $\textstyle \int \operatorname { f } ( x + 2 )$ dx between various limits.

The graph of $y = \operatorname { f } ( x + 2 )$ is the graph of $y = \operatorname { f } ( x )$ translated left by 2 units, so we can draw a sketch to see what efect this has on the area between $x = 2$ and $x = 4$ :

![[Image/17-P1-Q12-sol1.jpg]]

![[Image/17-P1-Q12-sol2.jpg]]

This means that $\textstyle { \int _ { 2 } ^ { 4 } \mathrm { f } ( x ) \mathrm { d } x = \int _ { 0 } ^ { 2 } \mathrm { f } ( x + 2 ) \mathrm { d } x = A }$

(If you have learnt about integration by substitution, you can also show this as follows: writing $x = u + 2$ gives $\mathrm { d } x = \mathrm { d } u .$ and $u = x - 2$ , so $\begin{array} { r } { \int _ { 2 } ^ { 4 } \mathrm { f } ( x ) \mathrm { d } x = \int _ { 0 } ^ { 2 } \mathrm { f } ( u + 2 ) \mathrm { d } u ) } \end{array}$

Therefore the answer is either A or B. We have

$$
\int_ {0} ^ {2} [ \mathrm{f} (x + 2) + 1 ] \mathrm{d} x = \int_ {0} ^ {2} \mathrm{f} (x + 2) \mathrm{d} x + \int_ {0} ^ {2} 1 \mathrm{d} x
$$

The first integral equals A, as we have shown, and $\textstyle \int _ { 0 } ^ { 2 } 1 \mathrm { d } x = 2$ , so the whole integral equals $A + 2$ and the correct answer is B.
