## 题目
The function $f$ is defined on the positive integers as follows:

$$
\begin{array}{l l} 
f (1) = 5, \text {   and   for   } n \geqslant 1: & \quad f (n + 1) = 3 f (n) + 1 \quad \text {   if   } f (n) \text {   is   odd   } \\ & \quad f (n + 1) = \frac {1}{2} f (n) \quad \text {   if   } f (n) \text {   is   even   } \end{array}
$$

The function g is defined on the positive integers as follows:

$$
\begin{array}{l l} g (1) = 3, \text {   and   for   } n \geqslant 1: & g (n + 1) = g (n) + 5 \quad \text {   if   } g (n) \text {   is   odd   } \\ & g (n + 1) = \frac {1}{2} g (n) \quad \text {   if   } g (n) \text {   is   even   } \end{array}
$$

What is the value of $f(1000) - g(1000)$ ?

$$
\mathbf {A} \quad -6
$$

$$
\mathbf {B} \quad -5
$$

$$
\mathbf {C} \quad 1
$$

$$
\mathbf {D} \quad 2
$$

$$
\mathbf {E} \quad 4
$$

$$
\mathbf {F} \quad 8
$$

## 解析
From the question, it seems that we are expected to work out the first few values of the functions f(n) and g(n), and to look for a pattern.

So after the first three terms, f(n) repeats every 3 terms: for $k \geqslant 1 , \mathrm { f } ( 3 k + 1 ) = 4 , \mathrm { f } ( 3 k + 2 ) = 2 .$ f(3k+3) = 1, while g(n) repeats every 6 terms, and we can write similar expressions for $\mathrm { g } ( 6 k + r )$

We could either calculate $\operatorname { f } ( n ) - \operatorname { g } ( n )$ for all of these terms, and find the repeating pattern there, or find f(1000) and g(1000) separately. The latter approach seems like less efort, so we will go for that.

Note that $1 0 0 0 = 3 \times 3 3 3 + 1 = 6 \times 1 6 6 + 4 . { \mathrm { ~ S o ~ f ( } } 1 0 0 0 { \mathrm { ~ } } = 4 , { \mathrm { ~ g ( } } 1 0 0 0 { \mathrm { ) } } = 2 .$

Thus $\mathrm { f } ( 1 0 0 0 ) - \mathrm { g } ( 1 0 0 0 ) = 4 - 2 = 2$ and the answer is D.
