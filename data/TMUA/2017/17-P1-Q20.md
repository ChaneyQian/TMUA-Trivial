## 题目
The lengths of the sides $QR$, $RP$ and $PQ$ in triangle $PQR$ are $a$, $a + d$ and $a + 2d$ respectively, where $a$ and $d$ are positive and such that $3d > 2a$.

What is the full range, in degrees, of possible values for angle $PRQ$?

$$
\mathbf{A} \quad 0 < \text{angle } PRQ < 60
$$

$$
\mathbf{B} \quad 0 < \text{angle } PRQ < 120
$$

$$
\mathbf{C} \quad 60 < \text{angle } PRQ < 120
$$

$$
\mathbf{D} \quad 60 < \text{angle } PRQ < 180
$$

$$
\mathbf{E} \quad 120 < \text{angle } PRQ < 180
$$

E

## 解析
It would be really helpful to sketch this triangle so that we don’t get confused! We will write $\theta$ for the angle $\angle P R Q$

![[Image/17-P1-Q20-sol1.jpg]]

It is clear that we want to use the cosine rule to relate the three sides and the angle $\theta$. Using $\ ^ { \cdot } c ^ { 2 } = a ^ { 2 } + b ^ { 2 } -$ 2ab cos $C ^ { \bullet }$ , we have

$$
(a + 2 d) ^ {2} = a ^ {2} + (a + d) ^ {2} - 2 a (a + d) \cos \theta
$$

which we can expand and simplify to give

$$
a ^ {2} + 4 a d + 4 d ^ {2} = 2 a ^ {2} + 2 a d + d ^ {2} - 2 a (a + d) \cos \theta
$$

Rearranging gives

$$
\cos \theta = \frac {a ^ {2} - 2 a d - 3 d ^ {2}}{2 a (a + d)}
$$

We can simplify this by noticing that the numerator factorises:

$$
\cos \theta = \frac {(a + d) (a - 3 d)}{2 a (a + d)} = \frac {a - 3 d}{2 a}
$$

Since $3 d > 2 a , a - 3 d < - a$ , and so cos $\textstyle \theta < { \frac { - a } { 2 a } } = - { \frac { 1 } { 2 } }$ . This gives $\theta > 1 2 0 ^ { \circ }$ , and so the answer must be option E.

We can go further and show that $\theta < 1 8 0 ^ { \circ }$ . Since P QR is a triangle, the length P Q must be less than the sum of $P R$ and $R Q$ , that is $a + 2 d < a + d + a$ , so d $< a$ . This gives cos $\textstyle \theta > { \frac { - 2 a } { 2 a } } = - 1$ so $\theta < 1 8 0 ^ { \circ }$

An alternative approach is to just try values for d. We are given that d $> { \frac { 2 } { 3 } } a$. , so we could try $\begin{array} { r } { d = \frac { 2 } { 3 } a } \end{array}$ . This gives side lengths of $a , \ { \textstyle { \frac { 5 } { 3 } } } a , \ { \textstyle { \frac { 7 } { 3 } } } a$ , which we can take to be 3, 5, 7 if we choose $a = 3$ Plugging these lengths into the cosine rule gives $\theta = 1 2 0 ^ { \circ }$ , so this is one limit.

We are allowed larger values of $d$. If we take d too large, then we will no longer have a triangle, as $P Q > P R + R Q$ . So as d increases, the angle $\theta$ must increase too. Therefore the answer must be E: $1 2 0 ^ { \circ } < \theta < 1 8 0 ^ { \circ }$
