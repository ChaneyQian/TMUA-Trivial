## 题目
The function $f(x)$ is increasing and $f(0) = 0$.

The positive constants $a$ and $b$ are such that $a < b$.

The area of the region enclosed by the curve $y = f(x)$, the $x$-axis and the lines $x = a$ and $x = b$ is denoted by $R$.

The function $g(x)$ is defined by $g(x) = f(x) + 2f(b)$.

Which of the following is an expression for the area enclosed by the curve $y = g(x)$, the $x$-axis and the lines $x = a$ and $x = b$?

$$
\mathbf{A} \quad R + (b-a)f(b)
$$

$$
\mathbf{B} \quad R + 2(b-a)f(b)
$$

$$
\mathbf{C} \quad R + 2f(b) - f(a)
$$

$$
\mathbf{D} \quad R + 2f(b)
$$

$$
\mathbf{E} \quad R + (f(b))^2
$$

$$
\mathbf{F} \quad R + (f(b))^2 - (f(a))^2
$$

$$
\mathbf{G} \quad R + 2(f(b) - f(a))f(b)
$$

## 答案
B

## 解析
We can approach this question algebraically or graphically.

We start with an algebraic approach. We first note that $\operatorname { f } ( x ) \ \geqslant \ 0$ for all $x \ > \ 0$ as $\operatorname { f } ( x )$ is increasing. So the region described first, with area $R ,$ lies entirely above (or on) the x-axis, and

$$
R = \int_ {a} ^ {b} \mathrm{f} (x) \mathrm{d} x
$$

We note that $\mathrm { g } ( x ) = \mathrm { f } ( x ) + 2 \mathrm { f } ( b ) \geq 0$ for $x > 0$ as $\operatorname { f } ( x ) \geqslant 0$ and $\mathrm { f } ( b ) \geqslant 0$ . Then the area required under the graph $\mathrm { g } ( x )$ is given by

$$
\begin{array}{r l} \int_ {a} ^ {b} \mathrm{g} (x) \mathrm{d} x & = \int_ {a} ^ {b} \mathrm{f} (x) + 2 \mathrm{f} (b) \mathrm{d} x \\ & = \int_ {a} ^ {b} \mathrm{f} (x) \mathrm{d} x + 2 \mathrm{f} (b) \int_ {a} ^ {b} 1 \mathrm{d} x \\ & = R + 2 \mathrm{f} (b) (b - a) \end{array}
$$

On the second line we have split the integral into a sum of two integrals, and taken out the constant factor of $\ 2 \mathrm { f } ( b )$ from the second integral. Thus the answer is option B.

It is clear from this sketch that the area under the graph of $y = \operatorname { g } ( x )$ is formed of a rectangle which is $( b - a )$ by 2f(b) in size, and the area under the original graph, R, so that the required area is $R + ( b - a ) \times 2 \mathrm { f } ( b )$
