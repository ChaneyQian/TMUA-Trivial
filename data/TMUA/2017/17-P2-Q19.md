## 题目
Which one of the following is a **sufficient** condition for the equation $x^{3}-3x^{2}+a=0$ , where $a$ is a constant, to have exactly one real root?

$$
\mathbf {A} \quad a > 0
$$

$$
\mathbf {B} \quad a \leqslant 0
$$

$$
\mathbf {C} \quad a \geqslant 4
$$

$$
\mathbf {D} \quad a <   4
$$

$$
\mathbf {E} \quad | a | > 4
$$

$$
\mathbf {F} \quad | a | \leqslant 4
$$

$$
\mathbf {G} \quad a = \frac {9}{4}
$$

$$
\mathbf {H} \quad | a | = \frac {3}{2}
$$

E

## 解析
We recall that a ‘sufficient condition’ means that if the condition holds, then the equation has exactly one real root.

We can start by sketching the graph of the cubic $y = x ^ { 3 } - 3 x ^ { 2 } + a$. , noting that the impact of changing a is just to translate the graph vertically.

We diferentiate to find the stationary points: $\begin{array} { r } { { \frac { \mathrm { d } y } { \mathrm { d } x } } = 3 x ^ { 2 } - 6 x } \end{array}$ , so $\begin{array} { r } { { \frac { \mathrm { d } y } { \mathrm { d } x } } = 0 } \end{array}$ when $x = 0$ and $x = 2$ ， so the stationary points are at $( 0 , a )$ and $( 2 , a - 4 )$

So the graph looks like this:

![[Image/17-P2-Q19-sol1.jpg]]

There will be one real root for the equation $x ^ { 3 } - 3 x ^ { 2 } + a = 0$ if either the local maximum lies below the x-axis or if the local minimum lies above the x-axis, as in the case sketched.

The first occurs when $a < 0$ , the second when $a - 4 > 0$ or equivalently, when $a > 4$

So a necessary and sufficient condition is $a < 0 \mathrm { o r } a > 4$ . This does not, however, appear as one of the options, so we need to go through them to see which one is sufficient. (Recall from earlier that sufficient means that if this condition holds, then the equation has exactly one real root, but not necessarily the other way round.)

A This includes $a = 1$ , which gives more than one real root.

B This includes $a = 0$ , which gives more than one real root (as the minimum lies on the $x { \mathrm { - a x i s } } )$ .

C This includes $a = 4$ , which gives more than one real root (as the maximum lies on the x-axis).

D This includes $a = 1$ again.

E This is $a > 4$ or $a < - 4$ , both of which are part of the valid range, so this is a sufficient condition.

F This includes a = 1 again.

G This gives more than one real root.

H $\begin{array} { r } { a = \frac { 3 } { 2 } } \end{array}$ gives more than one real root.

So the correct answer is $\mathrm { E }$
