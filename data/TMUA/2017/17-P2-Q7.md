## 题目
The graphs of two functions are shown here:

		- $y = a^{x}$ is shown with a solid line, where $a$ is a positive real number
		- $y = f(x)$ is shown with a dashed line

![[Image/17-P2-Q7-fig1.jpg]]

Which of the following statements $(1, 2, 3, 4)$ could be true?

		**1**   $f(x) = b^{x}$ for some $b > a$
		**2**   $f(x) = b^{x}$ for some $b < a$

## 解析
The graph of $y = \operatorname { f } ( x )$ looks like an exponential graph, so all of the four given statements certainly seem plausible.

One approach to this question is to think about the shapes of different exponential graphs. Another is to consider a specific value of $x$, and see what happens.

If we take $x = 1 , a ^ { x } = a$ , and $\mathrm { f } ( 1 ) > a$ . We can now substitute $x = 1$ into the two expressions for $\operatorname { f } ( x )$ offered: $\operatorname { f } ( x ) = b ^ { x }$ gives $\mathbf { f } ( 1 ) = b$ , so we would need $b > a$ . Similarly, $\operatorname { f } ( x ) = a ^ { k x }$ gives $\operatorname { f } ( 1 ) = a ^ { k }$ . But it is clear from the solid line that $a > 1$ (as $a ^ { 0 } = 1$ and $a ^ { 1 } = a > 1 )$ , so $a ^ { k } > a$ requires $k > 1$

So both statements 1 and 3 could be true, but not 2 or 4.

We can be even more careful and show that we cannot have just one of 1 and 3 being true. If statement 3 is true, we have $\operatorname { f } ( x ) = a ^ { k x } = ( a ^ { k } ) ^ { x }$ , so writing $b = a ^ { k } >$ a shows that statement 1 is true; likewise, if statement 1 is true, we have $\operatorname { f } ( x ) = b ^ { x } = ( a ^ { \log _ { a } b } ) ^ { x } = a ^ { ( \log _ { a } b ) x }$ and $\log _ { a } b > 1$ so statement 3 is also true.

Hence the correct answer is E.
