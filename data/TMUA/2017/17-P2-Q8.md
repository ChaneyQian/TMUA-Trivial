## 题目
Which one of the following numbers is smallest in value?

$$
\mathbf{A} \quad \log_2 7
$$

$$
\mathbf{B} \quad (2^{-3} + 2^{-2})^{-1}
$$

$$
\mathbf{C} \quad 2^{(\pi/3)}
$$

$$
\mathbf{D} \quad \frac{1}{4(\sqrt{2}-1)^3}
$$

$$
\mathbf{E} \quad 4\sin^2\left(\frac{\pi}{4}\right)
$$

## 备注

### AI备注


## 答案
E

## 解析
We can start by estimating or calculating the values.

A $2 < \log _ { 2 } 7 < 3$. since $\log _ { 2 } 4 = 2$ and $\log _ { 2 } 8 = 3$

B $( 2 ^ { - 3 } + 2 ^ { - 2 } ) ^ { - 1 } = ( { \textstyle { \frac { 1 } { 8 } } } + { \textstyle { \frac { 1 } { 4 } } } ) ^ { - 1 } = ( { \textstyle { \frac { 3 } { 8 } } } ) ^ { - 1 } = { \textstyle { \frac { 8 } { 3 } } }$ which again lies between 2 and 3

$\textbf { C } \pi / 3$ is just a little greater than 1, so $2 ^ { \pi / 3 }$ is a little greater than 2

D We expand $( { \sqrt { 2 } } - 1 ) ^ { 3 }$ using the binomial theorem to get

$$
(\sqrt {2}) ^ {3} - 3 (\sqrt {2}) ^ {2} + 3 \sqrt {2} - 1 = 2 \sqrt {2} - 6 + 3 \sqrt {2} - 1 = 5 \sqrt {2} - 7
$$

Thus

$$
\frac {1}{4 (\sqrt {2} - 1) ^ {3}} = \frac {1}{4 (5 \sqrt {2} - 7)} = \frac {5 \sqrt {2} + 7}{4 ((5 \sqrt {2}) ^ {2} - 7 ^ {2})} = \frac {5 \sqrt {2} + 7}{4}
$$

This is greater than ${ \frac { 5 + 7 } { 4 } } = 3$; , so is certainly not the smallest in value.

E $\begin{array} { r } { \sin ( \frac { \pi } { 4 } ) = \frac { 1 } { \sqrt { 2 } } } \end{array}$ , so 4 $\begin{array} { r } { { } _ { : } \sin ^ { 2 } ( \frac { \pi } { 4 } ) = 4 \big ( \frac { 1 } { \sqrt { 2 } } \big ) ^ { 2 } = 4 \times \frac { 1 } { 2 } = 2 } \end{array}$

Since $A$, $B$ and $C$ are each greater than 2, the correct answer is E.
