## 题目
The first three terms of an arithmetic progression are $p$, $q$ and $p^2$ respectively, where $p < 0$

The first three terms of a geometric progression are $p$, $p^2$ and $q$ respectively.

Find the sum of the first 10 terms of the arithmetic progression.

$$
\mathbf{A} \quad \frac{23}{8}
$$

$$
\mathbf{B} \quad \frac{95}{8}
$$

$$
\mathbf{C} \quad \frac{115}{8}
$$

$$
\mathbf{D} \quad \frac{185}{8}
$$

### AI备注


## 答案
B

## 解析
Let the common difference of the arithmetic progression be d and the common ratio of the geometric progression be r. Then we can write the first three terms of each as

$$
p, q = p + d, p ^ {2} = p + 2 d \quad \text {and} \quad p, p ^ {2} = p r, q = p r ^ {2}.
$$

The second term of the geometric progression shows that $r = p$ (as $p$ is non-zero), so the third term gives $q = p ^ { 3 }$

Looking again at the arithmetic progression, using $q = p ^ { 3 }$ now shows that the second and third terms are

$$
\begin{array}{l} {p ^ {3} = p + d} \\ {p ^ {2} = p + 2 d} \end{array}
$$

We can eliminate d from these by subtracting twice the first equation from the second, giving $p ^ { 2 } - 2 p ^ { 3 } = - p$ . This rearranges to

$$
2 p ^ {3} - p ^ {2} - p = 0
$$

This factorises as $p ( 2 p ^ { 2 } - p - 1 ) = 0$ , and then to $p ( 2 p + 1 ) ( p - 1 ) = 0$ . This has the three solutions $\textstyle p = 0 , p = - { \frac { 1 } { 2 } }$ and $p = 1$ . We were told that $p < 0$ , so we must have $p = - \frac { 1 } { 2 }$ Thus $d = p ^ { 3 } - p = - { \textstyle { \frac { 1 } { 8 } } } - \bigl ( - { \textstyle { \frac { 1 } { 2 } } } \bigr ) = { \textstyle { \frac { 3 } { 8 } } }$ and the sum of the first 10 terms of the arithmetic progression is given, using the formula $\begin{array} { r } { \overline { { S } } _ { n } = \frac { 1 } { 2 } n ( 2 a + ( n - 1 ) d ) } \end{array}$ , by

$$
S _ {1 0} = \frac {1}{2} \times 1 0 \left(2 \times \left(- \frac {1}{2}\right) + 9 \times \frac {3}{8}\right) = 5 \left(- 1 + \frac {2 7}{8}\right) = \frac {9 5}{8}
$$

and the correct answer is B.
