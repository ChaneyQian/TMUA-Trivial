## 题目
The diagram shows the graphs of $y = \sin 2x$ and $y = \cos 2x$ for $-\frac{\pi}{2} < x < \frac{\pi}{2}$

![[Image/17-P2-Q12-fig1.jpg]]

Which one of the following is **not** true?

$$
\mathbf{A} \quad \cos 2x < \sin 2x < \tan x \text{ for some real number } x \text{ with } -\frac{\pi}{2} < x < \frac{\pi}{2}
$$

$$
\mathbf{B} \quad \cos 2x < \tan x < \sin 2x \text{ for some real number } x \text{ with } -\frac{\pi}{2} < x < \frac{\pi}{2}
$$

$$
\mathbf{C} \quad \sin 2x < \cos 2x < \tan x \text{ for some real number } x \text{ with } -\frac{\pi}{2} < x < \frac{\pi}{2}
$$

$$
\mathbf{D} \quad \sin 2x < \tan x < \cos 2x \text{ for some real number } x \text{ with } -\frac{\pi}{2} < x < \frac{\pi}{2}
$$

$$
\mathbf{E} \quad \tan x < \sin 2x < \cos 2x \text{ for some real number } x \text{ with } -\frac{\pi}{2} < x < \frac{\pi}{2}
$$

$$
\mathbf{F} \quad \tan x < \cos 2x < \sin 2x \text{ for some real number } x \text{ with } -\frac{\pi}{2} < x < \frac{\pi}{2}
$$

## 解析
We clearly need to sketch the graph of $y = \tan x$ onto the given sketch.

This graph has asymptotes at $x = \pm \frac { \pi } { 2 }$ , and passes through the points $( { \frac { \pi } { 4 } } , 1 )$ and $( - \frac { \pi } { 4 } , - 1 )$ Since the function is increasing as it passes through these points, it must lie below the graph of $y = \sin { 2 x }$ between 0 and ${ \frac { \pi } { 4 } } ,$ , and above it between $- \frac { \pi } { 4 }$ and 0.

We now pick various values for x and see which order the functions lie in. For example, when x is close to $- \frac { \pi } { 2 }$ , we have tan x < cos 2x < sin 2x.
