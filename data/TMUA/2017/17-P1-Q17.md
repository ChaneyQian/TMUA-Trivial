## 题目
The two functions $F(n)$ and $G(n)$ are defined as follows for positive integers $n$:

$$
F(n) = \frac{1}{n}\int_0^n (n - x)\,dx
$$

$$
G(n) = \sum_{r=1}^n F(r)
$$

What is the smallest positive integer $n$ such that $G(n) > 150$?

$$
\mathbf{A} \quad 22
$$

$$
\mathbf{B} \quad 23
$$

$$
\mathbf{C} \quad 24
$$

$$
\mathbf{D} \quad 25
$$

$$
\mathbf{E} \quad 26
$$

## 答案
D

## 解析
It seems that we need to calculate $\mathrm { F } ( n )$ before we can find ${ \mathrm { G } } ( n )$ . We could do this either using integration or geometry. We start with an integration method:

$$
{ \begin{array}{r l} & {\operatorname{F} (n) = \frac {1}{n} \int_ {0} ^ {n} (n - x) \mathrm{d} x} \\ & {\qquad = \frac {1}{n} \big [ n x - \frac {1}{2} x ^ {2} \big ] _ {0} ^ {n}} \\ & {\qquad = \frac {1}{n} (n ^ {2} - \frac {1}{2} n ^ {2})} \\ & {\qquad = \frac {1}{2} n} \end{array} }
$$

We could reach the same conclusion by sketching a graph of the function:

![[Image/17-P1-Q17-sol1.jpg]]

The area of this triangle is $\frac{1}{2} n^{2}$, so ${ \scriptstyle { \frac { 1 } { 2 } } } n ^ { 2 }$ $\begin{array} { r } { \mathrm { F } ( n ) = \frac { 1 } { n } \times \frac { 1 } { 2 } n ^ { 2 } = \frac { 1 } { 2 } n } \end{array}$

We now have:

$$
\begin{array}{c} \mathrm{G} (n) = \sum_ {r = 1} ^ {n} \mathrm{F} (r) \\ = \sum_ {r = 1} ^ {n} \frac {1}{2} r \\ = \frac {1}{2} \sum_ {r = 1} ^ {n} r \end{array}
$$

where for the last line we have used $( { \textstyle { \frac { 1 } { 2 } } } \mathrm { F } ( 1 ) + { \textstyle { \frac { 1 } { 2 } } } \mathrm { F } ( 2 ) + \cdots ) = { \textstyle { \frac { 1 } { 2 } } } ( \mathrm { F } ( 1 ) + \mathrm { F } ( 2 ) + \cdots )$

Now $\textstyle \sum _ { r = 1 } ^ { n } r = 1 + 2 + \cdots + n = { \frac { 1 } { 2 } } n ( n + 1 )$ , either using the formula for triangular numbers or of the sum of an arithmetic series.

So $\begin{array} { r } { \mathrm { G } ( n ) = \frac { 1 } { 4 } n ( n + 1 ) } \end{array}$

Therefore

$$
\begin{array}{r l r} & & {\mathrm{G} (n) > 1 5 0} \\ & \Longleftrightarrow & {\frac {1}{4} n (n + 1) > 1 5 0} \\ & \Longleftrightarrow & {n (n + 1) > 6 0 0} \end{array}
$$

So we can try values: 25 is a nice number to calculate with, so we start with options C and D:

$$
\begin{array}{l} {2 4 \times 2 5 = 6 0 0} \\ {2 5 \times 2 6 = 6 5 0} \end{array}
$$

so $n = 2 5$ is the smallest positive integer for which $\mathrm { G } ( n ) > 1 5 0$ , and the answer is D.
