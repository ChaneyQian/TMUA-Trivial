## 题目
Consider the following statement:

		$(*)$ If $f(x)$ is an integer for every integer $x$, then $f'(x)$ is an integer for every integer $x$.

Which one of the following is a **counterexample** to $(*)$?

$$
\mathbf{A} \quad f(x) = \frac{x^3 + x + 1}{4}
$$

$$
\mathbf{B} \quad f(x) = \frac{x^4 + x^2 + x}{2}
$$

$$
\mathbf{C} \quad f(x) = \frac{x^4 + x^3 + x^2 + x}{2}
$$

$$
\mathbf{D} \quad f(x) = \frac{x^4 + 2x^3 + x^2}{4}
$$

## 备注

### AI备注


## 答案
C

## 解析
For a function to be a counterexample to (∗), it must be the case that $\operatorname { f } ( x )$ is an integer for every integer x, but for which $\mathrm { f ^ { \prime } } ( x )$ is not an integer for every integer x.

We can start by substituting in $x = 0$ and $x = 1$ into the given functions to see whether $\operatorname { f } ( x )$ is even potentially an integer for every integer x:

A $\begin{array} { r } { \mathrm { f } ( 0 ) = \frac { 1 } { 4 } } \end{array}$ . This cannot be a counterexample.

$\begin{array} { r } { \textbf { B } \mathrm { f } ( 0 ) = 0 , \mathrm { f } ( 1 ) = \frac { 3 } { 2 } } \end{array}$ . This cannot be a counterexample.

$\textbf { C } \mathrm { f } ( 0 ) = 0 , \mathrm { f } ( 1 ) = 2$ . This could potentially be a counterexample.

D $\mathrm { f ( 0 ) } = 0 , \mathrm { f ( 1 ) = 1 }$ . This could potentially be a counterexample.

So we now only need to consider C and D.

Our next step is to diferentiate them and then substitute $x = 0$ and $x = 1$ into the derivatives.

$$
\textbf {C} \mathrm{f} ^ {\prime} (x) = \frac {4 x ^ {3} + 3 x ^ {2} + 2 x + 1}{2}, \mathrm{f} ^ {\prime} (0) = \frac {1}{2}, \text {so this is potentially a counterexample.}
$$

$$
\textbf {D} \mathrm{f} ^ {\prime} (x) = \frac {4 x ^ {3} + 6 x ^ {2} + 2 x}{4}, \mathrm{f} ^ {\prime} (0) = 0, \mathrm{f} ^ {\prime} (1) = 4.
$$

It therefore seems most likely that C is a counterexample and D is not. To prove this, we need to show that for $\operatorname { C } , \operatorname { f } ( x )$ is an integer for every integer x, and that for D, either $\operatorname { f } ( x )$ is not an integer for some integer x or that $\mathrm { f ^ { \prime } } ( x )$ is an integer for every integer x.

For the purposes of the test, it probably makes most sense at this point to choose the answer C and move on, but we will go on here to complete the solution.

For C, we have

$$
\mathrm{f} (x) = \frac {x (x ^ {3} + x ^ {2} + x + 1)}{2} = \frac {x (x + 1) (x ^ {2} + 1)}{2}
$$

We see that $x ( x + 1 )$ is even if x is even and also if x is odd, so $x ( x + 1 ) ( x ^ { 2 } + 1 )$ is even for every integer x, hence f(x) is an integer for every integer x. Therefore C is a counterexample.

For D, we have

$$
\mathrm{f} (x) = \frac {x ^ {2} (x ^ {2} + 2 x + 1)}{4} = \frac {x ^ {2} (x + 1) ^ {2}}{4}
$$

Since $x ( x + 1 )$ is even for every integer x, as we just showed, $x ^ { 2 } ( x + 1 ) ^ { 2 }$ is a multiple of 4 for every integer x, and thus f(x) is an integer for every integer x.

For the derivative,

$$
\mathrm{f} ^ {\prime} (x) = \frac {x (2 x ^ {2} + 3 x + 1)}{2} = \frac {x (x + 1) (2 x + 1)}{2}
$$

and as before, the numerator is always even, so $\mathrm { f ^ { \prime } } ( x )$ is an integer for every integer x. Therefore D is not a counterexample.
