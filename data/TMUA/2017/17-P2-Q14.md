## 答案
F

## 解析
We can complete the square for the original quadratic:

$$
x ^ {2} - 2 b x + c = (x - b) ^ {2} - b ^ {2} + c
$$

so the vertex P is at $( b , c - b ^ { 2 } )$

The graph given shows that $b > 0$ and $c - b ^ { 2 } > 0$

The new quadratic is

$$
x ^ {2} - 2 B x + c = (x - B) ^ {2} - B ^ {2} + c
$$

so the new vertex is at $( B , c - B ^ { 2 } )$

Now $B > b ,$ so the new vertex is to the right of P . As $B > b > 0 , B ^ { 2 } > b ^ { 2 } \mathrm{~so~} c - B ^ { 2 } < c - b ^ { 2 }$ 2 and the new vertex is below P .

Therefore the correct answer is F.
