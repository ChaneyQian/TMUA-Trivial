## 题目
$(2x+1)$ and $(x-2)$ are factors of $2x^3 + px^2 + q$.

What is the value of $2p + q$?

$$
\mathbf{A} \quad -10
$$

$$
\mathbf{B} \quad -\frac{38}{5}
$$

$$
\mathbf{C} \quad -\frac{22}{3}
$$

$$
\mathbf{D} \quad \frac{22}{3}
$$

$$
\mathbf{E} \quad \frac{38}{5}
$$

$$
\mathbf{F} \quad 10
$$

## 答案
C

## 解析
Since $2 x + 1 = 2 ( x + { \textstyle { \frac { 1 } { 2 } } } )$ is a factor of $\operatorname { f } ( x ) = 2 x ^ { 3 } + p x ^ { 2 } + q$ , it follows that $\operatorname { f } ( - { \frac { 1 } { 2 } } ) = 0$ . Similarly, $\operatorname { f } ( 2 ) = 0 .$

Substituting these values in to $\operatorname { f } ( x )$ gives

$$
\begin{array}{r} 2 (- \frac {1}{2}) ^ {3} + p (- \frac {1}{2}) ^ {2} + q = 0 \\ 2 (2) ^ {3} + p (2 ^ {2}) + q = 0 \end{array}
$$

so

$$
\begin{array}{r} - \frac {1}{4} + \frac {1}{4} p + q = 0 \\ 1 6 + 4 p + q = 0 \end{array}
$$

Multiplying the first equation by 16 gives

$$
- 4 + 4 p + 1 6 q = 0.
$$

Subtracting $1 6 + 4 p + q = 0$ from this gives $- 2 0 + 1 5 q = 0$ , so $\textstyle q = { \frac { 4 } { 3 } }$ , hence $\textstyle 4 p = - 1 6 - q = - { \frac { 5 2 } { 3 } }$ Therefore $\textstyle 2 p + q = - { \frac { 2 6 } { 3 } } + { \frac { 4 } { 3 } } = - { \frac { 2 2 } { 3 } }$ , which is option C.
