## 题目
What is the complete range of values of $k$ for which the curves with equations

$$
y = x ^ {3} - 1 2 x
$$

and

$$
y = k - (x - 2) ^ {2}
$$

intersect at three distinct points, of which exactly two have positive x-coordinates?

$$
\mathbf {A} \quad - 4 <   k <   0
$$

$$
\mathbf {B} \quad - 4 <   k <   4
$$

$$
\mathbf {C} \quad - 4 <   k <   1 6
$$

$$
\mathbf {D} \quad - 1 6 <   k <   0
$$

$$
\mathbf {E} \quad - 1 6 <   k <   4
$$

$$
\mathbf {F} \quad - 1 6 <   k <   1 6
$$

E

## 解析
Finding the values of $x$ at which the two curves intersect is the same as finding the values of $x$ at which the y-values are equal, that is,

$$
x ^ {3} - 1 2 x = k - (x - 2) ^ {2}
$$

or

$$
x ^ {3} - 1 2 x - k + (x - 2) ^ {2} = 0.
$$

Thus we are finding out something about the roots of a cubic.

We can expand the brackets in the final equation to give

$$
x ^ {3} + x ^ {2} - 1 6 x - k + 4 = 0,
$$

and we write $\mathrm { f } ( x ) = x ^ { 3 } + x ^ { 2 } - 1 6 x - k + 4$.

We can determine something about the locations of the roots of $\operatorname { f } ( x )$ by finding the stationary points. We have

$$
\mathrm{f} ^ {\prime} (x) = 3 x ^ {2} + 2 x - 1 6,
$$

so $\mathrm { f } ^ { \prime } ( x ) = 0$ when

$$
x = \frac {- 2 \pm \sqrt {2 ^ {2} + 4 \times 3 \times 1 6}}{6} = \frac {- 2 \pm \sqrt {1 9 6}}{6} = \frac {- 2 \pm 1 4}{6} = 2 \mathrm{or} - \frac {8}{3}.
$$

(We could have found these roots by factorising, but that did not look particularly easy.) Therefore there are stationary points at $x = 2$ and $\begin{array} { r } { x = - \frac { 8 } { 3 } } \end{array}$ . We have $\operatorname { f } ( 2 ) = - 1 6 - k$ , but calculating $\operatorname { f } ( - { \frac { 8 } { 3 } } )$ by hand would be painful, so let us try to avoid doing so if we can!

We note that ${ \mathrm { f } } ( 0 ) = 4 - k$ , and that $\operatorname { f } ( x )$ gets big as x gets big, so if there are exactly two roots with positive x-coordinates, we need the graph to look something like this:

![[Image/19-P1-Q20-sol1.jpg]]

In particular, we require $\mathrm { f } ( 0 ) > 0$ , so we must have $k < 4$

It must also be the case that the stationary point at $x = 2$ lies below the $x { \mathrm { - a x i s } }$ , so we need $- 1 6 - k < 0$ , that is, $- 1 6 < k$

Once we have met these two conditions, it becomes clear that there are three distinct roots, exactly one of which has $x \ < \ 0$ . Therefore, the complete range of values of $k$ is given by $- 1 6 < k < 4$ , which is option E.
