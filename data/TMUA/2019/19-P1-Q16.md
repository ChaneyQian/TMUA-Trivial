## 题目
Given that

$$
2 \int_ {0} ^ {1} \mathrm{f} (x) \mathrm{d} x + 5 \int_ {1} ^ {2} \mathrm{f} (x) \mathrm{d} x = 1 4
$$

and

$$
\int_ {0} ^ {1} \mathrm{f} (x + 1) \mathrm{d} x = 6
$$

find the value of

$$
\int_ {0} ^ {2} \mathrm{f} (x) \mathrm{d} x
$$

$$
\mathbf {A} \quad -8
$$

$$
\mathbf {B} \quad -4
$$

$$
\mathbf {C} \quad -2
$$

$$
\mathbf {D} \quad 2
$$

$$
\mathbf {E} \quad 4
$$

$$
\mathbf {F} \quad \frac {29}{5}
$$

$$
\mathbf {G} \quad \frac {32}{5}
$$

$$
\mathbf {H} \quad 14
$$

## 答案
C

## 解析
Let $\begin{array} { r } { A = \int _ { 0 } ^ { 1 } \mathrm { f } ( x ) } \end{array}$ dx, which is the (signed) area under the graph of $y = \operatorname { f } ( x )$ between $x = 0$ and $x = 1$ (taking signs into account, as usual: parts of the graph under the x-axis are counted as negative areas). Likewise, let $\textstyle B = \int _ { 1 } ^ { 2 } \operatorname { f } ( x )$ dx, which is the (signed) area between $x = 1$ and $x = 2$

The integral $\textstyle \int _ { 0 } ^ { 1 } \mathrm { f } ( x + 1 )$ dx gives the (signed) area under the graph of $y = \operatorname { f } ( x + 1 )$ between $x = 0$ and $x = 1$ . This graph is the graph of $y = \operatorname { f } ( x )$ translated left by 1 unit, so this equals the area under the original graph between $x = 1$ and $x = 2$ , which is B. Hence $B = 6$

The first equation gives $2 A + 5 B = 1 4 .$ , and as $B = 6 ,$ we get $A = - 8$

The final integral $\textstyle \int _ { 0 } ^ { 2 } \mathrm { f } ( x )$ dx is the (signed) area between $x = 0$ and $x = 2$ , which is $A + B =$ $- 8 + 6 = - 2$

Hence the answer is C.
