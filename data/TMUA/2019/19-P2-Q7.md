## 题目
For which one of the following statements can the fact that $12^{2} + 16^{2} = 20^{2}$ be used to produce a counterexample?

$$
\mathbf {A} \quad \text{If } a, b \text{ and } c \text{ are positive integers which satisfy the equation } a^{2} + b^{2} = c^{2} \text{, and the three numbers have no common divisor, then two of them are odd and the other is even.}
$$

$$
\mathbf {B} \quad \text{The equation } a^{4} + b^{2} = c^{2} \text{ has no solutions for which } a, b \text{ and } c \text{ are positive integers.}
$$

$$
\mathbf {C} \quad \text{The equation } a^{4} + b^{4} = c^{4} \text{ has no solutions for which } a, b \text{ and } c \text{ are positive integers.}
$$

$$
\mathbf {D} \quad \text{If } a, b \text{ and } c \text{ are positive integers which satisfy the equation } a^{2} + b^{2} = c^{2} \text{, then one is the arithmetic mean of the other two.}
$$

## 答案
B

## 解析
We work through these in turn:

A A counterexample here is a case for which the antecedent (the ‘if’ part) is true but the consequent (the ‘then’ part) is false. In this case, taking $a = 1 2 , b = 1 6 , c = 2 0$ to match $1 2 ^ { 2 } + 1 6 ^ { 2 } = 2 0 ^ { 2 }$ does not satisfy the antecedent, as they do have a common divisor of 4. Even if we were to divide all three by 4 to get $3 ^ { 2 } + 4 ^ { 2 } = 5 ^ { 2 }$ , we would still not have a counterexample, as two of them are odd and the other is even. (The statement is actually true, so there are no counterexamples.)

B A counterexample in this case is an example to show that there is a solution. Since $1 6 = 4 ^ { 2 }$ • we can rewrite $1 2 ^ { 2 } + 1 6 ^ { 2 } = 2 0 ^ { 2 } { \mathrm { ~ a s ~ } } 4 ^ { 4 } + 1 2 ^ { 2 } = 2 0 ^ { 2 }$ , so this does provide a counterexample.

C Since neither 12 nor 20 is a perfect square, we cannot use this fact to obtain a counterexample. (And that is quite a relief, since Fermat proved that this statement is true! It is the simplest case of Fermat’s Last Theorem.)

D We note that $1 2 ^ { 2 } + 1 6 ^ { 2 } = 2 0 ^ { 2 }$ satisfies the antecedent, but as 16 is the arithmetic mean of 12 and 20, this does not provide a counterexample. (The statement is false, and a counterexample is $5 ^ { 2 } + 1 2 ^ { 2 } = 1 3 ^ { 2 } .$ )

The correct answer is therefore B.
