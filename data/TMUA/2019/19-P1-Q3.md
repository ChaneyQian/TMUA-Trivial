## 解析
The coefficient of x in the expansion of $( 1 + x ) ^ { n } { \mathrm{~is~} } ( { \mathit { \Pi } } _ { 1 } ^ { n } ) = n$ , so the coefficient of x in this whole expression is

$$
0 + 1 + 2 + 3 + \dots + 7 9 + 8 0 = \frac {1}{2} \times 8 0 \times 8 1
$$

using the formula for the sum of the first n positive integers, ${ \scriptstyle { \frac { 1 } { 2 } } } n ( n + 1 )$ . This gives $4 0 \times 8 1 = 3 2 4 0$ 2 so the answer is E.
