## 解析
This is a rather ugly looking expression! Let us consider the first square root to begin with:

$$
\sqrt {8 - 4 \sqrt {2} + 1}
$$

We could simplify this to ${ \sqrt { 9 - 4 { \sqrt { 2 } } } }$ , but it seems likely that the examiners have written it in this way to help us.

One way to approach this question is to square the given expression, see what comes out, and then compare the answer with the squares of the given options. We will try this approach below.

Another approach is to see if we can write the inside of the square root as the square of something. We have $8 = ( 2 \sqrt { 2 } ) ^ { 2 }$ and $1 = 1 ^ { 2 }$ , which suggests that we try $2 \sqrt { 2 } + 1$ . But as the middle term has a minus sign, we should actually try $2 { \sqrt { 2 } } - 1$ . Squaring this gives

$$
\left(2 \sqrt {2} - 1\right) ^ {2} = 8 - 4 \sqrt {2} + 1
$$

and so

$$
\sqrt {8 - 4 \sqrt {2} + 1} = 2 \sqrt {2} - 1.
$$

It is important that we take the positive square root; since $2 \sqrt { 2 } > 1$ , this is the positive square root.

Similarly,

$$
\sqrt {9 - 1 2 \sqrt {2} + 8} = 3 - 2 \sqrt {2},
$$

where again we note that $3 > 2 { \sqrt { 2 } }$ , so this is the positive square root.

These sum to 2, and hence the answer is E.

The alternative approach was to square the given expression. Writing it as

$$
\sqrt {9 - 4 \sqrt {2}} + \sqrt {1 7 - 1 2 \sqrt {2}}
$$

we can square it to get

$$
\begin{array}{r l} & 9 - 4 \sqrt {2} + 1 7 - 1 2 \sqrt {2} + 2 \sqrt {\left(9 - 4 \sqrt {2}\right) \left(1 7 - 1 2 \sqrt {2}\right)} \\ & \qquad = 2 6 - 1 6 \sqrt {2} + 2 \sqrt {1 5 3 - 6 8 \sqrt {2} - 1 0 8 \sqrt {2} + 9 6} \\ & \qquad = 2 6 - 1 6 \sqrt {2} + 2 \sqrt {2 4 9 - 1 7 6 \sqrt {2}} \end{array}
$$

Unfortunately, we are now left in an even worse situation than we started with, as we have to find some way of simplifying this square root; can we find a and b with $( a - b { \sqrt { 2 } } ) ^ { 2 }$ = 249−176 2? It turns out that 11− $\boldsymbol { \cdot } 8 \sqrt { 2 }$ does the job; this, however, is negative (as $1 1 ^ { 2 } < ( 8 { \sqrt { 2 } } ) ^ { 2 } )$ , so the positive square root is $8 { \sqrt { 2 } } - 1 1$ . Thus the whole expression simplifies to $2 6 - 1 6 { \sqrt { 2 } } + 2 ( 8 { \sqrt { 2 } } - 1 1 ) = 4$ and so the correct solution is ${ \sqrt { 4 } } = 2$ , which is option E.

The first approach was certainly simpler.
