## 题目
Consider the following statements about the polynomial p(x), where $a < b$ :

I $\mathrm { p } ( a ) \leq \mathrm { p } ( b )$

II $\mathrm { p } ^ { \prime } ( a ) \leq \mathrm { p } ^ { \prime } ( b )$

III $\mathrm { p } ^ { \prime \prime } ( a ) \leq \mathrm { p } ^ { \prime \prime } ( b )$

Which of these statements is a necessary condition for p(x) to be increasing for $a \leq x \leq b$ ?

$$
\mathbf {A} \quad \text{none of them}
$$

$$
\mathbf {B} \quad \text{I only}
$$

$$
\mathbf {C} \quad \text{II only}
$$

$$
\mathbf {D} \quad \text{III only}
$$

$$
\mathbf {E} \quad \text{I and II only}
$$

$$
\mathbf {F} \quad \text{I and III only}
$$

$$
\mathbf {G} \quad \text{II and III only}
$$

$$
\mathbf {H} \quad \text{I, II and III}
$$

## 答案
B

## 解析
A necessary condition is one which must follow. To show that a condition is not necessary, we need to exhibit a counterexample, while to show that a condition is necessary, we need to give a justification.

I If $\mathrm { p } ( x )$ is increasing for $a \leq x \leq b$ , the value of the polynomial is not decreasing in this interval, so we must have $\mathrm { p } ( a ) \leq \mathrm { p } ( b )$ , and this is therefore a necessary condition.

II A quadratic such as $\mathrm { p } ( x ) = 9 { - } x ^ { 2 }$ provides a counterexample: it is increasing for $- 3 \leq x \leq 0$ but $\mathrm { p ( - 3 ) > 0 }$ while $\mathrm { p } ( 0 ) = 0$ . Hence this is not a necessary condition.

III It is not clear why this should be the case, and we need to look beyond quadratics (as $\mathrm { p } ^ { \prime \prime } ( x )$ is constant for every quadratic). Let us see if we can construct a counterexample. Let us take $\mathrm { p } ^ { \prime \prime } ( x ) = - x$ , so that it is decreasing. Then $\mathrm { p } ^ { \prime } ( x ) = - { \textstyle \frac { 1 } { 2 } } x ^ { 2 } + c .$ giving $\begin{array} { r } { \mathrm { p } ( x ) = - \frac { 1 } { 6 } x ^ { 3 } + c x } \end{array}$ (There is a further constant of integration here, but we can choose it to be zero, as it has no impact on where $\mathrm { p } ( x )$ is increasing.)

If we now choose some $c > 1$ , then $\mathrm { p } ^ { \prime } ( x )$ will be positive for $0 \leq x \leq 1$ , so $\mathrm { p } ( x )$ will be increasing there, yet $\mathrm { p } ^ { \prime \prime } ( 0 ) < \mathrm { p } ^ { \prime \prime } ( 1 )$

Therefore this condition is not necessary.

Another way of thinking about this is: to say that $\mathrm { p } ( x )$ is increasing for $a \leq x \leq b$ only tells us about the function values; it does not tell us anything about the derivatives, so neither II nor III could possibly be necessary conditions.

Either way, the correct answer is B.
