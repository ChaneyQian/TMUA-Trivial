## 题目
A student approximates the integral $\int_a^b \sin^2 x \, \mathrm{d}x$ using the trapezium rule with 4 strips. The resulting approximation is an overestimate.

Which of the following is/are **necessarily** true?

I. If the student approximates $\int_{-b}^{-a} \sin^2 x \, \mathrm{d}x$ in the same way, the result will be an overestimate.

II. If the student approximates $\int_a^b \cos^2 x \, \mathrm{d}x$ in the same way, the result will be an underestimate.

$$
\mathbf{A} \quad \text{neither of them}
$$

$$
\mathbf{B} \quad \text{I only}
$$

$$
\mathbf{C} \quad \text{II only}
$$

$$
\mathbf{D} \quad \text{I and II}
$$

## 答案
D

## 解析
It will help us to draw a sketch of this situation, remembering that we do not know that values of $a$ and b. The exact shape of the graph does not matter; the only thing that is important for this question is that it is symmetrical about the y-axis, since $\sin ^ { 2 } ( - x ) = ( - \sin x ) ^ { 2 } = \sin ^ { 2 }$ x.

![[Image/19-P2-Q13-sol1.jpg]]

I We can now add to our sketch the trapezium rule calculation for the integral $\textstyle \int _ { - b } ^ { - a } \sin ^ { 2 }$ x dx:

![[Image/19-P2-Q13-sol2.jpg]]

We see that the strips are just a reflection of the original 4 strips. Since the original approximation was an overestimate, this approximation is also an overestimate.

II We note that $\cos ^ { 2 }$ x is related to $\sin ^ { 2 }$ x by the identity si $1 ^ { 2 } x + \cos ^ { 2 } x = 1$ , so $\cos ^ { 2 } x =$ $1 - \sin ^ { 2 } x$ . Thus the graph of $y = \cos ^ { 2 }$ x is a reflection of the graph of $y = \sin ^ { 2 }$ x in the line $y = \mathrm { \frac { 1 } { 2 } \ ( w h y ? ) }$ . Therefore the sketch of the graph and trapezia for $\textstyle \int _ { a } ^ { b } \cos ^ { 2 }$ x dx is:

![[Image/19-P2-Q13-sol3.jpg]]

Since $\cos ^ { 2 } x = 1 - \sin ^ { 2 } x$. , we can also draw on the original trapezia, coming down from the line $y = 1$ :

![[Image/19-P2-Q13-sol4.jpg]]

We can see from this sketch that the blue and red trapezia exactly sum to $\textstyle \int _ { a } ^ { b } \sin ^ { 2 } x \mathrm { d } x +$ $\textstyle \int _ { a } ^ { b } \cos ^ { 2 }$ x dx; since the blue trapezia give an overestimate, the red ones must give an underestimate.

Hence this statement is also necessarily true.

Therefore the correct answer is D.
