## 题目
$x$ satisfies the simultaneous equations

$$
\sin 2 x + \sqrt {3} \cos 2 x = - 1
$$

and

$$
\sqrt {3} \sin 2 x - \cos 2 x = \sqrt {3}
$$

where $0^{\circ} \leq x \leq 360^{\circ}$ .

Find the sum of the possible values of $x$ .

$$
\mathbf {A} \quad 210^{\circ}
$$

$$
\mathbf {B} \quad 330^{\circ}
$$

$$
\mathbf {C} \quad 390^{\circ}
$$

$$
\mathbf {D} \quad 660^{\circ}
$$

$$
\mathbf {E} \quad 780^{\circ}
$$

$$
\mathbf {F} \quad 930^{\circ}
$$

## 解析
We write $S = \sin 2 x$ and $C = \cos 2 x$ , so the simultaneous equations become

$$
S + \sqrt {3} C = - 1
$$

$$
\sqrt {3} S - C = \sqrt {3}
$$

Multiplying the second equation by $\sqrt { 3 }$ and then adding to the first equation gives

$$
4 S = 2
$$

so $\begin{array} { r } { S = \frac { 1 } { 2 } } \end{array}$ and hence $C = - { \frac { \sqrt { 3 } } { 2 } }$

The solutions to sin 2x $= \textstyle { \frac { 1 } { 2 } }$ for $0 ^ { \circ } \leq x \leq 3 6 0 ^ { \circ }$ , or $0 ^ { \circ } \leq 2 x \leq 7 2 0 ^ { \circ }$ , are given by $2 x = 3 0 ^ { \circ } , 1 5 0 ^ { \circ }$ $3 9 0 ^ { \circ }$ and $5 1 0 ^ { \circ }$

The solutions to cos $2 x = - { \frac { \sqrt { 3 } } { 2 } }$ in the same range are given by $2 x = 1 5 0 ^ { \circ } , 2 1 0 ^ { \circ } , 5 1 0 ^ { \circ }$ and $5 7 0 ^ { \circ }$ 2 so the values of 2x for which both are true are $1 5 0 ^ { \circ }$ and $5 1 0 ^ { \circ }$

Thus the solutions for x in this range are $7 5 ^ { \circ }$ and $2 5 5 ^ { \circ }$ , and their sum is $3 3 0 ^ { \circ }$ . Hence the correct answer is option B.
