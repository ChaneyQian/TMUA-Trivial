## 题目
The terms of an infinite series $S$ are formed by adding together the corresponding terms in two infinite geometric series, $T$ and $U$.

The first term of $T$ and the first term of $U$ are each 4.

In order, the first three terms of the combined series $S$ are 8, 3, and $\frac{5}{4}$.

What is the sum to infinity of $S$?

$$
\mathbf{A} \quad \frac{32}{5}
$$

$$
\mathbf{B} \quad \frac{20}{3}
$$

$$
\mathbf{C} \quad \frac{64}{5}
$$

$$
\mathbf{D} \quad \frac{40}{3}
$$

$$
\mathbf{E} \quad 16
$$

$$
\mathbf{F} \quad 32
$$

## 答案
D

## 解析
Let us write out the first few terms of the three sequences explicitly. Let the common ratio of T be R and the common ratio of U be r.

| term | 1 | 2 | 3 | 4 | 5 | ... | n | ... |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| T | 4 | 4R | $4R^2$ | $4R^3$ | $4R^4$ | ... | $4R^{n-1}$ | ... |
| U | 4 | 4r | $4r^2$ | $4r^3$ | $4r^4$ | ... | $4r^{n-1}$ | ... |
| S | 8 | $4R+4r$ | $4R^2+4r^2$ | $4R^3+4r^3$ | $4R^4+4r^4$ | ... | $4R^{n-1}+4r^{n-1}$ | ... |


We are given the first three terms of S, so

$$
\begin{array}{c} {8 = 8} \\ {4 R + 4 r = 3} \\ {4 R^{2} + 4 r^{2} = \frac {5}{4}} \end{array}
$$

Therefore $\textstyle R + r = { \frac { 3 } { 4 } }$ and $\textstyle R^{2} + r^{2} = { \frac { 5 } { 16 } }$ . We can work out the values of $R$ and r by guessing, or we can work them out by solving these equations. We show the second approach here.

The first equation gives $\textstyle R = { \frac { 3 } { 4 } } - r$ , which we can substitute into the second equation to give

$$
(\frac {3}{4} - r) ^{2} + r^{2} = \frac {5}{16}
$$

so $\begin{array} { r } { 2 r^{2} - \frac { 3 } { 2 } r + \frac { 1 } { 4 } = 0 } \end{array}$ , hence $8 r^{2} - 6 r + 1 = 0$ , which factorises as $( 4 r - 1 ) ( 2 r - 1 ) = 0$ , giving $\begin{array} { r } { r = { \frac { 1 } { 2 } } \ \mathrm { o r } \ \stackrel { \sim } { r } = { \frac { 1 } { 4 } } } \end{array}$ and $\textstyle R = { \frac { 1 } { 4 } }$ or $\begin{array} { r } { R = \frac { 1 } { 2 } } \end{array}$ respectively.

We can therefore work out the sums to infinity of T and U, taking $\textstyle R = { \frac { 1 } { 4 } }$ and $\begin{array} { r } { r = \frac { 1 } { 2 } } \end{array}$ :

sum to infinity of $\mathrm { T } = { \frac { 4 } { 1 - { \frac { 1 } { 4 } } } } = { \frac { 16 } { 3 } }$

sum to infinity of $\mathrm { U } = { \frac { 4 } { 1 - { \frac { 1 } { 2 } } } } = 8$

giving the sum to infinity of S as $\begin{array} { r } { \frac { 16 } { 3 } + 8 = \frac { 40 } { 3 } } \end{array}$ , since S is the sum of T and U. If we took the values of $R$ and r to be the other way round, we would have the series T and U swapped, but their sum would be unchanged.

So the answer is D.
