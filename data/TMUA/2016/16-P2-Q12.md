## 题目
The first term of an arithmetic sequence is $a$ and the common difference is $d$.

The sum of the first $n$ terms is denoted by $S_n$.

If $S_8 > 3S_6$, what can be deduced about the sign of $a$ and the sign of $d$?

$$
\mathbf{A} \quad \text{both } a \text{ and } d \text{ are negative}
$$

$$
\mathbf{B} \quad a \text{ is positive, } d \text{ is negative}
$$

$$
\mathbf{C} \quad a \text{ is negative, } d \text{ is positive}
$$

$$
\mathbf{D} \quad a \text{ is negative, but the sign of } d \text{ cannot be deduced}
$$

$$
\mathbf{E} \quad d \text{ is negative, but the sign of } a \text{ cannot be deduced}
$$

$$
\mathbf{F} \quad \text{neither the sign of } a \text{ nor the sign of } d \text{ can be deduced}
$$

## 答案
F

## 解析
The formula for $S_{n}$ in terms of $a$ and d is $\begin{array} { r } { S_{n} = \frac { 1 } { 2 } n ( 2 a + ( n - 1 ) d ) } \end{array}$ . Substituting $n = 8$ and $n = 6$ gives

$$
\begin{array}{c} {S_{8} = 4 (2 a + 7 d)} \\ {S_{6} = 3 (2 a + 5 d)} \end{array}
$$

so the condition $S_{8} > 3 S_{6}$ becomes

$$
4 (2 a + 7 d) > 3 \times 3 (2 a + 5 d).
$$

Expanding the brackets gives $8 a + 28 d > 18 a + 45 d$ , which on rearranging gives $- 8 a > 17 d$ , or d $< - { \frac { 8 } { 17 } } a$

If $a$ is positive, then $- { \frac { 8 } { 17 } } a$ is negative, so d must be negative. If $a$ is negative, then $- { \frac { 8 } { 17 } } a$ is positive, so d could be positive or negative. So a can be positive or negative, as can d.

We therefore cannot deduce the sign of either a or $d$, and so the correct option is F.
