## 题目
The four real numbers $a$, $b$, $c$, and $d$ are all greater than 1.

Suppose that they satisfy the equation $\log_c d = (\log_a b)^2$.

Use some of the lines given to construct a proof that, in this case, it follows that

$$
(^{*})\ \log_b d = (\log_a b)(\log_a c).
$$

	(1) Let $x = \log_a b$ and $y = \log_a c$
	
	(2) $d = (c^x)^2$
	(3) $d = c^{(x^2)}$
	(4) $d = b^{xy}$
	
	(5) $d = (a^y)^{(x^2)}$
	(6) $d = ((a^y)^x)^2$
	(7) $d = (a^x)^{xy}$
	
	(8) $d = a^{(y^{2x})}$
	(9) $d = a^{(x^2 y)}$

$$
\mathbf{A} \quad \text{(1). Then (2), so (6), so (8), so (7), and therefore (4), hence }(^{*})\text{ as required}
$$

$$
\mathbf{B} \quad \text{(1). Then (2), so (7), so (8), so (6), and therefore (4), hence }(^{*})\text{ as required}
$$

$$
\mathbf{C} \quad \text{(1). Then (3), so (5), so (9), so (7), and therefore (4), hence }(^{*})\text{ as required}
$$

$$
\mathbf{D} \quad \text{(1). Then (3), so (7), so (9), so (5), and therefore (4), hence }(^{*})\text{ as required}
$$

$$
\mathbf{E} \quad \text{(1). Then (4), so (5), so (9), so (7), and therefore (3), hence }(^{*})\text{ as required}
$$

$$
\mathbf{F} \quad \text{(1). Then (4), so (6), so (8), so (7), and therefore (2), hence }(^{*})\text{ as required}
$$

$$
\mathbf{G} \quad \text{(1). Then (4), so (7), so (8), so (6), and therefore (2), hence }(^{*})\text{ as required}
$$

$$
\mathbf{H} \quad \text{(1). Then (4), so (7), so (9), so (5), and therefore (3), hence }(^{*})\text{ as required}
$$

### Addition

**题型：证明排序（Proof-Ordering，考纲 Prf4「把给定语句排成一个证明」）。** 官方 TMUA 真题里目前只有这一道纯排序题。

**风格**
- 给一串编号行，其中有真有假、有用有没用；选项是若干条「(1). Then (…), so (…), … hence (∗)」的链。题目不要求你自己证，要求你**判断每一步能否由上一步推出**。
- 内容只是外壳：指数律与换底公式（$\log_c d = x^2 \Rightarrow d = c^{x^2}$，$c = a^y$）。难点不在计算，而在分清看起来很像的写法：$(c^x)^2 = c^{2x}$ 与 $c^{(x^2)}$ 不同；$a^{(y^{2x})}$ 是把指数的指数写错了的干扰行。
- 干扰行是**真命题但推不出来**，或者**形式相近的错误式子**——考的是「这一步从哪来」，不是「这一步对不对」。

**命题视角**
- 选项被设计成可以**逐步淘汰**：第一步只有 (2)(3)(4) 三种选择，由已知 $\log_c d = x^2$ 只能直接得到 (3)，一步就把 A、B、E–H 排除，只剩 C、D；第二步只需判断从 $d = c^{x^2}$ 出发下一步是 (5) 还是 (7)。官方解答正是这么做的，全程几乎不用写算式。
- 考的是证明的**方向性**：起点是已知条件、终点是 (∗)，中间每一行只能用前面的行。倒着从 (4) $d = b^{xy}$ 出发也能配出 E–H 那样的链，但那是从结论往回推，方向错了。
- 与纠错题是同一能力的两面：纠错题问「哪一步推不出来」，排序题问「哪一种排法每一步都推得出来」。

## 答案

## 解析
The proof certainly begins with (1):

$$
\mathrm{Let} x = \log_{a} b \mathrm{and} y = \log_{a} c.
$$

We are then given a choice of writing d in various ways (line $( 2 ) , ( 3 ) { \mathrm { ~ o r ~ } } ( 4 ) )$ ). We are given

$$
\log_{c} d = (\log_{a} b) ^{2}
$$

so we can rewrite this using x as log $d = x^{2}$ . Therefore $d = c^{(x^{2} ) }$ , which is line (3).

Our next choice is between lines (5) and (7) (these are the only options, as the correct answer must be C or D); these are equivalent, but expressed differently. How can we get from $d = c^{(x^{2} ) }$ to d being a power of a? We must rewrite c in terms of $y$: since $y = \log_{a} c$, , it follows that $c = a^{y}$ so $d = ( a^{y} ) ^{(x^{2} ) }$ , which is line (5).

Without doing any more work, the answer must therefore be option C, and the whole proof reads as follows:

Suppose that log $\mathbf { \Phi } _{c} d = ( \log_{a} b ) ^{2}$

(1) Let x = $\log b$ and $y = \log_{a} c$. Then (3) $\ d \ = \ c^{(x^{2} ) }$, so $( 5 ) \ d \ = \ ( a^{y} ) ^{(x^{2} ) }$ , so

(9) $d = a^{(x^{2} y ) }$, so $( 7 ) \ d = ( a^{x} ) ^{xy}$ , and therefore $( 4 ) \ d = b^{xy}$ , hence (\*) as required.
