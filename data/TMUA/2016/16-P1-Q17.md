## 题目
It is given that

$$
y = (1 + 2\cos x)\cos 2x \quad \text{for } 0 < x < \pi
$$

The complete set of values of $x$ for which $y$ is negative is

$$
\mathbf{A} \quad 0 < x < \frac{\pi}{4},\ \frac{2\pi}{3} < x < \frac{3\pi}{4}
$$

$$
\mathbf{B} \quad 0 < x < \frac{\pi}{4},\ \frac{3\pi}{4} < x < \pi
$$

$$
\mathbf{C} \quad 0 < x < \frac{2\pi}{3},\ \frac{3\pi}{4} < x < \pi
$$

$$
\mathbf{D} \quad \frac{\pi}{4} < x < \frac{2\pi}{3},\ \frac{3\pi}{4} < x < \pi
$$

$$
\mathbf{E} \quad \frac{\pi}{4} < x < \frac{2\pi}{3}
$$

$$
\mathbf{F} \quad \frac{\pi}{4} < x < \frac{3\pi}{4}
$$

## 解析
The formula for y is the product of two factors, namely $1 + 2$ cos x and cos 2x. The whole expression is negative when one of the two factors is positive and the other is negative. The factors change sign when they cross a point where the factor is zero, and we can find these points:

$1 + 2$ cos $x = 0$ when cos $x = - { \frac { 1 } { 2 } }$ , which is when $\begin{array} { r } { x = \frac { 2 \pi } { 3 } } \end{array}$ (within the range $0 < x < \pi )$

cos $2 x = 0$ when $\textstyle x = { \frac { \pi } { 4 } }$ and when $\textstyle x = { \frac { 3 \pi } { 4 } }$

We can now make a table showing the signs of the two factors in the different parts of the interval $0 < x < \pi$ . (This is a useful technique in general.)

$$
\begin{array}{c c c c c c c c} & 0 <   x <   \frac {\pi}{4} & x = \frac {\pi}{4} & \frac {\pi}{4} <   x <   \frac {2 \pi}{3} & x = \frac {2 \pi}{3} & \frac {2 \pi}{3} <   x <   \frac {3 \pi}{4} & x = \frac {3 \pi}{4} & \frac {3 \pi}{4} <   x <   \pi \\ \hline 1 + 2 \cos x & + & + & + & 0 & - & - & - \\ \cos 2 x & + & 0 & - & - & - & 0 & + \\ \hline y & + & 0 & - & 0 & + & 0 & - \end{array}
$$
