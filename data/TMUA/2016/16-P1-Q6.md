## 题目
$P$, $Q$, and $R$ are each mixtures of red and white paint.

The percentage by volume of red paint in P is 30%.

The percentage by volume of red paint in Q is 20%.

The mixtures $P$, $Q$, and $R$ are combined in the proportion $12:5:3$ respectively.

If the resulting mixture contains 25% by volume of red paint, what percentage by volume of mixture R is red paint?

$$
\mathbf{A} \quad 25\%
$$

$$
\mathbf{B} \quad 23\%
$$

$$
\mathbf{C} \quad 13\frac{1}{3}\%
$$

$$
\mathbf{D} \quad 19\frac{1}{2}\%
$$

$$
\mathbf{E} \quad 9\frac{3}{4}\%
$$

$$
\mathbf{F} \quad \text{It is impossible to achieve this result.}
$$

## 答案
C

## 解析
We can either work in fractions or percentages. This solution works in fractions.

The fraction of red paint in P is $\frac { 3 } { 10 }$ and in $\mathrm { Q }$ is $\frac { 1 } { 5 }$ . Let the fraction of red paint in R be x. The combination is in the ratio $12 : 5 : 3 \ : \$: , with $\textstyle { \frac { 1 } { 4 } }$ red paint, so the composition is as follows:

| Paint | Volume | Red |
| --- | --- | --- |
| P | 12 | $12 \times \frac{3}{10}$ |
| Q | 5 | $5 \times \frac{1}{5}$ |
| R | 3 | $3x$ |
| total | 20 | $20 \times \frac{1}{4}$ |


We can now sum the individual red amounts, giving:

$$
12 \times \frac {3}{10} + 5 \times \frac {1}{5} + 3 x = 20 \times 14
$$

so $\textstyle { \frac { 23 } { 5 } } + 3 x = 5$ , giving $\textstyle 3 x = { \frac { 2 } { 5 } } = 40 \%$ , so $x = 13 \frac { 1 } { 3 } \%$ .

The correct answer is C.
