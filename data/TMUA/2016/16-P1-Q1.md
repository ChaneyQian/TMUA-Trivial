## 题目
It is given that the expansion of $(ax + b)^3$ is $8x^3 - px^2 + 18x - 3\sqrt{3}$, where $a$, $b$ and $p$ are real constants.

What is the value of $p$?

$$
\mathbf{A} \quad -12\sqrt{3}
$$

$$
\mathbf{B} \quad -6\sqrt{3}
$$

$$
\mathbf{C} \quad -4\sqrt{3}
$$

$$
\mathbf{D} \quad -\sqrt{3}
$$

$$
\mathbf{E} \quad \sqrt{3}
$$

$$
\mathbf{F} \quad 4\sqrt{3}
$$

$$
\mathbf{G} \quad 6\sqrt{3}
$$

$$
\mathbf{H} \quad 12\sqrt{3}
$$

## 答案
H

## 解析
We expand $( a x + b ) ^{3}$ and compare with the given expansion.

$$
(a x + b) ^{3} = a^{3} x^{3} + 3 a^{2} b x^{2} + 3 a b^{2} x + b^{3} = 8 x^{3} - p x^{2} + 18 x - 3 \sqrt {3}.
$$

So we must have:

$$
a^{3} = 8
$$

$$
3 a^{2} b = - p
$$

$$
3 a b^{2} = 18
$$

$$
b^{3} = - 3 \sqrt {3}
$$

The final equation can be rewritten as $b^{3} = - 3 ^{\frac{3} { 2 } } , \mathrm { { s o } } \ b = - 3 ^{\frac{1} { 2 } } = - { \sqrt { 3 } } .$

Then the third equation becomes 3a $\times 3 = 18 .$ , so $a = 2$

Finally, the second equation gives $3 \times 2 ^{2} \times ( - { \sqrt { 3 } } ) = - p , \operatorname { s o } p = 12 { \sqrt { 3 } }$ and the answer is H.
