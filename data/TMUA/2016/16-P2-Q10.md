## 题目
In this question $x$ and $y$ are non-zero real numbers.

Which one of the following is **sufficient** to conclude that $x < y$?

$$
\mathbf{A} \quad x^{4} < y^{4}
$$

$$
\mathbf{B} \quad y^{4} < x^{4}
$$

$$
\mathbf{C} \quad x^{-1} < y^{-1}
$$

$$
\mathbf{D} \quad y^{-1} < x^{-1}
$$

$$
\mathbf{E} \quad x^{\frac{3}{5}} < y^{\frac{3}{5}}
$$

$$
\mathbf{F} \quad y^{\frac{3}{5}} < x^{\frac{3}{5}}
$$

## 答案
E

## 解析
A key point in this question is that $x$ and $y$ are permitted to be positive or negative.

To show that a condition is not sufficient, we need to find values of $x$ and y where the condition holds but $x \geqslant y$ . To show that a condition is sufficient, we must prove it to be the case.

We can argue algebraically or graphically; we start with an algebraic approach.

A If $y = - 2 \ \mathrm { a n d } \ x = 1$ , the condition holds but $x > y$

B We do not even need to look at negative cases here: if $x$ and $y$ are both positive, we can take fourth roots and deduce that $y < x$ , for example $y = 1$ and $x = 2$

C If x = 2 and $y = 1$ , then $x^{-1} < y^{-1}$ but $x > y$.

D Positive values of $x$ and y do not work, but if we take x = 1 and $y = - 1$ , then $y^{-1} < x^{-1}$ but $x > y$

E This looks quite plausible: if we raise this inequality to the power of 5 (which we are allowed to do, as $\operatorname { f } ( x ) = x^{5}$ is an increasing function), we get $x^{3} < y^{3}$ . We can now take cube roots (again, this is permissible as $\mathrm { f } ( x ) = x^{\frac{1} { 3 } } = { \sqrt [ { 3 } ] { x } }$ in an increasing function) to give $x < y$. . So this condition is sufficient.

F Arguing as in part E, $y^{\frac{3} { 5 } } < x^{\frac{3} { 5 } }$ implies $y < x$ , so this is not sufficient. Alternatively, we can just substitute in the values $x = 1 , y = - 1$

Thus the answer is option E.

We can also see this by looking at the graphs of the functions $\operatorname { f } ( x ) = x^{4} , \operatorname { f } ( x ) = x^{-1}$ and $\operatorname { f } ( x ) = x^{\frac{3} { 5 } }$ : if these are strictly increasing functions, then $x < y$ if and only if $\operatorname { f } ( x ) < \operatorname { f } ( y )$ , while if they are strictly decreasing functions, then $x < y$ if and only if $\operatorname { f } ( x ) > \operatorname { f } ( y )$

The third function is strictly increasing, so the answer is option $\mathrm { E }$
