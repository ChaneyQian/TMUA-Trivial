## 题目
The diagram shows a square-based pyramid with base $PQRS$ and vertex $O$. All the edges of the pyramid are of length 20 metres.

![[Image/16-P1-Q20-fig1.jpg]]

Find the shortest distance, in metres, along the outer surface of the pyramid from $P$ to the midpoint of $OR$.

## 解析
Let us label the midpoint of OR as $T_{i}$ , so that we can refer to it.

We first observe that since all the edges of the pyramid are of length 20m, the triangles are all equilateral.

There are two ways to get from P to the midpoint of OR in a short distance: one can either travel along the base to RS and then along the triangular face to $T ,$ , or one could travel along the triangular face $O P S$ to the edge OS and from there to $T .$ . It is not obvious which route is shorter, so we will calculate both. (There are also routes which are mirror-reflections of these going via the edge QR or $O Q . )$ 0

To find these distances, we can "unfold" the tetrahedron, that is, make a net for the tetrahedron. For the first route, we draw just the faces P QRS and ORS:

![[Image/16-P1-Q20-sol1.jpg]]

The height of the triangle OSR is 20 sin $60 ^{\circ} = 20 \times { \frac { \sqrt { 3 } } { 2 } } = 10 { \sqrt { 3 } }$ , so T lies $5 \sqrt { 3 }$ above the line $S R { \mathrm { : } }$ $T$ also lies $\textstyle { \frac { 3 } { 4 } } \times 20 = 15$ to the right of S (as it is at the midpoint of OR). We can therefore find the length $P T$ using Pythagoras's theorem:

$$
\begin{array}{r l} P T^{2} & = 15 ^{2} + (20 + 5 \sqrt {3}) ^{2} \\ & = 225 + 400 + 200 \sqrt {3} + 75 \\ & = 700 + 200 \sqrt {3} \end{array}
$$

We now look at the other route, which we can do by drawing the triangles OP S and OSR:

![[Image/16-P1-Q20-sol2.jpg]]

Using the height of the triangle as calculated above, $P$ lies $10 \sqrt { 3 }$ to the left of OS and $T$ lies $5 \sqrt { 3 }$ to its right, while $T$ lies 5 above $P$ (being a quarter of OS). Pythagoras's theorem therefore gives

$$
\begin{array}{r l} & P T^{2} = (15 \sqrt {3}) ^{2} + 5 ^{2} \\ & \qquad = 225 \times 3 + 25 \\ & \qquad = 700 \end{array}
$$

This is therefore the shorter of the two routes, and its length is ${ \sqrt { 700 } } = 10 { \sqrt { 7 } }$ , hence the solution is option D.
