## 题目
$f(x)$ is a polynomial with real coefficients.

The equation $f(x) = 0$ has exactly two real roots, $x = -p$ and $x = p$, where $p > 0$.

Consider the following three statements:

	1.  $f'(x) = 0$ for exactly one value of $x$ between $-p$ and $p$
	2.  The area between the curve $y = f(x)$, the $x$-axis and the lines $x = -p$ and $x = p$ is given by $2\int_0^p f(x)\,\mathrm{d}x$
	3.  The graph of $y = -f(-x)$ intersects the $x$-axis at the points $x = -p$ and $x = p$ only

Which of the above statements **must** be true?

$$
\mathbf{A} \quad \text{none}
$$

$$
\mathbf{B} \quad \text{1 only}
$$

$$
\mathbf{C} \quad \text{2 only}
$$

$$
\mathbf{D} \quad \text{3 only}
$$

$$
\mathbf{E} \quad \text{1 and 2 only}
$$

$$
\mathbf{F} \quad \text{1 and 3 only}
$$

$$
\mathbf{G} \quad \text{2 and 3 only}
$$

$$
\mathbf{H} \quad \text{1, 2 and 3}
$$

## 解析
We know that the polynomial intersects the x-axis at $x = - p$ and $x = p$ only. It may touch the x-axis at those points or it may cross it  -  we are not told whether $x = p$ is a single root or double root, for example. We consider the three statements in turn.

1 It is entirely possible that $y = \operatorname { f } ( x )$ has multiple stationary points between $x = - p$ and $x = p$ without crossing the x-axis, for example in this sketch:

![[Image/16-P2-Q11-sol1.jpg]]

Therefore this statement need not be true.

2 This is not necessarily true for (at least) two different reasons:

• If the graph of $y = \operatorname { f } ( x )$ is entirely below the x-axis between $x = p$ and $x = - p ,$ , as in the above sketch, then the integral $\textstyle \int_{0} ^{p} \mathrm { f } ( x )$ dx will be negative, but the area is positive.

If the graph of $y = \operatorname { f } ( x )$ is not symmetrical about $x = 0$ , then there is no reason that the integal $\textstyle \int_{-p} ^{p} \operatorname { f } ( x )$ dx will be twice $\textstyle \int_{0} ^{p} \mathrm { f } ( x )$ dx. An example is this sketch, which is of the graph of $y = ( x + 1 ) ( x - 1 ) ( x^{2} + x + 1 )$ ; here $p = 1$ , and the graph of $y = x^{2} + x + 1$ is always positive, but it is not symmetrical about $x = 0 \cdot$

![[Image/16-P2-Q11-sol2.jpg]]

3 The graph of $y = \operatorname { f } ( - x )$ is obtained by reflecting the graph of $y = \operatorname { f } ( x )$ in the $y \mathrm { - a x i s } ,$ , so this graph intersects the x-axis at $x = - p$ and $x = p$ . The graph of $y = - \mathrm { f } ( - x )$ is obtained from this by reflecting the graph in the x-axis, which does not change the points of intersection with the x-axis. Therefore this statement must be true.

The graph obtained by combining these two transformations is the rotation of the original graph about the origin by 180◦.

The answer is therefore option D.
