## 题目
A line is drawn normal to the curve $y = \frac{2}{x^2}$ at the point on the curve where $x = 1$.

This line cuts the $x$-axis at $P$ and the $y$-axis at $Q$.

The length of $PQ$ is

$$
\mathbf{A} \quad \frac{3\sqrt{5}}{2}
$$

$$
\mathbf{B} \quad \frac{3\sqrt{17}}{4}
$$

$$
\mathbf{C} \quad \frac{7\sqrt{17}}{4}
$$

$$
\mathbf{D} \quad \frac{35}{4}
$$

$$
\mathbf{E} \quad \frac{35\sqrt{5}}{2}
$$

$$
\mathbf{F} \quad \frac{3\sqrt{17}}{2}
$$

C

## 解析
We need to find the gradient of the curve at $( 1 , 2 )$ . We have $y = 2 x^{-2}$ and so $\begin{array} { r } { { \frac { \mathrm { d } y } { \mathrm { d } x } } = - 4 x^{-3} } \end{array}$ . At $x = 1$ , this $\textstyle { \mathrm { g i v e s ~ } } { \frac { \mathrm { d } y } { \mathrm { d } x } } = - 4$ and so the normal has gradient $\textstyle { \frac { 1 } { 4 } }$ . As it passes through $( 1 , 2 )$ , it has equation

$$
y - 2 = \frac {1}{4} (x - 1).
$$

It cuts the x-axis $( y = 0 )$ at $P ,$ so at $P ,$ , we have $- 2 = { \textstyle { \frac { 1 } { 4 } } } ( x - 1 )$ ), giving $x = - 7$ , and so $P$ has coordinates $( - 7 , 0 )$

It cuts the y-axis $( x = 0 )$ at $Q ,$ so at $Q ,$ , we have $\begin{array} { r } { y - 2 = \frac { 1 } { 4 } ( - 1 ) } \end{array}$ , giving $\begin{array} { r } { y = \frac { 7 } { 4 } } \end{array}$ , and so $Q$ has coordinates $( 0 , \textstyle { \frac { 7 } { 4 } } )$

Thus $P Q$ has length

$$
\sqrt {7 ^{2} + (\frac {7}{4}) ^{2}} = \frac {7}{4} \sqrt {4 ^{2} + 1} = \frac {7 \sqrt {17}}{4}
$$

(where we have written $\begin{array} { r } { 7 = \frac { 7 } { 4 } \times 4 } \end{array}$ for the first equality).

Hence the answer is C.
