## 题目
Consider this statement about a function $f(x)$:

		$(^{*})$ If $\bigl(f(x)\bigr)^2 \leq 1$ for all $-1 \leq x \leq 1$ then $\displaystyle\int_{-1}^{1}\bigl(f(x)\bigr)^2\,\mathrm{d}x \leq \int_{-1}^{1} f(x)\,\mathrm{d}x$.

Which one of the following functions provides a **counterexample** to $(^{*})$?

$$
\mathbf{A} \quad f(x) = x + \frac{1}{2}
$$

$$
\mathbf{B} \quad f(x) = x - \frac{1}{2}
$$

$$
\mathbf{C} \quad f(x) = x + x^3
$$

$$
\mathbf{D} \quad f(x) = x - x^3
$$

$$
\mathbf{E} \quad f(x) = x^2 + x^4
$$

$$
\mathbf{F} \quad f(x) = x^2 - x^4
$$

## 解析
For a function to be a counterexample to this $\cdot_{\mathrm{if} } ^{} ,$ statement, the first condition (the antecedent) must be true but the second condition (the consequent) must be false.

So we first check whether these functions satisfy the condition $\left( \operatorname { f } ( x ) \right) ^{2} \leqslant 1$ for all $- 1 \leqslant x \leqslant$ 1:

A This function goes from $- { \frac { 1 } { 2 } } \ \mathrm { t o } \ { \frac { 3 } { 2 } }$ as x goes from 1 to 1. So when $x = 1 , \left( \operatorname { f } ( x ) \right) ^{2} = ( { \textstyle { \frac { 3 } { 2 } } } ) ^{2} > 1$ So this function does not satisfy the antecedent.

B Similarly to A, when $x = - { \textstyle { \frac { 1 } { 2 } } } , { \mathrm { ~ f } } ( x ) = - { \textstyle { \frac { 3 } { 2 } } } , { \mathrm { ~ s o ~ } } \left( { \mathrm { f } } ( x ) \right) ^{2} > 1$ and this function also does not satisfy the antecedent.

C When $x = 1 , { \mathrm { f } } ( x ) = 2 { \mathrm { ~ s o ~ } } { \bigl ( } { \mathrm { f } } ( x ) { \bigr ) } ^{2} > 1$ and this function does not satisfy the antecedent.

D This function looks as though it might satisfy the antecedent, as it does not obviously fail to do so: $\operatorname { f } ( - 1 ) = \operatorname { f } ( 0 ) = \operatorname { f } ( 1 ) = 0$ , so the cubic graph has two stationary points in the interval $- 1 \leqslant x \leqslant 1$ . We can locate these by differentiating:

$$
\mathrm{f} ^{\prime} (x) = 1 - 3 x^{2}
$$

so $\mathrm { f^{\prime} } ( x ) = 0$ when $\textstyle x = \pm { \frac { 1 } { \sqrt { 3 } } }$ . As

$$
\mathrm{f} \left(\frac {1}{\sqrt {3}} b i g r\right) = \frac {1}{\sqrt {3}} - \frac {1}{3 \sqrt {3}} = \frac {2}{3 \sqrt {3}} <   1 \quad \text {and} \quad \mathrm{f} \left(- \frac {1}{\sqrt {3}}\right) = - \frac {1}{\sqrt {3}} + \frac {1}{3 \sqrt {3}} = - \frac {2}{3 \sqrt {3}} > - 1,
$$

we see that the function lies between $- { \frac { 2 } { 3 { \sqrt { 3 } } } }$ and $\scriptstyle { \frac { 2 } { 3 { \sqrt { 3 } } } }$ when 16 x 61, so $\left( \operatorname { f } ( x ) \right) ^{2} \leqslant 1$ in this interval, and the antecedent is satisfied.

E As in C, when $x = 1 , \operatorname { f } ( x ) = 2 \operatorname { s o } \left( \operatorname { f } ( x ) \right) ^{2} > 1$ and this function does not satisfy the antecedent.

F As with $\mathbf { D } , \mathbf { f } ( - 1 ) = \mathbf { f } ( 0 ) = \mathbf { f } ( 1 ) = 0$ , so we look for stationary points of the function. We have

$$
\mathrm{f} ^{\prime} (x) = 2 x - 4 x^{3} = 2 x (1 - 2 x^{2})
$$

so $\mathrm { f } ^{\prime} ( x ) = 0$ when $x = 0$ or $x = \pm { \frac { 1 } { \sqrt { 2 } } }$ . We have $\mathrm { { f } ( 0 ) = 0 }$ and $\begin{array} { r } { \mathrm { f } \left( \pm \frac { 1 } { \sqrt { 2 } } \right) = \frac { 1 } { 2 } - \frac { 1 } { 4 } = \frac { 1 } { 4 } } \end{array}$ , so the function lies between 0 and $\begin{array} { r } { \frac { 1 } { 4 } \mathrm { ~ w h e n ~ \dot { ~ } - 1 } \leqslant x \leqslant 1 } \end{array}$ , so the antecedent is satisfied.

We therefore only need to consider the consequent condition for D and F.

For the function in D, the integral on the right, $\textstyle \int_{-1} ^{1} \operatorname { f } ( x )$ dx, is zero, since both x and $x^{3}$ are odd functions: the area between 0 and 1 and the area between 1 and 0 are equal, but the first is above the x-axis and the second below it, so they cancel each other out. We could also see this by calculating the integral explicitly. The integral on the left, $\textstyle \int_{-1} ^{1} \left( \operatorname { f } ( x ) \right) ^{2}$ dx, is the integral of a square, which is never negative, so the integral must be greater than 0. (We could likewise find this exactly by explicit integration.) Thus $\begin{array} { r } { \int_{-1} ^{1} \left( \operatorname { f } ( x ) \right) ^{2} \mathrm { d } x > \int_{-1} ^{1} \operatorname { f } ( x ) } \end{array}$ dx and the consequent is false. Hence D provides a counterexample.

For the sake of completeness, we will show that F is not a counterexample. Note that $0 \leqslant$ $\mathrm { f } ( x ) < 1$ for all $- 1 \leqslant x \leqslant 1$ . This means that $\left( \operatorname { f } ( x ) \right) ^{2} \leqslant \operatorname { f } ( x )$ for all $- 1 \leqslant x \leqslant 1$ , and so $\begin{array} { r } { \int_{-1} ^{1} \left( \operatorname { f } ( x ) \right) ^{2} \mathrm { d } x \leqslant \int_{-1} ^{1} \operatorname { f } ( x ) } \end{array}$ dx. Thus F is not a counterexample. (We could, of course, find these integrals by explicitly integrating.)

The correct answer is therefore D.
