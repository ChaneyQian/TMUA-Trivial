## 题目
What is the value, in radians, of the largest angle $x$ in the range $0 \leq x \leq 2\pi$ that satisfies the equation $8\sin^{2}x + 4\cos^{2}x = 7$?

$$
\mathbf{A} \quad \frac{2\pi}{3}
$$

$$
\mathbf{B} \quad \frac{5\pi}{6}
$$

$$
\mathbf{C} \quad \frac{4\pi}{3}
$$

$$
\mathbf{D} \quad \frac{5\pi}{3}
$$

$$
\mathbf{E} \quad \frac{7\pi}{4}

$$

## 解析
We use the identity $\sin^{2} x + \cos^{2} x = 1$ to write the equation in terms of sin x:

$$
8 \sin^{2} x + 4 \cos^{2} x = 4 \sin^{2} x + 4 = 7
$$

so $4 \sin^{2} x = 3 .$ , giving $\sin^{2} x = \frac{3}{4}$ so $\sin x = \pm\frac{\sqrt{3}}{2}$

The solutions to sin $\textstyle x = { \frac { \sqrt { 3 } } { 2 } }$ lie in the interva $0 < x < \pi$ , while the solutions to sin $\begin{array} { r } { x = - \frac { \sqrt { 3 } } { 2 } } \end{array}$ lie in the interval $\pi < x < 2 \pi$ , and thus the largest angle in the range $0 < x < 2 \pi$ which satisfies the original equation is the largest solution to sin $\begin{array} { r } { x = - \frac { \sqrt { 3 } } { 2 } } \end{array}$ . This is $\begin{array} { r } { 2 \pi - \frac { \pi } { 3 } = \frac { 5 \pi } { 3 } } \end{array}$ ,
