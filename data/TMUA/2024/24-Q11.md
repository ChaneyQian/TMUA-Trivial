## 题目
Given a geometric sequence $(S_{n})$ with the parity of first term $a_{1}$, the parity of the number of terms $n$, and the parity (odd or even nature) of the common ratio $r$, is it possible to determine the parity of the terms in the sequence $(S_{n})$?

$$\mathbf{A} \quad \text{Possible}$$

$$\mathbf{B} \quad \text{Impossible, need value of } a_{1}$$

$$\mathbf{C} \quad \text{Impossible, need value of } n$$

$$\mathbf{D} \quad \text{Impossible, need value of } r$$

$$\mathbf{E} \quad \text{All of them are incorrect}$$

### 我的备注

### AI备注


## 答案
A

## 解析
Parity is multiplicative, so the parities of $a_1$ and $r$ alone already settle every term: $a_k=a_1r^{\,k-1}$, and

$$\begin{aligned}
a_1\ \text{even}&\;\Rightarrow\; \text{every term is even},\\
a_1\ \text{odd},\ r\ \text{odd}&\;\Rightarrow\; \text{every term is odd},\\
a_1\ \text{odd},\ r\ \text{even}&\;\Rightarrow\; a_1\ \text{is odd and every later term is even}.
\end{aligned}$$

No actual values are needed, only the parities, which are given.

The same is true if one instead asks for the parity of the sum $S_n=a_1\left(1+r+\cdots+r^{\,n-1}\right)$: if $a_1$ is even then $S_n$ is even; if $a_1$ is odd and $r$ is even then the bracket is $1+\text{even}$, so $S_n$ is odd; and if $a_1$ and $r$ are both odd the bracket is a sum of $n$ odd numbers, so $S_n$ has the parity of $n$, which is also given.

Either way the three given parities determine the answer, so no extra information about $a_1$, $n$ or $r$ is required. The answer is A.
