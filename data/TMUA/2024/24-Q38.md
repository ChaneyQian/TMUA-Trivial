## 题目
Which of the following is a sufficient but not necessary condition for $\sin x > \frac{1}{2}$?

$$\mathbf{A} \quad \cos x = 0$$

$$\mathbf{B} \quad \frac{1}{2}\sin x < \frac{1}{4}$$

$$\mathbf{C} \quad \tan\frac{x}{2} = 1$$

$$\mathbf{D} \quad \cos x > \frac{\sqrt{3}}{2}$$

$$\mathbf{E} \quad \sin^{2} x > \frac{9}{4}$$

## 答案
C

## 解析
Recall that $\sin x>\tfrac12$ holds exactly when

$$\frac{\pi}{6}+2k\pi<x<\frac{5\pi}{6}+2k\pi,\qquad k\in\mathbb{Z}.$$

A condition $C$ is *necessary* if $\sin x>\tfrac12\Rightarrow C$, and *sufficient* if $C\Rightarrow\sin x>\tfrac12$. We test each option.

- **A**: $\cos x=0$ means $x=\tfrac{\pi}{2}+k\pi$, so $\sin x=\pm1$. It is not sufficient (take $\sin x=-1$) and not necessary (e.g. $x=\tfrac{\pi}{3}$ satisfies $\sin x>\tfrac12$ but $\cos x=\tfrac12\neq0$).
- **B**: $\tfrac12\sin x<\tfrac14$ is just $\sin x<\tfrac12$, which directly contradicts $\sin x>\tfrac12$. It is therefore neither necessary nor sufficient.
- **C**: $\tan\tfrac{x}{2}=1$ gives $\tfrac{x}{2}=\tfrac{\pi}{4}+k\pi$, i.e. $x=\tfrac{\pi}{2}+2k\pi$, so $\sin x=1>\tfrac12$. Hence C **implies** $\sin x>\tfrac12$, but it is not implied by it (again $x=\tfrac{\pi}{3}$ gives $\tan\tfrac{x}{2}=\tfrac{1}{\sqrt3}\neq1$). So C is sufficient but not necessary.
- **D**: $\cos x>\tfrac{\sqrt3}{2}$ forces $x$ to lie within $\tfrac{\pi}{6}$ of a multiple of $2\pi$, so $|\sin x|<\tfrac12$. Not sufficient, and not necessary.
- **E**: $\sin^2x>\tfrac94$ is impossible, since $\sin^2x\le1$. It can never be satisfied, so it is certainly not necessary. (Strictly, a condition that is never satisfied implies everything, so E is *vacuously* sufficient; but it picks out no value of $x$ at all, and is not the intended answer.)

So C is the option that is sufficient but not necessary for $\sin x>\tfrac12$. A tempting slip is to reverse the two words: a *necessary* condition would have to hold for every $x$ in the intervals above, and none of the options does.

The answer is C.
