## 题目
If the statement P: "For any n such that $n \not\equiv 1 \pmod 6$, n is not prime" is false, then which of the following is true?

$$\mathbf{A} \quad \text{There exist a } n \not\equiv 1 \pmod 6 \text{ and } n \text{ is prime.}$$

$$\mathbf{B} \quad \text{There exist a } n \equiv 1 \pmod 6 \text{ and } n \text{ is prime.}$$

$$\mathbf{C} \quad \text{For any prime } n,\ n \equiv 1 \pmod 6$$

$$\mathbf{D} \quad \text{For any prime } n,\ n \not\equiv 1 \pmod 6$$
