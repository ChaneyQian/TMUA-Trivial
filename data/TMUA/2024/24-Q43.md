## 题目
Solve the equation

$$\log_4(3x-1)^2 = \frac{\log_4(12x-4)}{\log_4(3x-1)}$$

$$\mathbf{A} \quad x = \frac{3}{5},\ x = \frac{2}{3}$$

$$\mathbf{B} \quad x = \frac{2}{3},\ x = \frac{5}{3}$$

$$\mathbf{C} \quad x = \frac{5}{12},\ x = \frac{1}{2}$$

$$\mathbf{D} \quad x = \frac{5}{3},\ x = \frac{1}{2}$$

## 备注

### 我的备注

### AI备注


## 答案
D

## 解析
The key observation is that $12x-4=4(3x-1)$, so both sides can be written in terms of the single quantity

$$u=\log_4(3x-1).$$

For the logarithms to be defined we need $3x-1>0$, and the right-hand side also requires $\log_4(3x-1)\neq0$, i.e. $3x-1\neq1$. Then

$$\log_4(3x-1)^2=2u,\qquad \log_4(12x-4)=\log_44+\log_4(3x-1)=1+u,$$

so the equation becomes

$$2u=\frac{1+u}{u}\quad\Longrightarrow\quad 2u^2-u-1=0\quad\Longrightarrow\quad(2u+1)(u-1)=0.$$

Thus $u=1$ or $u=-\tfrac12$.

If $u=1$ then $3x-1=4$, so $x=\tfrac53$. If $u=-\tfrac12$ then $3x-1=4^{-1/2}=\tfrac12$, so $x=\tfrac12$.

Both satisfy $3x-1>0$ and $3x-1\neq1$. Checking $x=\tfrac53$: the left side is $\log_4 16=2$ and the right side is $\log_4 16/\log_4 4=2/1=2$. Checking $x=\tfrac12$: the left side is $\log_4\tfrac14=-1$ and the right side is $\log_4 2/\log_4\tfrac12=\tfrac12/(-\tfrac12)=-1$.

The answer is D.
