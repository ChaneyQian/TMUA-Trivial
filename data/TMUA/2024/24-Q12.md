## 题目
Given the function $f(x) = \frac{a}{x} + bx^{2}$, determine which of the following conditions are true if $f(x)$ has a local minimum and a positive root.

$$\mathbf{A} \quad a > 0, b > 0$$

$$\mathbf{B} \quad a > 0, b < 0$$

$$\mathbf{C} \quad a < 0, b > 0$$

$$\mathbf{D} \quad a < 0, b < 0$$

### 我的备注

### AI备注


## 答案
C

## 解析
Deal with the root and the stationary point separately; the domain is $x\neq0$.

**Positive root.** Multiplying $f(x)=0$ by $x$ gives

$$a+bx^3=0\quad\Longrightarrow\quad x^3=-\frac ab .$$

A positive root needs $-\dfrac ab>0$, i.e. $a$ and $b$ have opposite signs. This leaves only options B and C.

**Local minimum.** Differentiating,

$$f'(x)=-\frac{a}{x^2}+2bx,\qquad f''(x)=\frac{2a}{x^3}+2b .$$

Setting $f'(x)=0$ gives $x^3=\dfrac{a}{2b}$, and substituting this into $f''$ at the stationary point,

$$f''=\frac{2a}{a/(2b)}+2b=4b+2b=6b .$$

So the unique stationary point is a minimum precisely when $b>0$, and a maximum when $b<0$.

Combining: $b>0$ and $a,b$ of opposite signs force $a<0$, $b>0$. Checking option C directly, say $a=-1$, $b=1$: $f(x)=-\tfrac1x+x^2$ has root $x=1>0$ and a minimum at $x=\sqrt[3]{-\tfrac12}$, as required. Option B has $b<0$, so its stationary point is a maximum; options A and D give $x^3=-a/b<0$, so their only root is negative. The answer is C.
