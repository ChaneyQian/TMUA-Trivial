## 题目
Given the function $f(x) = x^{3} + px^{2} + q$, it has a local maximum at $x = 0$ and 3 distinct roots. Find the conditions for $p$ and $q$.

$$\mathbf{A} \quad \frac{8}{27}p^{3} < q < 0$$

$$\mathbf{B} \quad 0 < q < -\frac{8}{27}p^{3}$$

$$\mathbf{C} \quad \frac{4}{27}p^{3} < q < 0$$

$$\mathbf{D} \quad 0 < q < -\frac{4}{27}p^{3}$$

## 备注

### 我的备注

### AI备注


## 答案
D

## 解析
A cubic with positive leading coefficient has three distinct real roots exactly when it has two stationary points with the local maximum value positive and the local minimum value negative.

Differentiating,

$$f'(x)=3x^2+2px=x(3x+2p),$$

so the stationary points are $x=0$ and $x=-\dfrac{2p}{3}$. Since $f''(x)=6x+2p$ gives $f''(0)=2p$, the point $x=0$ is a local maximum precisely when

$$p<0,$$

and then $-\tfrac{2p}{3}>0$ is the local minimum.

The two sign conditions are therefore

$$f(0)=q>0$$

and

$$f\!\left(-\frac{2p}{3}\right)=-\frac{8p^3}{27}+p\cdot\frac{4p^2}{9}+q=\frac{4p^3}{27}+q<0 .$$

The second gives $q<-\dfrac{4p^3}{27}$, so altogether

$$0<q<-\frac{4p^3}{27},$$

which is consistent because $p<0$ makes $-\tfrac{4}{27}p^3$ positive. (For instance $p=-3$ gives $0<q<4$, and $f(x)=x^3-3x^2+2$ indeed has three distinct roots.)

Options A and B use $\tfrac{8}{27}p^3$, the value of $-\tfrac{8p^3}{27}$ before the $px^2$ term is added, and B also reverses the role of the maximum. The answer is D.
