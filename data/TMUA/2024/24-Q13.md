$$\mathbf{B} \quad a_{1} = 1, d = 3, n = 10$$

$$\mathbf{C} \quad a_{1} = 3, d = 6, n = 30$$

$$\mathbf{D} \quad a_{1} = 5, d = 4, n = 15$$

$$\mathbf{E} \quad a_{1} = 4, d = 5, n = 8$$
