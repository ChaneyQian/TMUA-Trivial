## 题目
An arithmetic sequence $(S_{n})$ is defined by its first term $a_{1}$, number of terms $n$, and common difference $d$. Consider the following statement: "If $a_{1}$ is odd, then all terms $S_{n}$ are odd." Identify a counterexample for this statement from the options below.

$$\mathbf{A} \quad a_{1} = 2, d = 2, n = 20$$

$$\mathbf{B} \quad a_{1} = 1, d = 3, n = 10$$

$$\mathbf{C} \quad a_{1} = 3, d = 6, n = 30$$

$$\mathbf{D} \quad a_{1} = 5, d = 4, n = 15$$

$$\mathbf{E} \quad a_{1} = 4, d = 5, n = 8$$

## 备注

### 我的备注

### AI备注


## 答案
B

## 解析
A counterexample must satisfy the hypothesis and contradict the conclusion: the first term $a_1$ must be **odd**, and some term of the sequence must be **even**.

The terms are $a_k=a_1+(k-1)d$. If $d$ is even, every term keeps the parity of $a_1$; so an odd first term can only produce an even term when $d$ is odd.

- **A:** $a_1=2$ is even, so the hypothesis fails and this says nothing about the statement.
- **B:** $a_1=1$ is odd and $d=3$ is odd, giving $1,4,7,10,\dots$ — the second term $4$ is even. This is a counterexample.
- **C:** $a_1=3$ is odd but $d=6$ is even, giving $3,9,15,\dots$, all odd: the statement holds here.
- **D:** $a_1=5$ is odd and $d=4$ is even, giving $5,9,13,\dots$, all odd: again no contradiction.
- **E:** $a_1=4$ is even, so the hypothesis fails.

Only B has an odd first term together with an even term. The answer is B.
