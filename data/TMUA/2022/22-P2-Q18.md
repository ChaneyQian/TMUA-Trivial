## 题目
P, Q, R and S show the graphs of

$$
y = (\cos x)^{\cos x},\quad y = (\sin x)^{\sin x},\quad y = (\cos x)^{\sin x}\quad \text{and}\quad y = (\sin x)^{\cos x}
$$

for $0 < x < \dfrac{\pi}{2}$ in some order.

| | |
|---|---|
| **P** ![[Image/22-P2-Q18-fig1.jpg]] | **Q** ![[Image/22-P2-Q18-fig2.jpg]] |
| **R** ![[Image/22-P2-Q18-fig3.jpg]] | **S** ![[Image/22-P2-Q18-fig4.jpg]] |

Which row in the following table correctly identifies the graphs?

|  | $y = (\cos x)^{\cos x}$ | $y = (\sin x)^{\sin x}$ | $y = (\cos x)^{\sin x}$ | $y = (\sin x)^{\cos x}$ |
| --- | --- | --- | --- | --- |
| **A** | P | Q | R | S |
| **B** | P | Q | S | R |
| **C** | Q | P | R | S |
| **D** | Q | P | S | R |
| **E** | R | S | P | Q |
| **F** | R | S | Q | P |
| **G** | S | R | P | Q |
| **H** | S | R | Q | P |

## 答案
E

## 解析
Let us substitute values into the four equations to begin with.

When $x = 0$ , we have

$$
(\cos x) ^ {\cos x} = 1 ^ {1} = 1
$$

$$
(\sin x) ^ {\sin x} = 0 ^ {0} = ?
$$

$$
(\cos x) ^ {\sin x} = 1 ^ {0} = 1
$$

$$
(\sin x) ^ {\cos x} = 0 ^ {1} = 0
$$

This shows that graph Q is $y = ( \sin x ) ^ { \cos x }$ . (We do not know what $( \sin x ) ^ { \sin x }$ is when $x = 0$ 2 but from the graphs given, since three of the functions have value 1 at $x = 0$ and only one is 0, it must be 1.)

Next, let us consider the value at $\begin{array} { r } { x = \frac { \pi } { 2 } } \end{array}$

$$
\begin{array}{r l} & {(\cos x) ^ {\cos x} = 0 ^ {0} = ?} \\ & {(\sin x) ^ {\sin x} = 1 ^ {1} = 1} \\ & {(\cos x) ^ {\sin x} = 0 ^ {1} = 0} \\ & {(\sin x) ^ {\cos x} = 1 ^ {0} = 1} \end{array}
$$

Again, as only one graph has value 0 at $\begin{array} { r } { x = \frac { \pi } { 2 } } \end{array}$ , graph P depicts $( \cos x ) ^ { \sin x }$ . (We did not actually need to calculate the final line of this list, as we have already identified this function as being graph Q.)

So we are left with $( \cos x ) ^ { \cos x }$ and $( \sin x ) ^ { \sin x }$ as graphs R and S in some order. Let us put in the value $\begin{array} { r } { x = \frac { \pi } { 6 } } \end{array}$ , as that is clearly different between the two functions. We have

$$
\begin{array}{l} (\cos x) ^ {\cos x} = \left(\frac {\sqrt {3}}{2}\right) ^ {\frac {\sqrt {3}}{2}} \\ (\sin x) ^ {\sin x} = \left(\frac {1}{2}\right) ^ {\frac {1}{2}} \end{array}
$$

The first of these looks horrible, but we can approximate the value of the second of these; it is just $\textstyle { \frac { 1 } { \sqrt { 2 } } } \approx 0 . 7$ , so this must be graph S. Similarly, $( \cos x ) ^ { \cos x } \approx 0 . 7$ at $\begin{array} { r } { x = \frac { \pi } { 3 } } \end{array}$ , which is graph R.

Therefore the graphs are:

$$
(\cos x) ^ {\cos x}: \mathrm{graphR}
$$

$$
(\sin x) ^ {\sin x}: \mathrm{graphS}
$$

$$
(\cos x) ^ {\sin x}: \mathrm{graphP}
$$

$$
(\sin x) ^ {\cos x}: \mathrm{graphQ}
$$

which is option E.
