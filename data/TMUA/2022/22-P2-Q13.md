## 题目
Consider the statement (\*) about a real number x:

(\*) There exists a real number y such that $x - xy + y$ is negative.

For how many real values of $x$ is (\*) true?

$$
\mathbf {A} \quad \text{no values of } x
$$

$$
\mathbf {B} \quad \text{exactly one value of } x
$$

$$
\mathbf {C} \quad \text{exactly two values of } x
$$

$$
\mathbf {D} \quad \text{all except exactly two values of } x
$$

$$
\mathbf {E} \quad \text{all except exactly one value of } x
$$

$$
\mathbf {F} \quad \text{all values of } x
$$

## 备注

### AI备注


## 答案
E

## 解析
For each fixed value of $x$, we can think about this expression as being a function of $y$. . We can write the expression as $( 1 - x ) y + x$ , which is just $m y + c$ where $m = 1 - x$ and $c = x$ . This is the equation of a straight line graph, so it takes every real value, both positive and negative, as long as $m \neq 0$

The case $m = 0$ occurs exactly when $x = 1$ , and in this case, the expression becomes $( 1 - 1 ) y + 1 =$ 1, so it is always 1, for every value of $y$.

Therefore (∗) is true for all except exactly one value of $x$, , namely $x = 1$ , and the correct answer is option E.
