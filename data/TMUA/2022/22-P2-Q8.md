## 题目
A selection, $S$, of $n$ terms is taken from the arithmetic sequence $1, 4, 7, 10, \ldots, 70$.

Consider the following statement:

$$
(*) \quad \text{There are two distinct terms in } S \text{ whose sum is } 74.
$$

What is the smallest value of $n$ for which $(*)$ is **necessarily** true?

$$
\mathbf{A} \quad 12
$$

$$
\mathbf{B} \quad 13
$$

$$
\mathbf{C} \quad 14
$$

$$
\mathbf{D} \quad 21
$$

$$
\mathbf{E} \quad 22
$$

$$
\mathbf{F} \quad 23
$$

## 答案
C

## 解析
We first determine the number of terms in the whole sequence: there are $\textstyle { \frac { 7 0 - 1 } { 3 } } + 1 = 2 3 + 1 = 2 4$ terms.

We next determine the number of pairs that sum to 74. The pairs are:

$$
\begin{array}{c} 4 + 7 0 \\ 7 + 6 7 \\ \vdots \\ 3 4 + 4 0 \\ [ 3 7 + 3 7 ] \end{array}
$$

The final pair is excluded because the two terms have to be distinct to fit the rule in (∗). The number of valid pairs is therefore $\textstyle { \frac { 3 4 - 4 } { 3 } } + 1 = 1 0 + 1 = 1 1$

If a selection S does not satisfy the rule in (∗), then it can have at most one term from each of these pairs, so it has to leave out at least 11 terms. So it can have at most 24 − 11 = 13 terms. Therefore if S has at least 14 terms, it must satisfy (∗).

We also need to show that if S only has 13 terms, it might not satisfy (∗). We can include 1, 37 and one term from each listed pair, giving 2 + 11 = 13 terms. These 13 terms do not contain a distinct pair summing to 37.

Hence the smallest value of $n$ which forces (∗) to be true is 14, and the correct answer is option C..
