## 题目
![[Image/22-P1-Q17-fig1.jpg]]

Find the complete set of values of $x$ for which there are two non-congruent triangles with the side lengths and angle as shown in the diagram.

$$
\mathbf {A} \quad 1 <   x <   3
$$

$$
\mathbf {B} \quad 1 <   x <   4
$$

$$
\mathbf {C} \quad 1 <   x <   5
$$

$$
\mathbf {D} \quad 3 <   x <   4
$$

$$
\mathbf {E} \quad 3 <   x <   5
$$

$$
\mathbf {F} \quad 4 <   x <   5
$$

## 答案
D

## 解析
We first require that the lengths shown are both positive; $x - 1 > 0$ if and only if $x > 1$ , and $- x ^ { 2 } + 6 x - 5 = - ( x - 5 ) ( x - 1 ) > 0$ if and only if $1 < x < 5$ . Therefore we require $1 < x < 5$ to ensure both lengths are positive.

There are two non-congruent triangles when the side marked $x - 1$ can be drawn in two configurations:

![[Image/22-P1-Q17-sol1.jpg]]

This is possible when the following conditions are satisfied:

$x - 1 < - x ^ { 2 } + 6 x - 5$ (otherwise one of the possibilities will lie to the right of the $3 0 ^ { \circ }$ angle in the above diagram)

$x - 1 > \left( - x ^ { 2 } + 6 x - 5 \right)$ sin $3 0 ^ { \circ }$ (so that the distance from the end of the $- x ^ { 2 } + 6 x - 5$ side to the base is at least $x - 1$ , making it possible to form a triangle; if there is equality here, then the dashed circle will be tangent to the base of the triangle, and there will only be one possibility)

The first inequality rearranges as $x ^ { 2 } - 5 x + 4 < 0$ , which factorises as $( x - 1 ) ( x - 4 ) < 0$ , giving $1 < x < 4$

The second equality, using sin $\begin{array} { r } { 3 0 ^ { \circ } = \frac { 1 } { 2 } } \end{array}$ , becomes $2 x - 2 > - x ^ { 2 } + 6 x - 5 , \mathrm { s o } x ^ { 2 } - 4 x + 3 > 0$ . This factorises as $( x - 1 ) ( x - 3 ) > 0$ , so $x < 1$ or $x > 3$

Requiring both of these inequalities to hold thus gives $3 < x < 4$; this also satifies the positivity requirement we started with $( 1 < x < 5 )$ , and so the answer is option D.
