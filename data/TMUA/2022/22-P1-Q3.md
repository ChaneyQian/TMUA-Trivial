## 题目
Given the following statements about a function $\mathrm{f}$

- $\mathrm{f}''(x) = a$ for all $x$
- $\mathrm{f}(0) = 1$, $\mathrm{f}(1) = 2$
- $\displaystyle\int_0^1 \mathrm{f}(x)\,\mathrm{d}x = 1$

find the value of $a$.

$$
\mathbf{A} \quad -6
$$

$$
\mathbf{B} \quad -3
$$

$$
\mathbf{C} \quad -2
$$

$$
\mathbf{D} \quad 2
$$

$$
\mathbf{E} \quad 3
$$

$$
\mathbf{F} \quad 6
$$

## 备注

### 我的备注

### AI备注


## 答案
F

## 解析
Using the first statement, $\mathrm { f ^ { \prime \prime } } ( x ) = a$ for all x, we can integrate to get $\mathrm { f } ^ { \prime } ( x ) = a x + b$ for some constant b, and a further integration gives $\begin{array} { r } { \mathrm { f } ( x ) = \frac { 1 } { 2 } a x ^ { 2 } + b x + c } \end{array}$ for some constant c.

The second statement then yields $\begin{array} { r } { \mathrm { f } ( 0 ) = c = 1 \mathrm{and} \mathrm { f } ( 1 ) = \frac { 1 } { 2 } a + b + 1 = 2 , \mathrm{so} a + 2 b = 2 . } \end{array}$

Finally, we can now use the third statement:

$$
\begin{array}{r l} \int_ {0} ^ {1} \mathrm{f} (x) \mathrm{d} x & = \left[ \frac {1}{6} a x ^ {3} + \frac {1}{2} b x ^ {2} + x \right] _ {0} ^ {1} \\ & = \frac {1}{6} a + \frac {1}{2} b + 1 \\ & = 1 \end{array}
$$

so that $a + 3 b = 0$

Combining the simultaneous equations

$$
a + 2 b = 2
$$

$$
a + 3 b = 0
$$

gives $b = - 2$ and $a = 6$ , so the correct answer is option F.
