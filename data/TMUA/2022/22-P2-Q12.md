## 题目
Place the following integrals in order of size, starting with the smallest.

$$
P = \int_0^1 2^{\sqrt{x}}\,\mathrm{d}x
$$

$$
Q = \int_0^1 2^{x}\,\mathrm{d}x
$$

$$
R = \int_0^1 (\sqrt{2})^{x}\,\mathrm{d}x
$$

$$
\mathbf{A} \quad P < Q < R
$$

$$
\mathbf{B} \quad P < R < Q
$$

$$
\mathbf{C} \quad Q < P < R
$$

$$
\mathbf{D} \quad Q < R < P
$$

$$
\mathbf{E} \quad R < P < Q
$$

$$
\mathbf{F} \quad R < Q < P
$$

## 备注

### 我的备注

### AI备注


## 答案
F

## 解析
We do not know how to integrate any of these, so we will instead compare the integrands as the integrals are all from 0 to 1.

We have $\left( { \sqrt { 2 } } \right) ^ { x } = 2 ^ { x / 2 }$ , which makes R look a little simpler. Since $x / 2 < x$ for $0 < x < 1$ ， $2 ^ { x / 2 } < 2 ^ { x }$ in this interval, and so $R < Q$

Now in this interval, we also have $x < \sqrt { x } \ ( \mathrm { a s } \ x ^ { 2 } < x )$ , so $2 ^ { x } < 2 ^ { \sqrt { x } }$ , hence $Q < P$

Combining these, we find that $R < Q < P$ , so the correct option is F.
