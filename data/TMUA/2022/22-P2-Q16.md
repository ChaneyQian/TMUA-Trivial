## 题目
In this question, $a_{1}, \ldots, a_{100}$ and $b_{1}, \ldots, b_{100}$ and $c_{1}, \ldots, c_{100}$ are three sequences of integers such that

$$
a _ {n} \leq b _ {n} + c _ {n}
$$

for each $n$.

Which of the following statements must be true?

$$
\text{I} \quad (\text{minimum of } a_1, \ldots, a_{100}) \leq (\text{minimum of } b_1, \ldots, b_{100}) + (\text{minimum of } c_1, \ldots, c_{100})
$$

$$
\text{II} \quad (\text{minimum of } a_1, \ldots, a_{100}) \geq (\text{minimum of } b_1, \ldots, b_{100}) + (\text{minimum of } c_1, \ldots, c_{100})
$$

$$
\text{III} \quad (\text{maximum of } a_1, \ldots, a_{100}) \leq (\text{maximum of } b_1, \ldots, b_{100}) + (\text{maximum of } c_1, \ldots, c_{100})
$$

$$
\mathbf {A} \quad \text{none of them}
$$

$$
\mathbf {B} \quad \text{I only}
$$

$$
\mathbf {C} \quad \text{II only}
$$

$$
\mathbf {D} \quad \text{III only}
$$

$$
\mathbf {E} \quad \text{I and II only}
$$

$$
\mathbf {F} \quad \text{I and III only}
$$

$$
\mathbf {G} \quad \text{II and III only}
$$

$$
\mathbf {H} \quad \text{I, II and III}
$$

## 解析
For each of these, we can try to construct a counterexample, and if that doesn’t work, we may understand why the statement must be true.

For simplicity in the explanations below, let’s write

$$
A _ {\mathrm{min}} = \mathrm{minimumof} a _ {1}, \ldots , a _ {1 0 0}
$$

$$
B _ {\mathrm{min}} = \mathrm{minimumof} b _ {1}, \ldots , b _ {1 0 0}
$$

$$
C _ {\mathrm{min}} = \mathrm{minimumof} c _ {1}, \ldots , c _ {1 0 0}
$$

and similarly for $A _ { \mathrm{max} }$ etc.

I Let’s suppose that $B _ { \operatorname* { m i n } } = 0$ and $C _ { \mathrm{min} } = 0$ . Can we then make the minimum of the $a _ { n } \mathrm { s }$ greater than zero?

Yes, we can: if we take $b _ { 1 } = 0$ and the rest of the $b _ { n } \mathrm { s }$ to be 100, and we take $c _ { 1 0 0 } = 0$ and the rest of the $c _ { n } \mathrm { s }$ to be 100, then we can have $a _ { n } = 1 0 0$ for every $n ,$ so the minimum of the $a _ { n } \mathrm { s }$ is 100.

Therefore this statement is not necessarily true.

II If we try the same example as in I, we find that $A _ { \operatorname* { m i n } } = 1 0 0$ , which is greater than $B _ { \mathrm{min} } $ $C _ { \mathrm{min} } .$ , so the inequality holds in this case.

But to get a counterexample, we want to make $A _ { \mathrm{min} }$ small. Helpfully, the condition $a _ { n } \leq$ $b _ { n } + c _ { n }$ allows us to make each $a _ { n }$ as small as we like. So if we take $a _ { n } = 0 , b _ { n } = 1$ and $c _ { n } = 1$ for all $n ,$ then the condition will be satisfied for each $n ,$ but we will have $A _ { \operatorname* { m i n } } = 0$ and $B _ { \mathrm{min} } = C _ { \mathrm{min} } = 1$ , so $A _ { \operatorname* { m i n } } < B _ { \operatorname* { m i n } } + C _ { \operatorname* { m i n } }$ in this case.

Therefore this statement is not necessarily true either.

III Both of the counterexamples we used for I and II satisfy this statement. It is not obvious how to construct a counterexample: every simple example satisfies this statement. So let us instead try to prove it.

Each $a _ { n }$ satisfies the condition $a _ { n } \leq b _ { n } + c _ { n }$ . Now $b _ { n } \leq B _ { \mathrm{max} }$ and $c _ { n } \leq C _ { \operatorname* { m a x } }$ for each $n .$ , so $a _ { n } \leq B _ { \mathrm{max} } + C _ { \mathrm{max} }$ for each n. But this means that the maximum of all of the $a _ { n } \mathrm { s }$ also satisfies this condition, that is $A _ { \mathrm{max} } \leq B _ { \mathrm{max} } + C _ { \mathrm{max} }$ , so the given statement must be true.

Therefore only statement III must be true, and the correct answer is option D.
