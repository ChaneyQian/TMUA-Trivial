## 题目
Given that

$$
\left(a^3 + \dfrac{2}{b^3}\right)\left(\dfrac{2}{a^3} - b^3\right) = \sqrt{2}
$$

where $a$ and $b$ are real numbers, what is the least value of $ab$?

$$
\mathbf{A} \quad -\sqrt{2}
$$

$$
\mathbf{B} \quad \sqrt{2}
$$

$$
\mathbf{C} \quad -2\sqrt{2}
$$

$$
\mathbf{D} \quad 2\sqrt{2}
$$

$$
\mathbf{E} \quad -\dfrac{\sqrt{2}}{2}
$$

$$
\mathbf{F} \quad \dfrac{\sqrt{2}}{2}
$$

$$
\mathbf{G} \quad -2^{\frac{1}{6}}
$$

$$
\mathbf{H} \quad 2^{\frac{1}{6}}
$$

## 答案
A

## 解析
Expanding the brackets gives

$$
2 - a ^ {3} b ^ {3} + \frac {4}{a ^ {3} b ^ {3}} - 2 = \sqrt {2}
$$

so

$$
\frac {4}{a ^ {3} b ^ {3}} - a ^ {3} b ^ {3} = \sqrt {2}.
$$

We are interested in the least possible value of $a b$, so we can find the least possible value of $a ^ { 3 } b ^ { 3 }$ and take the cube root. Let us simplify the notation by writing $x = a ^ { 3 } b ^ { 3 }$ , so $\begin{array} { r } { { \frac { 4 } { x } } - x = \sqrt { 2 } . } \end{array}$

Multiplying by x gives a quadratic: $4 - x ^ { 2 } = { \sqrt { 2 } } x$. , which we can rearrange to $x ^ { 2 } + { \sqrt { 2 } } x - 4 = 0$ and then solve using the quadratic formula:

$$
x = \frac {- \sqrt {2} \pm \sqrt {2 + 1 6}}{2} = \frac {- \sqrt {2} \pm 3 \sqrt {2}}{2} = - 2 \sqrt {2} \mathrm{or} \sqrt {2}.
$$

Since we want the least possible value of $x$, we take $x = a ^ { 3 } b ^ { 3 } = - 2 { \sqrt { 2 } } = - 2 ^ { \frac { 3 } { 2 } }$ , and so the minimum possible value of ab is $( - 2 ^ { \frac { 3 } { 2 } } ) ^ { \frac { 1 } { 3 } } = - 2 ^ { \frac { 1 } { 2 } } = - { \sqrt { 2 } }$ , which is option A.
