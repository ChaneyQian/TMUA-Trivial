## 题目
Determine the number of stationary points on the curve with equation

$$
y = 3 x ^ {4} + 4 x ^ {3} + 6 x ^ {2} - 5
$$

$$
\mathbf {A} \quad 0
$$

$$
\mathbf {B} \quad 1
$$

$$
\mathbf {C} \quad 2
$$

$$
\mathbf {D} \quad 3
$$

$$
\mathbf {E} \quad 4
$$

## 答案
B

## 解析
We differentiate to obtain

$$
{\frac {\mathrm{d} y}{\mathrm{d} x}} = 1 2 x ^ {3} + 1 2 x ^ {2} + 1 2 x.
$$

We solve the equation $\begin{array} { r } { { \frac { \mathrm { d } y } { \mathrm { d } x } } = 0 } \end{array}$ to find the number of stationary points:

$$
1 2 x ^ {3} + 1 2 x ^ {2} + 1 2 x = 0
$$

if and only if

$$
1 2 x (x ^ {2} + x + 1) = 0.
$$

So either $x = 0$ or $x ^ { 2 } + x + 1 = 0$ . But this quadratic has discriminant $1 ^ { 2 } - 4 \times 1 = - 3 < 0 .$ , so it has no real solutions.

Thus there is only one stationary point, at $x = 0$ , and the answer is option B.
