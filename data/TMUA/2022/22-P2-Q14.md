## 题目
Consider the two inequalities:

$$
\vert x + 5 \vert <   \vert x + 1 1 \vert
$$

$$
\vert x + 1 1 \vert <   \vert x + 1 \vert
$$

Which one of the following is correct?

$$
\mathbf {A} \quad \text{There is no real number for which both inequalities are true.}
$$

$$
\mathbf {B} \quad \text{There is exactly one real number for which both inequalities are true.}
$$

$$
\mathbf {C} \quad \text{The real numbers for which both inequalities are true form an interval of length 1.}
$$

$$
\mathbf {D} \quad \text{The real numbers for which both inequalities are true form an interval of length 2.}
$$

$$
\mathbf {E} \quad \text{The real numbers for which both inequalities are true form an interval of length 3.}
$$

$$
\mathbf {F} \quad \text{The real numbers for which both inequalities are true form an interval of length 4.}
$$

$$
\mathbf {G} \quad \text{The real numbers for which both inequalities are true form an interval of length 5.}
$$

## 答案
D

## 解析
To solve this question, we use the fact that $| x - a |$ can be understood as the distance of x from a. The first inequality is true if and only if x is closer to −5 than to −11, i.e., if and only if $x > - 8$ The second inequality is true if and only if x is closer to −11 than to −1, i.e., if and only if $x < - 6$

Therefore both inequalities are true if and only ${ \mathrm { i f ~ } } - 8 < x < - 6$ , which is an interval of length 2, which is option D.

One could also do this question by sketching the graphs of $y = | x + 5 |$ and $y = | x + 1 1 |$ and working out where they intersect, and so on. But that requires a lot more work than than the approach presented here.
