## 题目
This question is about pairs of functions $\mathrm{f}$ and $\mathrm{g}$ that satisfy

$$
\mathrm{f}(x) - \mathrm{g}(x) = 2\sin x
$$

$$
\mathrm{f}(x)\,\mathrm{g}(x) = \cos^2 x
$$

for all real numbers $x$.

Across all solutions for $\mathrm{f}(x)$, what is the minimum value that $\mathrm{f}(x)$ attains for any $x$?

$$
\mathbf{A} \quad 1 - \sqrt{2}
$$

$$
\mathbf{B} \quad -1 - \sqrt{2}
$$

$$
\mathbf{C} \quad 0
$$

$$
\mathbf{D} \quad -1
$$

$$
\mathbf{E} \quad -2
$$

$$
\mathbf{F} \quad -3
$$

$$
\mathbf{G} \quad -4
$$

## 解析
It may well require reading this question a couple of times to understand what it is asking! It seems like we need to find all possible functions f(x) and $\mathrm { g } ( x )$ , then for each one, to find the minimum value that $\operatorname { f } ( x )$ takes, and then to find the minimum of all the minima. There might, of course, be some shortcuts!

Let us try to solve the equations to find $\operatorname { f } ( x )$ . The first equation rearranges to give $\operatorname { g } ( x ) =$ $\operatorname { f } ( x ) - 2 \sin x$ , so we can substitute this into the second equation to give

$$
\mathrm{f} (x) (\mathrm{f} (x) - 2 \sin x) = \cos^ {2} x.
$$

This is a quadratic in f(x), so we can rearrange it into the standard form and use the quadratic formula:

$$
(\mathrm{f} (x)) ^ {2} - (2 \sin x) \mathrm{f} (x) - \cos^ {2} x = 0,
$$

hence

$$
\begin{array}{c} \mathrm{f} (x) = \frac {2 \sin x \pm \sqrt {4 \sin^ {2} x + 4 \cos^ {2} x}}{2} \\ = \sin x \pm 1. \end{array}
$$

So there are two possible functions $\operatorname { f } ( x )$ , namely $\operatorname { f } ( x ) = \sin x + 1$ and $\operatorname { f } ( x ) = \sin { x } - 1$ . The minimum value taken by these for any $x$ is 0 for the first function and −2 for the second, so the minimum possible value is −2, which is option E.
