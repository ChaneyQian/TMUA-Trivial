## 题目
Consider the following statement:

$$
(*) \quad \textbf{For all} \text{ real numbers } x, \textbf{ if } x < k \textbf{ then } x^2 < k
$$

What is the complete set of values of $k$ for which $(*)$ is true?

$$
\mathbf{A} \quad \text{no real numbers}
$$

$$
\mathbf{B} \quad k > 0
$$

$$
\mathbf{C} \quad k < 1
$$

$$
\mathbf{D} \quad k \leq 1
$$

$$
\mathbf{E} \quad 0 < k < 1
$$

$$
\mathbf{F} \quad 0 < k \leq 1
$$

$$
\mathbf{G} \quad \text{all real numbers}
$$

## 备注

### 我的备注

### AI备注


## 答案
A

## 解析
The statement (∗) does not restrict us to positive real numbers $x$, so whatever the value of $k$, we can always find a large negative number $x$ with $x < k$ and $x ^ { 2 } \geq k$

We can even be explicit about this (though that is not required to answer this question): if $k \leq 0$, , we can take $x = k - 1$ in which case $x ^ { 2 } > 0 \geq k$ , and if $k > 0$ , we can take $x = - { \sqrt { k } }$ so $x < 0 < k$ and $x ^ { 2 } = k \geq k$

Therefore (∗) is true for no real values of $k$, and the correct option is A.
