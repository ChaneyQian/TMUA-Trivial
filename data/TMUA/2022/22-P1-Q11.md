## 解析
We have $\log _ { 1 0 } ( 3 ^ { 1 - n } ) = ( 1 - n ) \log _ { 1 0 } 3$ , so the sum becomes

$$
\begin{array}{c} \sum_ {n = 1} ^ {1 0 0} \log_ {1 0} (3 ^ {1 - n}) = \sum_ {n = 1} ^ {1 0 0} (1 - n) \log_ {1 0} 3 \\ = (\log_ {1 0} 3) \sum_ {n = 1} ^ {1 0 0} (1 - n). \end{array}
$$

Now the sum is actually an arithmetic series: expanding it gives

$$
\begin{array}{r l} \sum_ {n = 1} ^ {1 0 0} (1 - n) & = 0 + (- 1) + (- 2) + \dots + (- 9 9) \\ & = - (0 + 1 + 2 + \dots + 9 9) \\ & = - \frac {1}{2} \times 1 0 0 (0 + 9 9 \times 1) \\ & = - 4 9 5 0 \end{array}
$$

using the formula $\begin{array} { r } { S _ { n } = \frac { 1 } { 2 } n ( 2 a + ( n - 1 ) d ) } \end{array}$ . (Alternatively, we could have used the formula for the nth triangular number.)

Therefore the original sum evaluates to $- 4 9 5 0 \log _ { 1 0 } 3$ , which is option A.
