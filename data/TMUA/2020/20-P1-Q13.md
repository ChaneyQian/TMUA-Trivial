## 解析
We have not learnt a “trinomial theorem” for expanding expressions like $( 1 + x + y ^ { 2 } ) ^ { 7 }$ , so instead we treat it as a binomial expression. If we write it as $( 1 + ( x + y ^ { 2 } ) ) ^ { 7 }$ , we will then have a series of complicated expressions like $( x + y ^ { 2 } ) ^ { 3 }$ that we have to handle. But if we write it as $( x + ( 1 + y ^ { 2 } ) ) ^ { 7 }$ , we will be separating the $x$’s and the $y$’s, which is much simpler for our needs.

We have

$$
\begin{array}{r l} (1 + x + y ^ {2}) ^ {7} & = (x + (1 + y ^ {2})) ^ {7} \\ & = x ^ {7} + \binom {7} {1} x ^ {6} (1 + y ^ {2}) + \dots + \binom {7} {5} x ^ {2} (1 + y ^ {2}) ^ {5} + \dots \end{array}
$$

so we need only consider the $x ^ { 2 }$ term; note also that $\textstyle { \binom { 7 } { 5 } } = { \binom { 7 } { 2 } } = { \frac { 7 \times 6 } { 2 } } = 2 1$ . So the $x ^ { 2 }$ term is $2 1 x ^ { 2 } ( 1 + y ^ { 2 } ) ^ { 5 }$

We next want the $y ^ { 4 }$ term of $( 1 + y ^ { 2 } ) ^ { 5 }$ , so we expand this too using the binomial theorem:

$$
(1 + y ^ {2}) ^ {5} = 1 + \binom {5} {1} y ^ {2} + \binom {5} {2} y ^ {4} + \dots
$$

so the $y ^ { 4 }$ term is $\binom { 5 } { 2 } y ^ { 4 } = 1 0 y ^ { 4 }$

Therefore the $x ^ { 2 } y ^ { 4 }$ term is $2 1 x ^ { 2 } \times 1 0 y ^ { 4 } = 2 1 0 x ^ { 2 } y ^ { 4 }$ , and the coefficient is 210; this is option F.
