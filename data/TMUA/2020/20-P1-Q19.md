## 解析
Let us write $\operatorname { f } ( x ) = x ^ { 2 } - 5 2 x - 5 2$ . We first note that $\operatorname { f } ( x )$ is a quadratic, and that $\mathrm { f } ( 0 ) = - 5 2$. We might notice that $\mathrm { f ( 5 2 ) = 5 2 ^ { 2 } - 5 2 ^ { 2 } - 5 2 = - 5 2 }$ , or we could complete the square to find that $\mathrm { f } ( x ) = ( x - 2 6 ) ^ { 2 } - 2 6 ^ { 2 } - 5 2$. , so the line of symmetry is at $x = 2 6$. , again giving $\mathrm { f ( 5 2 ) } = - 5 2$ It follows that $\mathrm { f } ( x ) < 0$ when $0 \leq x \leq 5 2$ (and other values of $x$ just outside this range).

We next check f(53). We have $\mathrm { f ( 5 3 ) = 5 3 ^ { 2 } - 5 2 \times 5 3 - 5 2 = 5 3 ^ { 2 } - 5 2 \times 5 4 }$ . Now $5 2 \times 5 4 =$ $( 5 3 - 1 ) ( 5 3 + 1 ) = 5 3 ^ { 2 } - 1$, so $\mathrm { f } ( 5 3 ) = 5 3 ^ { 2 } - ( 5 3 ^ { 2 } - 1 ) = 1$

Therefore 53 is the smallest integer for which $\operatorname { f } ( x ) > 0$ , and the correct answer is option E.
