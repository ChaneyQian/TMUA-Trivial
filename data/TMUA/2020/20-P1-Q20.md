## 题目
For how many values of $a$ is the equation

$$
(x - a) (x ^ {2} - x + a) = 0
$$

satisfied by exactly two distinct values of $x$ ?

$$
\mathbf {A} \quad 0
$$

$$
\mathbf {B} \quad 1
$$

$$
\mathbf {C} \quad 2
$$

$$
\mathbf {D} \quad 3
$$

$$
\mathbf {E} \quad 4
$$

$$
\mathbf {F} \quad \text{more than 4}
$$

## 答案
C

## 解析
The equation has solutions $x = a$ and $\textstyle x = { \frac { 1 \pm { \sqrt { 1 - 4 a } } } { 2 } }$

One case in which there are two distinct values is when $1 - 4 a = 0$ and $a \neq { \frac { 1 } { 2 } }$ , which occurs when $\textstyle a = { \frac { 1 } { 4 } }$

The other case in which there are two distinct values is when a is one of the solutions of the quadratic $x ^ { 2 } - x + a = 0$ . We could find this by equating $a = { \frac { 1 \pm { \sqrt { 1 - 4 a } } } { 2 } }$ , but a much simpler approach is to substitute $x = a$ into the quadratic, giving $a ^ { 2 } - a + \bar { a } = 0$ , hence $a ^ { 2 } = 0 ~ \mathrm { g i v i n g }$ $a = 0$

Therefore there are two such values, $a = 0$ and $\textstyle a = { \frac { 1 } { 4 } }$ , which is option C.
