## 题目
A student is asked to prove whether the following statement (\*) is true or false:

(\*) For all real numbers $a$ and $b$ , $|a + b| < |a| + |b|$

The student's proof is as follows:

Statement (\*) is false. A counterexample is a = 3, b = 4, as $|3 + 4| = 7$ and $|3| + |4| = 7$ , but 7 < 7 is false.

Which of the following best describes the student's proof?

$$
\mathbf {A} \quad \text{The statement } (*) \text{ is true, and the student's proof is not correct.}
$$

$$
\mathbf {B} \quad \text{The statement } (*) \text{ is false, but the student's proof is not correct: the counterexample is not valid.}
$$

$$
\mathbf {C} \quad \text{The statement } (*) \text{ is false, but the student's proof is not correct: the student needs to give all the values of } a \text{ and } b \text{ where } |a + b| < |a| + |b| \text{ is false.}
$$

$$
\mathbf {D} \quad \text{The statement } (*) \text{ is false, but the student's proof is not correct: the student should have instead stated that for all real numbers } a \text{ and } b \text{, } |a + b| \leq |a| + |b| .
$$

$$
\mathbf {E} \quad \text{The statement } (*) \text{ is false, and the student's proof is fully correct.}
$$

## 答案
E

## 解析
To prove that a ‘for all’ statement is true, it is necessary to show that the formula holds for every choice of the variables. On the other hand, to show that it is false, it is sufficient to just find a single counterexample, because that shows that it is not true for all choices of the variables.

This student has provided a correct counterexample (and it is easy to check that their arithmetic is correct). Therefore the student has correctly shown that (∗) is false, and the correct option is E.

One can also observe that ‘for all real numbers $a$ and $b$, $|a + b| \leq |a| + |b|$’ is a true statement, but noting that is different from showing that (∗) is false.
