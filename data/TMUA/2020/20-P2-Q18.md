## 题目
In this question, $f(x) = ax^{3} + bx^{2} + cx + d$ and $g(x) = px^{3} + qx^{2} + rx + s$ are cubic polynomials.

If $f(x) - g(x) > 0$ for every real $x$ , which of the following is/are necessarily true?

$$
\begin{array}{ll}
\text{I} & a > p \\
\text{II} & \text{If } b = q \text{ then } c = r \\
\text{III} & d > s
\end{array}
$$

\mathbf {A} \quad \text{none of them}

$$

## 解析
Let us write $\operatorname { f } ( x ) - \operatorname { g } ( x )$ explicitly:

$$
\mathrm{f} (x) - \mathrm{g} (x) = (a x ^ {3} + b x ^ {2} + c x + d) - (p x ^ {3} + q x ^ {2} + r x + s) = (a - p) x ^ {3} + (b - q) x ^ {2} + (c - r) x + (d - s).
$$

We are given that this cubic is positive for every real x. But a cubic always crosses the x-axis! The only way to reconcile this is if the cubic $\operatorname { f } ( x ) - \operatorname { g } ( x )$ is not actually a cubic, because $a - p = 0$ So we have $a - p = 0$ and statement I is false. We can also now write

$$
\mathrm{f} (x) - \mathrm{g} (x) = (b - q) x ^ {2} + (c - r) x + (d - s).
$$

If this function is always positive, then there are two possibilities: either $b - q$ is nonzero and the quadratic has a negative discriminant, or $b - q = 0$ and this is not actually a quadratic. The second option looks quite like statement II: if $b - q = 0$ , that is, $b = q$ , then we have

$$
\mathrm{f} (x) - \mathrm{g} (x) = (c - r) x + (d - s).
$$

Since a linear function always crosses the x-axis, this cannot be always positive unless $c - r = 0$, in which case the function is actually just the constant $\mathrm{f}(x) - \mathrm{g}(x) = (d - s)$. (To be more precise, this is still a linear function, just with zero x coefficient.) Therefore, if $\mathrm{f}(x) - \mathrm{g}(x) > 0$ for all real $x$, it follows that if $b = q$, then $c = r$, and so statement II is true.

We have reached the end of this line of reasoning. But $d$ and $s$ are the constant coefficients in the polynomials f and $\mathrm{g}$, so if we take $x = 0$, we have $\operatorname{f}(0) = d$ and $\mathrm{g}(0) = s$. Since $\mathrm{f}(0) - \mathrm{g}(0) > 0$, this shows that $d - s > 0$, or $d > s$, hence statement III is true.

The correct option is G.
