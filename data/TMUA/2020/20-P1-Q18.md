## 题目
Find the number of solutions and the sum of the solutions of the equation

$$
1 - 2 \cos^ {2} x = | \cos x |
$$

where $0 \leq x \leq 180^{\circ}$

$$
\mathbf {A} \quad \text{Number of solutions } = 2\text{, Sum of solutions } = 180^{\circ}
$$

$$
\mathbf {B} \quad \text{Number of solutions } = 2\text{, Sum of solutions } = 240^{\circ}
$$

$$
\mathbf {C} \quad \text{Number of solutions } = 3\text{, Sum of solutions } = 180^{\circ}
$$

$$
\mathbf {D} \quad \text{Number of solutions } = 3\text{, Sum of solutions } = 360^{\circ}
$$

$$
\mathbf {E} \quad \text{Number of solutions } = 4\text{, Sum of solutions } = 240^{\circ}
$$

$$
\mathbf {F} \quad \text{Number of solutions } = 4\text{, Sum of solutions } = 360^{\circ}
$$

## 解析
## Approach 1: graph sketching

One way to start this question is to sketch the two graphs $y = 1 - 2 \cos ^ { 2 } x$ and $y = \left| \cos x \right|$ . It may not be obvious how to sketch the first of these graphs (unless you happen to know about double-angle formulae), but we can sketch something adequate for this question.

We can sketch the graph of $y = \cos x $ , then use that to sketch both $y = \left| \cos x \right|$ and $y = \cos ^ { 2 } x$ 8 and then the latter one can be used to sketch $y = 1 - 2 \cos ^ { 2 } x$ . Squaring cos x gives a graph which is never negative, and is zero when cos $x = 0$ . So the graphs look like this:

Imagining overlaying the graphs of $y = \left| \cos x \right|$ and $y = 1 - 2 \cos ^ { 2 } x .$ , we see that there are two points of intersection symmetrically placed around $9 0 ^ { \circ }$ , so their sum is $1 8 0 ^ { \circ }$ , which is option A.

Approach 2: using algebra

We solve the two equations $1 - 2 \cos ^ { 2 } x = \cos x$ when cos $x \geq 0$ and $1 - 2 \cos ^ { 2 } x = - \cos x$ when cos $x < 0$

First, $1 - 2 \cos ^ { 2 } x = \cos x$ when cos $x \ge 0$ gives $2 \cos ^ { 2 } x + \cos x - 1 = 0$ , which factorises as $( 2 \cos x - 1 ) ( \cos x + 1 ) = 0$ . This has solutions cos $\begin{array} { r } { x = { \frac { 1 } { 2 } } } \end{array}$ and $\cos x = - 1$ . We must reject the second solution as we require cos $x \ge 0$ , so we have the solution $x = 6 0 ^ { \circ }$ (in the range $0 ^ { \circ } \leq x \leq 1 8 0 ^ { \circ } )$

Next, $1 - 2 \cos ^ { 2 } x = - \cos x$ when cos x $: < 0$ gives $2 \cos ^ { 2 } x - \cos x - 1 = 0$ , which factorises as (2 cos $x + 1 ) ( \cos x - 1 ) = 0$ . This has solutions cos $x = - { \frac { 1 } { 2 } }$ and cos $x = 1$ , of which only the first is valid. This gives the solution $x = 1 2 0 ^ { \circ }$

Therefore there are two solutions and their sum is $6 0 ^ { \circ } + 1 2 0 ^ { \circ } = 1 8 0 ^ { \circ }$
