## 题目
The quadratic expression $x^{2} - 14x + 9$ factorises as $(x - \alpha)(x - \beta)$ , where $\alpha$ and $\beta$ are positive real numbers.

Which quadratic expression can be factorised as $(x - \sqrt{\alpha})(x - \sqrt{\beta})$ ?

$$
\mathbf {A} \quad x^{2} - \sqrt{10} x + 3
$$

$$
\mathbf {B} \quad x^{2} - \sqrt{14} x + 3
$$

$$
\mathbf {C} \quad x^{2} - \sqrt{20} x + 3
$$

$$
\mathbf {D} \quad x^{2} - 178x + 81
$$

$$
\mathbf {E} \quad x^{2} - 176x + 81
$$

$$
\mathbf {F} \quad x^{2} + 196x + 81
$$

## 解析
As $x ^ { 2 } - 1 4 x + 9 = ( x - \alpha ) ( x - \beta )$ , the roots of the quadratic $x ^ { 2 } - 1 4 x + 9 = 0$ are $\alpha$ and $\beta .$ Approach 1: calculate $\alpha$ and $\beta$

The most obvious approach to answering this question is to calculate $\alpha$ and $\beta$ directly using the quadratic formula:

$$
\alpha , \beta = \frac {1 4 \pm \sqrt {1 4 ^ {2} - 4 \times 1 \times 9}}{2} = \frac {1 4 \pm 2 \sqrt {7 ^ {2} - 9}}{2} = 7 \pm \sqrt {7 ^ {2} - 9} = 7 \pm \sqrt {4 0} = 7 \pm 2 \sqrt {1 0}
$$

But now we need to find the square root of these expressions. We can guess that it has the form $p + q { \sqrt { 1 0 } }$ for some integers $p$ and $q .$ . Squaring this gives

$$
\left(p + q \sqrt {1 0}\right) ^ {2} = \left(p ^ {2} + 1 0 q ^ {2}\right) + 2 p q \sqrt {1 0}
$$

We cannot make $p ^ { 2 } + 1 0 q ^ { 2 } = 7 ,$ but if we take $p = 2$ and $q = \pm 1$ , we get $1 4 \pm 4 { \sqrt { 1 0 } }$ , which is $2\alpha$ or $2 \beta$ . So if we divide by $\sqrt { 2 }$ , taking $p = { \sqrt { 2 } }$ and $q = \pm \frac { 1 } { \sqrt { 2 } }$ , we will obtain $\pm\alpha$ and $\pm \beta$ Therefore

$$
\sqrt {\alpha}, \sqrt {\beta} = \pm (\sqrt {2} \pm \sqrt {5}).
$$

However, we must take the positive values for $\alpha$ and $\beta ,$ so we must have

$$
\sqrt {\alpha}, \sqrt {\beta} = \sqrt {5} \pm \sqrt {2}).
$$

Therefore

$$
{ \begin{array}{r l} & {\left(x - \sqrt {\alpha}\right) \left(x - \sqrt {\beta}\right) = x ^ {2} - \left(\sqrt {\alpha} + \sqrt {\beta}\right) + \sqrt {\alpha} \sqrt {\beta}} \\ & {\qquad = x ^ {2} - \left(\left(\sqrt {5} + \sqrt {2}\right) + \left(\sqrt {5} - \sqrt {2}\right)\right) x + \left(\sqrt {5} + \sqrt {2}\right) \left(\sqrt {5} - \sqrt {2}\right)} \\ & {\qquad = x ^ {2} - 2 \sqrt {5} x + 3} \\ & {\qquad = x ^ {2} - \sqrt {2 0} x + 3} \end{array} }
$$

which is option C.

Approach 2: use properties of $\alpha$ and $\beta$

An alternative way of approaching this question is as follows.

If we expand the two quadratics of interest, we have

$$
\begin{array}{c} (x - \alpha) (x - \beta) = x ^ {2} - (\alpha + \beta) x + \alpha \beta = x ^ {2} - 1 4 x + 9 \\ (x - \sqrt {\alpha}) (x - \sqrt {\beta}) = x ^ {2} - (\sqrt {\alpha} + \sqrt {\beta}) x + \sqrt {\alpha} \sqrt {\beta} \end{array}
$$

Thus $\alpha + \beta = 1$ 4 and $\alpha \beta = 9 .$ , and we need to determine ${ \sqrt { \alpha } } + { \sqrt { \beta } }$ and $\sqrt { \alpha } \sqrt { \beta }$ . We can take the square root of $\alpha \beta = 9$ to obtain ${ \sqrt { \alpha } } { \sqrt { \beta } } = 3$

Next,

$$
\left(\sqrt {\alpha} + \sqrt {\beta}\right) ^ {2} = \alpha + \beta + 2 \sqrt {\alpha} \sqrt {\beta} = 1 4 + 2 \times 3 = 2 0
$$

using the values we have determined already, and so ${ \sqrt { \alpha } } + { \sqrt { \beta } } = { \sqrt { 2 0 } }$ . Therefore the correct answer is option $\mathrm { C } ,$ as before.
