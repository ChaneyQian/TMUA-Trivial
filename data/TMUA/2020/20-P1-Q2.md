## 题目
$(2x + 1)$ and $(x - 2)$ are factors of $2x^3 + px^2 + q$

What is the value of $2p + q$ ?

$$
\mathbf {A} \quad -10
$$

$$
\mathbf {B} \quad -\frac{38}{5}
$$

$$
\mathbf {C} \quad -\frac{22}{3}
$$

$$
\mathbf {D} \quad \frac{22}{3}
$$

$$
\mathbf {E} \quad \frac{38}{5}
$$

$$
\mathbf {F} \quad 10
$$

## 答案
C

## 解析
We can use the factor theorem here. If we write $\operatorname { f } ( x ) = 2 x ^ { 3 } + p x ^ { 2 } + q$ , then the question tells us that $\mathrm { f } ( - \frac { 1 } { 2 } ) = 0$ and $\mathbf { f } ( 2 ) = 0$ . Substituting these in gives

$$
- \frac {1}{4} + \frac {1}{4} p + q = 0
$$

$$
1 6 + 4 p + q = 0
$$

We can subtract the first equation from the second to cancel the $q \mathrm { s } ,$ , giving

$$
\frac {6 5}{4} + \frac {1 5}{4} p = 0
$$

so $\textstyle p = - { \frac { 6 5 } { 1 5 } } = - { \frac { 1 3 } { 3 } }$ . Therefore $\begin{array} { r } { q = - 1 6 - 4 p = - \frac { 4 8 } { 3 } + \frac { 5 2 } { 3 } = \frac { 4 } { 3 } } \end{array}$

It follows that $\textstyle 2 p + q = - { \frac { 2 6 } { 3 } } + { \frac { 4 } { 3 } } = - { \frac { 2 2 } { 3 } }$ , which is option C.
