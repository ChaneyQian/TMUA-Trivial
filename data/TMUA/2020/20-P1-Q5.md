## 题目
The curve $S$ has equation

$$
y = p x ^ {2} + 6 x - q
$$

where $p$ and $q$ are constants.

$S$ has a line of symmetry at $x = -\frac{1}{4}$ and touches the $x$-axis at exactly one point.

What is the value of $p + 8q$?

$$
\mathbf {A} \quad 6
$$

$$
\mathbf {B} \quad 18
$$

$$
\mathbf {C} \quad 21
$$

$$
\mathbf {D} \quad 25
$$

$$
\mathbf {E} \quad 38
$$

## 答案
A

## 解析
The line of symmetry can be determined by completing the square of the right hand side of the given equation for S:

$$
\begin{array}{r l} p x ^ {2} + 6 x - q & = p (x ^ {2} + \frac {6}{p} x) - q \\ & = p \Big ((x + \frac {3}{p}) ^ {2} - \frac {9}{p ^ {2}} \Big) - q \\ & = p \big (x + \frac {3}{p} \big) ^ {2} - \frac {9}{p} - q \end{array}
$$

so the line of symmetry is at $\textstyle x = - { \frac { 3 } { p } }$ . Therefore − $- { \frac { 3 } { p } } = - { \frac { 1 } { 4 } }$ , giving $p = 1 2$

The curve touches the x-axis at exactly one point, so we must also have $- { \frac { 9 } { p } } - q = 0$ , giving $\begin{array} { r } { q = - \frac { 9 } { p } = - \frac { 9 } { 1 2 } = - \frac { 3 } { 4 } } \end{array}$

Therefore $p + 8 q = 1 2 - 6 = 6$ , which is option A.
