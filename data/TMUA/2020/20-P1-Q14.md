## 题目
The area enclosed between the line $y = mx$ and the curve $y = x^3$ is 6.

What is the value of $m$ ?

## 解析
We make a quick sketch of $y = m x$ and $y = x ^ { 3 }$ so that we can identify the area enclosed. Note that if $m \leq 0$ , then there is no area enclosed, so we must have $m > 0$

![[Image/20-P1-Q14-sol1.jpg]]

The first thing we note is that there are two regions we need to consider: one with $x > 0$ and one with $x < 0$ . By symmetry, their areas are equal, so it sufices to find m such that the area of the region with $x > 0$ is 3.

To find the area enclosed for $x > 0 .$ , we need to find where the line and cubic intersect; this is when $x ^ { 3 } = m x .$ , so at $x = 0$ and $x = \pm { \sqrt { m } }$ . As we are interested in the point where $x > 0$ , this is at $s = { \sqrt { m } }$

The enclosed area can be calculated as the area below the line minus the area below the cubic. So as a single integral, this gives

$$
\begin{array}{r} \int_ {0} ^ {\sqrt {m}} m x - x ^ {3} \mathrm{d} x = \left[ \frac {1}{2} m x ^ {2} - \frac {1}{4} x ^ {4} \right] _ {0} ^ {\sqrt {m}} \\ = \frac {1}{2} m ^ {2} - \frac {1}{4} m ^ {2} \\ = \frac {1}{4} m ^ {2} \end{array}
$$

(We could also have calculated the area under the line as the area of a triangle.)

Since this area is 3, we have ${ \textstyle { \frac { 1 } { 4 } } } m ^ { 2 } = 3 .$ , so $m ^ { 2 } = 1 2$ and $m = { \sqrt { 1 2 } } = 2 { \sqrt { 3 } }$ . This is option E.
