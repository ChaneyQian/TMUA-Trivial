## 题目
Find the complete set of values of $x$ for which

$$
(x + 4) (x + 3) (1 - x) > 0 \quad \text { and } \quad (x + 2) (x - 2) <   0
$$

$$
\mathbf {A} \quad 1 <   x <   2
$$

$$
\mathbf {B} \quad - 2 <   x <   1
$$

$$
\mathbf {C} \quad - 2 <   x <   2
$$

$$
\mathbf {D} \quad x <   -2 \ \text{ or } \ x > 1
$$

$$
\mathbf {E} \quad x <   -4 \ \text{ or } \ x > 2
$$

$$
\mathbf {F} \quad x <   -4 \ \text{ or } \ -3 <   x <   1
$$

$$
\mathbf {G} \quad -4 <   x <   -2 \ \text{ or } \ x > 1
$$

## 解析
We first work on each inequality separately. Each one is a product of factors, so we consider when each factor is positive or negative.

For the first inequality, $( x + 4 ) ( x + 3 ) ( 1 - x ) > 0$ , we have the following table:

<table><tr><td></td><td> $(x + 4)$ </td><td> $(x + 3)$ </td><td> $(1 - x)$ </td><td>product</td></tr><tr><td> $x < -4$ </td><td>-</td><td>-</td><td>+</td><td>+</td></tr><tr><td> $-4 < x < -3$ </td><td>+</td><td>-</td><td>+</td><td>-</td></tr><tr><td> $-3 < x < 1$ </td><td>+</td><td>+</td><td>+</td><td>+</td></tr><tr><td> $x > 1$ </td><td>+</td><td>+</td><td>-</td><td>-</td></tr></table>

Thus the first inequality holds when $x < - 4$ and when − $\cdot 3 < x < 1$

Likewise for the second inequality, $( x + 2 ) ( x - 2 ) < 0 :$

<table><tr><td></td><td> $(x + 2)$ </td><td> $(x - 2)$ </td><td>product</td></tr><tr><td> $x < -2$ </td><td>-</td><td>-</td><td>+</td></tr><tr><td> $-2 < x < 2$ </td><td>+</td><td>-</td><td>-</td></tr><tr><td> $x > 2$ </td><td>+</td><td>+</td><td>+</td></tr></table>

Therefore the second inequality holds when $- 2 < x < 2$

Combining these two conditions, they both hold when $- 2 < x < 1$ , which is option B.
