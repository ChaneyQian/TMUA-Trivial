## 题目
The circle $C_1$ has equation $(x + 2)^2 + (y - 1)^2 = 3$

The circle $C_2$ has equation $(x - 4)^2 + (y - 1)^2 = 3$

The straight line $l$ is a tangent to both $C_1$ and $C_2$ and has positive gradient.

The acute angle between l and the x-axis is $\theta$

Find the value of $\tan \theta$

$$
\mathbf {A} \quad \frac{1}{2}
$$

$$
\mathbf {B} \quad 2
$$

$$
\mathbf {C} \quad \frac{\sqrt{2}}{2}
$$

$$
\mathbf {D} \quad \sqrt{2}
$$

$$
\mathbf {E} \quad \frac{\sqrt{6}}{2}
$$

$$
\mathbf {F} \quad \frac{\sqrt{6}}{3}
$$

$$
\mathbf {G} \quad \frac{\sqrt{3}}{3}
$$

$$
\mathbf {H} \quad \sqrt{3}
$$

## 解析
It is helpful to sketch the situation before going any further. The circle $C _ { 1 }$ has centre (−2, 1) and radius ${ \sqrt { 3 } } .$ , while circle $C _ { 2 }$ has centre (4, 1) and radius $\sqrt { 3 }$ . A quick sketch shows the configuration:

![[Image/20-P1-Q16-sol1.jpg]]

There are four straight lines which are tangent to both of these circles: two of these are horizontal, and the other two are not. We want the one with a positive gradient, so we sketch it on the graph along with the radii which meet it.

![[Image/20-P1-Q16-sol2.jpg]]

By joining the two circle centres, we see that the angle the line l makes with the x-axis, which is $\theta ,$ is the same as the angle marked on this diagram. We have also labelled some of the points so that we can refer to them later.

Since the radius at D meets the tangent l at right angles, we can work out the side lengths of the triangle $O _ { 2 } D E$ and hence $\tan\theta$. The distance between the circle centres is $4 - ( - 2 ) = 6$ so the hypotenuse $E O _ { 2 }$ has length 3. The circle $C _ { 2 }$ has radius $O _ { 2 } D = { \sqrt { 3 } } ,$ , so by Pythagoras’s Theorem, $D E ^ { 2 } = ( E O _ { 2 } ) ^ { 2 } - ( D O _ { 2 } ) ^ { 2 } = 9 - 3 = 6$ . Thus $D E = { \sqrt { 6 } }$ and hence

$$
\tan \theta = \frac {\sqrt {3}}{\sqrt {6}} = \frac {1}{\sqrt {2}} = \frac {\sqrt {2}}{2}
$$

and the correct answer is option C.
