## 题目
The function $\mathrm{f}$ is defined for all real $x$ as

$$
\mathrm{f} (x) = (p - x) (x + 2)
$$

Find the complete set of values of $p$ for which the maximum value of $\mathrm{f}(x)$ is less than 4.

$$
\mathbf {A} \quad - 2 - 4 \sqrt {2} <   p <   - 2 + 4 \sqrt {2}
$$

$$
\mathbf {B} \quad - 2 - 2 \sqrt {2} <   p <   - 2 + 2 \sqrt {2}
$$

$$
\mathbf {C} \quad - 2 \sqrt {5} <   p <   2 \sqrt {5}
$$

$$
\mathbf {D} \quad - 6 <   p <   2
$$

$$
\mathbf {E} \quad - 4 <   p <   0
$$

$$
\mathbf {F} \quad - 2 <   p <   2
$$

D

## 解析
We can find the maximum value of $\operatorname { f } ( x )$ by completing the square or by differentiating.

In both methods, we start by expanding the brackets to write $\operatorname { f } ( x ) = - x ^ { 2 } + ( p - 2 ) x + 2 p$.

We can then complete the square:

$$
{ \begin{array}{r l} & {\operatorname{f} (x) = - (x ^ {2} - (p - 2) x) + 2 p} \\ & {\qquad = - \big ((x - \frac {1}{2} (p - 2)) ^ {2} - \frac {1}{4} (p - 2) ^ {2} \big) + 2 p} \\ & {\qquad = - (x - \frac {1}{2} (p - 2)) ^ {2} + \frac {1}{4} (p - 2) ^ {2} + 2 p} \end{array} }
$$

so the maximum value occurs when $\begin{array} { r } { x = \frac { 1 } { 2 } ( p - 2 ) } \end{array}$ and the value at this point is ${ \scriptstyle { \frac { 1 } { 4 } } } ( p - 2 ) ^ { 2 } + 2 p$ Alternatively, we can differentiate to get

$$
\mathrm{f} ^ {\prime} (x) = - 2 x + (p - 2)
$$

so the stationary point is at $x = { \textstyle { \frac { 1 } { 2 } } } ( p - 2 )$ ; substituting this value into the function $\operatorname { f } ( x )$ gives the same maximum value as before.

A third approach is to note that the stationary point of a quadratic lies midway between its two roots, that is midway between p and −2, so at $x = { \textstyle { \frac { 1 } { 2 } } } ( p - 2 )$ , and then substitute to find the minimum value.

We now require

$$
\frac {1}{4} (p - 2) ^ {2} + 2 p <   4.
$$

Multiplying by 4 and rearranging gives $( p - 2 ) ^ { 2 } + 8 p - 1 6 < 0$; we next expand the brackets and simplify to give $p ^ { 2 } + 4 p - 1 2 < 0$, so $( p + 6 ) ( p - 2 ) < 0$ . This quadratic inequality is satisfied exactly when $- 6 < p < 2$ , which is option D.
