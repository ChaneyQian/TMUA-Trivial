## 题目
$$
\mathrm{f} (x) = x ^ {\frac {1}{7}} \left(x ^ {2} - x + 1\right)
$$

Find the fraction of the interval $0 < x < 1$ for which $\mathrm{f}(x)$ is decreasing.

$$
\mathbf {A} \quad \frac{2}{15}
$$

$$
\mathbf {B} \quad \frac{1}{5}
$$

$$
\mathbf {C} \quad \frac{1}{3}
$$

$$
\mathbf {D} \quad \frac{1}{2}
$$

$$
\mathbf {E} \quad \frac{2}{3}
$$

$$
\mathbf {F} \quad \frac{4}{5}
$$

$$
\mathbf {G} \quad \frac{13}{15}
$$

## 答案
A

## 解析
The function is decreasing when $\mathrm { f ^ { \prime } } ( x ) < 0$ (and possibly also at points where $\mathrm { f } ^ { \prime } ( x ) = 0 )$ . We have

$$
\mathrm{f} (x) = x ^ {1 5 / 7} - x ^ {8 / 7} + x ^ {1 / 7}
$$

so

$$
\begin{array}{c} \mathrm{f} ^ {\prime} (x) = \frac {1 5}{7} x ^ {8 / 7} - \frac {8}{7} x ^ {1 / 7} + \frac {1}{7} x ^ {- 6 / 7} \\ = \frac {1}{7} x ^ {- 6 / 7} (1 5 x ^ {2} - 8 x + 1) \\ = \frac {1}{7} x ^ {- 6 / 7} (5 x - 1) (3 x - 1) \end{array}
$$

This is negative when $( 5 x - 1 ) ( 3 x - 1 ) < 0$ (note that we are only considering the region x $> 0$ here).

We note that $( 5 x - 1 ) ( 3 x - 1 ) = 0$ exactly when $\begin{array} { r } { x = \frac { 1 } { 5 } \mathrm{~or~} x = \frac { 1 } { 3 } } \end{array}$ and is therefore negative when $\textstyle { \frac { 1 } { 5 } } < x < { \frac { 1 } { 3 } }$ . Therefore the function f(x) is decreasing when $\textstyle { \frac { 1 } { 5 } } < x < { \frac { 1 } { 3 } }$ (and possibly also at the endpoints of this interval).

Thus the fraction of the interval $0 < x < 1$ for which f(x) is decreasing is $\textstyle { \frac { 1 } { 3 } } - { \frac { 1 } { 5 } } = { \frac { 2 } { 1 5 } }$ , which is option A.
