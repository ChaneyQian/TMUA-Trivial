## 题目
Consider the following functions defined for $x > 1$ :

$$
\mathrm{f} (x) = \log_ {2} \left(\log_ {2} \sqrt {x}\right)
$$

$$
\mathrm{g} (x) = \log_ {2} \left(\sqrt {\log_ {2} x}\right)
$$

Which one of the following is true for all values of $x > 1$?

$$
\mathbf {A} \quad 0 \leq \mathrm{f} (x) \leq \mathrm{g} (x) \text {or} \mathrm{g} (x) \leq \mathrm{f} (x) \leq 0
$$

$$
\mathbf {B} \quad 0 \leq \mathrm{g} (x) \leq \mathrm{f} (x) \text {or} \mathrm{f} (x) \leq \mathrm{g} (x) \leq 0
$$

$$
\mathbf {C} \frac {1}{2} \leq \mathrm{f} (x) \leq \mathrm{g} (x) \mathbf {o r} \mathrm{g} (x) \leq \mathrm{f} (x) \leq \frac {1}{2}
$$

$$
\mathbf {D} \frac {1}{2} \leq \mathrm{g} (x) \leq \mathrm{f} (x) \text {or} \mathrm{f} (x) \leq \mathrm{g} (x) \leq \frac {1}{2}
$$

$$
\mathbf {E} \quad 1 \leq \mathrm{f} (x) \leq \mathrm{g} (x) \text {or} \mathrm{g} (x) \leq \mathrm{f} (x) \leq 1
$$

$$
\mathbf {F} \quad 1 \leq \mathrm{g} (x) \leq \mathrm{f} (x) \text {or} \mathrm{f} (x) \leq \mathrm{g} (x) \leq 1
$$

## 答案
F

## 解析
The expressions for $\operatorname { f } ( x )$ and $\mathrm { g } ( x )$ look quite complicated, so we start by simplifying them using the laws of logarithms:

$$
{ \begin{array}{r l} & {\operatorname{f} (x) = \log_ {2} \left(\log_ {2} {\sqrt {x}}\right)} \\ & {\qquad = \log_ {2} ({\frac {1}{2}} \log_ {2} x)} \\ & {\qquad = - 1 + \log_ {2} (\log_ {2} x)} \\ & {\operatorname{g} (x) = \log_ {2} \left({\sqrt {\log_ {2} x}}\right)} \\ & {\qquad = {\frac {1}{2}} \log_ {2} (\log_ {2} x)} \end{array} }
$$

We now see that both $\operatorname { f } ( x )$ and $\mathrm { g } ( x )$ can be written as a function of $\log _ { 2 } ( \log _ { 2 } x )$ . As $x > 1$ $\log _ { 2 } x > 0$ and $\log _ { 2 } ( \log _ { 2 } x )$ can take any real value.

Let us write $z = \log _ { 2 } ( \log _ { 2 } x )$ , so that we have $\operatorname { f } ( x ) = z - 1$ and $\mathrm { g } ( x ) = { \textstyle { \frac { 1 } { 2 } } } z$ . We can sketch a graph showing these two functions of z:

![[Image/21-P2-Q17-sol1.jpg]]

We can calculate the intersection of $y = z - 1$ and $\begin{array} { r } { y = \frac { 1 } { 2 } z } \end{array}$ , obtaining $z = 2 , y = 1$

We can then see from the graph that $\operatorname { f } ( x ) \geq \operatorname { g } ( x )$ when both are at least 1, and $\operatorname { f } ( x ) \leq \operatorname { g } ( x )$ when both are at most 1, so either $\operatorname { f } ( x ) \geq \operatorname { g } ( x ) \geq 1$ or $\operatorname { f } ( x ) \leq \operatorname { g } ( x ) \leq 1$ (or both), which is option F. (Note that the ‘or’ in the options is inclusive ‘or’, so we are allowed to have both of the inequalities being true.)
