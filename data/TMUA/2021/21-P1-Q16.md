## 题目
Consider the expansion of

$$
(a + bx)^{n}
$$

The third term, in **ascending** powers of $x$, is $105x^{2}$

The fourth term, in **ascending** powers of $x$, is $210x^{3}$

The fourth term, in **descending** powers of $x$, is $210x^{3}$

Find the value of $\left(\dfrac{a}{b}\right)^{2}$

$$
\mathbf {A} \quad \frac{1}{4}
$$

$$
\mathbf {B} \quad \frac{4}{9}
$$

$$
\mathbf {C} \quad \frac{25}{36}
$$

$$
\mathbf {D} \quad \frac{5}{6}
$$

$$
\mathbf {E} \quad 1
$$
## 备注

## 答案
B

## 解析
We can expand the binomial expression in ascending powers of x using the binomial theorem:

$$
\begin{array}{c} (a + b x) ^ {n} = a ^ {n} + \binom {n} {1} a ^ {n - 1} b x + \binom {n} {2} a ^ {n - 2} b ^ {2} x ^ {2} + \binom {n} {3} a ^ {n - 3} b ^ {3} x ^ {3} + \dots + \\ \binom {n} {n - 1} a b ^ {n - 1} x ^ {n - 1} + b ^ {n} x ^ {n} \end{array}
$$

The third term in ascending powers of x is ${ \binom { n } { \cdot } } a ^ { n - 2 } b ^ { 2 } x ^ { 2 } = 1 0 5 x ^ { 2 }$

The fourth term in ascending powers of x is ${ \binom { n } { 3 } } a ^ { n - 3 } b ^ { 3 } x ^ { 3 } = 2 1 0 x ^ { 3 }$

The fourth term in descending powers of x is ${ \binom { n } { n - 3 } } a ^ { 3 } b ^ { n - 3 } x ^ { n - 3 } = 2 1 0 x ^ { 3 }$

From the last statement, we see that $n = 6$ . Then the first two statements give:

$$
\binom {6} {2} a ^ {4} b ^ {2} = 1 0 5
$$

$$
\binom {6} {3} a ^ {3} b ^ {3} = 2 1 0
$$

Now ${ \binom { 6 } { 2 } } = 1 5$ and ${ \binom { 6 } { 3 } } = 2 0$ , so

$$
a ^ {4} b ^ {2} = 7
$$

$$
a ^ {3} b ^ {3} = \frac {2 1}{2}
$$

Dividing these two equations gives

$$
{\frac {a}{b}} = {\frac {2}{3}}
$$

and so $\begin{array} { r } { \left( { \frac { a } { b } } \right) ^ { 2 } = { \frac { 4 } { 9 } } } \end{array}$ , which is option B.
