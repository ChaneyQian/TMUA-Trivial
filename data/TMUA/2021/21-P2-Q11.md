## 题目
A student attempts to solve the following problem, where $a$ and $b$ are non-zero real numbers:

Show that if $a^2 - 4b^3 \geq 0$ **then** there exist real numbers $x$ and $y$ such that $a = xy(x + y)$ and $b = xy$.

Consider the following attempt:

$$
(x - y)^2 \geq 0 \qquad \text{(I)}
$$

$$
\text{so } x^2 + y^2 - 2xy \geq 0 \qquad \text{(II)}
$$

$$
\text{so } (x + y)^2 - 4xy \geq 0 \qquad \text{(III)}
$$

$$
\text{so } x^2 y^2 (x + y)^2 - 4x^3 y^3 \geq 0 \qquad \text{(IV)}
$$

$$
\text{so } a^2 - 4b^3 \geq 0 \qquad \text{(V)}
$$

Which of the following best describes this attempt?

$$
\mathbf{A} \quad \text{It is completely correct.}
$$

$$
\mathbf{B} \quad \text{It is incorrect, but it would be correct if written in the reverse order.}
$$

$$
\mathbf{C} \quad \text{It is incorrect, but the student has correctly proved the converse.}
$$

$$
\mathbf{D} \quad \text{It is incorrect because there is an error in line (II).}
$$

$$
\mathbf{E} \quad \text{It is incorrect because there is an error in line (III).}
$$

$$
\mathbf{F} \quad \text{It is incorrect because there is an error in line (IV).}
$$

## 答案
C

## 解析
We start by checking that each step works.

Line (II) follows from line (I) by expanding the brackets.

The algebraic expression in line (III) expands as $x ^ { 2 } + 2 x y + y ^ { 2 } - 4 x y$ , so it follows from line (II). Line (IV) follows from line (III) by multiplying by $x ^ { 2 } y ^ { 2 }$ . Since $x ^ { 2 } y ^ { 2 } \geq 0$ , the inequality keeps the same direction, so this is a valid deduction.

However, how does line (V) follow from line (IV)? It assumes that $a = x y ( x + y )$ and $b = x y$ in order to make the deduction.

This argument has therefore shown that ${ i f } \ a = x y ( x + y )$ and $b = x y$ , then $a ^ { 2 } - 4 b ^ { 3 } \geq 0$ , or even more explicitly: if there exist real numbers $x$ and $y$ such that $a = x y ( x + y )$ and $b = x y$, then $a ^ { 2 } - 4 b ^ { 3 } \geq 0$ . However, the problem posed is the converse: ‘show that if $a ^ { 2 } - 4 b ^ { 3 } \geq 0$ , then there exist real numbers $x$ and $y$ such that $a = x y ( x + y )$ and $b = x y$

So this attempt has proved the converse, though the argument would have been slightly better presented if the student had explicitly stated ‘assume that $x$ and $y$ are real numbers with $a = x y ( x + y )$ and $b = x y ^ { \prime }$

The correct option is therefore C.
