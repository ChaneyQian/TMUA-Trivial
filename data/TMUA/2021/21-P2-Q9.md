## 题目
Consider the following statements about a polynomial $\mathrm{f}(x)$:

I $\mathrm{f}(x) = px^3 + qx^2 + rx + s$, where $p \neq 0$.

II There is a real number $t$ for which $\mathrm{f}'(t) = 0$.

III There are real numbers $u$ and $v$ for which $\mathrm{f}(u)\mathrm{f}(v) < 0$.

Which of these statements is/are **sufficient** for the equation $\mathrm{f}(x) = 0$ to have a real solution?

|  | Statement I is sufficient | Statement II is sufficient | Statement III is sufficient |
| --- | --- | --- | --- |
| **A** | Yes | Yes | Yes |
| **B** | Yes | Yes | No |
| **C** | Yes | No | Yes |
| **D** | Yes | No | No |
| **E** | No | Yes | Yes |
| **F** | No | Yes | No |
| **G** | No | No | Yes |
| **H** | No | No | No |

## 答案
C

## 解析
I Every cubic crosses the x-axis, so this condition is sufficient for $\operatorname { f } ( x ) = 0$ to have a real root. This also follows from III below if we take u to be a very large positive number and v to be a very large negative number.

II Consider, for example, $\operatorname { f } ( x ) = x ^ { 2 } + 1$ . This quadratic has $\mathrm { f } ^ { \prime } ( x ) = 2 x$ so $\mathrm { f ^ { \prime } } ( 0 ) = 0$ , but there is no real x for which $x ^ { 2 } + 1 = 0$ . So this condition is not sufficient.

III As $\operatorname { f } ( u ) \operatorname { f } ( v ) < 0$ , we must have $\mathrm { f } ( u ) < 0$ and $\mathrm { f } ( v ) > 0$ or the other way round; either way, the graph of $y = \operatorname { f } ( x )$ has values above and below the x-axis. Since $\operatorname { f } ( x )$ is a polynomial, it must therefore cross the x-axis, and so the equation $\operatorname { f } ( x ) = 0$ has a real root. (If we did not know that $\operatorname { f } ( x )$ was a polynomial, this would not be sufficient; consider $\textstyle \mathrm { f } ( x ) = { \frac { 1 } { x } }$ for example.)

The correct option is therefore C.
