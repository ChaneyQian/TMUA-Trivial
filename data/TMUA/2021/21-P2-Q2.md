## 题目
$A(0,2)$ and $C(4,0)$ are opposite vertices of the square $ABCD$ .

What is the equation of the straight line through B and D?

$$
\mathbf {A} \quad y = -2x + 5
$$

$$
\mathbf {B} \quad y = - \frac {1}{2} x - 3
$$

$$
\mathbf {C} \quad y = - \frac {1}{2} x + 2
$$

$$
\mathbf {D} \quad y = x
$$

$$
\mathbf {E} \quad y = 2 x - 3
$$

$$
\mathbf {F} \quad y = 2 x + 2
$$

### AI备注


## 答案
E

## 解析
We can sketch the situation:

![[Image/21-P2-Q2-sol1.jpg]]

We know that the two diagonals of the square bisect each other at right angles, so this question requires us to find the perpendicular bisector of AC.

The midpoint of AC is $\textstyle \left( { \frac { 0 + 4 } { 2 } } , { \frac { 2 + 0 } { 2 } } \right) = ( 2 , 1 )$ , which is the centre of the square.

The gradient of AC is $\textstyle { \frac { 0 - 2 } { 4 - 0 } } = - { \frac { 1 } { 2 } }$ , so the gradient of BD is 2.

The equation of BD is therefore $y - 1 = 2 ( x - 2 )$ , which rearranges to give $y = 2 x - 3$ , which is option E.
