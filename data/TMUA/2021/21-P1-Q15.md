## 题目
The diagram shows the graph of $y = \mathrm{f}(x)$ .

The graph consists of alternating straight-line segments of gradient 1 and -1 and continues in this way for all values of $x$.

The function $g$ is defined as

$$
\mathrm{g} (x) = \sum_ {r = 1} ^ {1 0} f \left(2 ^ {r - 1} x\right)
$$

Find the value of

$$
\int_ {0} ^ {1} \mathrm{g} (x) \mathrm{d} x
$$

$$
\mathbf {A} \quad \frac{1023}{1024}
$$

$$
\mathbf {B} \quad \frac{1023}{512}
$$

$$
\mathbf {C} \quad 5
$$

$$
\mathbf {D} \quad 10
$$

$$
\mathbf {E} \quad \frac{55}{2}
$$

$$
\mathbf {F} \quad 55
$$

## 解析
We can write the integral out in full by substituting the value of $\mathrm { g } ( x )$ :

$$
\begin{array}{r l} & {\int_ {0} ^ {1} \mathrm{g} (x) \mathrm{d} x = \int_ {0} ^ {1} \sum_ {r = 1} ^ {1 0} \mathrm{f} (2 ^ {r - 1} x) \mathrm{d} x} \\ & {\qquad = \int_ {0} ^ {1} \mathrm{f} (2 ^ {0} x) + \mathrm{f} (2 ^ {1} x) + \mathrm{f} (2 ^ {2} x) + \dots + \mathrm{f} (2 ^ {9} x) \mathrm{d} x} \\ & {\qquad = \int_ {0} ^ {1} \mathrm{f} (2 ^ {0} x) \mathrm{d} x + \int_ {0} ^ {1} \mathrm{f} (2 ^ {1} x) \mathrm{d} x + \int_ {0} ^ {1} \mathrm{f} (2 ^ {2} x) \mathrm{d} x + \dots + \int_ {0} ^ {1} \mathrm{f} (2 ^ {9} x) \mathrm{d} x} \end{array}
$$

So we can calculate the integral of $\mathrm { g } ( x )$ if we can calculate the integral of each $\mathrm { f } ( 2 ^ { r - 1 } x )$

Now $\begin{array} { r } { \int _ { 0 } ^ { 1 } \mathrm { f } ( 2 ^ { 0 } x ) \mathrm { d } x = \int _ { 0 } ^ { 1 } \mathrm { f } ( x ) } \end{array}$ dx is just the area under the graph of $y = \operatorname { f } ( x )$ between $x = 0$ and $x = 1$ , which is $\begin{array} { l } { { \frac { 1 } { 2 } } } \end{array}$ (it is a right angled triangle with base and height both 1).

To work out $\textstyle \int _ { 0 } ^ { 1 } \operatorname { f } ( 2 x ) \mathrm { d } x$. , we consider the graph of $y = \operatorname { f } ( 2 x )$ . This is the graph of $y = \operatorname { f } ( x )$ scaled by a factor of $1 / 2$ in the x-direction, so looks like this:

![[Image/21-P1-Q15-sol1.jpg]]

The area between $x = 0$ and $x = 1$ is again $\textstyle { \frac { 1 } { 2 } }$ .

The graph of $y = \operatorname { f } ( 2 ^ { 2 } x )$ between $x = 0$ and $x = 1$ consists of two triangles:

![[Image/21-P1-Q15-sol2.jpg]]

Helpfully, the area under this graph is still $\scriptstyle { \frac { 1 } { 2 } }$: : this is perhaps easiest to see by noticing that we can draw a rectangle (actually a square) around the graph:

![[Image/21-P1-Q15-sol3.jpg]]

In each rectangular slice, half of the area is below the graph and half is above, so the total area below the graph is $\frac { 1 } { 2 }$ .

This same reasoning will apply for each of the functions $\mathrm { f } ( 2 ^ { r - 1 } x )$ , and so the total area is $1 0 \times { \frac { 1 } { 2 } } = 5$ , which is option C.
