## 题目
Consider the following statement about the polynomial $\mathrm{p}(x)$, where $a$ and $b$ are real numbers with $a < b$:

$$
(*) \qquad \text{There exists a number } c \text{ with } a < c < b \text{ such that } \mathrm{p}'(c) = 0.
$$

Which one of the following is true?

$$
\mathbf{A} \quad \text{The condition } \mathrm{p}(a) = \mathrm{p}(b) \text{ is necessary and sufficient for } (*)
$$

$$
\mathbf{B} \quad \text{The condition } \mathrm{p}(a) = \mathrm{p}(b) \text{ is necessary but not sufficient for } (*)
$$

$$
\mathbf{C} \quad \text{The condition } \mathrm{p}(a) = \mathrm{p}(b) \text{ is sufficient but not necessary for } (*)
$$

$$
\mathbf{D} \quad \text{The condition } \mathrm{p}(a) = \mathrm{p}(b) \text{ is not necessary and not sufficient for } (*)
$$

## 答案
C

## 解析
If $\operatorname { p } ( a ) = \operatorname { p } ( b ) = c .$ , say, then if the graph of $y = \mathrm { p } ( x )$ (strictly) increases as it leaves $( a , c )$ towards $x = b$ , but then it must decrease again to get back to $( b , c )$ , so there must be a stationary point between $x = a$ and $x = b$ . Similarly, if the graph (strictly) decreases as it leaves $( a , c )$ , it must then increase again, which also results in a stationary point. The only other possibility is that the graph of $y = \mathrm { p } ( x )$ is constant, in which case $\mathrm { p } ^ { \prime } ( x ) = 0$ throughout. In all cases, (∗) holds, so $\mathrm { p } ( a ) = \mathrm { p } ( b )$ is sufficient for (∗).

However, it is not necessary for (∗): if $\mathrm { p } ( x ) = x ^ { 2 }$ and a = −1, b = 2, then this satisfies (∗) (with $c = 0 )$ but $\mathrm { p } ( a ) \neq \mathrm { p } ( b )$

Thus the correct option is $\mathrm { C }$
