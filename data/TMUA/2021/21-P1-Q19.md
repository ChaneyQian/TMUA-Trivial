## 题目
The equation

$$
\sin^2\left(4^{\cos\theta} \times 60^{\circ}\right) = \frac{3}{4}
$$

has exactly three solutions in the range $0^{\circ} \leq \theta \leq x^{\circ}$.

What is the range of all possible values of $x$?

$$
\mathbf{A} \quad 90 \leq x < 120
$$

$$
\mathbf{B} \quad 90 \leq x < 270
$$

$$
\mathbf{C} \quad 120 \leq x < 240
$$

$$
\mathbf{D} \quad 270 \leq x < 300
$$

$$
\mathbf{E} \quad 300 \leq x < 360
$$

$$
\mathbf{F} \quad 450 \leq x < 630
$$

### AI备注


## 答案
B

## 解析
We can start by solving the equation before considering the possible values of $x .$

We have

$$
\sin \left(4 ^ {\cos \theta} \times 6 0 ^ {\circ}\right) = \pm \frac {\sqrt {3}}{2}
$$

so that

$$
4 ^ {\cos \theta} \times 6 0 ^ {\circ} = 6 0 ^ {\circ}, 1 2 0 ^ {\circ}, 2 4 0 ^ {\circ}, 3 0 0 ^ {\circ}, \dots
$$

(noting that the left hand side is always positive, so we do not need to consider negative values for the right hand side).

Dividing by $6 0 ^ { \circ }$ gives

$$
4 ^ {\cos \theta} = 1, 2, 4, 5, \ldots
$$

and so

$$
\cos \theta = 0, \frac {1}{2} \mathrm{or} 1;
$$

there are no values of $\cos\theta$ for which $4 ^ { \cos \theta } > 4$

We can now find the possible values of \theta:

$\cos\theta = 0$ gives $\theta = 9 0 ^ { \circ } , 2 7 0 ^ { \circ } , 4 5 0 ^ { \circ }$

cos $; \theta = { \textstyle { \frac { 1 } { 2 } } } \operatorname { g i v e s } \theta = 6 0 ^ { \circ } , 3 0 0 ^ { \circ } , 4 2 0 ^ { \circ } , . . .$

$\cos\theta$ = 1 gives $\theta = 0 ^ { \circ } , 3 6 0 ^ { \circ } , \ldots .$

Collecting these solutions and arranging them in increasing order gives $\theta = 0^{\circ}, 60^{\circ}, 90^{\circ}, 270^{\circ}, 300^{\circ}, \ldots$

We are told that there are exactly three solutions in the range $0 ^ { \circ } \leq \theta \leq x ^ { \circ }$ . Therefore $x \geq 9 0$ to get the third solution, and $x < 2 7 0$ to avoid getting the fourth solution. This gives the answer $9 0 \leq x < 2 7 0$ , which is option B.
