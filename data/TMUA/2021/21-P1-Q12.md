## 题目
The minimum value of the function $x^{4}-p^{2}x^{2}$ is $-9$, where $p$ is a real number.

Find the minimum value of the function $x^{2}-px+6$

$$
\mathbf {A} \quad -3
$$

$$
\mathbf {B} \quad 6-\frac{3\sqrt{2}}{2}
$$

$$
\mathbf {C} \quad \frac{3}{2}
$$

$$
\mathbf {D} \quad 3
$$

$$
\mathbf {E} \quad \frac{9}{2}
$$

$$
\mathbf {F} \quad 6+\frac{3\sqrt{2}}{2}
$$

## 答案
E

## 解析
We can complete the square with the first function: we have

$$
x ^ {4} - p ^ {2} x ^ {2} = (x ^ {2} - \frac {1}{2} p ^ {2}) ^ {2} - \frac {1}{4} p ^ {4}
$$

This attains its minimum value when the parenthesised expression is 0, that is when $\begin{array} { r } { x = \pm \frac { 1 } { \sqrt { 2 } } p . } \end{array}$ At that point, $x ^ { 4 } - p ^ { 2 } x ^ { 2 } = - { \textstyle \frac { 1 } { 4 } } p ^ { 4 } = - 9$ , so $p ^ { 4 } = 3 6$ . Since $p$ is a real number, we must have $p ^ { 2 } = 6$ (rather than −6).

We now consider $x ^ { 2 } - p x + 6$ . We can again complete the square to get

$$
x ^ {2} - p x + 6 = (x - \frac {1}{2} p) ^ {2} - \frac {1}{4} p ^ {2} + 6.
$$

The minimum of this function again occurs when the parenthesised expression is 0, that is when $\begin{array} { r } { x = \frac { 1 } { 2 } p . } \end{array}$ . At this point,

$$
x ^ {2} - p x + 6 = - \frac {1}{4} p ^ {2} + 6 = - \frac {1}{4} \times 6 + 6 = \frac {9}{2}
$$

and so the answer is option E.

Alternatively, we could have used calculus instead of completing the square to find the minima; the results would be the same.
