## 题目
Which of the following statements about polynomials f and g is/are true?

I If $\mathrm{f}(x) \geq \mathrm{g}(x)$ for all $x \geq 0$ , then $\int_0^x \mathrm{f}(t) \, \mathrm{d}t \geq \int_0^x \mathrm{g}(t) \, \mathrm{d}t$ for all $x \geq 0$ .

II If $\mathrm{f}(x) \geq \mathrm{g}(x)$ for all $x \geq 0$ , then $\mathrm{f}'(x) \geq \mathrm{g}'(x)$ for all $x \geq 0$ .

III If $f'(x) \geq g'(x)$ for all $x \geq 0$ , then $f(x) \geq g(x)$ for all $x \geq 0$ .

$$
\mathbf {A} \quad \text{none of them}
$$

$$
\mathbf {B} \quad \text{I only}
$$

$$
\mathbf {C} \quad \text{II only}
$$

$$
\mathbf {D} \quad \text{III only}
$$

$$
\mathbf {E} \quad \text{I and II only}
$$

$$
\mathbf {F} \quad \text{I and III only}
$$

$$
\mathbf {G} \quad \text{II and III only}
$$

$$
\mathbf {H} \quad \text{I, II and III}
$$

## 答案
B

## 解析
We can think of the integral $\textstyle \int _ { 0 } ^ { x } \mathrm { f } ( t )$ ) dt as being the (signed) area under the graph of $y = \operatorname { f } ( x )$ from 0 to x. Since $\operatorname { f } ( x ) \geq \operatorname { g } ( x )$ for all $x \ge 0$ , the area under the graph of $y = \operatorname { f } ( x )$ will also be greater than that under the graph of $y = \mathrm { g } ( x )$ , so this statement is true.

You might be concerned about values of $x$ for which $\mathrm { g } ( x )$ is negative. We could therefore demonstrate this algebraically as well.

We have

$$
\int_ {0} ^ {x} \mathrm{f} (t) \mathrm{d} t - \int_ {0} ^ {x} \mathrm{g} (t) \mathrm{d} t = \int_ {0} ^ {x} (\mathrm{f} (t) - \mathrm{g} (t)) \mathrm{d} t.
$$

Since $\mathrm { f } ( t ) - \mathrm { g } ( t ) \geq 0$ for all $x \ge 0$ , we are integrating a non-negative function, and so the integral must be non-negative, that is to say, we must have $\begin{array} { r } { \int _ { 0 } ^ { x } \mathrm { f } ( t ) \mathrm { d } t \geq \int _ { 0 } ^ { x } \mathrm { g } ( t ) \mathrm { d } t } \end{array}$

II It is not clear why $\operatorname { f } ( x ) \geq \operatorname { g } ( x )$ should imply that the gradient (derivative) of $\operatorname { f } ( x )$ is greater than that of $\mathrm { g } ( x )$ , and it is relatively straightforward to find a counterexample. Here is one:

![[Image/21-P2-Q12-sol1.jpg]]

In this example, $\operatorname { f } ( x ) \geq \operatorname { g } ( x )$ for all x, but $\mathrm { f ^ { \prime } } ( 0 ) < 0$ while $\mathrm { g } ^ { \prime } ( x ) = 0$ for all $x$.

III This is not necessarily true, as we could add a constant to $\mathrm { g } ( x )$ without changing $\mathrm { g } ^ { \prime } ( x )$ . For example, we could have $\operatorname { f } ^ { \prime } ( x ) = \operatorname { g } ^ { \prime } ( x ) = 1$ for all x, but $\operatorname { f } ( x ) = x$ while $\operatorname { g } ( x ) = x + 1$ , so $\operatorname { f } ( x ) < \operatorname { g } ( x )$ for all x.

The correct option is therefore B.
