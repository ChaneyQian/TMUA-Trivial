## 题目
Consider the following two statements about the polynomial $\mathrm{f}(x)$:

$P$: $\mathrm{f}(x) = 0$ for exactly three real values of $x$

$Q$: $\mathrm{f}'(x) = 0$ for exactly two real values of $x$

Which one of the following is correct?

$$
\mathbf{A} \quad P \text{ is \textbf{necessary} but \textbf{not sufficient} for } Q.
$$

$$
\mathbf{B} \quad P \text{ is \textbf{sufficient} but \textbf{not necessary} for } Q.
$$

$$
\mathbf{C} \quad P \text{ is \textbf{necessary} and \textbf{sufficient} for } Q.
$$

$$
\mathbf{D} \quad P \text{ is \textbf{not necessary} and \textbf{not sufficient} for } Q.
$$

## 答案
D

## 解析
If $\operatorname { f } ( x ) = 0$ has exactly three roots then there must be a stationary point between the first and second root, and another stationary point between the second and third roots, but there may be other stationary points. For example, here is a sketch of a degree 5 polynomial $y = \operatorname { f } ( x )$ which has $\operatorname { f } ( x ) = 0$ for three real values of $x$ but $\mathrm { f ^ { \prime } } ( x ) = 0$ for five real values of $x$:

![[Image/21-P2-Q6-sol1.jpg]]

A second example is $\operatorname { f } ( x ) = x ^ { 4 } - x ^ { 2 }$ . Here, the graph of $y = \operatorname { f } ( x )$ touches the x-axis at $x = 0$ 2 so $\operatorname { f } ( x ) = 0$ has exactly three real roots $x = - 1 , 0$ , and 1, but three stationary points $\textstyle x = \pm { \frac { 1 } { \sqrt { 2 } } }$ and $x = 0 \cdot$

![[Image/21-P2-Q6-sol2.jpg]]

So P is not sufficient for $Q$.

It is also not necessary, for example $f ( x ) = x ^ { 3 } - x + 1$ has exactly two stationary points but only one real root:

![[Image/21-P2-Q6-sol3.jpg]]

So option D is correct.
