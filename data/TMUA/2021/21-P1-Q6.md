## 题目
$$
\mathrm{f} (x) = \frac {\cos x + 3}{7 + 5 \cos x - \sin^ {2} x}
$$

Find the positive difference between the maximum and the minimum values of $\mathrm{f}(x)$ .

$$
\mathbf {A} \quad 0
$$

$$
\mathbf {B} \quad \frac{1}{3}
$$

$$
\mathbf {C} \quad \frac{1}{2}
$$

$$
\mathbf {D} \quad \frac{2}{3}
$$

$$
\mathbf {E} \quad 1
$$

$$
\mathbf {F} \quad 2
$$

## 答案
D

## 解析
This is almost a function in cos x except for the $\sin ^ { 2 }$ x term, so we rewrite this in terms of cos x:

$$
\mathrm{f} (x) = \frac {\cos x + 3}{7 + 5 \cos x - (1 - \cos^ {2} x)} = \frac {\cos x + 3}{6 + 5 \cos x + \cos^ {2} x}
$$

We can then factorise the denominator to give

$$
\mathrm{f} (x) = \frac {\cos x + 3}{(\cos x + 2) (\cos x + 3)}
$$

and the cos $x + 3$ factor cancels. (We should also check that this can never be zero; if it were, the function would be undefined at some points.) Therefore we can write

$$
\mathrm{f} (x) = \frac {1}{\cos x + 2}
$$

The maximum value of this function occurs where cos $x = - 1$ , giving $\operatorname { f } ( x ) = 1$ , and the minimum value occurs where cos $x = + 1$ , giving $\operatorname { f } ( x ) = { \frac { 1 } { 3 } }$ . The difference between the minimum and maximum values is therefore $\textstyle 1 - { \frac { 1 } { 3 } } = { \frac { 2 } { 3 } }$ , which is option D.
