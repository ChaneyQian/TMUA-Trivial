## 题目

\int_ {- 2} ^ {2} \mathrm{f} (x) \mathrm{d} x = 4
$$

$$
\int_ {- 2} ^ {2} | \mathrm{f} (x) | \mathrm{d} x = 8

## 解析
Let us start with the condition $x \mathrm { f } ( x ) > 0$ for all non-zero values of $x .$ When $x > 0$ , this means that $\operatorname { f } ( x ) > 0$ , as we can divide the inequality by x and the direction of the inequality is unchanged. On the other hand, when $x < 0$ , this gives $\mathrm { f } ( x ) < 0$ , since dividing by x now changes the direction of the inequality. In summary:

$$
\begin{array}{l} \mathrm{f(x)>0whenx>0} \\ \mathrm{f(x)=0whenx=0} \\ \mathrm{f(x)< 0whenx< 0} \end{array}
$$

Now let us turn to the integrals. The final question asks about an integral from $- 2$ to $0 ,$ so we would do well to split the two given integrals into the ranges $- 2$ to 0 and 0 to 2:

$$
\begin{array}{c} \int_ {- 2} ^ {2} \mathrm{f} (x) \mathrm{d} x = \int_ {- 2} ^ {0} \mathrm{f} (x) \mathrm{d} x + \int_ {0} ^ {2} \mathrm{f} (x) \mathrm{d} x \\ = 4 \end{array}
$$

$$
\begin{array}{r l} \int_ {- 2} ^ {2} | \mathrm{f} (x) | \mathrm{d} x & = \int_ {- 2} ^ {0} | \mathrm{f} (x) | \mathrm{d} x + \int_ {0} ^ {2} | \mathrm{f} (x) | \mathrm{d} x \\ & = \int_ {- 2} ^ {0} - \mathrm{f} (x) \mathrm{d} x + \int_ {0} ^ {2} \mathrm{f} (x) \mathrm{d} x \\ & = - \int_ {- 2} ^ {0} \mathrm{f} (x) \mathrm{d} x + \int_ {0} ^ {2} \mathrm{f} (x) \mathrm{d} x \\ & = 8 \end{array}
$$

Therefore

$$
\begin{array}{c} {\int_ {- 2} ^ {0} \mathrm{f} (x) \mathrm{d} x + \int_ {0} ^ {2} \mathrm{f} (x) \mathrm{d} x = 4} \\ {- \int_ {- 2} ^ {0} \mathrm{f} (x) \mathrm{d} x + \int_ {0} ^ {2} \mathrm{f} (x) \mathrm{d} x = 8} \end{array}
$$

If we now add these two simultaneous equations together, the $\textstyle \int _ { - 2 } ^ { 0 } \mathrm { f } ( x )$ dx terms cancel and we are left with $\begin{array} { r } { 2 \int _ { 0 } ^ { 2 } \mathrm { f } ( x ) \mathrm { d } x = 1 2 } \end{array}$ , so $\textstyle \int _ { 0 } ^ { 2 } \operatorname { f } ( x ) \operatorname { d } x = 6$ and $\textstyle \int _ { - 2 } ^ { 0 } \mathrm { f } ( x ) \mathrm { d } x = - 2$

The question asks us to evaluate $\textstyle \int _ { - 2 } ^ { 0 } \mathrm { f } ( | x | )$ dx. Thinking about graph transformations, the graph of $y = \operatorname { f } ( x )$ is transformed into the graph of $y = \operatorname { f } ( | x | )$ by removing the left half of the graph (left of the $y \mathrm { - a x i s ) }$ and reflecting the right half of the graph in the $y -$ axis (the line $x = 0 )$ . The integral of this transformed function from −2 to 0 is therefore equal to the integral of the original function from 0 to 2, thus

$$
\int_ {- 2} ^ {0} \mathrm{f} (| x |) \mathrm{d} x = \int_ {0} ^ {2} \mathrm{f} (x) \mathrm{d} x = 6
$$

and the correct option is $\mathrm { G }$
