## 题目
Consider the following simultaneous equations, where $p$ is a real number:

$$
p\,2^x + \log_2 y = 2
$$

$$
2^x + \log_2 y = 1
$$

What is the complete range of $p$ for which these simultaneous equations have a real solution $(x, y)$?

$$
\mathbf{A} \quad p < 1
$$

$$
\mathbf{B} \quad p \neq 1
$$

$$
\mathbf{C} \quad p > 1
$$

$$
\mathbf{D} \quad p < 1 \text{ or } p > 2
$$

$$
\mathbf{E} \quad p \neq 1 \text{ and } p < 2
$$

$$
\mathbf{F} \quad p > 1 \text{ and } p < 2
$$

$$
\mathbf{G} \quad p > 2
$$

$$
\mathbf{H} \quad \text{All real values of } p
$$

## 答案
C

## 解析
Writing $X = 2 ^ { x }$ and $Y = \log _ { 2 } y$ gives the simultaneous equations

$$
p X + Y = 2
$$

$$
X + Y = 1
$$

Subtracting gives $( p - 1 ) X = 1$ , so as long as $p \neq 1$ , we have $\begin{array} { r } { X = \frac { 1 } { p - 1 } } \end{array}$ and so $\textstyle Y = { \frac { p - 2 } { p - 1 } }$

Now the equation $\textstyle \log _ { 2 } y \ = \ { \frac { p - 2 } { p - 1 } }$ gives a real value for y for any value of $p \neq 1$ (specifically $y = 2 ^ { ( p - 2 ) / ( p - 1 ) } )$ , but the equation $\textstyle 2 ^ { x } = { \frac { 1 } { p - 1 } }$ has a solution if and only if $\textstyle { \frac { 1 } { p - 1 } } > 0$ , which is if and only if $p > 1$

Therefore the original simultaneous equations have a real solution $( x , y )$ if and only if $p > 1$ , which is option C.
