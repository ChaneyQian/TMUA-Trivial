## 题目
Use the trapezium rule with 3 strips to estimate

$$
\int_{1/2}^{2} 2\log_{10} x \,\mathrm{d}x
$$

$$
\mathbf{A} \quad \log_{10}\frac{\sqrt{6}}{2}
$$

$$
\mathbf{B} \quad \log_{10}\frac{3}{2}
$$

$$
\mathbf{C} \quad \log_{10}\frac{9}{4}
$$

$$
\mathbf{D} \quad \log_{10} 3
$$

$$
\mathbf{E} \quad \log_{10}\frac{81}{16}
$$

$$
\mathbf{F} \quad \log_{10}\frac{\sqrt{23}}{2}
$$

## 备注

### AI备注


## 答案
B

## 解析
The interval has width $\begin{array} { r } { 2 \mathrm { ~ - ~ } \frac { 1 } { 2 } = \mathrm { ~ } \frac { 3 } { 2 } . } \end{array}$ , so each strip will have width ${ \frac { 1 } { 2 } } .$ The boundaries of the three strips will be at ${ \frac { 1 } { 2 } } , \ 1 , \ { \frac { 3 } { 2 } }$ and 2. The trapezium rule then gives the estimate (writing $\operatorname { f } ( x ) = 2 \log _ { 1 0 } x ) \colon$

$$
\int_ {\frac {1}{2}} ^ {2} \mathrm{f} (x) \mathrm{d} x \approx \frac {1}{2} \times \frac {1}{2} \big (\mathrm{f} (\frac {1}{2}) + 2 \mathrm{f} (1) + 2 \mathrm{f} (\frac {3}{2}) + \mathrm{f} (2) \big)
$$

We can now work out the individual function values:

$$
\mathrm{f} (\frac {1}{2}) = 2 \log_ {1 0} \frac {1}{2} = - 2 \log_ {1 0} 2
$$

$$
\mathrm{f} (1) = 2 \log_ {1 0} 1 = 0
$$

$$
\mathrm{f} (\frac {3}{2}) = 2 \log_ {1 0} \frac {3}{2} = 2 \log_ {1 0} 3 - 2 \log_ {1 0} 2
$$

$$
\mathrm{f(2)} = 2 \log_ {1 0} 2
$$

Therefore we get the approximation

$$
\begin{array}{r l} & {\int_ {\frac {1}{2}} ^ {2} \mathrm{f} (x) \mathrm{d} x \approx \frac {1}{2} \times \frac {1}{2} \bigl (- 2 \log_ {1 0} 2 + 2 \times 0 + 2 (2 \log_ {1 0} 3 - 2 \log_ {1 0} 2) + 2 \log_ {1 0} 2 \bigr)} \\ & {\qquad = \frac {1}{4} (4 \log_ {1 0} 3 - 4 \log_ {1 0} 2)} \\ & {\qquad = \log_ {1 0} 3 - \log_ {1 0} 2} \\ & {\qquad = \log_ {1 0} \frac {3}{2}} \end{array}
$$

which is option B.
