## 题目
A sequence of functions $\mathrm{f}_1, \mathrm{f}_2, \mathrm{f}_3, \ldots$ is defined by

$$
\mathrm{f}_1(x) = |x|
$$

$$
\mathrm{f}_{n+1}(x) = |\mathrm{f}_n(x) + x| \quad \text{for } n \geq 1
$$

Find the value of

$$
\int_{-1}^{1} \mathrm{f}_{99}(x)\,\mathrm{d}x
$$

$$
\mathbf{A} \quad 0
$$

$$
\mathbf{B} \quad 0.5
$$

$$
\mathbf{C} \quad 1
$$

$$
\mathbf{D} \quad 49.5
$$

$$
\mathbf{E} \quad 50
$$

$$
\mathbf{F} \quad 99
$$

$$
\mathbf{G} \quad 99.5
$$

$$
\mathbf{H} \quad 100
$$

## 解析
It is helpful to get a feeling for what this sequence of functions looks like, so we will sketch the first few. We are only interested in the range from −1 to 1 (because that is what the integral asks for). The first function, $\mathrm { f } _ { 1 } ( x ) = | x |$ is standard:

![[Image/21-P2-Q20-sol1.jpg]]

Note that when $x < 0 .$ , this is the graph of $y = - x ,$ and when $x \geq 0$ , this is the graph of $y = x$ We next have $\mathrm { f } _ { 2 } ( x ) = | \mathrm { f } _ { 1 } ( x ) + x |$ . We can calculate this on the two regions $x < 0$ and $x \ge 0$ separately: when $x < 0$ , we get $\mathrm { f } _ { 2 } ( x ) = \left| - x + x \right| = 0$ , and when $x > 0$ , we get $\mathrm { f } _ { 2 } ( x ) = | x + x | = 2 x$ giving this graph:

![[Image/21-P2-Q20-sol2.jpg]]

We can determine $\mathrm { f _ { 3 } } ( x )$ and $\mathrm { f } _ { 4 } ( x )$ in a similar way:

![[Image/21-P2-Q20-sol3.jpg]]

Here, the graphs for $x \geq 0$ are $y = 3 x$ and $y = 4 x$ respectively.

We can see a pattern forming: when n is odd, the graph of $y = \mathrm { f } _ { n } ( x )$ looks like $y = \mathrm { f } _ { 3 } ( x )$ , with $y = - x$ for $x < 0$ and $y = n x$ for $x \geq 0$ , and when n is even, it looks like $y = \mathrm { f } _ { 4 } ( x )$ , with $y = 0$ for $x < 0$ and $y = n x$ for $x \geq 0$

We are interested in $\mathrm { f } _ { 9 9 } ( x )$ , which looks like $y = \operatorname { f } _ { 3 } ( x ) ;$ : it is $y = - x$ for $x < 0$ and $y = 9 9 x$ for $x \geq 0$ . We can calculate the integral $\textstyle \int _ { - 1 } ^ { 1 } \mathrm { f } _ { 9 9 } ( x )$ dx by finding the area under the graph, which is just the sum of two triangles.

The area between $x = - 1$ and $x = 0$ is $\textstyle { \frac { 1 } { 2 } } \times 1 \times 1$ and the area between $x = 0$ and $x = 1$ is $\textstyle { \frac { 1 } { 2 } } \times 1 \times 9 9 $ , so the integral equals $\textstyle { \frac { 1 } { 2 } } \times 1 + { \frac { 1 } { 2 } } \stackrel { \sim } { \times } 9 9 = { \frac { 1 } { 2 } } \times 1 0 0 = 5 0$ ; the correct option is therefore E.
