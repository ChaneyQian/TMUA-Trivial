## 题目
The expression $(ax+b)(cx+d)$ is expanded, where $a$, $b$, $c$ and $d$ are real numbers.

Consider the following three conditions:

$$\textbf{condition 1} \quad b = -d$$

$$\textbf{condition 2} \quad ad = -bc$$

$$\textbf{condition 3} \quad a = c = 1 \text{ and } b = -d$$

Which of these conditions is/are **sufficient** for the expansion of $(ax+b)(cx+d)$ to equal $px^{2}+q$, for all $x$, where $p$ and $q$ are real numbers?

|  | condition 1 | condition 2 | condition 3 |
|---|---|---|---|
| A | not sufficient | not sufficient | not sufficient |
| B | not sufficient | not sufficient | sufficient |
| C | not sufficient | sufficient | not sufficient |
| D | not sufficient | sufficient | sufficient |
| E | sufficient | not sufficient | not sufficient |
| F | sufficient | not sufficient | sufficient |
| G | sufficient | sufficient | not sufficient |
| H | sufficient | sufficient | sufficient |

## 答案
D

## 解析
Expanding gives

$$(ax+b)(cx+d) = acx^2 + (ad + bc)x + bd$$

This equals $px^2 + q$ for all $x$ exactly when the coefficient of $x$ vanishes, that is when $ad + bc = 0$.

Condition 1 ($b = -d$): then $ad + bc = ad - dc = d(a - c)$, which need not be zero — for example $a = 2$, $c = 1$, $d = 1$, $b = -1$ gives $ad + bc = 1$. Not sufficient.

Condition 2 ($ad = -bc$): this is precisely $ad + bc = 0$. Sufficient.

Condition 3 ($a = c = 1$ and $b = -d$): then $ad + bc = d + (-d)(1) = 0$. Sufficient.

So the pattern is not sufficient / sufficient / sufficient, which is option D.
