## 题目
Find the complete set of possible values of the real constant $k$ for which the equation

$$(x-2)^{3} - 12(x-2) + k^{2} = 0$$

has exactly one real root.

$$\mathbf{A} \quad k < -4 \ \text{ or } \ k > 4$$

$$\mathbf{B} \quad -4 < k < 4$$

$$\mathbf{C} \quad k < 0 \ \text{ or } \ k > 4$$

$$\mathbf{D} \quad 0 < k < 4$$

$$\mathbf{E} \quad k < -16 \ \text{ or } \ k > 16$$

$$\mathbf{F} \quad -16 < k < 16$$

$$\mathbf{G} \quad -6 < k < 6$$

$$\mathbf{H} \quad k < -6 \ \text{ or } \ k > 6$$

### AI备注


## 答案
A

## 解析
Substitute $t = x - 2$, so the equation becomes $t^{3} - 12t = -k^{2}$.

Let $g(t) = t^{3} - 12t$. Its stationary points are given by $g'(t) = 3t^{2} - 12 = 0$, so $t = \pm 2$.

$$g(-2) = 16 \ \text{ (local maximum)}, \qquad g(2) = -16 \ \text{ (local minimum)}$$

A horizontal line $g(t) = -k^{2}$ meets the cubic once only when it lies strictly outside the range between the turning values, i.e. when $-k^{2} < -16$ or $-k^{2} > 16$. The second case is impossible.

$$-k^{2} < -16 \iff k^{2} > 16 \iff k < -4 \ \text{ or } \ k > 4$$

This is option A.
