## 题目
Consider the following three statements:

$$\mathbf{1} \quad x^{2} - 3x + 2 = 0 \ \textbf{ if } \ x = 1$$

$$\mathbf{2} \quad x^{2} - 3x + 2 = 0 \ \textbf{ only if } \ x = 1$$

$$\mathbf{3} \quad x^{2} - 3x + 2 = 0 \ \textbf{ if and only if } \ x = 1$$

Which of the statements is/are true?

$$\mathbf{A} \quad \text{none of them}$$

$$\mathbf{B} \quad \text{1 only}$$

$$\mathbf{C} \quad \text{2 only}$$

$$\mathbf{D} \quad \text{3 only}$$

$$\mathbf{E} \quad \text{1 and 2 only}$$

$$\mathbf{F} \quad \text{1 and 3 only}$$

$$\mathbf{G} \quad \text{2 and 3 only}$$

$$\mathbf{H} \quad \text{1, 2 and 3}$$

## 答案
B

## 解析
The quadratic factorises as $x^2 - 3x + 2 = (x-1)(x-2)$, so its roots are $x = 1$ and $x = 2$.

Statement 1 says $x = 1 \implies x^2 - 3x + 2 = 0$. Substituting $x = 1$ gives $1 - 3 + 2 = 0$, so this is true.

Statement 2 says $x^2 - 3x + 2 = 0 \implies x = 1$. This fails at $x = 2$, so it is false.

Statement 3 requires both implications, so it is false as well.

Only statement 1 is true, which is option B.
