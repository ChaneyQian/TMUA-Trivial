$$1 + \frac{x^{2}+9x+9}{x} > 0$$

$$\mathbf{B} \quad -1 < x < 0$$

$$\mathbf{C} \quad x < -9 \ \text{ or } \ x > -1$$

$$\mathbf{D} \quad -9 < x < -1$$

$$\mathbf{E} \quad x < -9 \ \text{ or } \ -1 < x < 0$$

$$\mathbf{F} \quad -9 < x < -1 \ \text{ or } \ x > 0$$
