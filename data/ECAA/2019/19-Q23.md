## 题目
Find the complete set of values of $x$ for which

$$1 + \frac{x^{2}+9x+9}{x} > 0$$

$$\mathbf{A} \quad x < -1 \ \text{ or } \ x > 0$$

$$\mathbf{B} \quad -1 < x < 0$$

$$\mathbf{C} \quad x < -9 \ \text{ or } \ x > -1$$

$$\mathbf{D} \quad -9 < x < -1$$

$$\mathbf{E} \quad x < -9 \ \text{ or } \ -1 < x < 0$$

$$\mathbf{F} \quad -9 < x < -1 \ \text{ or } \ x > 0$$

## 答案
F

## 解析
Combine over the common denominator $x$.

$$1 + \frac{x^{2}+9x+9}{x} = \frac{x^{2}+10x+9}{x} = \frac{(x+1)(x+9)}{x}$$

The critical values are $x = -9$, $x = -1$ and $x = 0$. Test the sign of the quotient in each interval.

$$x < -9:\ \frac{(-)(-)}{(-)} < 0 \qquad -9 < x < -1:\ \frac{(-)(+)}{(-)} > 0$$

$$-1 < x < 0:\ \frac{(+)(+)}{(-)} < 0 \qquad x > 0:\ \frac{(+)(+)}{(+)} > 0$$

So the expression is positive for $-9 < x < -1$ or $x > 0$, which is option F.
