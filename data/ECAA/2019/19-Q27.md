## 题目
A test consists of 20 questions.

10 of the questions each score 1 for a correct answer and 0 otherwise.

The other 10 questions each score 2 for a correct answer and 0 otherwise.

Jenna's mean score per question is 1.15

For Jenna's answers, the modal number of marks per question is 1.

For how many questions did Jenna score 0?

$$\mathbf{A} \quad 3$$

$$\mathbf{B} \quad 4$$

$$\mathbf{C} \quad 5$$

$$\mathbf{D} \quad 6$$

$$\mathbf{E} \quad 7$$

## 答案
B

## 解析
Jenna's total score is $20 \times 1.15 = 23$.

Let $a$ be the number of correct answers among the 1-mark questions and $b$ the number among the 2-mark questions, so $0 \le a \le 10$ and $0 \le b \le 10$.

$$a + 2b = 23$$

The number of questions scoring $0$ is $20 - a - b$. Since $a = 23 - 2b \le 10$, we need $b \ge 7$.

$$b = 7 \implies a = 9,\quad b = 8 \implies a = 7,\quad b = 9 \implies a = 5,\quad b = 10 \implies a = 3$$

The mode of the marks per question is $1$, so $a$ must exceed both $b$ and $20 - a - b$. Only $b = 7$, $a = 9$ works: the marks $0$, $1$, $2$ occur $4$, $9$, $7$ times respectively.

So Jenna scored $0$ on $4$ questions, which is option B.
