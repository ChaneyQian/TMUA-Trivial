## 题目
$x$ satisfies the equation

$$\log_{3}\left(k + \log_{5} x\right) = 1$$

Which one of the following is an expression for $x$ in terms of $k$?

$$\mathbf{A} \quad x = 3^{\,5-k}$$

$$\mathbf{B} \quad x = 3^{\,5+k}$$

$$\mathbf{C} \quad x = 5^{\,3-k}$$

$$\mathbf{D} \quad x = 5^{\,3+k}$$

$$\mathbf{E} \quad x = 3^{5} - k$$

$$\mathbf{F} \quad x = 3^{5} + k$$

$$\mathbf{G} \quad x = 5^{3} - k$$

$$\mathbf{H} \quad x = 5^{3} + k$$

## 备注

### 我的备注

### AI备注


## 答案
C

## 解析
Since $\log_{3} N = 1$ means $N = 3$, the bracket equals $3$.

$$k + \log_{5} x = 3$$

Rearrange for the logarithm.

$$\log_{5} x = 3 - k$$

Convert to index form.

$$x = 5^{\,3-k}$$

This is option C.
