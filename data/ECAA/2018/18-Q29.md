## 题目
The line with equation

$$\left(1 + \sqrt{3}\right) y = px + 5$$

is perpendicular to the line with equation

$$y = \left(2 - \sqrt{3}\right) x + 8$$

What is the value of $p$?

$$\mathbf{A} \quad -5 - 3\sqrt{3}$$

$$\mathbf{B} \quad -5 + 3\sqrt{3}$$

$$\mathbf{C} \quad 5 - 3\sqrt{3}$$

$$\mathbf{D} \quad 5 + 3\sqrt{3}$$

## 备注

### 我的备注

### AI备注


## 答案
A

## 解析
Rearranged, the first line is

$$y = \dfrac{p}{1 + \sqrt{3}} x + \dfrac{5}{1 + \sqrt{3}}$$

so its gradient is $\dfrac{p}{1 + \sqrt{3}}$. For perpendicular lines the product of the gradients is $-1$:

$$\dfrac{p}{1 + \sqrt{3}} \left(2 - \sqrt{3}\right) = -1 \implies p = \dfrac{-\left(1 + \sqrt{3}\right)}{2 - \sqrt{3}}$$

Since $\left(2 - \sqrt{3}\right)\left(2 + \sqrt{3}\right) = 1$, multiplying numerator and denominator by $2 + \sqrt{3}$ gives

$$p = -\left(1 + \sqrt{3}\right)\left(2 + \sqrt{3}\right) = -\left(2 + \sqrt{3} + 2\sqrt{3} + 3\right) = -5 - 3\sqrt{3}$$

which is option A.
