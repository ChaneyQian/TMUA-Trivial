## 题目
Find the set of values of $x$ such that both $x^2 + x - 6 \ge 0$ and $4 + 3x - x^2 \le 0$

$$\mathbf{A} \quad 2 \le x \le 4$$

$$\mathbf{B} \quad -3 \le x \le -1$$

$$\mathbf{C} \quad x \le -3 \ \text{ or } \ -1 \le x \le 4$$

$$\mathbf{D} \quad -3 \le x \le -1 \ \text{ or } \ 2 \le x \le 4$$

$$\mathbf{E} \quad x \le -1 \ \text{ or } \ x \ge 2$$

$$\mathbf{F} \quad x \le -3 \ \text{ or } \ x \ge 4$$

## 答案
F

## 解析
Factorise each inequality.

$$x^2 + x - 6 = (x + 3)(x - 2) \ge 0 \implies x \le -3 \ \text{ or } \ x \ge 2$$

$$4 + 3x - x^2 \le 0 \iff x^2 - 3x - 4 \ge 0 \iff (x - 4)(x + 1) \ge 0 \implies x \le -1 \ \text{ or } \ x \ge 4$$

Both conditions hold only where the two sets overlap, giving $x \le -3$ or $x \ge 4$, which is option F.
