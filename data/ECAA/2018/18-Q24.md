## 题目
$ax - 1$ is a factor of $3ax^3 + (6a + 1)x^2 - 4$

$a$ is a non-zero real number.

What are the possible values of $a$?

$$\mathbf{A} \quad -1 \ \text{ or } \ -\dfrac{1}{2}$$

$$\mathbf{B} \quad +\dfrac{1}{2} \ \text{ or } \ +1$$

$$\mathbf{C} \quad -2 \ \text{ or } \ +\dfrac{1}{2}$$

$$\mathbf{D} \quad -\dfrac{1}{2} \ \text{ or } \ +2$$

$$\mathbf{E} \quad -\dfrac{1}{3} - \dfrac{\sqrt{7}}{3} \ \text{ or } \ -\dfrac{1}{3} + \dfrac{\sqrt{7}}{3}$$

$$\mathbf{F} \quad +\dfrac{1}{3} - \dfrac{\sqrt{7}}{3} \ \text{ or } \ +\dfrac{1}{3} + \dfrac{\sqrt{7}}{3}$$

## 备注

### 我的备注

### AI备注


## 答案
D

## 解析
If $ax - 1$ is a factor then $x = \dfrac{1}{a}$ is a root.

$$3a \cdot \dfrac{1}{a^3} + (6a + 1) \cdot \dfrac{1}{a^2} - 4 = 0$$

Multiply through by $a^2$:

$$3 + 6a + 1 - 4a^2 = 0 \implies 2a^2 - 3a - 2 = 0$$

$$(2a + 1)(a - 2) = 0$$

So $a = -\dfrac{1}{2}$ or $a = 2$, which is option D.
