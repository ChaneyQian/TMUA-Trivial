## 题目
Consider the statement:

$$f(x) > x \text{ for all real values of } x > 1$$

Which one of the following is a negation of this statement?

$$\mathbf{A} \quad f(x) \le x \text{ for all real values of } x \le 1$$

$$\mathbf{B} \quad f(x) \le x \text{ for all real values of } x > 1$$

$$\mathbf{C} \quad f(x) \le x \text{ for at least one real value of } x \le 1$$

$$\mathbf{D} \quad f(x) \le x \text{ for at least one real value of } x > 1$$

$$\mathbf{E} \quad f(x) > x \text{ for at least one real value of } x \le 1$$

$$\mathbf{F} \quad f(x) > x \text{ for at least one real value of } x > 1$$

$$\mathbf{G} \quad f(x) > x \text{ for no real values of } x \le 1$$

$$\mathbf{H} \quad f(x) \le x \text{ for no real values of } x > 1$$

### AI备注


## 答案
D

## 解析
The statement has the form "for all $x > 1$, $f(x) > x$".

Negating a universal statement gives an existential one over the same range, with the inequality reversed: there is at least one $x > 1$ for which $f(x) > x$ fails, i.e. for which $f(x) \le x$.

The range $x > 1$ is part of the statement and is not negated, so options referring to $x \le 1$ are wrong, as are the options that keep "for all".

This is option D.
