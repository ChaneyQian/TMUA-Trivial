## 题目
The real solution of the equation

$$5^{2x+1} + 5^{x} - 4 = 0$$

can be written as

$$\mathbf{A} \quad \frac{2}{\log_{2} 5} - 1$$

$$\mathbf{B} \quad 2\log_{2} \frac{2}{5}$$

$$\mathbf{C} \quad 0$$

$$\mathbf{D} \quad \frac{2}{\log_{2} 5}$$

$$\mathbf{E} \quad \frac{1}{\log_{2} 5}$$

## 备注

### 我的备注

### AI备注


## 答案
A

## 解析
Write $u = 5^{x}$, so that $5^{2x+1} = 5u^{2}$.

$$5u^{2} + u - 4 = 0 \implies (5u - 4)(u + 1) = 0$$

Since $u = 5^{x} > 0$, the root $u = -1$ is rejected and $5^{x} = \dfrac{4}{5}$.

$$x = \log_{5}\frac{4}{5} = \log_{5}4 - 1$$

Changing to base $2$,

$$\log_{5}4 = \frac{\log_{2}4}{\log_{2}5} = \frac{2}{\log_{2}5}$$

so $x = \dfrac{2}{\log_{2}5} - 1$, which is option A.
