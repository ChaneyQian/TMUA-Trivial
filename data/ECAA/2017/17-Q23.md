## 题目
Find the complete set of values of $x$ for which

$$x - \frac{3}{2} > \frac{1}{x}$$

$$\mathbf{A} \quad x < -\frac{1}{2}, \; x > 2$$

$$\mathbf{B} \quad x < -\frac{1}{2}, \; 0 < x < 2$$

$$\mathbf{C} \quad x < -2, \; 0 < x < \frac{1}{2}$$

$$\mathbf{D} \quad x < -2, \; x > \frac{1}{2}$$

$$\mathbf{E} \quad -\frac{1}{2} < x < 0, \; x > 2$$

$$\mathbf{F} \quad -2 < x < 0, \; x > \frac{1}{2}$$

## 备注

### AI备注


## 答案
E

## 解析
Multiply through by $x^{2}$, which is positive for all $x \neq 0$, so the inequality sign is unchanged.

$$x^{3} - \frac{3}{2}x^{2} > x$$

$$x\left(2x^{2} - 3x - 2\right) > 0$$

$$x(2x+1)(x-2) > 0$$

The critical values are $x = -\dfrac{1}{2}$, $x = 0$ and $x = 2$. The cubic is positive on the intervals

$$-\frac{1}{2} < x < 0 \quad \text{and} \quad x > 2$$

which is option E.
