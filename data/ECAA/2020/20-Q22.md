## 题目
$(x - 1)$ and $(x - 2)$ are both factors of $x^4 + ax^3 + bx^2 - 12x + 4$

What are the values of $a$ and $b$?

$$\mathbf{A} \quad a = -6 \ \text{ and } \ b = -23$$

$$\mathbf{B} \quad a = -6 \ \text{ and } \ b = 13$$

$$\mathbf{C} \quad a = 6 \ \text{ and } \ b = -11$$

$$\mathbf{D} \quad a = 6 \ \text{ and } \ b = 1$$

## 备注

### 我的备注

### AI备注


## 答案
B

## 解析
Write $f(x) = x^4 + ax^3 + bx^2 - 12x + 4$. By the factor theorem, $f(1) = 0$ and $f(2) = 0$.

$$f(1) = 1 + a + b - 12 + 4 = 0 \implies a + b = 7$$

$$f(2) = 16 + 8a + 4b - 24 + 4 = 0 \implies 2a + b = 1$$

Subtracting the first equation from the second gives $a = -6$, and then $b = 13$, which is option B.
