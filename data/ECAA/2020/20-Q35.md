## 题目
Find the complete set of values of $x$ for which

$$x^4 + 36 < 13x^2$$

$$\mathbf{A} \quad 4 < x < 9$$

$$\mathbf{B} \quad x < 4,\ x > 9$$

$$\mathbf{C} \quad -9 < x < -4,\ 4 < x < 9$$

$$\mathbf{D} \quad x < -9,\ -4 < x < 4,\ x > 9$$

$$\mathbf{E} \quad 2 < x < 3$$

$$\mathbf{F} \quad x < 2,\ x > 3$$

$$\mathbf{G} \quad -3 < x < -2,\ 2 < x < 3$$

$$\mathbf{H} \quad x < -3,\ -2 < x < 2,\ x > 3$$

## 答案
G

## 解析
Rearrange and treat the expression as a quadratic in $x^2$:

$$x^4 - 13x^2 + 36 < 0$$

$$(x^2 - 4)(x^2 - 9) < 0$$

The product is negative when $x^2$ lies strictly between the roots:

$$4 < x^2 < 9 \implies 2 < |x| < 3$$

Taking both signs gives $-3 < x < -2$ or $2 < x < 3$, which is option G.
