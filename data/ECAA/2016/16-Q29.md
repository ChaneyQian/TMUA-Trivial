## 题目
Find all possible positive values of $x$ for which $2 + 2\log_5 x = \log_5(24 + 10x)$ is true.

$$\mathbf{A} \quad 5 \pm 2\sqrt{6}$$

$$\mathbf{B} \quad \dfrac{6}{5}$$

$$\mathbf{C} \quad 2\sqrt{6}$$

$$\mathbf{D} \quad \dfrac{4}{5}$$

$$\mathbf{E} \quad \text{There are no values of } x.$$

## 备注

### 我的备注

### AI备注


## 答案
B

## 解析
Write $2 = \log_5 25$ and $2\log_5 x = \log_5 x^2$, so the left-hand side is $\log_5\left(25x^2\right)$.

$$\log_5\left(25x^2\right) = \log_5(24 + 10x)$$

$$25x^2 = 24 + 10x$$

$$25x^2 - 10x - 24 = 0$$

$$x = \frac{10 \pm \sqrt{100 + 2400}}{50} = \frac{10 \pm 50}{50}$$

This gives $x = \dfrac{6}{5}$ or $x = -\dfrac{4}{5}$. The logarithm requires $x > 0$, so only $x = \dfrac{6}{5}$ survives, which is option B.
