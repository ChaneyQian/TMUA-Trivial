## 题目
An electronic circuit contains three light bulbs, X, Y and Z, which are each either on or off at any particular time. It is known that if bulb X is off **or** bulb Y is on, then bulb Z is on.

Which one of these statements **necessarily** follows from this?

$$\mathbf{A} \quad \text{If bulb Z is on, then bulb X is off } \textbf{or} \text{ bulb Y is on.}$$

$$\mathbf{B} \quad \text{If bulb Z is on, then bulb X is on } \textbf{and} \text{ bulb Y is off.}$$

$$\mathbf{C} \quad \text{If bulb Z is on, then bulb X is on } \textbf{or} \text{ bulb Y is on.}$$

$$\mathbf{D} \quad \text{If bulb Z is off, then bulb X is off } \textbf{and} \text{ bulb Y is off.}$$

$$\mathbf{E} \quad \text{If bulb Z is off, then bulb X is on } \textbf{or} \text{ bulb Y is off.}$$

$$\mathbf{F} \quad \text{If bulb Z is off, then bulb X is on } \textbf{and} \text{ bulb Y is on.}$$

## 答案
E

## 解析
The given information is

$$(\text{X off} \ \textbf{or} \ \text{Y on}) \implies \text{Z on}$$

An implication is equivalent to its contrapositive, so

$$\text{Z off} \implies \textbf{not}\,(\text{X off} \ \textbf{or} \ \text{Y on}) = (\text{X on} \ \textbf{and} \ \text{Y off})$$

This exact statement is not offered, but "X on **and** Y off" implies the weaker "X on **or** Y off", so option E follows.

Options A and C are converses of the given statement and need not hold; D and F contradict the contrapositive.

The answer is option E.
