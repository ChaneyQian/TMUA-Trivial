## 题目
A curve has the equation $y = ax^3 + bx^2 + c$

The curve has a maximum stationary point at $x = 0$ and a minimum stationary point in the 4th quadrant (that is, the region where $x > 0$ and $y < 0$)

Which of the following set of conditions is **sufficient** to ensure this?

$$\mathbf{A} \quad a < 0,\ b < 0,\ c < 0$$

$$\mathbf{B} \quad a < 0,\ b < 0,\ c > 0$$

$$\mathbf{C} \quad a < 0,\ b > 0,\ c < 0$$

$$\mathbf{D} \quad a < 0,\ b > 0,\ c > 0$$

$$\mathbf{E} \quad a > 0,\ b < 0,\ c < 0$$

$$\mathbf{F} \quad a > 0,\ b < 0,\ c > 0$$

$$\mathbf{G} \quad a > 0,\ b > 0,\ c < 0$$

$$\mathbf{H} \quad a > 0,\ b > 0,\ c > 0$$

## 答案
E

## 解析
Differentiate:

$$\frac{dy}{dx} = 3ax^2 + 2bx = x(3ax + 2b)$$

So the stationary points are at $x = 0$ and $x = -\dfrac{2b}{3a}$.

For a maximum at $x = 0$:

$$\frac{d^2y}{dx^2} = 6ax + 2b, \qquad \left.\frac{d^2y}{dx^2}\right|_{x=0} = 2b < 0 \implies b < 0$$

The other stationary point must have $x > 0$. Since $b < 0$ gives $-2b > 0$, this requires $3a > 0$, so $a > 0$.

At $x_0 = -\dfrac{2b}{3a}$ we have $ax_0 = -\dfrac{2b}{3}$, so

$$y(x_0) = x_0^2(ax_0 + b) + c = x_0^2 \cdot \frac{b}{3} + c$$

As $b < 0$ the first term is negative, so $c < 0$ is enough to force $y(x_0) < 0$.

The conditions $a > 0$, $b < 0$, $c < 0$ are sufficient, which is option E.
