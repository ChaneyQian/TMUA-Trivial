## 题目
A box is a hollow pyramid. The base of the box is a square with sides $10\ \text{cm}$ and all the slant edges of the box are $12\ \text{cm}$ long.

![[Image/Spec-Q30-fig1.png]]

What is the angle made by the slant edge $TP$ with the base $PQRS$?

$$\mathbf{A} \quad \sin^{-1}\frac{2\sqrt{5}}{12}$$

$$\mathbf{B} \quad \sin^{-1}\frac{5}{12}$$

$$\mathbf{C} \quad \sin^{-1}\frac{5\sqrt{2}}{12}$$

$$\mathbf{D} \quad \cos^{-1}\frac{2\sqrt{5}}{12}$$

$$\mathbf{E} \quad \cos^{-1}\frac{5}{12}$$

$$\mathbf{F} \quad \cos^{-1}\frac{5\sqrt{2}}{12}$$

## 答案
F

## 解析
1.

![[Image/Spec-Q30-sol1.png]]

We need to find angle $TPX$.

Draw a perpendicular from $T$ to $X$ (midpoint of square $PQRS$), then find $PX$.

2.

![[Image/Spec-Q30-sol2.png]]

Using Pythagoras' Theorem

$$PX^2 = 5^2 + 5^2 = 50$$

$$\text{so } PX = \sqrt{50} = 5\sqrt{2}$$

3.

![[Image/Spec-Q30-sol3.png]]

Then $\cos TPX = \dfrac{5\sqrt{2}}{12}$, so $TPX = \cos^{-1}\dfrac{5\sqrt{2}}{12}$
