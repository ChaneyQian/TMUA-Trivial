## 题目
The complete set of values of $a$ for which the equation $3x^2 = (a + 2)x - 3$ has two real distinct roots is:

$$\mathbf{A} \quad \text{no values of } a$$

$$\mathbf{B} \quad -4\sqrt{2} < a < 4\sqrt{2}$$

$$\mathbf{C} \quad a < -4\sqrt{2},\ a > 4\sqrt{2}$$

$$\mathbf{D} \quad -4 < a < 8$$

$$\mathbf{E} \quad a < -4,\ a > 8$$

$$\mathbf{F} \quad -8 < a < 4$$

$$\mathbf{G} \quad a < -8,\ a > 4$$

$$\mathbf{H} \quad \text{all values of } a$$

## 答案
G

## 解析
Rearranging $3x^2 = (a+2)x - 3$:

$$3x^2 - (a+2)x + 3 = 0$$

Considering the discriminant ($b^2 - 4ac$) of the quadratic:

$$[-(a+2)]^2 - (4 \times 3 \times 3) > 0$$

$$a^2 + 4a + 4 - 36 > 0$$

$$a^2 + 4a - 32 > 0$$

$$(a+8)(a-4) > 0$$

Referring to the sketch of the quadratic in $a$

it is seen that the required set of values is: $a < -8$, $a > 4$
