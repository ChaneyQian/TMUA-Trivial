## 题目
When $x = 2$ is substituted in the expression $x^3 + px^2 + qx + p^2$ the result is $0$

When $x = 1$ is substituted into the same expression, the result is $-3.5$

Find all possible values of $p$.

$$\mathbf{A} \quad p = -1 \pm \frac{\sqrt{6}}{3}$$

$$\mathbf{B} \quad p = 1 \ \text{ or } \ p = -3$$

$$\mathbf{C} \quad p = 1$$

$$\mathbf{D} \quad p = 1 \pm \sqrt{7}$$

$$\mathbf{E} \quad \text{there are no values for } p$$

### AI备注


## 答案
C

## 解析
Substituting values for $x$ and using the Remainder Theorem gives:

$$\text{for } x = 2 \qquad 8 + 4p + 2q + p^2 = 0 \qquad \text{(i)}$$

$$\text{for } x = 1 \qquad 1 + p + q + p^2 = -3.5 \qquad \text{(ii)}$$

Multiply (ii) by $-2$:

$$-2 - 2p - 2q - 2p^2 = 7 \qquad \text{(iii)}$$

Add (i) and (iii):

$$6 + 2p - p^2 = 7$$

Rearranging:

$$p^2 - 2p + 1 = 7$$

$$(p-1)^2 = 0 \qquad \text{so } p = 1$$
