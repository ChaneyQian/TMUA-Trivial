## 题目
Find the complete set of values of $\theta$ for which the following inequality is valid:

$$\sin\theta < \int_{\sin\theta}^{\cos\theta} (2x - 1)\,\mathrm{d}x \qquad \text{where } 0 < \theta < 2\pi$$

$$\mathbf{A} \quad 0 < \theta < 2\pi$$

$$\mathbf{B} \quad \dfrac{\pi}{6} < \theta < \dfrac{11\pi}{6}$$

$$\mathbf{C} \quad \dfrac{\pi}{3} < \theta < \dfrac{5\pi}{3}$$

$$\mathbf{D} \quad \dfrac{2\pi}{3} < \theta < \dfrac{4\pi}{3}$$

$$\mathbf{E} \quad \dfrac{5\pi}{6} < \theta < \dfrac{7\pi}{6}$$

$$\mathbf{F} \quad \dfrac{\pi}{4} < \theta < \dfrac{3\pi}{4},\; \dfrac{5\pi}{4} < \theta < \dfrac{7\pi}{4}$$

$$\mathbf{G} \quad 0 < \theta < \dfrac{\pi}{4},\; \dfrac{3\pi}{4} < \theta < \dfrac{5\pi}{4},\; \dfrac{7\pi}{4} < \theta < 2\pi$$

## 答案
D

## 解析
Evaluate the integral:

$$\int_{\sin\theta}^{\cos\theta}(2x - 1)\,dx = \left[x^2 - x\right]_{\sin\theta}^{\cos\theta} = \left(\cos^2\theta - \sin^2\theta\right) - \cos\theta + \sin\theta$$

So the inequality $\sin\theta < \cos 2\theta - \cos\theta + \sin\theta$ reduces to

$$\cos 2\theta > \cos\theta$$

Writing $c = \cos\theta$ and using $\cos 2\theta = 2c^2 - 1$:

$$2c^2 - c - 1 > 0 \implies (2c + 1)(c - 1) > 0$$

On $0 < \theta < 2\pi$ we have $c < 1$, so $c - 1 < 0$ and the inequality needs $2c + 1 < 0$, that is $c < -\dfrac{1}{2}$.

This holds for $\dfrac{2\pi}{3} < \theta < \dfrac{4\pi}{3}$, which is option D.
