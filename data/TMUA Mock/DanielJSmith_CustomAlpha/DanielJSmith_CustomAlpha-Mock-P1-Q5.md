## 题目
Let $P(n)$ be a statement about integers with the following properties: $P(1)$ and $P(2)$ are true; for all $n\ge 1$ the following statement is true: $(P(n)$ **and** $P(n+1))$ is **sufficient** for $P(n+2)$ What is the strongest conclusion that necessarily follows?

$$ \mathbf{A} \quad P(n) \text{is true for all} n\ge 1 $$
$$ \mathbf{B} \quad P(n) \text{is true for all sufficiently large} n \text{, but not necessarily for all} n $$
$$ \mathbf{C} \quad P(n) \text{is true for infinitely many} n \text{, but not necessarily for all} n $$
$$ \mathbf{D} \quad P(n) \text{is true for all odd} n \text{but not necessarily for all even} n $$
$$ \mathbf{E} \quad P(n) \text{is true for all even} n \text{but not necessarily for all odd} n $$
$$ \mathbf{F} \quad \text{No general conclusion can be drawn beyond} P(1) \text{and} P(2) $$
