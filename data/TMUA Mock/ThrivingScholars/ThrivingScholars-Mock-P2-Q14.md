## 题目
Four distinct real numbers $a$, $b$, $c$, and $d$ are used to define four points $A = (a, b)$, $B = (b, c)$, $C = (c, d)$, $D = (d, a)$. The quadrilateral $ABCD$ has all four sides the same length

$$
\mathbf{A} \quad \text{if and only if } (a - b)^2 = (c - d)^2
$$

$$
\mathbf{B} \quad \text{for no values of } a, b, c, d
$$

$$
\mathbf{C} \quad \text{if and only if } (a - d)^2 = (b - c)^2
$$

$$
\mathbf{D} \quad \text{if and only if } a - b + c - d = 0
$$

$$
\mathbf{E} \quad \text{if and only if } (a - c)^2 = (b - d)^2
$$
