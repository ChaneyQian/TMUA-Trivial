## 题目
Let $y = \log_a x$ and $a > 1$. Then only one of the following statements is false. Which one is it?
$$\mathbf{A} \quad \text{If } x = 1 \text{, then } y = 0$$
$$\mathbf{B} \quad \text{If } x < 1 \text{, then } y < 0$$
$$\mathbf{C} \quad \text{If } x = \frac{1}{2} \text{, then } y = \frac{1}{2}$$
$$\mathbf{D} \quad \text{If } x = a \text{, then } y = 1$$

### 我的备注

### AI备注


## 答案
C

## 解析
For any base $a > 1$ the logarithm is strictly increasing with $\log_a 1 = 0$ and $\log_a a = 1$, so A and D hold, and B holds as well because a value of $x$ in $(0, 1)$ lies below the point where the logarithm vanishes. Statement C asserts $\log_a \frac{1}{2} = \frac{1}{2}$, which would mean $a^{1/2} = \frac{1}{2}$ and hence $a = \frac{1}{4}$, contradicting $a > 1$. Indeed for $a > 1$ the value $\log_a \frac{1}{2}$ is negative and so can never equal $\frac{1}{2}$. The answer is C.
