## 题目
Five sealed jars, labelled A, B, C, D and E, each contain the same (non-zero) number of £1 coins. The following statements are attached to the jars: A: This jar contains less than £4 B: This jar contains £5 or £6 C: This jar contains £1 or £6 D: This jar contains more than £3 and less than £6 E: This jar contains £2 or £3 Exactly one of the jars has a true statement attached to it. Which jar is it?
