## 题目
For how many of these functions is $f'(x)$ strictly increasing for all real $x$?
1. $\ln(x)$
2. $\sin(x)$
3. $-\ln(x)$
4. $x^2$
5. $x^3$

## 答案
B

## 解析
The condition is that $f'$ be strictly increasing *for all real $x$*, which requires $f$ to be defined and differentiable on the whole real line.

$\ln x$ and $-\ln x$ are only defined for $x > 0$, so 1 and 3 fail immediately on domain grounds.

For $\sin x$, $f'(x) = \cos x$ oscillates and is certainly not increasing, so 2 fails.

For $x^{2}$, $f'(x) = 2x$ is a line of positive gradient, strictly increasing on all of $\mathbb{R}$: 4 works.

For $x^{3}$, $f'(x) = 3x^{2}$ decreases on $x < 0$ before increasing on $x > 0$, so 5 fails.

Exactly one function qualifies, so the answer is B.
