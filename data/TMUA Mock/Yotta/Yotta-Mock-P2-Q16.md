## 题目
Of the following 7 statements about numbered lamps in a factory, exactly one of them is true. Which one is the true statement? [$n$ is a positive integer]

$$
\mathbf{A} \quad \text{If } n \text{ is even, lamp } n \text{ is switched on.}
$$

$$
\mathbf{B} \quad \text{If } n \text{ is odd, lamp } n \text{ is switched off.}
$$

$$
\mathbf{C} \quad \text{If } n \text{ is even, lamp } n \text{ is switched off.}
$$

$$
\mathbf{D} \quad \text{If } n \text{ is odd, lamp } n \text{ is switched on.}
$$

$$
\mathbf{E} \quad \text{If lamp } n \text{ is switched on, then } n \text{ is even.}
$$

$$
\mathbf{F} \quad \text{If lamp } n \text{ is switched off, then } n \text{ is odd.}
$$

$$
\mathbf{G} \quad \text{If lamp } n \text{ is switched off, then } n \text{ is even.}
$$

## 答案
C

## 解析
A conditional and its contrapositive are logically equivalent, so if one of a contrapositive pair is true, both are. Since exactly one of the seven statements is true, no such pair can be the true one — that would make two true statements.

Pair up the options:

- E ("if lamp $n$ is on then $n$ is even") is the contrapositive of B ("if $n$ is odd then lamp $n$ is off").
- F ("if lamp $n$ is off then $n$ is odd") is the contrapositive of A ("if $n$ is even then lamp $n$ is on").
- G ("if lamp $n$ is off then $n$ is even") is the contrapositive of D ("if $n$ is odd then lamp $n$ is on").

That accounts for A, B, D, E, F and G in three pairs, each of which must therefore be false. The only option left unpaired is C, whose contrapositive ("if lamp $n$ is on then $n$ is odd") does not appear in the list.

So the true statement must be C, and the answer is C.
