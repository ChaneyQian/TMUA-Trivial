## 题目
For a real constant $k$, the function $f$ is defined by $$f(x) = x^3 - 3x + k.$$ The equation $$f\big(f(x)\big) = k$$ has exactly seven distinct real solutions. Which of the following gives the complete set of possible values of $k$?

$$ \mathbf{A} \quad -2 < k < 2 $$
$$ \mathbf{B} \quad -2 < k < \sqrt{3}-2 \text{ or } 2-\sqrt{3} < k < 2 $$
$$ \mathbf{C} \quad -2 < k \le \sqrt{3}-2 \text{ or } 2-\sqrt{3} \le k < 2 $$
$$ \mathbf{D} \quad \sqrt{3}-2 < k < 2-\sqrt{3} $$
$$ \mathbf{E} \quad k < \sqrt{3}-2 \text{ or } k > 2-\sqrt{3} $$
