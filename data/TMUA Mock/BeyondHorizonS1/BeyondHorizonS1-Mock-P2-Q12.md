## 题目
Define $x\heartsuit y$ to be $|x-y|$ for all real numbers $x$ and $y$. Which of the following statements is not true?
$$\mathbf{A} \quad x\heartsuit y=y\heartsuit x \text{ for all } x \text{ and } y$$
$$\mathbf{B} \quad 2(x\heartsuit y)=(2x)\heartsuit(2y) \text{ for all } x \text{ and } y$$
$$\mathbf{C} \quad x\heartsuit 0=x \text{ for all } x$$
$$\mathbf{D} \quad x\heartsuit x=0 \text{ for all } x$$
$$\mathbf{E} \quad x\heartsuit y>0 \text{ if } x\neq y$$

## 备注

### 我的备注

### AI备注


## 答案
C

## 解析
Statement A holds because $|x-y|=|y-x|$, statement B holds because $|2x-2y|=2|x-y|$ by absolute homogeneity, statement D holds because $|x-x|=0$, and statement E holds because an absolute value vanishes only when its argument does. Statement C claims $|x-0|=x$, that is $|x|=x$, which is true only for $x\geq 0$; taking $x=-3$ gives $(-3)\heartsuit 0=|-3|=3\neq -3$. So C is the statement that fails. The answer is C.
