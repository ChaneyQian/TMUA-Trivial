## 题目
Two functions are defined as:
$$f(x) = \left| x^2 - 4 \right|, \; x \in \mathbb{R}$$
$$g(x) = x + 2, \; x \in \mathbb{R}$$
Which range of values satisfy the inequality $f(x) < g(x)$?
$$\mathbf{A} \quad -2 < x < 3$$
$$\mathbf{B} \quad -2 < x < 1$$
$$\mathbf{C} \quad 1 < x < 3$$
$$\mathbf{D} \quad x < 1 \text{ and } x > 3$$
$$\mathbf{E} \quad x < -2 \text{ and } x > 3$$
$$\mathbf{F} \quad x < -2 \text{ and } x > 1$$

### AI备注


## 答案
C

## 解析
Since $f(x) = |x^2-4| \geq 0$, any solution must have $x + 2 > 0$, so $x > -2$. On that range $x+2$ is positive, and factorising gives $|x^2-4| = |x-2|\,|x+2| = |x-2|(x+2)$. The inequality becomes
$$|x-2|(x+2) < x+2$$
and dividing by the positive quantity $x+2$ leaves $|x-2| < 1$, that is $1 < x < 3$. Every such $x$ indeed satisfies $x > -2$, so this is the full solution set. A quick check at $x = 0$ confirms it: $f(0) = 4$ is not less than $g(0) = 2$, so $0$ must be excluded, which rules out options A and B. The answer is C.
