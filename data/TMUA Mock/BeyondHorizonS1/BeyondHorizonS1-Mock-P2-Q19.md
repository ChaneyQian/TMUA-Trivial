## 题目
Let $x,y,z$ be real numbers. Then only one of the following statements is true. Which one is it?
$$\mathbf{A} \quad \text{If } x<y, \text{ then } xz<yz \text{ for all values of } z.$$
$$\mathbf{B} \quad \text{If } x<y, \text{ then } \frac{x}{z}\leq\frac{y}{z} \text{ for all values of } z.$$
$$\mathbf{C} \quad \text{If } x<y, \text{ then } (x+z)<(y+z) \text{ for all values of } z.$$
$$\mathbf{D} \quad \text{If } 0<x<y, \text{ then } xz<yz \text{ for all values of } z.$$

## 答案
C

## 解析
Options A and D both fail at $z=0$, where $xz=yz=0$ and the strict inequality collapses; taking $x=1$, $y=2$, $z=0$ breaks both at once, and negative $z$ breaks them again by reversing the inequality. Option B fails both because $z=0$ makes the expressions undefined and because a negative $z$ reverses the order, as with $x=1$, $y=2$, $z=-1$ giving $-1\leq -2$, which is false. Option C is the order axiom for addition: subtracting $z$ from both sides of $x+z<y+z$ recovers $x<y$ and the step is reversible for every real $z$, positive, negative or zero, so the implication holds unconditionally. The answer is C.
