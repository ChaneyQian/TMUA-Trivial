## 题目
Find the complete set of values of the constant $c$ for which the cubic equation
$$x^3 - 3x + c = 0$$
has three distinct real solutions.
$$\mathbf{A} \quad 0 < c < 2$$
$$\mathbf{B} \quad -2 < c < 0$$
$$\mathbf{C} \quad -2 < c < 2$$
$$\mathbf{D} \quad c > -2$$
$$\mathbf{E} \quad c < 2$$
$$\mathbf{F} \quad c < 0$$

## 备注

### 我的备注

### AI备注


## 答案
C

## 解析
Let $p(x) = x^3 - 3x + c$. Then $p'(x) = 3x^2 - 3$, so the stationary points are at $x = -1$ and $x = 1$, giving a local maximum $p(-1) = c + 2$ and a local minimum $p(1) = c - 2$. A cubic has three distinct real roots exactly when its local maximum is strictly above the axis and its local minimum strictly below it, so we need $c + 2 > 0$ and $c - 2 < 0$, that is
$$-2 < c < 2.$$
The answer is C. Options D and E each impose only one of the two inequalities, so they admit values of $c$ for which the curve turns without recrossing the axis.
