## 题目
Consider the statement: For every real number $x$, there exists a positive integer $n$ such that $$x < n \le x + 2.$$ Which is its logical negation?

$$ \mathbf{A} \quad \text{For every real} x \text{, every positive integer} n \text{satisfies} n \le x \text{or} n > x + 2 \text{.} $$
$$ \mathbf{B} \quad \text{There exists a real} x \text{and a positive integer} n \text{such that} n \le x \text{or} n > x + 2 \text{.} $$
$$ \mathbf{C} \quad \text{There exists a real} x \text{such that every positive integer} n \text{satisfies} n \le x \text{or} n > x + 2 \text{.} $$
$$ \mathbf{D} \quad \text{For every real} x \text{, there exists a positive integer} n \text{such that} n \le x \text{or} n > x + 2 \text{.} $$
$$ \mathbf{E} \quad \text{There exists a positive integer} n \text{such that every real} x \text{satisfies} n \le x \text{or} n > x + 2 \text{.} $$
