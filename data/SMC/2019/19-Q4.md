## 题目
For how many positive integer values of $n$ is $n^2 + 2n$ prime?

A 0 $\qquad$ B 1 $\qquad$ C 2 $\qquad$ D 3 $\qquad$ E more than 3

## 中文题干
有多少个正整数 $n$ 使得 $n^2 + 2n$ 是质数？

## 答案
B

## 解析
We have $n^2 + 2n = n(n+2)$. Therefore $n^2 + 2n$ is divisible by $n$. Hence, for $n^2 + 2n$ to be prime, $n$ can only have the value $1$.

When $n = 1$, we have $n^2 + 2n = 3$, which is prime.

Therefore there is just one positive integer value of $n$ for which $n^2 + 2n$ is prime.
