## 题目
The number $x$ is the solution to the equation $3^{(3^x)} = 333$.

Which of the following is true?

A $0 < x < 1$ $\qquad$ B $1 < x < 2$ $\qquad$ C $2 < x < 3$ $\qquad$ D $3 < x < 4$ $\qquad$ E $4 < x < 5$

## 备注

### 我的备注

### AI备注


## 答案
B

## 解析
The first few powers of $3$ are

$$3^1 = 3,\quad 3^2 = 9,\quad 3^3 = 27,\quad 3^4 = 81,\quad 3^5 = 243 \quad\text{and}\quad 3^6 = 729.$$

Because $3^{(3x)} = 333$, it follows that

$$3^5 < 3^{(3x)} < 3^6$$

and hence

$$5 < 3x < 6.$$

Therefore

$$3^1 < 3x < 3^2$$

and hence

$$1 < x < 2.$$
