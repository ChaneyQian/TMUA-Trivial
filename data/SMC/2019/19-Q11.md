## 题目
For how many integer values of $k$ is $\sqrt{200 - \sqrt{k}}$ also an integer?

A 11 $\qquad$ B 13 $\qquad$ C 15 $\qquad$ D 17 $\qquad$ E 20

## 备注

### 我的备注

### AI备注


## 答案
C

## 解析
The number $\sqrt{200 - \sqrt{k}}$ is an integer if, and only if, the number $200 - \sqrt{k}$ is a square.

Now $0 \le 200 - \sqrt{k} \le 200$. There are $15$ squares in this range, namely $n^2$ for integer values of $n$ with $0 \le n \le 14$.

We have that $200 - \sqrt{k} = n^2$, if, and only if $k = (200 - n^2)^2$.

Hence there are $15$ integer values of $k$ for which $\sqrt{200 - \sqrt{k}}$ is an integer, namely, $k = (200 - n^2)^2$ for $0 \le n \le 14$.
