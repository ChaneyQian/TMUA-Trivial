## 题目
Lucy is asked to choose $p$, $q$, $r$ and $s$ to be the numbers 1, 2, 3 and 4, in some order, so as to make the value of $\dfrac{p}{q} + \dfrac{r}{s}$ as small as possible.

What is the smallest value Lucy can achieve in this way?

A $\dfrac{7}{12}$ $\qquad$ B $\dfrac{2}{3}$ $\qquad$ C $\dfrac{3}{4}$ $\qquad$ D $\dfrac{5}{6}$ $\qquad$ E $\dfrac{11}{12}$

## 答案
D

## 解析
To make the value of $\dfrac{p}{q} + \dfrac{r}{s}$ as small as possible, $q$ and $s$ need to be as large as possible, and so have the values $3$ and $4$.

Therefore the expression with the smallest value that Lucy can achieve is either $\dfrac{1}{3} + \dfrac{2}{4}$ or $\dfrac{2}{3} + \dfrac{1}{4}$.

Now,

$$\begin{aligned}
\frac{1}{3} + \frac{2}{4} &= \frac{1}{3} + \frac{1}{4} + \frac{1}{4}\\
&< \frac{1}{3} + \frac{1}{3} + \frac{1}{4}\\
&= \frac{2}{3} + \frac{1}{4}.
\end{aligned}$$

It follows that the smallest value that Lucy can achieve is

$$\frac{1}{3} + \frac{2}{4} = \frac{4+6}{12} = \frac{10}{12} = \frac{5}{6}.$$
