## 题目
Olive Green wishes to colour all the circles in the diagram so that, for each circle, there is exactly one circle of the same colour joined to it.

![[Image/19-Q5-fig1.png|110]]

What is the smallest number of colours that Olive needs to complete this task?

A 1 $\qquad$ B 2 $\qquad$ C 3 $\qquad$ D 4 $\qquad$ E 5

## 答案
B

## 解析
If Olive uses just one colour, then each circle would be joined to three circles with the same colour as it. So one colour is not enough.

However, as the diagram shows, it is possible using just two colours to colour the circles so that each white circle is joined to just one white circle, and each black circle is joined to just one black circle.

![[Image/19-Q5-sol1.png|150]]

Therefore the smallest number of circles that Olive needs is two.
