## 题目
The letters $S, M$ and $C$ represent whole numbers. If $S \times M \times C = 240, S \times C + M = 46$ and $S + M \times C = 64$, what is the value of $S + M + C$?

A 19 $\qquad$ B 20 $\qquad$ C 21 $\qquad$ D 24 $\qquad$ E 36

## 答案
B

## 解析
Multiplying the equation $S + M \times C = 64$ by $S$ gives $S^2 + S \times M \times C = 64S$. Therefore $S^2 + 240 = 64S$, that is $(S - 60)(S - 4) = 0$. So $S = 60$ or $S = 4$. Multiplying the equation $S \times C + M = 46$ by $M$ gives $M \times S \times C + M^2 = 46M$. Therefore $240 + M^2 = 46M$, that is $(M - 40)(M - 6) = 0$. So $M = 40$ or $M = 6$. If $M = 40$ then $S \times C = 6$, so $C = 6/60$ or $6/4$, neither of which is a whole number. If $M = 6$ then $S \times C = 40$, so $C = 40/60$ or $40/4$. Hence the only whole number solutions of the equations are $S = 4$, $M = 6$, $C = 10$.
