## 题目
What is the value of $x$ in the equation $\dfrac{1 + 2x + 3x^2}{3 + 2x + x^2} = 3$?

A $-5$ $\qquad$ B $-4$ $\qquad$ C $-3$ $\qquad$ D $-2$ $\qquad$ E $-1$

## 答案
D

## 解析
We note first that $3 + 2x + x^2 = 2 + (1 + x)^2$. Therefore for all real numbers $x$, we have $3 + 2x + x^2 \ge 2$. Hence for all real numbers $x$, it follows that $3 + 2x + x^2 \ne 0$.

Therefore we can multiply both sides of the equation given in the question by $3 + 2x + x^2$. In this way, we have

$$\begin{aligned} \dfrac{1 + 2x + 3x^2}{3 + 2x + x^2} = 3 &\Longleftrightarrow 1 + 2x + 3x^2 = 3(3 + 2x + x^2) \\ &\Longleftrightarrow 1 + 2x + 3x^2 = 9 + 6x + 3x^2 \\ &\Longleftrightarrow 4x + 8 = 0 \\ &\Longleftrightarrow x = -2. \end{aligned}$$
