## 题目
Given an unlimited supply of 50p, £1 and £2 coins, in how many different ways is it possible to make a sum of £100?

A 1326 $\qquad$ B 2500 $\qquad$ C 2601 $\qquad$ D 5050 $\qquad$ E 10 000

### AI备注


## 答案
C

## 解析
To count the number of ways, it is necessary to have a structure. One strategy is to consider the number of £2 coins and then £1 coins; the balance can be made up with 50p coins.

| | | | | | |
| --- | --- | --- | --- | --- | --- |
| Number of £2 coins | 50 | 49 | 48 | … | 0 |
| Maximum number of £1 coins | 0 | 2 | 4 | … | 100 |
| Ways | 1 | 3 | 5 | … | 101 |

Total ways $= 1 + 3 + 5 + \ldots + 101 = \dfrac{1}{2} \times 51\,(1 + 101) = 51 \times 51 = 2601$.
