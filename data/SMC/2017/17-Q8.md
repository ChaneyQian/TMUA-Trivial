## 题目
When evaluated, which of the following is not an integer?

A $1^{-1}$ $\qquad$ B $4^{-\frac{1}{2}}$ $\qquad$ C $6^0$ $\qquad$ D $8^{\frac{2}{3}}$ $\qquad$ E $16^{\frac{3}{4}}$

## 备注

### 我的备注

### AI备注


## 答案
B

## 解析
We have

$$1^{-1} = \frac{1}{1} = 1,$$

$$4^{-\frac{1}{2}} = \frac{1}{4^{\frac{1}{2}}} = \frac{1}{\sqrt{4}} = \frac{1}{2},$$

$$6^0 = 1,$$

$$8^{\frac{2}{3}} = \left(8^{\frac{1}{3}}\right)^2 = \left(\sqrt[3]{8}\right)^2 = 2^2 = 4,$$

and

$$16^{\frac{3}{4}} = \left(16^{\frac{1}{4}}\right)^3 = \left(\sqrt[4]{16}\right)^3 = 2^3 = 8.$$

We therefore see that only the expression of option B gives a number which is not an integer when it is evaluated.
