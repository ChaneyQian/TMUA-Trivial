## 题目
How many solutions are there of the equation $1 + 2\sin X - 4\sin^2 X - 8\sin^3 X = 0$ with $0^\circ < X < 360^\circ$?

A 1 $\qquad$ B 2 $\qquad$ C 4 $\qquad$ D 6 $\qquad$ E 8

### 我的备注

### AI备注


## 答案
C

## 解析
For convenience we put $x = \sin X$.

We have

$$\begin{aligned} 1 + 2\sin X - 4\sin^2 X - 8\sin^3 X &= 1 + 2x - 4x^2 - 8x^3 \\ &= 1 + 2x - 4x^2(1 + 2x) \\ &= (1 + 2x)(1 - 4x^2) \\ &= (1 + 2x)(1 + 2x)(1 - 2x), \end{aligned}$$

It follows that

$$\begin{aligned} 1 + 2\sin X - 4\sin^2 X &- 8\sin^3 X = 0 \\ &\Longleftrightarrow (1 + 2x)(1 + 2x)(1 - 2x) = 0 \\ &\Longleftrightarrow x = -\tfrac{1}{2} \text{ or } x = \tfrac{1}{2} \\ &\Longleftrightarrow \sin X = -\tfrac{1}{2} \text{ or } \sin X = \tfrac{1}{2}. \end{aligned}$$

The solutions of the equation $\sin X = -\tfrac{1}{2}$ with $0^\circ < X < 360^\circ$ are $x = 210^\circ$ and $X = 330^\circ$. The solutions of $\sin X = \tfrac{1}{2}$ in the same interval are $X = 30^\circ$ and $X = 150^\circ$.

![[Image/23-Q18-sol1.png]]

Therefore the equation $1 + 2\sin X - 4\sin^2 X - 8\sin^3 X = 0$ has $4$ solutions with $0^\circ < X < 360^\circ$.
