## 题目
The expression $\dfrac{7n + 12}{2n + 3}$ takes integer values for certain integer values of $n$.

What is the sum of all such integer values of the expression?

A 4 $\qquad$ B 8 $\qquad$ C 10 $\qquad$ D 12 $\qquad$ E 14

## 答案
E

## 解析
We have

$$\dfrac{7n + 12}{2n + 3} = \dfrac{7}{2} + \dfrac{3}{2(2n + 3)} = \dfrac{1}{2}\left(7 + \dfrac{3}{2n + 3}\right).$$

It follows that $\dfrac{7n + 12}{2n + 3}$ is an integer provided that $7 + \dfrac{3}{2n + 3}$ is an even integer and hence provided that $\dfrac{3}{2n + 3}$ is an odd integer.

Now $\dfrac{3}{2n + 3}$ is an integer provided that $2n + 3$ is a factor of $3$.

Therefore the only possible values of $2n + 3$ are $-3$, $-1$, $1$ and $3$. In all these cases $\dfrac{3}{2n + 3}$ is a factor of $3$ and hence is odd.

When $2n + 3 = -3$, we have $n = -3$ and $\dfrac{7n + 12}{2n + 3} = \dfrac{1}{2}\left(7 + \dfrac{3}{2n + 3}\right) = \dfrac{1}{2}\left(7 + \dfrac{3}{-3}\right) = \dfrac{1}{2}(7 - 1) = 3$.

When $2n + 3 = -1$, we have $n = -2$ and $\dfrac{7n + 12}{2n + 3} = \dfrac{1}{2}\left(7 + \dfrac{3}{2n + 3}\right) = \dfrac{1}{2}\left(7 + \dfrac{3}{-1}\right) = \dfrac{1}{2}(7 - 3) = 2$.

When $2n + 3 = 1$, we have $n = -1$ and $\dfrac{7n + 12}{2n + 3} = \dfrac{1}{2}\left(7 + \dfrac{3}{2n + 3}\right) = \dfrac{1}{2}\left(7 + \dfrac{3}{1}\right) = \dfrac{1}{2}(7 + 3) = 5$.

When $2n + 3 = 3$, we have $n = 0$ and $\dfrac{7n + 12}{2n + 3} = \dfrac{1}{2}\left(7 + \dfrac{3}{2n + 3}\right) = \dfrac{1}{2}\left(7 + \dfrac{3}{3}\right) = \dfrac{1}{2}(7 + 1) = 4$.

We see that $n$ is an integer whenever $2n + 3$ is equal to either $-3$, $-1$, $1$ or $3$. Therefore the sum of the integer values of $\dfrac{7n + 12}{2n + 3}$ that correspond to integer values of $n$ is $3 + 2 + 5 + 4 = 14$.
