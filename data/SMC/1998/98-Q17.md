## 题目
$(x - 1)(x^4 + 1)(x^2 + 1)(x + 1)$ equals

A $x^8 - 1$  
B $x^8 + x^6 + x^4 + x^2 + 1$  
C $x^8 + 1$  
D $x^8 + x^7 + x^6 + x^5 + x^4 + x^3 + x^2 + x + 1$  
E $x^8 - x^6 + x^4 - 1$

## 备注

### 我的备注

### AI备注


## 答案
A

## 解析
Re-ordering

$$(x - 1)(x^4 + 1)(x^2 + 1)(x + 1) = (x - 1)(x + 1)(x^2 + 1)(x^4 + 1)$$

$$= (x^2 - 1)(x^2 + 1)(x^4 + 1) = (x^4 - 1)(x^4 + 1) = x^8 - 1$$

**Note**: $(x - 1)(x^4 + 1)(x^2 + 1)(x + 1)$ has value $0$ when $x = 1$. This enables B, C and D to be eliminated.
