## 题目
Note that $1647/8235 = 1/5$. Start with $1647/8235$. First delete one digit from the numerator and one digit from the denominator leaving a fraction $A/B$ which is equivalent to the fraction you started with. Then delete one digit from the new numerator $A$ and one digit from the new denominator $B$ leaving a fraction $C/D$ which is equivalent to $A/B$. What is the value of the difference $D - C$?

A 64 $\qquad$ B 68 $\qquad$ C 72 $\qquad$ D 76 $\qquad$ E 80

## 中文题干
注意 $1647/8235 = 1/5$。从 $1647/8235$ 开始，首先从分子中删去一个数字，并从分母中删去一个数字，得到一个与原分数相等的分数 $A/B$。然后从新分子 $A$ 中删去一个数字，从新分母 $B$ 中删去一个数字，得到一个与 $A/B$ 相等的分数 $C/D$。差 $D - C$ 的值是多少？

## 答案
B

## 解析
$\dfrac{1647}{8235} = \dfrac{1}{5}$ becomes $\dfrac{167}{835} = \dfrac{1}{5}$ which in turn becomes $\dfrac{17}{85} = \dfrac{1}{5}$. Hence $D = 85$ and $C = 17$ so $D - C = 68$.
