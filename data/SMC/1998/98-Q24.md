## 题目
If $x^2 - 3x + 1 = 0$, what is the value of $x^2 + (1/x)^2$?

A 7 $\qquad$ B $(7 - 3\sqrt{5})/2$ $\qquad$ C 9 $\qquad$ D $(7 + 3\sqrt{5})/2$ $\qquad$ E 10

## 备注

### 我的备注

### AI备注


## 答案
A

## 解析
This *could* be done by using the quadratic formula and manipulating surds. However, a neater way is

$$x^2 - 3x + 1 = 0 \Longrightarrow x - 3 + 1/x = 0 \Longrightarrow x + 1/x = 3.$$

Now, squaring both sides, $9 = (x + 1/x)^2 = x^2 + 2 + 1/x^2$. Hence $x^2 + 1/x^2 = 7$.
