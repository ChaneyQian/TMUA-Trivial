## 题目
Given that $y = \dfrac{x}{x + \dfrac{x}{x + y}}$, for which of the following values of $x$ is $y$ not a real number?

A $-6$ $\qquad$ B $-3$ $\qquad$ C 1 $\qquad$ D 3 $\qquad$ E 6

## 备注

### 我的备注

### AI备注


## 答案
B

## 解析
$$y = \dfrac{x}{x + \dfrac{x}{x + y}} = \dfrac{x(x + y)}{x(x + y) + x} = \dfrac{x + y}{x + y + 1} \qquad (x \ne 0,\ x + y \ne 0,\ x + y + 1 \ne 0)$$

i.e. $y(x + y + 1) = x + y$

i.e. $y^2 + xy - x = 0$

For $y$ to be real, this quadratic equation must have real roots so $x^2 + 4x \ge 0$, i.e. $x(x + 4) \ge 0$.

This condition is satisfied when $x \le -4$ or when $x \ge 0$.

However, $x \ne 0$ so $y$ is real when $x \le -4$ or when $x > 0$.
