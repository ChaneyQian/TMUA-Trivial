## 题目
Four positive integers $a$, $b$, $c$ and $d$ are such that

$$abcd + abc + bcd + cda + dab + ab + bc + cd + da + ac + bd + a + b + c + d = 2009.$$

What is the value of $a + b + c + d$?

A 73 $\qquad$ B 75 $\qquad$ C 77 $\qquad$ D 79 $\qquad$ E 81

### 我的备注

### AI备注


## 答案
A

## 解析
The left-hand side of the equation can be written as

$$(a + 1)(b + 1)(c + 1)(d + 1) - 1.$$

Hence

$$(a + 1)(b + 1)(c + 1)(d + 1) = 2010.$$

Now expressing $2010$ as a product of primes gives $2010 = 2 \times 3 \times 5 \times 67$ hence $a + b + c + d = 1 + 2 + 4 + 66 = 73$.
