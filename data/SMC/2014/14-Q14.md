## 题目
Given that $\dfrac{3x + y}{x - 3y} = -1$, what is the value of $\dfrac{x + 3y}{3x - y}$?

A $-1$ $\qquad$ B 2 $\qquad$ C 4 $\qquad$ D 5 $\qquad$ E 7

### AI备注


## 答案
E

## 解析
From $\dfrac{3x+y}{x-3y} = -1$, it follows that $3x + y = -(x - 3y)$, that is, $3x + y = -x + 3y$. Hence $4x = 2y$ and so $y = 2x$. Therefore

$$\frac{x+3y}{3x-y} = \frac{x+6x}{3x-2x} = \frac{7x}{x} = 7.$$

## For investigation
**14.1** It is, in fact, possible to evaluate $\dfrac{x+3y}{3x-y}$ directly from the given value for $\dfrac{3x+y}{x-3y}$ without the need to find $y$ in terms of $x$. However this involves rather more work!

(a) Show that

$$\frac{x+3y}{3x-y} = \frac{3\left(\dfrac{3x+y}{x-3y}\right) - 4}{4\left(\dfrac{3x+y}{x-3y}\right) + 3}.$$

(b) Use the result of part (a) to verify that $\dfrac{x+3y}{3x-y} = 7$.

**14.2**

(a) Find values for $a$, $b$, $c$ and $d$ so that

$$\frac{a\left(\dfrac{3x+y}{x-3y}\right) + b}{c\left(\dfrac{3x+y}{x-3y}\right) + d} = \frac{x+y}{x-y}.$$

(b) Use the result of part (a) to evaluate $\dfrac{x+y}{x-y}$, given that $\dfrac{3x+y}{x-3y} = 5$.
