## 题目
The diagram shows four sets of parallel lines, containing 2, 3, 4 and 5 lines respectively.

![[Image/14-Q8-fig1.png|250]]

How many points of intersection are there?

A 54 $\qquad$ B 63 $\qquad$ C 71 $\qquad$ D 95 $\qquad$ E 196

## 答案
C

## 解析
When a set of $p$ parallel lines intersects a set of $q$ parallel lines, each line of the first set meets each line of the second set and so there are $p \times q$ points of intersection. Here there are $4$ sets of parallel lines, and there are $6$ pairs of these sets that intersect each other. The total number of intersections is $2\times3+2\times4+2\times5+3\times4+3\times5+4\times5 = 6+8+10+12+15+20 = 71$.
