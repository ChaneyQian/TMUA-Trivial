## 题目
$P$, $Q$ and $R$ are the three angles of a triangle, when each has been rounded to the nearest degree.

Which of the following is the complete list of possible values of $P + Q + R$?

A $179^\circ$, $180^\circ$ or $181^\circ$  
B $180^\circ$, $181^\circ$ or $182^\circ$  
C $178^\circ$, $179^\circ$ or $180^\circ$  
D $180^\circ$  
E $178^\circ$, $179^\circ$, $180^\circ$, $181^\circ$ or $182^\circ$

## 答案
A

## 解析
We suppose that the actual angles of the triangle are $P'$, $Q'$ and $R'$, which are rounded to $P$, $Q$ and $R$, respectively.

The sum of the angles of a triangle is $180^\circ$ and therefore

$$P' + Q' + R' = 180^\circ.$$

When an angle is rounded up to the nearest degree, it is increased by at most $0.5^\circ$; when it is rounded down to the nearest degree, it is decreased by at most $0.5^\circ$. Therefore,

$$P' - 0.5^\circ \le P \le P' + 0.5^\circ,$$

$$Q' - 0.5^\circ \le Q \le Q' + 0.5^\circ,$$

and

$$R' - 0.5^\circ \le R \le R' + 0.5^\circ.$$

Adding these inequalities gives

$$P' + Q' + R' - 1.5^\circ \le P + Q + R \le P' + Q' + R' + 1.5^\circ.$$

Therefore, as $P' + Q' + R' = 180^\circ$,

$$178.5^\circ \le P + Q + R \le 181.5^\circ.$$

Each of $P$, $Q$ and $R$ is an integer number of degrees. Hence $P + Q + R$ is also an integer number of degrees. It follows that the only possible values of $P + Q + R$ are $179^\circ$, $180^\circ$ and $181^\circ$.

To complete the solution we show that each of these possible values actually occurs for some triangle. This is shown by the following examples.

$P' = 60.3^\circ$, $Q' = 60.3^\circ$, $R' = 59.4^\circ$ gives $P = 60^\circ$, $Q = 60^\circ$, $R = 59^\circ$. Hence $P + Q + R = 179^\circ$.

$P' = 60^\circ$, $Q' = 60^\circ$, $R' = 60^\circ$ gives $P = 60^\circ$, $Q = 60^\circ$, $R = 60^\circ$. Hence $P + Q + R = 180^\circ$.

$P' = 59.7^\circ$, $Q' = 59.7^\circ$, $R' = 60.6^\circ$ gives $P = 60^\circ$, $Q = 60^\circ$, $R = 61^\circ$. Hence $P + Q + R = 181^\circ$.

We deduce that $179^\circ$, $180^\circ$, $181^\circ$ is a complete list of the possible values of $P + Q + R$.
