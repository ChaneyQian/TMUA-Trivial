## 题目
The numbers $p$, $q$, $r$ and $s$ satisfy the following equations:

$$p + 2q + 3r + 4s = k \qquad 4p = 3q = 2r = s.$$

What is the smallest value of $k$ for which $p$, $q$, $r$ and $s$ are all positive integers?

A 20 $\qquad$ B 24 $\qquad$ C 25 $\qquad$ D 77 $\qquad$ E 154

## 答案
D

## 解析
From the set of equations $4p = 3q = 2r = s$, we have $q = \dfrac{4}{3}p$, $r = 2p$ and $s = 4p$.

We require $p$ and $q$ to be positive integers. Therefore, from the equation $q = \dfrac{4}{3}p$ we deduce that $p$ has to be an integer which is a multiple of $3$. We also note that if $p$ is a positive integer, then so also will be $r$ and $s$.

It also follows that

$$\begin{aligned}
k = p + 2q + 3r + 4s &= p + 2\left(\tfrac{4}{3}p\right) + 3(2p) + 4(4p) \\
&= p + \tfrac{8}{3}p + 6p + 16p = \tfrac{77}{3}p.
\end{aligned}$$

Because $p$ is a positive integer which is a multiple of $3$, its smallest value is $3$. Therefore the smallest value of $k$ is $\dfrac{77}{3} \times 3$, which equals $77$.
