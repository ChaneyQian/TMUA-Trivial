## 题目
The diagram represents the addition of three 3-digit numbers, which between them use all the digits from 1 to 9. Which of the following cannot be obtained as the answer to the addition?

![[Image/00-Q15-fig1.png]]

A 1500 $\qquad$ B 1503 $\qquad$ C 1512 $\qquad$ D 1521 $\qquad$ E 1539

## 答案
A

## 解析
Let the 3 three-digit numbers be $100a + 10b + c$; $100d + 10e + f$; $100g + 10h + i$ where $a$, $b$, $c$, $d$, $e$, $f$, $g$, $h$, $i$ represent the digits 1 to 9 in some order.

Then $a + b + c + d + e + f + g + h + i = 45$.

The sum of the three numbers is

$$\begin{aligned}
&100(a + d + g) + 10(b + e + h) + (c + f + i) \\
&= 99(a + d + g) + 9(b + e + h) + (a + d + g) + (b + e + h) + (c + f + i) \\
&= 99(a + d + g) + 9(b + e + h) + 45 = 9\left(11(a + d + g) + (b + e + h) + 5\right).
\end{aligned}$$

The sum must, therefore, be a multiple of 9 and 1500 is the only one of the options which is not a multiple of 9.

**Note**: a complete solution should check that the other four options are possible: $1503 = 216 + 538 + 749$; $1512 = 125 + 638 + 749$; $1521 = 124 + 638 + 759$; $1539 = 132 + 648 + 759$.
