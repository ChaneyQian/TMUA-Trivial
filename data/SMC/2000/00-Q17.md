## 题目
The following equation is true for all $a, b$ and $c$:
$$a^3 + b^3 + c^3 = (a + b + c)^3 - 3(a + b + c)(ab + bc + ca) + kabc$$
What is the value of $k$?

A $-6$ $\qquad$ B $-3$ $\qquad$ C 0 $\qquad$ D 3 $\qquad$ E 6

## 中文题干
以下等式对所有的 $a, b$ 和 $c$ 均成立：$a^3 + b^3 + c^3 = (a + b + c)^3 - 3(a + b + c)(ab + bc + ca) + kabc$。$k$ 的值是多少？

## 答案
D

## 解析
$$\begin{aligned}
(a + b + c)^3 &= a^3 + b^3 + c^3 + 3a^2b + 3ab^2 + 3b^2c + 3bc^2 + 3c^2a + 3ca^2 + 6abc \\
&= a^3 + b^3 + c^3 + 3(a + b + c)(ab + bc + ca) - 9abc + 6abc
\end{aligned}$$

Hence: $a^3 + b^3 + c^3 = (a + b + c)^3 - 3(a + b + c)(ab + bc + ca) + 3abc$.
