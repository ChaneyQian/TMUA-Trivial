## 题目
Given that $a$ and $b$ are integers greater than zero, which of the following equations could be true?

A $a - b = a \div b$  
B $a + b = a \div b$  
C $a - b = a \times b$  
D $a + b = a - b$  
E $\sqrt{a + b} = \sqrt{a} + \sqrt{b}$

## 中文题干
已知 $a$ 和 $b$ 是大于零的整数，下列哪一个等式可能成立？

## 答案
A

## 解析
B cannot be true since $a + b > a$ but $a \div b \le a$; C cannot be true since $a - b < a$ but $a \times b \ge a$; similarly, D cannot be true. Furthermore, E cannot be true since $\left(\sqrt{a} + \sqrt{b}\right)^2 \ne a + b$. However, A is true if $a = 4$ and $b = 2$.
