## 题目
What is the sum to infinity of the convergent series
$$\frac{1}{2} + \frac{1}{4} + \frac{2}{8} + \frac{3}{16} + \frac{5}{32} + \frac{8}{64} + \frac{13}{128} + \frac{21}{256} + \frac{34}{512} + \dots ?$$

A $7/4$ $\qquad$ B $2$ $\qquad$ C $\sqrt{5}$ $\qquad$ D $9/4$ $\qquad$ E $7/3$

## 答案
B

## 解析
$$S = \frac{1}{2} + \frac{1}{4} + \frac{2}{8} + \frac{3}{16} + \frac{5}{32} + \frac{8}{64} + \frac{13}{128} + \frac{21}{256} + \frac{34}{512} + \ldots$$

$$= \frac{1}{2} + \frac{1}{4} + \left(\frac{1}{8} + \frac{1}{8}\right) + \left(\frac{1}{16} + \frac{2}{16}\right) + \left(\frac{2}{32} + \frac{3}{32}\right) + \left(\frac{3}{64} + \frac{5}{64}\right) + \ldots$$

$$= \frac{1}{2} + \left(\frac{1}{8} + \frac{1}{16} + \frac{2}{32} + \frac{3}{64} + \ldots\right) + \left(\frac{1}{4} + \frac{1}{8} + \frac{2}{16} + \frac{3}{32} + \frac{5}{64} + \ldots\right)$$

$$= \frac{1}{2} + \frac{1}{4}\left(\frac{1}{2} + \frac{1}{4} + \frac{2}{8} + \frac{3}{16} + \ldots\right) + \frac{1}{2}\left(\frac{1}{2} + \frac{1}{4} + \frac{2}{8} + \frac{3}{16} + \frac{5}{32} + \ldots\right)$$

$$= \frac{1}{2} + \frac{1}{4}S + \frac{1}{2}S = \frac{1}{2} + \frac{3}{4}S$$

Therefore $\frac{1}{4}S = \frac{1}{2}$ and so $S = 2$.
