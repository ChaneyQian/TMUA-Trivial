## 题目
What is the sum of the digits of the largest 4-digit palindromic number which is divisible by 15? [Palindromic numbers read the same backwards and forwards, e.g. 7227.]

A 18 $\qquad$ B 20 $\qquad$ C 24 $\qquad$ D 30 $\qquad$ E 36

## 答案
C

## 解析
A 4-digit palindromic number has the form $\mathsf{deed}$ where $\mathsf{d}$ and $\mathsf{e}$ are digits. This number is divisible by 15 if and only if it is divisible by both 3 and 5. It will be divisible by 5 if and if only if $\mathsf{d}$ is 0 or 5, but the first digit of a number cannot be 0, so $\mathsf{d}$ is 5, and the number has the form $\mathsf{5ee5}$.

A number is divisible by 3 if and only if the sum of its digits is divisible by 3. So $\mathsf{5ee5}$ is divisible by 3 if and only if $10 + 2\mathsf{e}$ is divisible by 3, that is, when $\mathsf{e}$ is 7, 4 or 1. So the largest 4-digit palindromic number which is divisible by 15 is 5775. The sum of the digits of 5775 is $5 + 7 + 7 + 5 = 24$.
