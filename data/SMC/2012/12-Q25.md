## 题目
How many distinct pairs $(x, y)$ of real numbers satisfy the equation $(x + y)^2 = (x + 4)(y - 4)$?

A 0 $\qquad$ B 1 $\qquad$ C 2 $\qquad$ D 3 $\qquad$ E 4

## 答案
B

## 解析
**Method 1**

The most straightforward method is to rewrite the given equation as a quadratic in $x$, whose coefficients involve $y$, and then use the "$b^2 - 4ac \ge 0$" condition for a quadratic, $ax^2 + bx + c = 0$, to have real number solutions.

Now,
$$(x + y)^2 = (x + 4)(y - 4) \Longleftrightarrow x^2 + 2xy + y^2 = xy - 4x + 4y - 16$$
$$\Longleftrightarrow x^2 + xy + 4x + y^2 - 4y + 16 = 0 \Longleftrightarrow x^2 + (y + 4)x + (y^2 - 4y + 16) = 0.$$

So here $a = 1$, $b = y + 4$ and $c = y^2 - 4y + 16$. We see that $b^2 - 4ac = (y + 4)^2 - 4(y^2 - 4y + 16) = -3y^2 + 24y - 48 = -3(y^2 - 8y + 16) = -3(y - 4)^2$. So there is a real number solution for $x$ if and only if $-3(y - 4)^2 \ge 0$. Now, as for all real numbers $y$, $(y - 4)^2 \ge 0$, it follows that $-3(y - 4)^2 \ge 0 \Longleftrightarrow y - 4 = 0 \Longleftrightarrow y = 4$. When $y = 4$ the quadratic equation becomes $x^2 + 8x + 16 = 0$, that is $(x + 4)^2 = 0$, which has just the one solution $x = -4$. So $(-4,4)$ is the only pair of real numbers, $(x, y)$, for which $(x + y)^2 = (x + 4)(y - 4)$.

**Method 2**

We can simplify the algebra by making the substitution $w = x + 4$ and $z = y - 4$. Then $x + y = (w - 4) + (z + 4) = w + z$, and the equation becomes $(w + z)^2 = wz$.

Now, $(w + z)^2 = wz \Longleftrightarrow w^2 + 2wz + z^2 = wz \Longleftrightarrow w^2 + wz + z^2 = 0 \Longleftrightarrow (w + \tfrac{1}{2}z)^2 + (\tfrac{\sqrt{3}}{2}z)^2 = 0$. The sum of the squares of two real numbers is zero if and only if each real number is 0. So the only real number solution of $(w + \tfrac{1}{2}z)^2 + (\tfrac{\sqrt{3}}{2}z)^2 = 0$ is $w + \tfrac{1}{2}z = \tfrac{\sqrt{3}}{2}z = 0$. This is equivalent to $w = z = 0$ and hence to $x = -4$ and $y = 4$. So again we deduce that there is just this one solution.
