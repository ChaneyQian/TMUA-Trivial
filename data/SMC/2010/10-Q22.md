## 题目
If $x^2 - px - q = 0$, where $p$ and $q$ are positive integers, which of the following could *not* equal $x^3$?

A $4x + 3$ $\qquad$ B $8x + 5$ $\qquad$ C $8x + 7$ $\qquad$ D $10x + 3$ $\qquad$ E $26x + 5$

## 备注

### 我的备注

### AI备注


## 答案
B

## 解析
If $x^2 - px - q = 0$, then $x^2 = px + q$. Hence

$$x^3 = px^2 + qx = p(px + q) + qx = (p^2 + q)x + pq.$$

From the expressions given in the question, we see that we need to consider the cases $pq = 3$, $pq = 5$ and $pq = 7$.

Since $p$ and $q$ are positive integers, if $pq = 3$, then either $p = 1$ and $q = 3$, or $p = 3$ and $q = 1$. So $p^2 + q$ is either 4 or 10. So alternatives A and D could equal $x^3$. Similarly, if $pq = 5$, then either $p = 1$ and $q = 5$, or $p = 5$ and $q = 1$. So $p^2 + q$ is either 6 or 26. So alternative E could equal $x^3$, but B could not. Finally, if $pq = 7$, then either $p = 1$ and $q = 7$, or $p = 7$ and $q = 1$. So $p^2 + q$ is either 8 or 50. So alternative C could equal $x^3$.
