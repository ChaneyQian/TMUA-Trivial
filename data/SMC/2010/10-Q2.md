## 题目
What is the smallest possible value of $20p + 10q + r$ when $p, q$ and $r$ are *different* positive integers?

A 31 $\qquad$ B 43 $\qquad$ C 53 $\qquad$ D 63 $\qquad$ E 2010

## 答案
B

## 解析
It seems “obvious” that $p$, $q$ and $r$ should be as small as possible, and, as the coefficient of $p$ is larger than that of $q$, that we should take $p < q$, and, similarly, $q < r$. This suggests that the smallest value of $20p + 10q + r$, where $p$, $q$ and $r$ are different positive integers, is obtained by putting $p = 1$, $q = 2$, and $r = 3$, when we obtain the value $20 + 20 + 3 = 43$.

We can prove that this is the smallest possible value as follows. If $p \ne 1$, then $p \ge 2$, and hence, as $q > 0$, $20p + 10q + r \ge (20 \times 2) + (10 \times 1) = 50$. So the smallest possible value occurs when $p = 1$.

Now, if $q \ne 2$, $q \ge 3$, and so $20p + 10q + r \ge (20 \times 1) + (10 \times 3) = 50$. So the smallest possible value occurs when $p = 1$ and $q = 2$.

Finally, if $r \ne 3$, $r \ge 4$, and so $20p + 10q + r \ge (20 \times 1) + (10 \times 2) + 4 = 44$. So the smallest possible value is 43 and occurs when $p = 1$, $q = 2$ and $r = 3$.
