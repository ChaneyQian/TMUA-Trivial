## 题目
A function $f$ satisfies the equation $f(x) + f\left(\dfrac{1}{1 - x}\right) = 24x$ for all real values of $x$ except $x = 0$ and $x = 1$.

What is the value of $f(3)$?

A 40 $\qquad$ B 42 $\qquad$ C 45 $\qquad$ D 48 $\qquad$ E 50

## 答案
E

## 解析
> In a question of this type, it is not easy to see which path will lead to a solution.
>
> All we can do is to substitute values of $x$ in the equation $f(x) + f\left(\dfrac{1}{1 - x}\right) = 24x$.
>
> Since we are asked for the value of $f(3)$, we begin by putting $x = 3$. This brings in the value of $f(-\tfrac{1}{2})$, so we next put $x = -\tfrac{1}{2}$. Now $f(\tfrac{2}{3})$ appears. It looks as this might go on indefinitely, but when we put $x = \tfrac{2}{3}$ we have an "AHA" moment.

We put $x = 3$ in the equation

$$f(x) + f\left(\dfrac{1}{1 - x}\right) = 24x. \qquad (1)$$

given in the question.

This gives

$$f(3) + f(-\tfrac{1}{2}) = 72. \qquad (2)$$

Next, putting $x = -\tfrac{1}{2}$ in equation (1), we obtain

$$f(-\tfrac{1}{2}) + f(\tfrac{2}{3}) = -12. \qquad (3)$$

Now, putting $x = \tfrac{2}{3}$, we have

$$f(\tfrac{2}{3}) + f(3) = 16. \qquad (4)$$

By adding equations (2) and (4) we deduce that

$$2f(3) + f(-\tfrac{1}{2}) + f(\tfrac{2}{3}) = 88. \qquad (5)$$

Hence, from equation (3),

$$2f(3) - 12 = 88.$$

Therefore

$$2f(3) = 100.$$

We conclude that

$$f(3) = 50.$$
