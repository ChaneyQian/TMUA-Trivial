## 题目
Let $x$ and $y$ be positive integers such that $\dfrac{1}{x} + \dfrac{1}{y} = \dfrac{1}{20}$. What is the maximum possible value of $y$?

A 40 $\qquad$ B 60 $\qquad$ C 240 $\qquad$ D 420 $\qquad$ E 480

## 答案
D

## 解析
The maximum possible value of $y$ corresponds to the minimum possible value of $\dfrac{1}{y}$.

Since $\dfrac{1}{x} + \dfrac{1}{y} = \dfrac{1}{20}$, the minimum possible value of $\dfrac{1}{y}$ corresponds to the maximum possible value of $\dfrac{1}{x}$, and hence to the minimum possible value of $x$.

Now $\dfrac{1}{x} = \dfrac{1}{20} - \dfrac{1}{y} < \dfrac{1}{20}$ because $y > 0$. Therefore $x > 20$.

Since $x$ is a positive integer, it follows that the minimum possible value of $x$ is $21$.

When $x = 21$, we have $\dfrac{1}{y} = \dfrac{1}{20} - \dfrac{1}{21} = \dfrac{21 - 20}{20 \times 21} = \dfrac{1}{420}$ and hence $y = 420$.

Therefore the maximum possible value of $y$ is $420$.
