## 题目
As shown in the diagram, triangle $FGH$ is divided into four smaller triangles which have areas 4, 8, 12 and 8 respectively.

What is the area of triangle $IKH$?

## 解析
In this question we use the fact that if $M$ is a point on the side $QR$ of the triangle $PQR$, we have

$$\dfrac{\text{area } MPQ}{\text{area } MPR} = \dfrac{MQ}{MR}. \qquad (1)$$

[You are asked to prove this in Problem 22.1.]

![[Image/24-Q22-sol1.png]]

From the diagram in the question we have

$$\dfrac{\text{area } IGF}{\text{area } IGH} = \dfrac{12 + 8 + 4}{8} = \dfrac{24}{8} = 3. \qquad (2)$$

It follows from (1) and (2) that

$$\dfrac{IF}{IH} = 3. \qquad (3)$$

Therefore, by (1) and (3),

$$\dfrac{\text{area } IKF}{\text{area } IKH} = 3.$$

Hence

$$\text{area } IKH = \tfrac{1}{3}(\text{area } IKF) = \tfrac{1}{3}(4 + 8) = \tfrac{1}{3}(12) = 4.$$
