## 题目
It is given that $y = (\sqrt{3} + 2\sin 2x)\cos x$ for
$-\frac{\pi}{2} \le x \le \frac{\pi}{2}$.
The complete set of values for which $y$ is negative is

$$\mathbf{A} \quad -\frac{\pi}{2} < x < -\frac{\pi}{3}, 0 < x < \frac{\pi}{2}$$

$$\mathbf{B} \quad -\frac{\pi}{2} < x < -\frac{\pi}{3}, -\frac{\pi}{6} < x < \frac{\pi}{2}$$

$$\mathbf{C} \quad -\frac{\pi}{3} < x < -\frac{\pi}{6}$$

$$\mathbf{D} \quad \frac{\pi}{6} < x < \frac{\pi}{3}$$

$$\mathbf{E} \quad -\frac{\pi}{6} < x < 0, 0 < x < \frac{\pi}{2}$$

$$\mathbf{F} \quad -\frac{\pi}{3} < x < -\frac{\pi}{6}, \frac{\pi}{6} < x < \frac{\pi}{3}$$

## 答案
C

## 解析
On $-\frac{\pi}{2} < x < \frac{\pi}{2}$ we have $\cos x > 0$, and $\cos x = 0$ at the two endpoints, so on the open interval the sign of $y$ is the sign of $\sqrt{3} + 2\sin 2x$.
$$\sqrt{3} + 2\sin 2x < 0 \iff \sin 2x < -\frac{\sqrt{3}}{2}$$
Here $-\pi < 2x < \pi$, and on that range $\sin 2x < -\frac{\sqrt{3}}{2}$ exactly when $-\frac{2\pi}{3} < 2x < -\frac{\pi}{3}$, that is
$$-\frac{\pi}{3} < x < -\frac{\pi}{6}$$
The correct answer is (C).
Option F adds the mirror-image interval $\frac{\pi}{6} < x < \frac{\pi}{3}$; there $\sin 2x$ is positive, so $y > 0$.
