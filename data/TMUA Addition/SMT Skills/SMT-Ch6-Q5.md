## 题目
Find the complete set of values of $k$ for which the cubic equation $2x^3 - 3x^2 - 36x + k = 0$ has three distinct real solutions.

$$\mathbf{A} \quad x < 44$$

$$\mathbf{B} \quad x < 81$$

$$\mathbf{C} \quad -81 < x < 44$$

$$\mathbf{D} \quad -44 < x < 81$$

$$\mathbf{E} \quad x > 44$$

$$\mathbf{F} \quad x > 81$$

## 答案
D

## 解析
Consider the function $y = 2x^{3} - 3x^{2} - 36x$. Then $\frac{dy}{dx} = 6x^{2} - 6x - 36 \equiv 6\left( x^{2} - x - 6 \right) \equiv 6(x + 2)(x - 3) = 0$ precisely when $x = - 2$ or $x = 3$.
If $x = - 2$ then $y = - 16 - 12 + 72 = 44$.
If $x = 3$ then $y = 54 - 27 - 108 = - 81$. The two turning points are at $( - 2,\ 44)$ and $(3,\  - 81)$.
It follows that the equation $2x^{3} - 3x^{2} - 36x + k = 0 \Leftrightarrow 2x^{3} - 3x^{2} - 36x = - k$ has three distinct real solutions when $- 81 < - k < 44 \Leftrightarrow - 44 < k < 81$. The answer is D.
