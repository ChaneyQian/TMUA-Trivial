## 题目
The equation in $x$, $x^3 + 6x^2 - 63x + k = 0$ has three real solutions when

(a) $-108 < k < 392$
(b) $-392 < k < 108$
(c) $108 < k < 392$
(d) $-392 < k < 0$
(e) $0 < k < 108$

## 备注

### 我的备注

### AI备注

## 答案
B

## 解析
Same method: the equation is $h(x) = -k$ with $h(x) = x^{3} + 6x^{2} - 63x$.
$$h'(x) = 3x^{2} + 12x - 63 = 3(x + 7)(x - 3)$$
so $h$ has a local maximum $h(-7) = -343 + 294 + 441 = 392$ and a local minimum $h(3) = 27 + 54 - 189 = -108$.
A cubic with positive leading coefficient is met three times by the line $y = -k$ exactly when $-k$ lies between the two stationary values:
$$-108 < -k < 392 \quad\Longleftrightarrow\quad -392 < k < 108$$
The correct answer is (b).
At either endpoint the line passes through a turning point, so there is a repeated root and only two distinct solutions.
