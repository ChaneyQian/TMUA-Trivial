## 题目
The function $f(x)$ is defined for $x \in \mathbb{R}$ and satisfies the equation
$$ 2f(x) - 5f\left(\frac{4x + 5}{2x - 4}\right) = \frac{37 - 14x}{2} $$
$f(3)$ is equal to

(a) $10$
(b) $\frac{17}{2}$
(c) $5$
(d) $2$
(e) $1$

## 备注

### 我的备注

### AI备注

## 答案
A

## 解析
Let $x = 3$ so $2f(3) - 5f\left( \frac{17}{2} \right) = - \frac{5}{2}$ A

Another equation in $f(3)$ is required

For $\frac{4x + 5}{2x - 4} = 3,\ 4x + 5 = 6x - 12$ so $x = \frac{17}{2}$

Let $x = \frac{17}{2}$ so $2f\left( \frac{17}{2} \right) - 5f(3) = - 41$ B

B $\times - 5$: $25f(3) - 10f\left( \frac{17}{2} \right) = 205$

A $\times 2$: $4f(3) - 10f\left( \frac{17}{2} \right) = - 5$

Subtracting: $21f(3) = 210$

So $f(3) = 10$

The correct answer is (a)
