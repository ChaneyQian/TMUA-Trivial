## 题目
The reflection of the point $(a, a)$ in the line $y = \frac{1}{a}x$ where $a \neq 0$ is

(a) $\left( \frac{a(a - 1)^2}{a^2 + 1}, \frac{a^2(a^2 + 3)}{a^2 + 1} \right)$
(b) $\left( \frac{a(a^2 + 2a - 1)}{a^2 + 1}, \frac{-a(a^2 - 2a - 1)}{a^2 + 1} \right)$
(c) $\left( \frac{a(a - 1)^2}{a^2 + 1}, \frac{-a(a - 1)^2}{a^2 + 1} \right)$
(d) $\left( \frac{a(a + 1)^2}{a^2 + 1}, \frac{a^2(a + 1)^2}{a^2 + 1} \right)$
(e) $\left( \frac{a(a - 1)^2}{a^2 + 1}, \frac{a^2(a + 1)^2}{a^2 + 1} \right)$

## 答案
B

## 解析
When $a = 1$ you need the image of the point $(1,1)$ when reflected in the line $y = x$ (which is $(1,1)$). Only option (b) gives this point so the rest can be eliminated. The correct answer is (b).
