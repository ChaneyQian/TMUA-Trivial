## 题目
Which is the least of the following numbers?

(a) $(5\cos 330^\circ)^2$
(b) $\left(\log_5 (125^{3/2})\right)^2$
(c) $(\sqrt{3})^5$
(d) $\log_3 \left((\log_3 (9^3))^9\right)$
(e) $(\sqrt{2})^8$

## 答案
D

## 解析
For (a) $\cos{330{^\circ}} = \cos{30{^\circ}} = \frac{\sqrt{3}}{2}$ so $\left( 5\cos{330{^\circ}} \right)^{2} = \left( \frac{5\sqrt{3}}{2} \right)^{2} = \frac{75}{4} = 18\frac{3}{4}$

For (b) $\left( \log_{5}125^{\frac{5}{2}} \right)^{2} = \left( \log_{5}5^{\frac{9}{2}} \right)^{2} = \left( \frac{9}{2} \right)^{2} = \frac{81}{4} = 20\frac{1}{4}$

So (a) is less than (b)

For (c) $\left( \sqrt{3} \right)^{5} = 9\sqrt{3}$. As $1 < \sqrt{3} < 2$, $9 < 9\sqrt{3} < 18$ both are lower than (a)

For (d) ${\log_{3}\left( \log_{3}\left( 9^{3} \right) \right)}^{9} = 9\log_{3}\left( \log_{3}3^{6} \right) = 9\log_{3}6 = 9\left( \log_{3}3 + \log_{3}2 \right) = 9 + 9\log_{3}2$

$= 9 + \log_{3}2^{9} = 9 + \log_{3}512$. As $5 < \log_{3}512 < 6$ ($3^{5} = 243$ and $3^{6} = 729$) this gives

$14 < 9 + \log_{3}512 < 15$ this is lower than (a)

For (e) $\left( \sqrt{2} \right)^{8} = 16$ this is greater than (d)

To compare (c) and (d) some more precision can be used for (c)

Since $17^{2} = 289,\ {1.7}^{2} = 2.89$ so $9\sqrt{3} > 9 \times 1.7 = 15.3$ this is greater than (d).

The **least** value is (d).
