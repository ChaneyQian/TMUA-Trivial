## 题目
The inequality
$$ (x^2 + 1)^2 < 29 - x^2 $$
is satisfied precisely when

(a) $0 < x < 2$
(b) $-2 < x < 2$
(c) $-2 < x < 0$
(d) $-4 < x < 4$
(e) $-4 < x < 0$

## 备注

### 我的备注

### AI备注

## 答案
B

## 解析
Expanding, simplifying and attempting to factorise:
$\left( x^{2} + 1 \right)^{2} < 29 - x^{2} \Leftrightarrow x^{4} + 2x^{2} + 1 < 29 - x^{2} \Leftrightarrow x^{4} + 3x^{2} - 28 < 0 \Leftrightarrow \left( x^{2} + 7 \right)\left( x^{2} - 4 \right) < 0$.
Since $x^{2} + 7 \geq 7$ is positive for all values of $x$, it follows that $x^{2} - 4 = (x - 2)(x + 2) < 0 \Leftrightarrow - 2 < x < 2$. The answer is (b).
