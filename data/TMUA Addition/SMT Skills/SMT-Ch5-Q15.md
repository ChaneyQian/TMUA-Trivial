## 题目
Which is the largest of the following numbers?

(a) $\frac{\log_3 80}{\log_5 127}$
(b) $\frac{6\sqrt{5}!}{4!\sqrt{5}}$
(c) $\frac{2\sqrt{2}}{3\sqrt{\log_{10} \pi}}$
(d) $\frac{\log_2 257}{\log_3 25}$
(e) $\frac{2 + \sqrt{5}}{3}$

## 答案
D

## 解析
A mixture of approximation and calculation can be used for this question

$\log_{3}80 \approx \log_{3}81 = 4$ and $\log_{5}127 \approx \log_{5}125 = 5$

So (a) $\frac{\log_{3}80}{\log_{5}127} \approx \frac{4}{5}$

For (b) $\frac{6}{4!}\sqrt{\frac{5!}{5}} = \frac{6}{24}\sqrt{4!} = \frac{2\sqrt{6}}{4} = \frac{\sqrt{6}}{2}$

As $2 < \sqrt{6} < 3$, $1 < \frac{\sqrt{6}}{2} < \frac{3}{2}$

Since $\frac{\sqrt{6}}{2} > 1$ (b) is greater than (a)

For (c) using $\pi \approx \sqrt{10}$ gives $\frac{2\sqrt{2}}{3\sqrt{\log_{10}\pi}} \approx \frac{2\sqrt{2}}{3\sqrt{\frac{1}{2}}} = \frac{2\sqrt{2}\sqrt{2}}{3} = \frac{4}{3}$

This shows that (c) is greater than (a)

For (d) $\frac{\log_{2}257}{\log_{3}25} \approx \frac{\log_{2}256}{\log_{3}27} = \frac{8}{3}$

$\frac{8}{3} > 2$ so (d) is greater than (a), (b) and (c)

For (e) as $2 < \sqrt{5} < 3$, $\frac{4}{3} < \frac{2 + \sqrt{5}}{3} < \frac{5}{3}$ so $\frac{2 + \sqrt{5}}{3} < 2$

The correct answer is (d)
