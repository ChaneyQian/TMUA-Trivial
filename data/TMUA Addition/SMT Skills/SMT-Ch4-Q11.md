## 题目
The circle $x^2 + y^2 + 2ax + 2by = c$ encloses the point $(1, 1)$ precisely when

(a) $c > 2(1 - a - b)$
(b) $a^2 + b^2 < 1$
(c) $c > 2(a + b + 1)$
(d) $a^2 + 2ab + b^2 < c$
(e) $a + b > 1 - c$

## 备注

### 我的备注

### AI备注

## 答案
A

## 解析
$x^{2} + y^{2} + 2ax + 2by = c \Longrightarrow (x + a)^{2} + (y + b)^{2} = c + a^{2} + b^{2}.$ The point $(1,1)$ to lies within the circle if and only if $c + a^{2} + b^{2} > (a - 1)^{2} + (b - 1)^{2}$. Rearranging gives $c > 2(1 - a - b)$. The correct answer is (a).
