## 题目
The diagram shows the ellipse $4x^2 + y^2 - 24x = 32$.

![[Image/SMT-Ch6-Q8-fig1.png]]

The point $P$ moves on the ellipse. What is the greatest possible distance of $P$ from the origin?

(a) $2\sqrt{5}$
(b) $3\sqrt{5}$
(c) $4\sqrt{5}$
(d) $5\sqrt{5}$
(e) $6\sqrt{5}$

## 备注

## 答案
C

## 解析
The distance of any point, $(x,\ y)$, from the origin is $\sqrt{x^{2} + y^{2}}$, and this is greatest when $x^{2} + y^{2}$ is greatest. If the point also lies on the above ellipse then $4x^{2} + y^{2} - 24x = 32 \Leftrightarrow x^{2} + y^{2} = - 3x^{2} + 24x + 32 = - 3(x - 4)^{2} + 80$. This is greatest when $x = 4$, giving $x^{2} + y^{2} = 80$, so the greatest distance from the origin is $\sqrt{80} = 4\sqrt{5}$. The answer is c).
