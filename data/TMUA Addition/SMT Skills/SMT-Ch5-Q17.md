## 题目
Let $n$ be an integer such that $n > 1$. Let $P(n)$ denote the greatest prime factor of $n$ and $d(n)$ denote the final digit of $n$. For example $P(35) = 7$ and $d(72) = 2$. Which of the following statements is true?

(a) If $P(n) = 7$, $d(n)$ cannot be $3$.
(b) If $P(n) = 13$, $d(n)$ cannot be prime.
(c) If $P(n) = 3$, $d(n^2)$ cannot be $9$.
(d) If $P(n) = 7$, $d(n^2)$ cannot be $3$.
(e) If $P(n) = 13$, $d(n^2)$ cannot be $9$.

## 答案
D

## 解析
This can be done by considering simple counter examples

For (a) $P(63) = P\left( 7 \times 3^{2} \right) = 7$ and $d(63) = 3$ this is not true

For (b) $P(13) = 13$ and $d(13) = 3$ this is not true

For (c) $P(3) = 3$ and $d\left( 3^{2} \right) = 9$ this is not true

For (d) $P(n) = 7$ and $d\left( n^{2} \right) \neq 3$ this is true as no square number ends in $3$

For (e) $P(13) = 13$ and $d\left( 13^{2} \right) = 9$ this is not true

The correct answer is (d)
